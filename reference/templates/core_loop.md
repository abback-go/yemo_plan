# 부록 C. 핵심 플레이 루프 작성 템플릿

출처: reference/textbook.pdf 부록 C

핵심 플레이 루프는 플레이어가 게임에서 가장 자주 반복하는 행동 흐름을 정리한 문서입니다. 게임의 재미는 대부분 이 반복 구조 안에서 만들어집니다. 플레이어가 무엇을 하고, 어떤 결과를 얻고, 다시 무엇을 하게 되는지 명확해야 필요한 시스템과 UI, 데이터 구조를 정리할 수 있습니다. 이 템플릿은 게임의 반복 흐름을 구현 가능한 형태로 정리하기 위한 기본 양식입니다.

## 2. 핵심 플레이 루프 한 문장 요약

플레이어가 반복하는 흐름을 한 문장으로 작성합니다.

작성 예시:

플레이어는 로비에서 스테이지에 입장하고, 적을 처치해 보상을 얻은 뒤, 캐릭터를 성장시켜 다음 스테이지에 도전합니다.

작성 기준:

- 플레이어의 시작 지점이 보이는가?
- 반복 행동이 명확한가?
- 보상과 성장 요소가 포함되어 있는가?
- 다음 행동으로 이어지는 구조가 있는가?

## 3. 기본 루프 구조

게임의 반복 흐름을 단계별로 작성합니다.

기본 형식:

준비 → 도전 → 행동 → 결과 → 보상 → 성장 → 재도전

실습 프로젝트 예시:

로비에서 준비한다 → 스테이지에 입장한다 → 적을 처치한다 → 스테이지를 클리어한다 → 경험치와 골드를 얻는다 → 캐릭터를 성장시킨다 → 다음 스테이지에 도전한다

상세 설명:

플레이어는 로비에서 캐릭터 상태와 보유 골드를 확인합니다. 이후 스테이지를 선택해 전투에 입장하고, 적을 처치해 경험치와 골드를 획득합니다. 스테이지를 클리어하면 보상 화면을 확인하고 로비로 돌아옵니다. 로비에서는 상점이나 인벤토리를 이용한 뒤 다음 스테이지에 다시 도전합니다.

## 4. 루프 단계별 정리

각 단계가 어떤 역할을 하는지 작성합니다.

| 단계 | 플레이어 행동 | 시스템 반응 | 결과 |
| --- | --- | --- | --- |
| 준비 | 로비에서 상태 확인 | 캐릭터 정보와 골드 표시 | 스테이지 도전 준비 |
| 도전 | 스테이지 선택 | StageData 로드 | 전투 시작 |
| 행동 | 이동과 공격 | 적 AI, 데미지 계산 | 적 체력 감소 |
| 결과 | 모든 적 처치 | 클리어 판정 | 결과 화면 표시 |
| 보상 | 보상 확인 | 경험치, 골드, 아이템 지급 | 데이터 갱신 |
| 성장 | 상점/인벤토리 사용 | 아이템 구매, 포션 사용 | 다음 도전 준비 |
| 재도전 | 다음 스테이지 선택 | 난이도 상승 | 루프 반복 |

이 표는 기획 내용을 시스템 단위로 분해하는 데 도움이 됩니다. 각 단계가 어떤 코드와 연결되는지 함께 생각하면 이후 구현 요청 프롬프트로 변환하기 쉽습니다.

## 11. MVP 기준 루프

가장 작은 플레이 가능 버전의 루프를 작성합니다.

MVP 루프 예시:

로비 화면 표시 → 스테이지 시작 버튼 클릭 → 적 3마리 스폰 → 플레이어가 적 처치 → 모든 적 사망 시 클리어 → 경험치와 골드 지급 → 결과 화면 표시 → 로비 복귀

MVP에서 제외할 기능:

- 복잡한 스킬 시스템
- 장비 강화
- 퀘스트 분기
- 멀티플레이
- 보스 패턴
- 온라인 랭킹
- 유료 결제

MVP 루프는 게임의 핵심이 실제로 동작하는지 확인하기 위한 최소 단위입니다. 이 흐름이 완성되면 이후 기능을 확장할 수 있습니다.

## 12. AI 구현 요청용 루프 요약

AI에게 전달할 수 있는 형태로 핵심 플레이 루프를 정리합니다.

예시:

Unity 6 C#으로 스테이지형 액션 RPG의 핵심 플레이 루프를 구현해줘. 플레이어는 로비 화면에서 스테이지 시작 버튼을 누르고, StageData를 기준으로 전투 스테이지에 입장한다. 스테이지가 시작되면 EnemyData에 따라 적을 스폰하고, 플레이어가 모든 적을 처치하면 클리어 처리한다. 클리어 시 RewardData를 기준으로 경험치와 골드를 지급하고 결과 화면을 표시한다. 결과 화면에서 확인 버튼을 누르면 로비로 돌아간다. 플레이어가 Dead 상태가 되면 실패 처리하고 클리어 보상은 지급하지 않는다.

## 13. 검토 체크리스트

- 플레이어가 반복하는 행동이 명확한가?
- 루프의 시작과 끝이 분명한가?
- 보상과 성장 요소가 연결되어 있는가?
- 다음 도전으로 이어지는 이유가 있는가?
- 각 단계가 필요한 시스템과 연결되어 있는가?
- 필요한 UI 화면이 정리되어 있는가?
- 필요한 데이터 테이블이 정리되어 있는가?
- 실패 조건과 재도전 흐름이 있는가?
- 예외 조건이 작성되어 있는가?
- MVP 기준 루프가 너무 크지 않은가?
- AI 구현 요청 프롬프트로 변환할 수 있는가?

핵심 플레이 루프는 게임의 중심 구조입니다. 루프가 명확하면 어떤 시스템을 먼저 만들어야 하는지 판단하기 쉽고, 루프가 모호하면 기능을 많이 만들어도 게임이 완성되지 않은 느낌을 줄 수 있습니다. 좋은 핵심 플레이 루프 문서는 플레이어의 반복 행동과 보상, 성장, 재도전 흐름을 하나의 개발 기준으로 연결하는 문서입니다.
