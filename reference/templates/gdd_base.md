## 12. AI 구현 요청 프롬프트

기본 구조:

환경 → 목적 → 기존 구조 → 구현 기능 → 데이터 구조 → 처리 흐름 → 예외 조건 → 출력 형식

예시:

Unity 6 C# 프로젝트에서 사용할 상점 구매 시스템을 구현해줘. 아이템 데이터는 ShopItemData를 사용하고, 플레이어 골드는 PlayerCurrencyManager가 관리한다. 구매 버튼을 누르면 상품 가격과 보유 골드를 비교한다. 골드가 충분하고 인벤토리에 공간이 있으면 골드를 차감하고 아이템을 InventoryManager에 추가한다. 골드가 부족하거나 인벤토리가 가득 찬 경우에는 false를 반환하고 어떤 데이터도 변경하지 않는다. 기존 클래스 이름과 public 메서드 시그니처는 변경하지 말아줘.

예시:

2026-06-21: 인벤토리가 가득 찬 경우 아이템 보상은 지급 실패 처리하고, 골드와 경험치는 정상 지급하도록 보상 예외 조건을 수정했습니다. RewardManager와 RewardData 문서를 함께 수정해야 합니다.

이 템플릿은 프로젝트의 모든 내용을 한 번에 완성하기 위한 양식이 아닙니다. 처음에는 게임 개요, 핵심 플레이 루프, 주요 시스템 목록만 작성해도 충분합니다. 이후 구현과 테스트를 반복하면서 조작, 전투, 보상, UI, 데이터, 예외 조건을 계속 보완하면 됩니다. 좋은 게임 상세 기획서는 고정된 문서가 아니라, 프로젝트와 함께 점점 정확해지는 개발 기준 문서입니다.
