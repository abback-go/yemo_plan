# 00. 게임 콘셉트

이 문서는 게임의 방향을 정의하는 기준 문서다. 이후 작성하는 모든 상세 기획서(01~09)는 이 문서의 콘셉트, 핵심 재미, 범위 정의를 기준으로 삼는다.

> **개정 안내**: 이 문서는 "폐급 불 마녀 + 여우신" 콘셉트로 전면 개정한 판이다. 01_핵심 플레이 루프, 02_플레이어 조작, 03_전투 시스템, 04_능력 게이트는 아직 구 콘셉트 기준이며 개정 예정이다. 개정 전까지 두 문서가 충돌하면 이 문서를 따른다. 구 용어의 대응은 3-1절 끝의 "폐기된 용어" 표를 기준으로 한다.

## 2. 한 문장 콘셉트

이 게임은 어린 시절 여우신의 불을 몸에 흡수한 뒤 그 불을 전혀 다루지 못해 폐급 취급을 받는 마녀가, 곁을 따르는 여우신과 함께 마녀학교를 거점으로 주변 땅을 모험하며, 학교에서 배운 불 마법과 여우의 힘으로 이전에 지나갈 수 없던 길을 열어 세계를 넓혀 가는 2D 메트로배니아다.

이 콘셉트가 가리키는 재미의 원인은 하나다. 이미 한 번 지나가며 본 적 있는 막힌 길이, 새 능력을 얻은 뒤 통과 가능한 길로 바뀌는 순간이다.

이 문장은 기능 추가 판단의 기준이다. 추가하려는 기능이 "능력 해금 → 막힌 길 개방 → 맵 확장"의 반복을 강화하지 않으면 우선순위를 뒤로 미룬다.

## 3. 핵심 플레이 경험

- 플레이어가 가장 자주 하는 행동: 챕터의 모험 지역을 이동하며 미탐험 구간을 탐색한다. 진로를 막는 적을 빗자루 기본공격과 불 마법으로 처치한다. 통과할 수 없는 지형을 확인하고 기억한다. 마녀학교로 돌아가 수업을 듣고 새 불 마법을 배운다.
- 플레이어가 달성해야 하는 목표: 개인 목표는 불을 제어해 마녀로 인정받는 것이다. 공동 목표는 여우신과 함께 불과 그날 사건의 진실을 밝히는 것이다. 불을 여우신에게 돌려줄지 등 결말은 미정이다. (05·08의 스토리 설정에서 결정)
- 플레이어가 얻는 보상: 새로 배우는 불 마법, 스킬 레벨업에 쓰는 자원, 여우 의태와 이동 능력, 결합 스킬, 특성, 열린 지도 영역, 마녀학교와 모험 지역에서 이어지는 스토리. 특성의 획득 경로는 미정이다. (04·06)
- 플레이어가 느껴야 할 감정: 막혀 있던 길이 열릴 때의 해결감. 맵 구조가 머릿속에서 하나로 연결될 때의 파악감. 배운 것이 곧 갈 수 있는 곳으로 바뀌는 성장감. 폭주 게이지를 쌓았다가 결합 스킬로 터뜨릴 때, 강한 한 방을 쏘고 쓰러지는 캐릭터성을 직접 조작하는 감각.
- 게임을 반복하게 만드는 이유: 새 능력을 얻을 때마다 이전에 지나친 막힌 길들이 다시 갈 수 있는 목적지 목록으로 바뀐다. 이전 챕터 지역의 막힌 곳도 이 목록에 포함된다.

### 3-1. 용어 정의

| 용어 | 정의 |
|---|---|
| 주인공 (폐급 마녀) | 불 속성 마녀. 어린 시절 모종의 사건으로 여우신의 불을 몸에 흡수했다. 그 뒤 그 불을 전혀 제어하지 못해 마녀학교에서 폐급 취급을 받아 왔다. 폐급인 이유는 힘이 약해서가 아니라 넘치는 힘을 제어하지 못해서다. 사건의 내용과 주인공 이름은 미정 (05·08) |
| 여우신 | 불을 잃고 오랜 세월 약해진 채 불의 행방을 찾아 떠돌던 신. 우연히 주인공을 찾아온다. 자신의 힘이 주인공 몸속에 있으므로 주인공과 떨어질 수 없다. 정령 또는 펫 형태로 주인공 곁을 따라다닌다. 최종 형태와 고유 이름은 미정 (05·08) |
| 마녀학교 | 여러 계열의 마법을 가르치는 학교. 세계의 중심 거점이다. 주인공은 여기서 수업을 듣고 마법을 배운다 |
| 모험 지역 | 마녀학교 주변으로 펼쳐진 탐험 공간. 강력한 마녀 도시별 또는 콘셉트별로 나눈다. 구체 지역은 미정 (05·08) |
| 챕터 | 메인 스토리의 진행 단위. 순서는 고정이다. 챕터마다 탐험할 모험 지역이 있다 |
| 불 마법 | 주인공이 수업으로 배우는 불 계열 마법. 약 7개다. 배운 마법은 전부 사용할 수 있다 (장착 슬롯 없음). 등급은 초급·고급이다. 목록은 04_능력 게이트 개정 시 정의 |
| 공통 마법 | 계열과 관계없이 모든 마녀가 배울 수 있는 마법. "기초"가 아니라 "공통"이라는 뜻이며 후반 해금도 가능하다. 비행이 여기에 속한다. 나머지 종류와 습득 경로는 미정 (04) |
| 결합 스킬 | 여우신과 힘을 합쳐 쓰는 최상위 스킬. 불 마법과 별개다. 불의 원래 주인인 여우신이 이끌 때 불이 제대로 다뤄진다는 설정이 명분이다. 폭주 게이지를 소모해 발동한다. 개수와 습득 조건은 미정 (04). 이 용어는 최상위 전투 스킬에만 쓴다 |
| 여우 의태 | 여우의 몸 일부를 의태해 쓰는 능력. 불을 섞지 않고 단독으로 사용한다. 예: 발 의태 = 질주, 발톱 의태 = 벽 붙기 |
| 불을 쓰는 이동기 | 여우 의태와 불을 함께 쓰는 이동 능력. 체공(꼬리 의태 + 상승하는 불기운)과 폭발 대시(가칭. 발 의태 + 불꽃 폭발)가 있다. 결합 스킬이 아니다. 분류 명칭과 폭주 게이지와의 관계는 미정 (04) |
| 폭주 게이지 | 이 게임의 유일한 마법 게이지. 인간의 몸에 담긴 신의 불이 넘쳐흐르는 정도를 나타낸다. 불 마법을 쓰면 쌓이고, 결합 스킬로 소모하며, 한계를 넘으면 폭주한다. 4-3절 참조 |
| 폭주 | 폭주 게이지가 한계를 넘었을 때 일어나는 현상. 강제 폭발이 먼저 일어나고, 그다음 탈진한다 |
| 탈진 | 폭주의 강제 폭발 뒤에 오는 상태. 지속 시간과 탈진 중 가능한 행동은 미정 (04·09) |
| 특성 | 슬롯에 장착하는 패시브 효과. 마법이 아니다. 종류, 슬롯 수, 획득 경로는 미정 (04·06) |
| 빗자루 | 주인공의 기본공격 수단. 평소에는 다른 무기의 모습을 하고 있다. 무기 형태는 미정 (후보: 낫, 우산). 위장 이유와 본모습이 드러나는 조건은 미정 (후보: 비행 해금 시점). 셋 모두 05·08에서 결정. 형태가 바뀌어도 기본공격 성능은 같다 (외형만 변화) |
| 여우 사당 (가칭) | 체크포인트 거점. 저장, HP 완전 회복, 횟수 제한형 회복 수단 충전이 이뤄진다. 폭주 게이지 처리는 미정 (04·09) |
| 자원 | 불 마법의 스킬 레벨업에 쓰는 소모성 가치. 이름과 종류는 미정 (06) |
| 스킬 레벨 | 자원으로 올리는 마법별 레벨. 성능과 불의 쓰임새 게이트 단계에 연결된다 |
| 능력 게이트 | 통과에 특정 능력이 필요한 지형·오브젝트. 불의 쓰임새 게이트, 폭주 폭발 게이트, 이동 게이트의 세 갈래다 (4-1절) |
| 조우 | 탐험 중 적과 만나 성립하는 전투 단위 (03_전투 시스템 개정 시 정의) |

용어 사용 규칙:

- 폭주 게이지를 "과열", "열"로 바꿔 부르지 않는다.
- "결합 스킬"은 최상위 전투 스킬에만 쓴다. 체공·폭발 대시를 결합 스킬이라 부르지 않는다.
- "여우 의태"는 불을 섞지 않는 단독 능력에만 쓴다.

### 3-2. 세계와 공간 구조

**주인공과 여우신의 관계**

주인공은 여우신의 불을 몸에 품고 있지만 다루지 못한다. 여우신은 불을 잃어 약해졌다. 불의 원래 주인인 여우신이 이끌 때 불이 제대로 다뤄진다. 이 관계가 결합 스킬의 명분이다. 여우신은 정령 또는 펫 형태로 주인공 곁을 따라다닌다. (최종 형태 미정, 11절)

**마녀 사회와 힘의 구조**

마녀학교에는 여러 계열의 마법이 있고, 마녀 사회가 존재한다. 마녀 외의 강자들도 존재한다. (세부 미정, 05·08)
주인공은 공통 마법을 제외하면 불 계열만 배울 수 있다.

**공간 구조**

마녀학교가 세계의 중심 거점이다. 모험 지역은 학교 주변으로 펼쳐진다.

| 공간 | 역할 | 플레이어가 하는 일 |
|---|---|---|
| 마녀학교 | 거점, 배움의 공간 | 수업을 듣고, 불 마법을 배우고, 스킬 레벨을 올린다. 학교 인물들과의 스토리를 본다 |
| 모험 지역 | 탐험의 공간 | 챕터의 메인 사건을 따라 맵을 탐험하고, 스토리를 보고, 막힌 길을 연다 |

**진행 구조: 큰 틀은 선형, 작은 틀은 자유**

- 챕터 순서는 고정이다. 메인 스토리는 선형으로 진행한다.
- 챕터 안에서는 탐험 순서, 선택 구역, 숨은 구역을 자유롭게 공략한다.
- 새 챕터에서 얻은 능력으로 이전 챕터 지역의 막힌 곳을 열 수 있다. 이것이 역주행의 이유다.
- 챕터 수, 챕터별 지역, 챕터 완료 조건은 미정 (05·08).

**톤 규칙**

톤은 챕터 단위로 가벼운 챕터와 무거운 챕터로 구분한다. 기준은 다음과 같다.

| 톤 | 해당 내용 |
|---|---|
| 가벼움 | 마녀학교 일상, 수업, 여우신과의 만담 |
| 진지함 | 메인 사건, 흑막, 보스전 |

챕터별 톤 배정은 미정 (05·08).

**미정 설정** (05·08의 스토리 설정에서 결정)

- 주인공이 불을 흡수한 사건의 내용.
- 적의 정체.
- 흑막. 구 콘셉트의 흑막(숨은 인간 세력)은 쓰지 않는다. 새 흑막은 미정이다.
- 퀘스트 구조: 메인 챕터 목표 외에 서브 의뢰를 둘지 미정 (05). 퀘스트 분기는 두지 않는다 (8절).
- 결말: 불을 여우신에게 돌려줄지 등.

## 4. 핵심 재미

이 게임의 핵심 재미는 두 축이다. 두 축 모두 핵심 재미로 다루되, 둘이 충돌하면 탐험을 우선한다.

### 4-1. 1순위 재미 — 탐험과 해금

핵심 재미 한 문장: 새 능력을 얻어 막혀 있던 길이 열리고, 어두웠던 지도가 한 칸씩 밝혀지는 재미.
이 재미를 만드는 기능 단위는 다음과 같다.

| 기능 | 역할 |
|---|---|
| 능력 획득 처리 | 수업과 모험 등으로 얻은 마법·능력을 보유 상태로 저장한다. 능력별 획득 경로는 미정 (04) |
| 능력 게이트 판정 | 지형·오브젝트마다 통과에 필요한 능력을 지정하고, 보유 여부와 스킬 레벨로 통과 가능·불가를 판정한다 |
| 통과 불가 피드백 | 능력이 없어 통과하지 못했을 때 무엇이 부족한지 플레이어에게 표시한다 |
| 자동 지도 기록 | 방문한 구간을 지도에 기록하고, 미탐험 구간과 구분해 표시한다 |
| 되돌아가기 동선 | 새 능력 획득 후 이전 구역과 이전 챕터 지역으로 돌아가는 경로와 단축로 개방 규칙을 둔다 (05) |
| 이동 능력 | 아래 배치표의 이동 능력으로 도달 범위를 넓힌다 |

**이동 능력 배치** (배치 확정. 세부 규칙은 02_플레이어 조작·04_능력 게이트 개정 시 정의)

| 이동 능력 | 분류 |
|---|---|
| 일반 대시 | 기본 보유 |
| 더블점프 | 해금 (획득 경로 미정, 04) |
| 벽 붙기 | 여우 의태 (발톱) |
| 질주 | 여우 의태 (발) |
| 체공 | 불을 쓰는 이동기 (꼬리 의태 + 상승하는 불기운) |
| 폭발 대시 (가칭) | 불을 쓰는 이동기 (발 의태 + 불꽃 폭발) |
| 비행 | 공통 마법. 후반 해금 |

**게이트 구성**: 게이트 열쇠는 세 갈래로 확정한다.

| 게이트 분류 | 여는 수단 | 비고 |
|---|---|---|
| 불의 쓰임새 게이트 | 불 마법 | 후보: 태우기, 녹이기, 밝히기, 터뜨리기, 상승하는 불기운. 확정 종류는 04. 스킬 레벨로 하위·상위 단계를 나눈다. 게이트별 열쇠 마법은 04, 요구 레벨 값은 09 |
| 폭주 폭발 게이트 | 폭주의 강제 폭발 | 폭주 폭발로만 부술 수 있다. 폭주를 일부러 활용하는 플레이를 허용하기 위한 게이트다 |
| 이동 게이트 | 이동 능력 | 위 이동 능력 배치표의 능력으로 연다 |

**게이트 설계 원칙**: 각 챕터의 메인 동선은 그 챕터 시점까지 얻을 수 있는 능력만 열쇠로 쓴다. 이후 챕터의 능력이 필요한 막힌 곳은 선택 구역과 역주행 대상에만 둔다. 세부 배치 규칙은 04_능력 게이트, 05_맵·진행에서 정의한다.

### 4-2. 2순위 재미 — 배움·성장·전투

마녀학교에서 수업을 듣고 불 마법을 배우며 강해지는 과정 자체가 재미다. 다만 전투 자체를 최종 목표로 설계하지 않는다. 전투는 탐험과 챕터 진행의 수단이다. 전투 재미의 중심 장치는 폭주 게이지 줄타기다 (4-3절).

| 기능 | 역할 |
|---|---|
| 기본공격 | 빗자루로 하는 근접 1타 공격. 진로를 막는 적을 제거한다. 폭주 게이지를 쌓지 않는다 |
| 불 마법 | 약 7개. 배운 마법은 전부 사용 가능하다. 사용하면 폭주 게이지가 쌓인다 |
| 결합 스킬 | 쌓인 폭주 게이지를 소모해 발동하는 최상위 스킬 |
| 여우 의태 | 여우의 몸 일부를 의태하는 단독 능력. 폭주 게이지와 무관하다 |
| 공통 마법 | 모든 마녀가 배우는 마법. 폭주 게이지와 무관하다 |
| 특성 슬롯 | 패시브·특성을 슬롯에 장착한다. 종류·슬롯 수·획득 경로 미정 (04·06) |
| 수업 | 마녀학교에서 수업을 들어 불 마법을 습득한다. 수업은 스토리 진행도에 따라 해금된다 |
| 스킬 레벨업 | 자원을 사용해 불 마법의 스킬 레벨을 올린다 |
| 자원 획득 | 탐험과 전투로 자원을 얻는다. 이름과 종류는 미정 (06) |

마법은 세 등급으로 나뉜다.

| 등급 | 대상 | 습득 방법 |
|---|---|---|
| 초급 | 불 마법 | 마녀학교 수업만으로 습득한다 |
| 고급 | 불 마법 | 수업에 더해 재료를 얻어 오거나 과제를 수행해야 습득한다 |
| 결합 (최상위) | 결합 스킬 | 불 마법 약 7개와 별개다. 개수와 습득 조건은 미정 (04) |

초급·고급 불 마법의 개수 배분은 미정 (04). 수업의 해금 조건은 스토리 진행도다. 자원만 모으면 아무 때나 배울 수 있는 구조가 아니다.
여우 능력(결합 스킬, 여우 의태)은 개수를 적게 두고 한 개 한 개의 연출과 효과를 크게 만드는 방향이다. 구체 목록은 04_능력 게이트 개정 시 정의한다.

**스킬 레벨업**: 자원을 소비해 불 마법의 스킬 레벨을 올린다. 오른 스킬 레벨이 불의 쓰임새 게이트의 하위·상위 단계 개방 조건과 연결된다 (4-1절). 강화가 전투 성능과 탐험 해금을 동시에 움직인다. 마법 습득과 스킬 레벨업이 이 게임의 자원 사용처다. 상점은 두지 않는다.

**전투 기조**: 고정 데미지, 1타 기본공격을 유지한다. 기본공격 위주 전투를 유지한다 (참고 게임: 스컬). 세부는 03_전투 시스템 개정 시 정의한다.

### 4-3. 폭주 게이지

**목적**: 강한 한 방을 쏘고 쓰러지는 캐릭터성을 조작으로 느끼게 한다 (참고: 코노스바의 메구밍). 동시에 불 마법 사용량에 위험과 보상을 함께 건다.

**설정 명분**: 인간의 몸에 담긴 신의 불이 넘쳐흐르는 정도다.

**순환 규칙** (확정)

1. 불 마법을 쓰면 폭주 게이지가 쌓인다.
2. 결합 스킬은 쌓인 폭주 게이지를 소모해 발동한다. 게이지가 많을수록 강해진다.
3. 게이지가 한계를 넘으면 폭주한다. 폭주하면 강제 폭발이 먼저 일어나고, 그다음 탈진한다.
4. 마법을 쓰지 않으면 게이지는 저절로 줄어든다.

**게이지와 무관한 행동**: 기본공격, 여우 의태, 공통 마법은 폭주 게이지를 쌓지도 소모하지도 않는다.

**폭주 활용**: 폭주를 일부러 일으키는 플레이를 허용한다. 폭주 폭발로만 여는 게이트를 둔다 (4-1절).

**soft lock 방지 의도**: 게이지는 저절로 줄고, 불 마법으로 언제든 쌓을 수 있다. 따라서 게이지가 부족하거나 넘쳐서 진행이 막히는 구조가 생기지 않게 한다. 결합 스킬이나 폭주 폭발이 필요한 지점에서도 플레이어는 불 마법으로 게이지를 다시 쌓을 수 있어야 한다.

**미정 항목** (04·09)

| 항목 | 담당 |
|---|---|
| 게이지 한계값, 불 마법별 증가량, 자연 감소량과 감소 시작 조건 | 04·09 |
| 결합 스킬의 최소 요구 게이지, 소모량 규칙(전량·일부), 게이지량에 따른 위력 규칙 | 04·09 |
| 폭주 폭발의 범위와 피해, 주인공 자신에게 주는 영향 | 04·09 |
| 탈진 시간, 탈진 중 가능한 행동 | 04·09 |
| 불을 쓰는 이동기(체공·폭발 대시)와 게이지의 관계 | 04 |
| 여우 사당에서의 게이지 처리 | 04·09 |

### 4-4. 이 재미를 방해하는 요소

- 전투 비중이 커져 탐험 시간이 밀리는 구성. 전투는 탐험 동선을 막는 장애물 수준으로 유지한다.
- 수업과 자원 수집이 길어져 탐험이 끊기는 구성. 수업 해금은 스토리 진행도를 기준으로 삼아 자원 파밍 반복을 만들지 않는다.
- 폭주 게이지 때문에 진행이 막히는 구성. 4-3절의 soft lock 방지 의도를 지킨다.
- 선형 챕터 구조가 탐험 자유를 없애는 구성. 챕터 안에서는 탐험 순서, 선택 구역, 숨은 구역을 자유롭게 둔다.
- 사망 시 자원 손실·시체 회수 방식. 되돌아가기 자체를 벌칙으로 만들어 탐험 의욕을 떨어뜨리므로 채택하지 않는다.
- 미저장 탐험 기록 소실 폭이 지나치게 큰 경우. 체크포인트 간격과 지도 저장 시점 규칙으로 통제한다. 세부 규칙은 미정 (05)

## 5. 대상 플레이어

- 대상 플레이어: 메트로배니아 경험자와 메트로배니아 입문자 양쪽.
- 예상 경험 수준: 일반 액션 게임을 조작할 수 있는 수준.
- 선호하는 플레이 방식: 챕터 안에서 맵을 직접 뒤지며 길을 찾는 방식.
- 플레이 길이: 메인 스토리 6~7시간의 단일 플레이. 짧은 반복 세션형이 아니다.
- 난이도 방향: 보통. 일반 액션 게임 수준으로 잡는다. 경험자와 입문자를 동시에 수용하기 위해 난이도 조절 수단을 둔다. 조절 방식은 미정이다. (조절 수단은 07, 적용 수치는 09에서 결정)

## 6. 게임의 기본 흐름

기본 흐름:
타이틀 화면 → 게임 시작(신규 또는 마지막 저장 시점부터 이어하기) → 도입부: 여우신과의 만남과 동행 시작 → 마녀학교에서 수업 수강·불 마법 습득·스킬 레벨업 → 현재 챕터의 모험 지역 탐험(챕터 안 자유 순서) → 능력 게이트 확인(통과 가능·불가 판정) → 전투와 자원 획득 → 챕터 메인 사건 해결 → 다음 챕터(고정 순서) → 새 능력으로 이전 챕터 지역의 막힌 곳 역주행(선택) → 마지막 챕터 → 결말(미정)

상세 설명:
도입부에서 여우신이 주인공을 찾아와 동행이 시작된다. 도입부의 구체 구성과 시작 시 보유 능력은 미정이다. (도입부는 05·08, 보유 능력은 04)
플레이어는 마녀학교를 거점으로 삼는다. 학교에서 수업을 듣고 불 마법을 배운 뒤, 현재 챕터의 모험 지역으로 나간다. 챕터 순서는 고정이지만, 챕터 안에서는 탐험 순서와 선택 구역·숨은 구역 공략을 자유롭게 정한다.
이동 중 통과할 수 없는 지형을 만나면 필요한 능력이 무엇인지 확인하고 지도에 남긴 뒤 다른 경로를 찾는다. 새 불 마법이나 이동 능력을 얻으면 이전에 막혀 있던 구간이 통과 가능해진다. 이전 챕터 지역의 막힌 곳도 다시 갈 수 있는 목적지가 된다.
탐험 중 얻은 자원은 불 마법의 스킬 레벨업에 사용한다. 고급 불 마법은 재료나 과제가 필요하므로, 마녀학교와 모험 지역을 오가는 동선이 생긴다.
게임을 다시 켜면 마지막 저장 시점부터 시작한다. 체크포인트는 여우 사당(가칭)이며 배치 간격은 미정이다. (05) 사망하면 마지막 여우 사당에서 부활한다. 챕터 진행, 획득한 자원, 습득한 마법·능력은 유지된다. 대신 마지막 저장 이후의 미저장 탐험 기록(지도 기록 등)이 소실된다. 사망 후 적 리스폰 여부는 미정 (05)

## 7. 포함할 기능 (MVP)

MVP는 "이 기능이 없으면 핵심 루프를 테스트할 수 없는가"를 기준으로 정한다. 핵심 루프는 "이동 → 막힌 길 확인 → 능력 획득 → 막힌 길 통과"다. 여기에 2순위 재미의 중심 장치인 폭주 게이지 순환을 함께 검증한다.

| 기능 | MVP 범위 | 없으면 안 되는 이유 |
|---|---|---|
| 기본 이동 | 좌우 이동, 점프, 일반 대시 | 맵을 이동할 수 없으면 탐험 자체가 성립하지 않는다 |
| 기본공격 | 빗자루 근접 1타 | 진로를 막는 적을 제거하는 최소 수단이다 |
| 불 마법 | 일부. 개수와 대상 마법은 미정 (04) | 폭주 게이지를 쌓는 수단이다 |
| 폭주 게이지 | 쌓임, 자연 감소, 한계 초과 시 폭주(강제 폭발 → 탈진) 포함 | 2순위 재미의 중심 장치를 검증하는 대상이다 |
| 결합 스킬 | 1개. 대상은 미정 (04) | 게이지를 쌓았다가 터뜨리는 흐름의 끝 지점이다 |
| 여우 의태 이동기 | 1개. 대상은 미정 (04) | 능력으로 도달 범위가 넓어지는 구조를 검증하는 최소 능력이다 |
| 능력 게이트 | 1종. 대상은 미정 (04) | 능력 획득 → 통과라는 핵심 루프 검증의 대상 그 자체다 |

MVP에서 불 마법·능력을 수업으로 습득시킬지, 초기 보유로 지급할지는 미정이다. (04)

MVP에서 검증할 질문:

1. "새 능력을 얻은 뒤 이전에 막혀 있던 길을 통과하는 흐름이 재미있는가?"
2. "폭주 게이지를 쌓았다가 결합 스킬로 터뜨리는 줄타기가 재미있는가?"

이 흐름이 성립하지 않으면 기능을 더 추가해도 문제는 해결되지 않는다.

MVP에는 포함하지 않지만 본편에는 필요한 기능(구현 순서는 이후 문서에서 정한다): 자원 획득, 마녀학교 수업과 불 마법 습득, 스킬 레벨업, 고급 불 마법, 나머지 여우 의태와 이동 능력, 불을 쓰는 이동기, 공통 마법(비행 등), 추가 결합 스킬, 특성 슬롯, 챕터 진행 관리, 보스전, 여우 사당 부활, 지도 기록·저장, 난이도 조절.

| 제외 기능 | 사유 |
|---|---|
| 장비 강화 | 성장 축을 마법 습득·스킬 레벨업 하나로 유지한다. 자원 사용처가 나뉘면 탐험 보상의 의미가 흐려진다. 특성 슬롯은 패시브를 장착하는 기능이며 장비 강화와 구분한다 |
| 퀘스트 분기 | 메인 스토리는 고정 순서의 챕터로 진행하며, 선택지에 따라 결과가 갈라지는 분기를 두지 않는다. 서브 의뢰를 두는 경우에도 분기는 두지 않는다 (서브 의뢰 유무는 05) |
| 상점 | 마법 습득·스킬 레벨업이 자원 사용처 역할을 대신한다 |
| 멀티플레이 | 싱글 플레이로 확정했다 |

사망 시 자원 손실과 시체 회수 방식도 채택하지 않는다. 화폐형 재화는 두지 않는다. (4-4절 참조)

콘셉트에서 필요성이 확정되는 화면만 적는다. 각 화면의 표시 데이터와 전환 조건은 07_UI 흐름에서 정의한다.

## 13. AI 구현 요청용 프롬프트 (콘셉트 요약)

**목적**
2D 메트로배니아의 MVP를 만든다. 검증 대상은 두 흐름이다. ① 새 능력을 얻어 이전에 막혀 있던 길을 통과하는 흐름. ② 불 마법으로 폭주 게이지를 쌓았다가 결합 스킬로 터뜨리는 흐름.

**환경**
Unity 6, C#, PC 단독 실행, 싱글 플레이, 픽셀아트 2D.

**요구 기능 (MVP)**
1. 플레이어 기본 이동: 좌우 이동, 점프.
2. 일반 대시(기본 보유). 해금 대상이 아니다.
3. 기본공격: 빗자루 근접 1타. 폭주 게이지를 바꾸지 않는다.
4. 불 마법 일부 (대상 미정, 04). 사용하면 폭주 게이지가 쌓인다.
5. 폭주 게이지: 불 마법 사용 시 증가, 마법 미사용 시 자연 감소, 결합 스킬 발동 시 소모, 한계 초과 시 폭주(강제 폭발 → 탈진).
6. 결합 스킬 1개 (대상 미정, 04). 게이지를 소모해 발동하고, 게이지가 많을수록 강해진다.
7. 여우 의태 이동기 1개 (대상 미정, 04). 능력 보유 여부로 사용 가능·불가가 갈린다. 폭주 게이지를 바꾸지 않는다.
8. 능력 게이트 1종 (대상 미정, 04). 통과에 필요한 능력을 지정할 수 있는 지형·오브젝트.

**데이터 구조**
- 플레이어 보유 능력 목록 (능력 ID 집합)
- 불 마법 정의 (마법 ID, 등급(초급·고급), 쿨타임, 폭주 게이지 증가량, 스킬 레벨) — 값 미정
- 폭주 게이지 상태 (현재값, 한계값, 자연 감소량, 폭주 여부, 탈진 남은 시간) — 플레이어 데이터에 둔다. 값 미정
- 폭주 정의 (강제 폭발 범위, 강제 폭발 피해, 탈진 시간) — 값 미정
- 결합 스킬 정의 (스킬 ID, 최소 요구 게이지, 소모량 규칙, 게이지량에 따른 위력 규칙) — 값과 규칙 미정
- 여우 의태 정의 (의태 ID, 의태 부위, 효과) — MVP 대상 미정
- 능력 게이트 정의 (게이트 ID, 게이트 분류, 필요 능력 ID, 요구 스킬 레벨, 위치) — 게이트 분류는 불의 쓰임새·폭주 폭발·이동 중 하나. 요구 스킬 레벨은 불의 쓰임새 게이트에만 쓴다. 값 미정
- 구체 수치는 09_데이터 테이블에서 확정한다. 임의 값으로 채우지 않는다.

**처리 흐름**
게이트 판정:
1. 플레이어가 게이트에 접촉한다.
2. 게이트 분류를 확인한다.
3. 불의 쓰임새 게이트: 필요 마법 보유 여부와 그 마법의 스킬 레벨이 요구 레벨 이상인지 검사한다.
4. 이동 게이트: 필요 이동 능력 보유 여부를 검사한다.
5. 폭주 폭발 게이트: 폭주의 강제 폭발 판정이 게이트에 닿았을 때만 연다.
6. 조건을 만족하면 통과를 허용한다. 만족하지 못하면 통과를 막고 부족한 능력·레벨을 알리는 피드백을 표시한다.
7. 능력을 획득하면 보유 능력 목록에 추가하고 저장한다.

폭주 게이지 순환:
1. 불 마법을 사용하면 그 마법의 증가량만큼 게이지를 올린다.
2. 게이지가 한계값을 넘으면 폭주를 시작한다. 강제 폭발을 먼저 처리하고, 그다음 탈진 상태로 전환한다.
3. 결합 스킬 입력 시 게이지를 확인하고, 조건을 만족하면 소모량 규칙에 따라 게이지를 줄이고 게이지량에 따른 위력으로 발동한다.
4. 마법을 쓰지 않는 동안 게이지를 자연 감소시킨다. 감소 시작 조건과 감소량은 미정이다. (TODO, 04·09)
5. 기본공격, 여우 의태, 공통 마법 입력은 게이지를 바꾸지 않는다.

**예외 조건**
- 이미 보유한 능력을 다시 획득하면 중복 추가하지 않는다.
- 필요 능력 ID가 정의되지 않은 게이트는 통과 불가로 처리하고 오류를 기록한다.
- 사망 상태에서 들어온 이동·공격·마법 입력은 무시한다.
- 게이트 통과 판정 중 능력이 변경되면 판정을 다시 수행한다.
- 게이지가 결합 스킬의 최소 요구치 미만이면 결합 스킬을 발동하지 않는다. (요구치 미정. TODO)
- 게이지는 0 미만으로 내려가지 않는다.
- 탈진 중 가능한 행동과 입력 처리는 미정이다. (TODO, 04)
- 불 마법 사용으로 한계를 넘는 경우, 그 마법의 발동과 폭주의 처리 순서는 미정이다. (TODO, 04)
- 폭주 폭발 게이트는 폭주 외의 수단(불 마법, 결합 스킬 등)으로는 열리지 않는다.
- 게이지 부족으로 진행이 막히는 구조를 만들지 않는다. 폭주 폭발 게이트 주변에서도 불 마법으로 게이지를 쌓을 수 있어야 한다.
- 스토리 진행도가 부족한 수업은 자원이 충분해도 습득을 허용하지 않는다. (본편)
- 고급 불 마법은 필요 재료·과제가 미충족이면 습득을 거부하고 부족한 조건을 표시한다. (본편)
