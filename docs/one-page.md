# 한 장 기획서 — 저주 매입합니다 (가제)

> 버전 0.2 · 대화하며 수정하는 초안. (0.2: 탐험=미로+텍스트 사건 카드 혼합, 전투=메뉴형 턴제, 생활→능력치 연동 반영) `[미결정]`은 아직 정하지 않은 항목, `[제안]`은 내가 임시로 채운 항목이다.

## 2. 핵심 콘셉트 한 문장

이 게임은 **저주에 걸린 견습 마녀**가 **마녀학교**에서 **저주 물건을 매입해 탐험과 턴제 전투로 정화하며**, **폐부 직전의 골동품 동아리를 지키고 자신의 저주를 푸는** 게임입니다.

## 3. 핵심 재미

| 질문 | 답변 |
|---|---|
| 가장 자주 하는 행동 | 봉인 창고 층 미로를 탭으로 이동하며 사건 카드(전투·이벤트·보물)를 만나고, 메뉴형 턴제 전투로 저주 물건을 회수한다 |
| 왜 재미있는가 | 마력이 바닥나기 전에 얼마나 더 내려갈지 정하는 판단(계속 vs 귀환), 미로 속 숨은 방 발견, 퀴즈·운 상자 같은 사건의 의외성 |
| 행동 후 보상 | 골동품(일반·고급·희귀·전설), 은화, 정화 재료, 마법서 조각 |
| 다시 하고 싶은 이유 | 더 깊은 층의 상위 등급 골동품, 정화한 물건을 장착해 강해지는 성장, 부실을 넓히고 꾸미는 수집 |

## 4. 기본 플레이 흐름

시작 → 의뢰·매입 → 탐험·전투 → 정화 → 판매·장착 → 성장 → 다음 탐험

| 단계 | 설명 |
|---|---|
| 시작 | 부실(메인 허브)에 들어가면 오늘 찾아온 학생 손님과 의뢰 게시판이 보인다 |
| 플레이어 행동 | 손님의 저주 물건을 감정 정보(저주 등급·증상)를 보고 **매입 또는 거절**한다. 또는 학교 지도에서 던전·교실을 골라 탐험한다 |
| 게임 반응 | 층 미로를 탭으로 한 칸씩 이동 → 칸에 도착하면 사건 카드(텍스트+선택지) 발생: 적 조우 → 턴제 전투 / 퀴즈·운 상자·이상한 방 / 보물 |
| 보상 또는 결과 | 전투 승리 시 골동품·재료 획득. 매입한 물건은 정화대에서 **정화 전투** `[제안]`에 이기면 정화 완료 |
| 다음 흐름 | 정화한 물건을 판매(은화) 또는 장착(전투 강화) → 은화로 수업 수강·마법 강화 → 더 깊은 층 도전 |

## 5. 주요 시스템

| 시스템 | 목적 | 발생 조건 | 결과 |
|---|---|---|---|
| 매입·정화 | 가게 운영의 중심. 재화 획득 | 손님 방문(하루 3명 `[제안]`) 또는 던전에서 저주 물건 획득 | 정화 성공 → 판매 가능 상태. 저주가 강할수록 싸게 사서 비싸게 팜 |
| 턴제 전투 (메뉴형) | 핵심 행동. 회수·정화·스토리 진행 | 사건 카드의 적 조우, 정화 시작, 스토리 교실 진입 | 매 턴 공격·마법·물약·도망 중 선택. 승리: 보상 / 패배: 획득물 일부만 가지고 부실 귀환 `[제안]` |
| 능력치 4종 | 생활 콘텐츠를 전투력으로 연결 (동물농장 '지수→탐험 능력치' 참고) | 부실 운영·수업·꾸미기 실적 누적 | 공격(정화 실적) · 방어(부실 꾸미기) · 체력(수업 출석) · 마력(마법 수업 성적) `[제안: 연결 항목]` |
| 마력·물약 | 탐험 길이를 정하는 자원 | 마법 1회 사용 시 마력 소모 | 마력 0 → 기본 공격만 가능. 물약(매점에서 은화로 구매)으로 체력·마력 회복 |
| 탐험(봉인 창고) | 상위 등급 골동품 획득처 | 학교 지도에서 층 선택. 하루 열쇠 3개 `[제안]`. 층 구간 입장에 봉인 해제 주문 필요(스토리로 획득) | 1차 10층, 5층마다 보스 `[제안]`. 층 끝 계단 도달 시 다음 층 해금. 보스전에서 도망 시 구간 시작 층으로 되돌아감 |
| 성장(마법) | 전투력 상승 | 수업 수강(은화), 도서관 강화(마법서 조각) | 새 마법 습득, 마법 강화(최대 3단계) |
| 클리어/실패 | 진행 판정 | 층 보스 격파 / 전투 HP 0 | 다음 층·학년 해금 / 부실 귀환 |

> 부가 시스템(1차 출시에 포함, 프로토타입 제외): 훈장, 부실 꾸미기, 부실 고양이(펫), 학기말 시험, 이상한 방.

## 6. 화면 구성

| 화면 | 목적 | 표시 정보 | 버튼/동작 |
|---|---|---|---|
| 부실(메인) | 허브. 매입·정화·판매 | 은화, 손님, 정화대, 진열장 | 손님 탭 → 매입 창 / 정화대 → 정화 전투 / 문 → 학교 지도 |
| 학교 지도 | 장소 선택 | 교실(수업·스토리), 도서관, 봉인 창고 층, 남은 열쇠 | 장소 탭 → 해당 화면 |
| 탐험 | 층 미로 이동 + 사건 카드 | 층 미니맵, 체력·마력, 획득물, 사건 카드(텍스트+선택지) | 칸 탭 이동, 카드 선택지 탭, 귀환 |
| 전투 | 메뉴형 턴제 전투 | 주인공·적 체력, 마력, 전투 로그 | 공격 / 마법(목록 선택) / 물약 / 도망 |
| 결과 | 보상 확인 | 획득 골동품(등급), 은화, 재료 | 부실로 / 계속 탐험 |

> 템플릿 권장(3개 안팎)보다 많다. 프로토타입에서는 학교 지도를 빼고 부실 ↔ 탐험 ↔ 전투 ↔ 결과 4개로 시작 `[제안]`.

## 7. 1차 구현 범위 (프로토타입)

| 포함할 기능 | 제외할 기능 |
|---|---|
| 부실 화면: 손님 1명 매입 흐름 | 서버, 로그인, 친구·방문, 장터 |
| 봉인 창고 1층(고정 미로 1개, 사건 카드 5종) + 보스 1 | 학교 지도, 수업, 도서관, 시험, 스토리 교실 |
| 메뉴형 턴제 전투: 공격·마법 3개·물약·도망, 적 3종 | 이상한 방(방 탈출), 능력치 연동(고정 수치로 대체) |
| 정화 → 판매 → 은화 | 훈장, 꾸미기, 펫 |
| 결과 화면 | 결제·광고, 등급 4단계 중 희귀·전설 |

프로토타입의 목적: **"매입 → 탐험·전투 → 정화 → 판매" 한 바퀴가 재미있는지** 확인.

## 9. 최종 점검

| 질문 | 현재 상태 |
|---|---|
| 한 문장으로 설명되는가 | ✅ 2장 |
| 반복할 핵심 행동이 분명한가 | ✅ 탐험·턴제 전투 |
| 행동과 보상이 연결되는가 | ✅ 전투 → 골동품 → 정화·판매·장착 → 성장 |
| 성공·실패 조건이 명확한가 | ⚠️ 패배 페널티 `[제안]` 단계 |
| 화면이 3개 안팎인가 | ⚠️ 5개. 프로토타입은 4개로 축소 |
| 1차 범위가 너무 크지 않은가 | ⚠️ 1차 출시(솔로)는 초보 1인에게 큼. 프로토타입은 적정 |
| AI에게 작게 나눠 요청할 수 있는가 | ✅ 8장 |
