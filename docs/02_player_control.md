# 02. 플레이어 조작

이 문서는 플레이어 입력이 어떤 조건에서 어떤 행동과 상태로 이어지는지 정의한다. 기준 문서는 00_게임 콘셉트와 01_핵심 플레이 루프이며 두 문서와 충돌하는 내용을 두지 않는다. 데미지 계산과 피격 처리 세부는 03_전투 시스템, 능력 해금 조건은 04_능력 게이트, 화면 표시는 07_UI 흐름, 구체 수치는 09_데이터 테이블에서 정의한다.

## 1. 게임 기본 정보

| 항목 | 내용 |
|---|---|
| 게임 제목 | 미정 (가제 미정) |
| 장르 | 2D 메트로배니아 |
| 플랫폼 | PC (Steam 출시 목표) |
| 개발 엔진 / 언어 | Unity 6 / C# |
| 입력 방식 | 키보드 우선. 게임패드는 지원을 전제로 설계하되 매핑은 미정 (07_UI 흐름에서 결정) |
| 카메라 방식 | 2D 횡스크롤 추적 카메라. 세부는 미정 (08_스테이지 설계에서 결정) |
| 조작 기준 | 월드 좌표 기준 좌우 이동. 플레이어가 직접 이동·점프·공격하고, 발현 중인 가호의 신성을 사용한다 |

입력 처리는 키 재매핑이 가능한 구조로 만든다. 코드에서 키 코드를 직접 참조하지 않고 행동 이름(Move, Jump, Attack 등)으로 참조한다. 키 설정 UI는 07_UI 흐름에서 정의한다.

## 2. 조작 콘셉트

플레이어는 방향키로 좌우 이동하고, Space로 가변 점프를 하며, D로 근접 1타 공격을 하고, Shift로 일반 대시를 사용한다. 발현 중인 가호의 공격 신성은 Q/W/E/R/S로, 이동 신성은 A/Z/X/C로 사용한다. 가호 전환은 Tab과 방향키로 하며, 전투 중을 포함해 장소 제약 없이 가능하다 (8-1절).

설계 기준은 셋이다.

- 근접 1타 기본공격 위주로 전투한다. 참고 게임은 스컬(Skul: The Hero Slayer)이며, 1타 공격 리듬은 할로우 나이트를 참고한다. 신성은 신력을 소모하므로 난사할 수 없다. 쿨타임은 병행 제약이다 (03_전투 시스템 4-2절).
- 이동 능력을 3층 구조로 나눈다. ① 기본 보유(좌우 이동, 가변 점프, 일반 대시) ② 더블점프 해금 ③ 이동 신성이다 (00_게임 콘셉트 4-1절, 01_핵심 플레이 루프 5절).
- 이동 신성은 종족(신)에 속하지 않는 공용 신성 체계(이동기·유틸)에 속한다. 각 마을의 메인 동선은 그 마을 신의 신성과 공용 능력만 열쇠로 쓰므로, 세 마을을 어느 순서로 공략해도 이동 신성이 공통 열쇠 역할을 한다 (00_게임 콘셉트 4-1절).
- 조작감은 중점 레퍼런스인 산나비와 오리와 도깨비불을 기준으로 삼는다. 입력 버퍼와 접지 유예(코요테 타임) 채택의 근거다.

## 4. 이동 기획

### 4-1. 좌우 이동

- 이동 입력: 방향키 좌·우. 이동 방향은 월드 좌표 기준 좌우 2방향이다. 2D 횡스크롤이므로 카메라 기준 이동은 쓰지 않는다.
- 이동 속도: MoveSpeed. 값 미정 (09_데이터 테이블에서 확정)
- 이동 가능 상태: Idle, Move, Jump(공중), Attack. 불가능 상태: Dash, Dead. 기본공격 중에는 이동할 수 있다.
- 애니메이션: 이동 중 Move, 정지 시 Idle. 좌우 입력이 동시에 들어오면 이동 입력이 없는 것으로 처리한다.

### 4-2. 점프 (가변 점프)

- 입력: Space. 누르는 순간 점프를 시작하고, 누르고 있는 동안 상승을 유지하며, 떼면 그 시점에 상승을 종료한다.
- 높이 결정: 누른 시간에 비례해 최소 높이에서 최대 높이 사이로 결정한다.
- 가능 조건: 지면에 닿아 있고 상태가 Idle 또는 Move일 때. 점프 중 좌우 방향 전환을 허용한다.
- 관련 값: JumpPower, JumpHoldMaxTime, AirControlRatio. 값 미정 (09_데이터 테이블에서 확정)

### 4-3. 더블점프 (해금형 능력)

- 획득 방법: 모험 중 획득한다. 신전 수업으로 배우지 않는다. 획득 시점·위치는 미정 (05·08에서 결정)
- 입력: 공중에서 Space. 가능 조건은 더블점프를 보유하고, 상태가 Jump(공중)이며, 남은 공중 점프 횟수가 1 이상일 때다.
- 횟수: 공중에서 1회. 착지하면 횟수를 초기화한다. 관련 값 MaxAirJumpCount는 미정 (09에서 확정)
- 미보유 시: 공중 Space 입력을 무시한다. 별도 실패 연출은 두지 않는다.

더블점프는 00_게임 콘셉트의 "MVP 이동기 1종"에 해당한다.

## 5. 공격 기획

### 5-1. 기본공격 (D)

- 공격 입력: D (누르는 순간). 공격 방향은 캐릭터가 바라보는 방향(좌우)이다.
- 공격 방식: 근접 1타 공격이다. 연속 입력 시 같은 공격을 BasicAttackCooldown 간격으로 반복한다. 판정·데미지 세부는 03_전투 시스템, 값은 09_데이터 테이블에서 확정한다.
- 공격 방향: 좌우뿐이다. 상단·하단 베기(위·아래 방향 공격)는 두지 않는다.
- 공격 중 이동: 가능하다. 이동하면서 공격한다.
- 공격 판정 범위·쿨타임: BasicAttackRange, BasicAttackCooldown. 값 미정 (09에서 확정)
- 공격 데미지: BasicAttackDamage(고정값). 값 미정. 계산식은 03_전투 시스템, 값은 09_데이터 테이블에서 확정한다.
- 공격 가능 상태: Idle, Move, Jump(공중), Attack. 불가능 상태: Dash, Dead. Attack 중 D 재입력은 입력 버퍼(InputBufferTime)로 저장했다가 쿨타임과 공격 모션이 끝난 뒤 1회 실행한다.
- 공격 중 피격: 공격은 취소되지 않는다. 피격은 상태 전환 없이 처리한다 (9절 참조).
- 애니메이션은 Attack 하나이며, 판정은 애니메이션 이벤트로 발생시킨다. 발생 시점은 BasicAttackHitTiming이며 값은 미정 (구조는 03, 값은 09에서 확정)

처리 흐름:

1. D 입력을 받고 현재 상태와 BasicAttackCooldown 경과 여부를 검사한다.
2. 조건을 만족하면 Attack 상태로 전환하고 Attack 애니메이션을 재생한다.
3. BasicAttackHitTiming 시점에 공격 판정을 생성한다. 판정 결과 처리는 03_전투 시스템이 담당한다.
4. 애니메이션이 끝나면 이동 입력이 있으면 Move로, 없으면 Idle로 돌아간다. 공중이면 Jump(공중)로 돌아간다.
5. 버퍼에 저장된 D 입력이 있고 쿨타임이 끝났으면 1번으로 돌아가 같은 공격을 다시 실행한다.

### 5-2. 공격 신성 (Q, W, E, R, S)

- 신성 구성: 종족(신)별로 초급 2개 + 고급 2개 + 강림 1개 = 5개다. 여우·늑대·용 세 신 모두 같은 구성이다.
- 사용 범위: 발현 중인 가호의 신성 중 배운 것 전부를 쓸 수 있다. 슬롯 선택은 두지 않는다.
- 키 대응: **Q·W = 초급 2개, E·R = 고급 2개, S = 강림**으로 고정한다. 등급별 키 위치가 세 가호에서 동일해, 가호를 전환해도 손 위치가 흔들리지 않는다.
- 가능 조건: 해당 신성을 배웠고, 발현 중인 가호에 속하며, 쿨타임이 끝났고, 남은 신력이 그 신성의 DivinityCost 이상일 때. 사용이 성립하면 DivinityCost만큼 신력을 차감한다.
- 불가능 조건: 미습득, 다른 가호의 신성, 쿨타임 진행 중, 신력 부족, Dash·Dead 상태. Attack 상태(기본공격 모션) 중에는 사용할 수 있다. 남은 공격 모션을 끊고 즉시 발동한다(캔슬 허용, 03_전투 시스템 4-2절)
- 상태 전환: 공격 신성을 쓰면 Attack 상태로 전환한다. 기본공격과의 Attack 상태 세부 차이는 미정 (03_전투 시스템 참조)
- 신력: 신성 사용의 실질 제약이다. 가호와 무관하게 게이지 하나를 공유하며, 가호를 전환해도 남은 신력은 유지된다. 충전은 적 처치·신앙 오브젝트 점등·제단 완전 충전으로만 이뤄지고 자연 회복은 없다 (00_게임 콘셉트 4-2절, 03_전투 시스템 4-2절).
- 신력 소모는 세 형태다. ① 1회 차감형(대부분. 사용 성립 시 DivinityCost 차감) ② 지속 소모형(화영난무·비행: 초당 소모) ③ 증가형(번개 광선: 회차마다 기하급수 증가). 세부는 04_능력 게이트 5절.

| 등급 | 개수 | 쿨타임 | 신력 소모 |
|---|---|---|---|
| 초급 | 2 | 짧음 (연타 방지 수준, 가안) | 낮음 (값 미정) |
| 고급 | 2 | 약 20초 (가안) | 높음 (값 미정) |
| 강림 | 1 | 60초 이상 (가안) | 높음 (값 미정) |

이 표는 방향성만 확정한 가안이다. 확정값(쿨타임, DivinityCost)은 09_데이터 테이블에서 정한다. 초급 신성의 쿨타임은 연타 방지 수준으로만 두고, 난사 억제는 신력 소모가 담당한다. 고급·강림 신성은 긴 쿨타임과 높은 신력 소모를 함께 둔다.

## 6. 대시 또는 회피 기획

### 6-1. 일반 대시 (Shift)

- 대시 입력: Shift (누르는 순간). 처음부터 보유하며 신성이 아니고 해금 대상이 아니다. 애니메이션은 Dash다.
- 대시 방향: 좌우 입력 중이면 그 방향으로 대시한다. 이때 캐릭터가 바라보는 방향도 그 방향으로 바뀐다. 좌우 입력이 없으면 바라보는 방향으로 대시한다.
- 대시 거리·지속 시간·쿨타임: DashDistance, DashDuration, DashCooldown. 값 미정 (09에서 확정)
- 무적 시간: 없다. 대시 중에도 피격 판정을 받는다.
- 공중 대시: 가능하다. 공중에서는 착지 전까지 **1회만** 사용할 수 있고, 착지하면 초기화된다. 이 횟수 제한은 대시 쿨타임과 별개로 적용한다. (관련 값 AirDashMaxCount, 기본 1. 09_데이터 테이블에서 확정)
- 대시 가능 상태: Idle, Move, Jump(공중). 불가능 상태: Dash(중복 입력), Attack, Dead. 쿨타임 진행 중에도 불가능하다.
- 대시 중 충돌 처리: 지형 충돌은 유지한다. 적 충돌은 무시하며 적을 통과한다.

### 6-2. 이동 신성 (A, Z, X, C)

- 성격: 이동 신성이다. 종족(신)에 속하지 않는 공용 신성 체계(이동기·유틸)에 속하며, 종족 신성과 별개로 모험 중 획득한다. 각 마을의 메인 동선이 공용 능력을 열쇠로 쓰므로, 세 마을을 어느 순서로 공략해도 동일하게 쓰인다.
- 키 배정: A, Z, X, C 4개로 확정한다. 이동 신성 1종당 키 1개를 배정한다.
- 대표 4종(확정)과 세부:

| 이동 신성 | 동작 | 미정 항목 |
|---|---|---|
| 체공 | 키를 누르는 동안 약 1초(가안) 공중에 머문다. 체공 중 미세한 좌우 이동을 허용한다 | 공중 사용 횟수 (미정. 05_맵·진행 작성 시 04_능력 게이트를 갱신해 확정, 값은 09) |
| 벽 붙기 | 벽에 붙는다 | 발동 방식(키 입력인지 자동인지) (04_능력 게이트에서 결정) |
| 신성 대시 | 신성으로 하는 대시. 일반 대시와 별개 능력이다 | 거리·지속 시간 값 (09에서 확정) |
| 비행 | 최후반 해금. 지속 중 신력을 크게 소모하며, 신력이 소진되면 하강한다 | 초당 소모량 값 (09), 하강 중 조작 (05_맵·진행 작성 시 04_능력 게이트를 갱신해 확정) |

- 종류·개수: 위 4종은 후보이며 추가 종류는 미정 (05_맵·진행·08_스테이지 설계에서 판단). 쿨타임 값은 미정 (09에서 확정)
- 신력: 비행은 지속 중 신력을 크게 소모하며 소진 시 하강한다. 나머지 이동 신성의 신력 소모 여부는 미정이다 (05_맵·진행 작성 시 04_능력 게이트를 갱신해 확정, 값은 09)
- 가능 조건: 해당 이동 신성을 배웠고 쿨타임이 끝났을 때. 신력을 소모하는 이동 신성은 남은 신력이 소모량 이상일 때만 발동한다.
- 불가능 조건: 미습득, 쿨타임 진행 중, 신력 부족(소모형에 한함), Dead 상태. 기본 허용 상태는 9절 표를 따른다(Idle·Move·Jump(공중)·Attack 가능, Dash·Dead 불가). 종류 확정 후 신성별 세부(공중 사용 제한 등)를 조정한다 (04_능력 게이트에서 결정)
- 상태 전환: 사용 시 Attack 상태로 전환한다. 신성별 세부는 미정 (04_능력 게이트·03_전투 시스템 참조)

이동 신성은 일반 대시와 다른 능력이다. 일반 대시는 처음부터 가진 기본 능력이고, 이동 신성은 습득 대상이며 능력 게이트 통과 조건으로 쓰인다.

## 7. 아이템 사용 기획

아이템과 인벤토리 구조가 정해지지 않았다. 이 절의 모든 항목이 미정이다. (06_아이템·보상에서 결정) 미정 항목은 아이템 사용 입력, 사용 가능한 아이템, 사용 조건, 사용 결과, 수량 감소 여부, 사용 실패 조건, UI 갱신 조건이다.

아이템 사용 키는 06_아이템·보상에서 구조가 확정된 뒤 3절 입력 목록에 추가한다. 그 전까지 임의의 키를 배정하지 않는다.
횟수 제한형 회복 수단(03_전투 시스템 7절)이 아이템으로 확정되면 이 절과 3절 입력 목록, 11절 표시 항목에 추가한다.

## 8. 상호작용 기획

- 상호작용 입력: F (누르는 순간). 가능 거리는 InteractionRange이며 값 미정 (09에서 확정)
- 상호작용 대상: NPC(대화), 제단(체크포인트 거점), 수업, 그 외 오브젝트. 대상 목록 확정은 05_맵·진행에서 한다.
- 가능 상태: Idle, Move. 불가능 상태: Jump(공중), Dash, Attack, Dead
- 상호작용 결과: 대상별로 대화 시작, 저장, 수업 수강으로 분기한다. 제단은 저장, HP 완전 회복(03_전투 시스템 7절), 신력 완전 충전, 회복 수단 충전을 함께 처리한다. 가호 전환은 상호작용 대상이 아니며 8-1절의 Tab 입력으로 처리한다. 세부는 05_맵·진행과 07_UI 흐름에서 정의한다.
- 우선순위 규칙: 범위 안에 여러 대상이 있으면 가장 가까운 대상을 우선한다. 상호작용 안내 UI를 표시하며 형식은 07_UI 흐름에서 결정한다.

### 8-1. 가호 전환

**목적**: 전투 중에도 세 가호의 신성을 이어 쓰게 해 전투 깊이를 만든다. 세 유틸 신성을 잇는 조합(장막 설치 → 전환 → 난무 등)이 이 조작 위에서 성립한다 (00_게임 콘셉트 4-2절).

- 기본 규칙: 가호 전환은 **장소 제약이 없다**. 전투 중을 포함해 언제 어디서나 가능하다. 제단 전용 기능이 아니며, F 상호작용으로 전환하지 않는다.
- 입력: **Tab**. 누르는 순간 캐릭터 주위 세 방향으로 가호(여우·늑대·용) 이펙트가 펼쳐지고, **방향키로 하나를 선택**한다. 세 가호와 세 방향의 대응은 미정 (07_UI 흐름에서 결정)
- 선택 중 슬로우: 선택이 열려 있는 동안 게임 시간이 느려진다. 슬로우 배율(SwitchTimeScale)과 선택 최대 지속 시간(SwitchWindowMaxTime)은 미정 (09_데이터 테이블에서 확정)
- 취소 조건: 선택 없이 Tab을 다시 누르거나, 선택 최대 지속 시간이 지나면 취소한다. 취소하면 발현 중인 가호를 그대로 두고 전환 쿨타임을 시작하지 않으며 게임 시간을 원래 배속으로 되돌린다. 취소 규칙의 세부는 07_UI 흐름에서 결정한다.
- 전환 쿨타임: 전환이 성립하면 BlessingSwitchCooldown 동안 다음 전환 입력을 막는다. 수 초 수준의 가안이며 값은 미정 (09_데이터 테이블에서 확정). 피격 직전에 늑대로 전환해 가호 패시브(받는 데미지 감소)만 취하는 프레임 단위 악용을 막기 위한 장치다.
- 가능 상태: Dead를 제외한 모든 상태(Idle, Move, Jump(공중), Dash, Attack)에서 입력할 수 있다. Dead 상태의 입력은 무시한다 (9절)
- 전환 결과: 발현 중인 가호가 바뀌고 Q/W/E/R/S의 공격 신성 5개와 가호 패시브가 새 가호의 것으로 교체된다. 가호를 전환해도 신성 쿨타임과 남은 신력은 유지된다. 전환으로 쿨타임이나 신력 소모를 회피할 수 없다 (03_전투 시스템 4-2절)
- 지속형·채널링 신성이 진행 중이면 전환 시 그 효과를 즉시 종료한다(남은 시간 미반환). 단 번개창의 전기 장막은 지속 시간까지 유지된다 (04_능력 게이트 9절)
- 이미 발현 중인 가호를 다시 선택하면 전환으로 처리하지 않는다. 취소와 같게 처리하고 전환 쿨타임을 시작하지 않는다.

## 9. 캐릭터 상태와 조작 가능 조건

상태는 Idle, Move, Jump(공중), Dash, Attack, Dead 6종이다. 상태를 임의로 추가하지 않는다. 피격 경직을 두지 않으므로 Hit 상태는 두지 않는다.

| 상태 | 좌우 이동 | 점프 | 기본공격 | 공격 신성 | 이동 신성 | 일반 대시 | 상호작용 |
|---|---|---|---|---|---|---|---|
| Idle | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 |
| Move | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 |
| Jump(공중) | 가능 | 더블점프 보유 시 1회 | 가능 | 가능 | 가능 | 가능 | 불가능 |
| Dash | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 |
| Attack | 가능 | 가능 (모션 캔슬) | 입력 버퍼로 처리 | 가능 (모션 캔슬) | 가능 (모션 캔슬) | 불가능 | 불가능 |
| Dead | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 |

가호 전환(Tab)은 이 표의 대상이 아니다. Dead를 제외한 모든 상태에서 입력할 수 있고, 제약은 전환 쿨타임뿐이다 (8-1절). 전환은 상태를 바꾸지 않는다.

피격 처리: 피격은 상태를 전환하지 않는다. 조작도 차단하지 않는다. 처리 내용은 HP 감소, 공격받은 반대 방향으로의 가벼운 넉백, 무적 시간(HitInvincibleTime) 부여, 피격 연출 재생이다. 무적 시간 값은 미정 (09_데이터 테이블에서 확정). 넉백 거리를 포함한 피격 세부 규칙은 03_전투 시스템에서 정의한다.
사망(Dead) 상태에서는 모든 플레이 입력을 무시한다.

상태 전환 조건:

| 전환 | 조건 |
|---|---|
| Idle ↔ Move | 좌우 이동 입력 발생 시 Move, 입력 해제로 이동 속도가 0이 되면 Idle |
| Idle·Move → Jump(공중) | 지면에서 Space 입력 |
| Idle·Move → Jump(공중) | 지면 이탈(낙하 시작). 접지 유예(코요테 타임) 안에는 지상 점프를 허용한다 |
| Jump(공중) → Idle·Move | 지면 착지. 이동 입력이 있으면 Move, 없으면 Idle |
| Idle·Move·Jump(공중) → Dash → 복귀 | Shift 입력과 쿨타임 종료로 진입, 대시 지속 시간 종료로 Idle·Move·Jump(공중)로 복귀 |
| Idle·Move·Jump(공중) → Attack → 복귀 | D 또는 Q/W/E/R/S 입력과 쿨타임 종료로 진입, 공격 애니메이션 종료로 복귀 |
| 모든 상태 → Dead | 체력이 0 이하 |

## 10. 애니메이션 연결

| 상태 | 애니메이션 | 재생 조건 |
|---|---|---|
| Idle | Idle | 지면에 있고 이동 입력이 없다 |
| Move | Move | 지면에 있고 이동 속도가 0보다 크다 |
| Jump(공중) | Jump / Fall | 상승 중이면 Jump, 하강 중이면 Fall |
| Dash | Dash | Dash 상태 진입 |
| Attack | Attack | Attack 상태 진입. 기본공격은 Attack 단일 애니메이션이며 신성별 구분은 미정 (신성 목록 확정 후 아트에서 결정) |
| Dead | Dead | 체력 0 이하 |

- 피격 연출은 상태와 무관한 오버레이(스프라이트 플래시 등)로 처리한다. 별도 피격 애니메이션 상태를 두지 않는다.
- 애니메이션 이벤트를 사용한다. 기본공격 판정은 애니메이션 이벤트 시점에 생성한다.
- 전환 우선순위: Dead > Dash > Attack > Jump(공중) > Move > Idle. 상위가 하위를 끊고 재생한다. 피격은 이 우선순위에 관여하지 않으며 진행 중인 애니메이션을 끊지 않는다.
- 더블점프는 Jump 애니메이션을 처음부터 다시 재생한다. 별도 애니메이션을 둘지는 미정 (아트 방향 확정 후 결정).

## 11. UI 안내

세부 화면 구성은 07_UI 흐름에서 정의한다. 이 절은 조작이 요구하는 표시 항목만 적는다.

- 쿨타임 표시: 공격 신성 5개, 이동 신성, 일반 대시, 가호 전환의 남은 쿨타임을 표시한다.
- 가호 선택 표시: Tab 입력 시 캐릭터 주위 세 방향에 여우·늑대·용 가호를 표시한다. 형식과 방향 대응은 미정 (07에서 결정)
- 신력 표시: 남은 신력을 게이지로 HUD에 표시한다. 신력 소모와 충전 시 갱신한다.
- 가호 표시: 현재 발현 중인 가호와 그 가호의 신성 5개를 HUD에 표시한다.
- 상호작용 안내: 상호작용 가능한 대상이 범위 안에 있으면 안내를 표시한다.
- 입력 불가 안내: 쿨타임 중 입력과 미습득 신성 입력에 짧은 피드백을 표시한다. 형식은 미정 (07에서 결정)
- 조작 안내: 표시한다. 표시 시점과 형식은 미정 (07에서 결정). 아이템 수량 표시는 미정 (06·07에서 결정), 튜토리얼 메시지는 미정 (08_스테이지 설계에서 결정)

| 가호 선택 중 피격 | 피격 처리를 정상 진행한다. 피격은 상태를 전환하지 않으므로 선택도 끊기지 않는다. 선택 창을 강제로 닫을지는 미정 (07_UI 흐름에서 결정) |
| 가호 선택 중 일시정지·UI 팝업 열림 | 선택을 취소하고 게임 시간을 원래 배속으로 되돌린다. 전환 쿨타임은 시작하지 않는다 |
| 가호 전환 UI 표시 중 신성 키 입력 | 입력을 무시한다. 신력·쿨타임을 소모하지 않는다 |
| 지속형 신성 진행 중 Tab 전환 | 진행 중 효과를 즉시 종료한 뒤 전환한다. 전기 장막만 유지된다 |
| UI 팝업이 열린 상태의 조작 입력 | 이동·점프·공격·신성·대시·상호작용 입력을 모두 무시한다. 팝업 닫기 입력만 처리한다 |
| 일시정지 중 조작 입력, 로딩 중 입력 | 플레이 입력을 무시한다. 일시정지 중에는 메뉴 입력만 처리한다. 로딩 완료 전 입력을 저장하지 않는다 |
| 좌우 방향키 동시 입력 | 이동 입력이 없는 것으로 처리한다 |
| 같은 프레임에 여러 행동 입력 | 우선순위는 대시 > 공격·신성 > 점프 > 이동으로 처리한다 |
| 키 연타·중복 입력 | 쿨타임과 상태 검사로 차단한다. 입력 버퍼(선입력)는 채택한다. 버퍼 시간 값은 미정 (09_데이터 테이블에서 확정) |
| 키 재매핑에서 두 행동에 같은 키 배정 | 배정을 거부하고 기존 배정을 유지한다. 안내는 07에서 결정. 게임패드 연결·해제 처리 방침도 미정 (07_UI 흐름에서 결정) |

## 13. 필요한 데이터

## 14. AI 구현 요청용 프롬프트

**목적**
2D 메트로배니아의 플레이어 조작 시스템을 구현한다. 입력을 상태·행동·애니메이션으로 연결하고, 가능·불가능 조건을 코드에 반영한다.

**환경**
Unity 6, C#, PC 단독 실행, 싱글 플레이, 2D 횡스크롤 픽셀아트. 입력은 키보드 우선이며 게임패드 확장을 전제로 키 재매핑이 가능한 구조로 만든다.

**요구 기능**

1. 좌우 이동: 방향키. 월드 좌표 기준 2방향. 공중에서도 방향 전환을 허용한다.
2. 가변 점프: Space를 누르는 순간 점프를 시작하고, 누르는 동안 상승을 유지하며, 떼면 상승을 종료한다.
3. 더블점프: 해금형 능력. 보유 시 공중에서 1회 추가 점프하고, 착지 시 횟수를 초기화한다.
4. 기본공격: D. 근접 1타 공격. Attack 상태로 전환하고 BasicAttackHitTiming 시점에 판정을 생성한다. 공격 중 이동을 허용한다. 연속 입력 시 같은 공격을 BasicAttackCooldown 간격으로 반복하고, 모션·쿨타임 중 재입력은 InputBufferTime 동안 저장했다가 가능해지면 1회 실행한다.
5. 공격 신성: Q/W/E/R/S. 발현 중인 가호의 배운 신성만 사용한다. 쿨타임과 남은 신력을 함께 검사하고, 사용이 성립하면 DivinityCost만큼 신력을 차감한다. 신력은 가호와 무관하게 하나를 공유한다. MVP 단계에서는 신력 검사를 비활성화하고 쿨타임만 검사한다 (00_게임 콘셉트 7절).
6. 이동 신성: A/Z/X/C. 종족 신성과 분리된 공용 신성 체계로 습득한다. 종류가 확정되지 않았으므로 습득 여부·쿨타임·신력 검사 구조만 만든다. 비행은 지속 중 신력을 소모하고 소진 시 하강하는 처리로 만든다.
7. 일반 대시: Shift. 처음부터 보유하는 기본 능력이며 쿨타임을 가진다. 좌우 입력이 있으면 그 방향, 없으면 바라보는 방향으로 대시한다. 무적은 없고, 공중에서도 사용하며, 대시 중 적 충돌을 무시하고 지형 충돌은 유지한다.
8. 상호작용: F. 범위 안에서 가장 가까운 대상과 상호작용한다. 제단은 저장, HP 완전 회복, 신력 완전 충전, 회복 수단 충전을 처리한다. 제단에서 가호를 전환하지 않는다.
9. 가호 전환: Tab. 장소 제약 없이 전투 중에도 가능하다. Tab 입력 시 세 방향 선택을 열고 게임 시간을 SwitchTimeScale로 느리게 하며, 방향키 입력으로 가호를 확정한다. 선택 없이 Tab 재입력 또는 SwitchWindowMaxTime 경과 시 취소한다. 전환이 성립하면 BlessingSwitchCooldown을 시작한다. 전환해도 신성 쿨타임과 남은 신력은 유지한다.
10. 상태 머신: Idle, Move, Jump(공중), Dash, Attack, Dead 6종. 상태를 추가하지 않는다. 가호 전환은 상태를 바꾸지 않는다.
11. 피격 처리: 상태를 전환하지 않는다. HP를 감소시키고, 공격받은 반대 방향으로 가벼운 넉백을 주고, HitInvincibleTime 동안 무적을 부여하고, 상태와 무관한 오버레이 연출을 재생한다. 조작을 차단하지 않는다.

**데이터 구조**

- 플레이어 능력치: MoveSpeed, AirControlRatio, JumpPower, JumpHoldMaxTime, MaxAirJumpCount, DashDistance, DashDuration, DashCooldown, HitInvincibleTime, KnockbackDistance, KnockbackDuration, InputBufferTime, CoyoteTime, InteractionRange
- 가호 전환 데이터(BlessingSwitchData): BlessingSwitchCooldown, SwitchTimeScale, SwitchWindowMaxTime
- 기본공격 데이터: BasicAttackDamage, BasicAttackRange, BasicAttackCooldown, BasicAttackHitTiming. AttackRange·AttackDamage·AttackCooldown·AttackHitTiming이라는 이름은 적 전용이므로 플레이어에 쓰지 않는다
- 보유 능력 목록: 능력 ID 집합 (더블점프, 이동 신성 포함)
- 가호 정의: 가호 ID, 소속 신(여우·늑대·용), 소속 신성 ID 5개
- 신성 정의: 신성 ID, 등급(초급·고급·강림), 쿨타임(DivinityCooldown), 신력 소모량(DivinityCost)
- 신력 데이터: MaxDivinePower, CurrentDivinePower, PurifyChargeAmount, ShrineChargeAmount. 자연 회복은 구현하지 않는다
- 모든 수치는 외부 데이터로 분리하고 하드코딩하지 않는다

**처리 흐름**

1. 입력을 행동 이름으로 받는다. 키 코드를 직접 참조하지 않는다.
2. 현재 상태와 쿨타임, 보유 능력을 검사한다.
3. 조건을 만족하면 상태를 전환하고 해당 행동을 실행한다.
4. 상태에 대응하는 애니메이션을 재생한다. 공격 판정은 애니메이션 이벤트로 생성한다.
5. 행동이 끝나면 이동 입력 유무와 접지 여부에 따라 Idle, Move, Jump(공중) 중 하나로 돌아간다.

**예외 조건**

- Dead 상태에서 모든 플레이 입력을 무시한다. UI 팝업, 일시정지, 로딩 중에도 플레이 입력을 차단한다.
- 쿨타임 중 입력, 미습득 신성 입력, 발현 중이 아닌 가호의 신성 사용은 모두 무시한다. 입력 버퍼(선입력)와 접지 유예(코요테 타임)는 채택하되, 시간 값은 하드코딩하지 말고 외부 데이터로 받는다.
- 신력이 DivinityCost보다 적으면 신성 사용을 거부한다. 신력을 차감하지 않고 쿨타임도 시작하지 않으며, 부족 표시를 요청한다. 비행 중 신력이 0이 되면 비행을 종료하고 하강시킨다.
- 더블점프 미보유 또는 횟수 소진 상태의 공중 Space 입력, 대시 중 대시 재입력, 대상 없는 F 입력을 무시한다.
- 좌우 동시 입력은 이동 없음으로 처리한다. 같은 프레임 다중 입력의 우선순위는 대시 > 공격·신성 > 점프 > 이동이다.
- 가호 전환은 장소로 차단하지 않는다. 전환 쿨타임(BlessingSwitchCooldown) 진행 중의 Tab 입력만 무시한다. 선택 중 Tab 재입력·시간 초과·이미 발현 중인 가호 선택·일시정지는 모두 취소로 처리하고, 취소 시 전환 쿨타임을 시작하지 않으며 게임 시간을 원래 배속으로 되돌린다.
- 피격은 진행 중인 행동을 취소하지 않는다. 공격 중 피격돼도 공격을 끝까지 진행한다.
- 공중 대시는 착지 전까지 1회만 허용하고, 초과 입력은 무시하며, 착지 시 초기화한다.
- Attack 상태 중 점프·공격 신성·이동 신성 입력은 남은 공격 모션을 끊고 즉시 실행한다(캔슬 허용). 판정 발생 시점 이전에 캔슬되면 그 공격의 판정은 생성하지 않는다.
- 이동 신성의 신성별 세부 처리는 미정이다. 임의로 구현하지 말고 TODO 주석으로 남긴다.

**출력 형식**
Unity 6용 C# 스크립트. 입력, 이동, 전투, 상태 머신, 능력치를 각각 분리한 구조로 작성한다. 입력은 PlayerInputController, 이동은 PlayerMovement, 전투는 PlayerCombat, 상태는 PlayerStateMachine, 능력치는 PlayerStats로 책임을 나눈다. 데이터와 로직을 분리하고, 수치는 ScriptableObject 등 외부 데이터로 뺀다. 미정 항목은 값을 채우지 말고 TODO 주석으로 남긴다.
