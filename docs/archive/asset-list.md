# 튜토리얼 이미지 목록과 규격

튜토리얼 흐름(캠프 → 일반 전투 → 거대 존재 등장 → 죽음 카드 → 사망 컷신 → 상속 스킬로 탈출) 기준. 튜토리얼에서 죽는 동료는 궁수로 가정.

## 규격

- 캐릭터·적·카드 아트: 투명 배경 PNG (단색 배경으로 생성한 뒤 배경 제거)
- 배경: 16:9, 1920×1080
- 게임용 이미지는 레이어별로 따로 만든다. `reference/images`의 전투 화면(04·05)은 분위기 목업일 뿐 그대로 쓸 수 없다.

## 진행 순서

1. 캐릭터 시트부터. 이후 모든 그림의 레퍼런스가 된다.
2. 배경 + 전투 스프라이트 → 전투 화면 조립.
3. 카드 아트와 컷신은 전투가 돌아가는 걸 확인한 뒤.
