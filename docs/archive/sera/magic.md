## 2. 레벨과 마도석
- **마도석**: 반짝이는 보라 결정. 숨은 곳·서브 퀘스트·강자 보스 보상. 게임 전체 약 40개(2장 10, 3장 10, 4장 10, 5장 6 + 학교 서브 4).
- 비용: 일반마법·고급마법 Lv2 3 / Lv3 5, 대마법 Lv2 5 / Lv3 8. 전부 올리려면 66개 → **고르는 재미**.
- 레벨은 **마법서**(일시정지 → 마법서)에서 언제든 올린다. 올릴 때 짧은 연출(책이 빛나고 등급 별이 하나 켜짐).

## 3. 장착
- A·S 칸: 불기둥·화염 폭풍·불꽃 방벽 중 둘. F 칸: 유성 낙화·불사조 중 하나.
- 처음엔 A = 불기둥, S = 화염 폭풍(1장과 같은 느낌). 방벽을 배우면 마법서에서 바꿔 끼운다(배운 직후 안내).
- 키: A·S·**F**(새 키), 패드 LB·RB·R3, 터치 버튼(작은 버튼 2개 + 대마법 버튼).

## 4. 마법 배우기 (수업)
- **수업 게시판**: 학교 중앙 홀(`s_hall`)의 게시판 개체 `class_board`. ↑로 열면 "마법 배우기" 창.
  - 왼쪽: 수업 목록 — 마법 이름·등급(일반마법/고급마법/대마법)·담당 교수. 상태: 🔒 잠김(조건 문구 표시) / 신청 가능 / 진행 중 / 습득.
  - 오른쪽: 고른 수업의 설명, 효과, **수업 과정**(퀘스트 단계), 보상.
  - "수업 신청" → 퀘스트 시작(동시에 하나만). 퀘스트창의 "수업" 칸에 들어간다.
- 1장에서 배운 3종(불기둥·화염 폭풍·부양)은 게시판에 "습득"으로 표시(1장 실습이 수업이었던 것으로).
