# 5장 기획서 — 별의 마녀 (목표 약 2시간 20분)

> 정본: [`bible/`](bible/README.md). 공통 시스템: [`systems2.md`](systems2.md). 마법: [`magic.md`](magic.md).
> 1~6절은 **뼈대(바꾸지 않음)**, 7절 이후는 제작하며 채우는 세부.
> 사용자 지정(바꾸지 않음): 별의 마녀와의 서사, **학교 중심 + 이전 모든 강자 등장 + 모든 맵 배경**. 별의 마녀 = 모든 인물을 합한 만큼 강함. 진실(세라의 힘·구슬 흡수 = 리라의 목적, 자신을 막아 줄 자신보다 강한 존재, 바깥 신들로부터 세계를 지키려고). 그 뒤 **막을 수 없는 침공 → 모든 것이 파괴되는 압도적 절망(땅울림 느낌) → 극적인 극복**. 교장이 여러 번 돕는다.

## 2. 줄거리 비트
1. **축제 준비**(학교, 폭풍 전 고요): 친구·교수와 마지막 일상(서브 다수). 불사조 수업. 오필리아의 별 관측에서 "별 하나가 너무 가깝구나~". 아스트리드가 혼자 창립자의 사진을 봄(창립자와 두 소녀 — 리라).
2. **리라의 방문**: 축제 저녁, 학교의 큰 결계가 유리처럼 깨지며 리라가 걸어 들어옴. 아스트리드와 대면 — "꼬마 아스트리드, 많이 늙었네." / "선배는 하나도 안 변했군요." 아스트리드가 학생들을 감싸며 맞서지만 리라가 가볍게 꺾음(교장의 진짜 힘이 잠깐 보이는 연출 → 그래도 짐). 리라: "나를 넘어 보렴, 나의 별." **별의 시련 4곳**.
3. **네 지역 순회**(순서 자유, 전이진): 
   - 제국: 레오니와 함께 **별 기사**(레오니를 흉내 낸 구조체) — 2장 브론의 새 검.
   - 엘프 숲: 엘라리엔의 엄호 아래 **별 궁수** — 세계수 꼭대기.
   - 신전: 아우렐리아와 함께 **별 창기사** — 종루.
   - 학교: 이졸데·엠버린과 함께 **별의 정원**(학교 곳곳에 내린 별 퍼즐).
   각 지역 끝에 **별의 열쇠**, 그리고 그 강자의 한마디(최종전 복선).
4. **별의 탑**(`st_tower_*`): 학교 위에 솟은 탑. 별자리 발판(별을 밝히면 이어지는 길), 중력 반전 방 1개, 리라의 기억 조각(창립자·아스트리드와의 과거)이 벽에.
5. **리라 결전**(`st_tower_top`): 4페이즈 — ① 별 마법(아스트리드식) ② 별검(레오니식: 잔상·일섬) ③ 별화살(엘라리엔식: 예고선 저격) ④ 별창(아우렐리아식: 돌진) → 마지막 "별의 비". 
6. **진실**: 쓰러진 리라가 말함 — 갓난 세라에게 심은 **별의 씨앗**, 신계 보물 **소문**, 구슬. 이유: 바깥 신들이 가장 강한 그릇(리라)을 문으로 삼으면 세계가 끝나니, 자신을 막아 줄 자신보다 강한 존재가 필요했다. 너울 격노("내 구슬을 미끼로 썼다고?!"), 세라의 분노와 혼란. 아스트리드 "…알고 있었어요. 확신은 없었지만."
7. **침공**: 그 순간 하늘이 갈라지고 리라가 **문**으로 붙잡혀 하늘로. 지평선을 메운 **하얀 거신들의 행진**(땅울림). 
8. **절망**(`r5_*`): 무너지는 학교에서 학생들을 데리고 도망치는 플레이. 거신에게 공격이 통하지 않음(맞혀도 "…" 흠집도 안 남). 제국·숲·신전에서 오는 소식(통신 수정 구슬): 레오니의 검이 부러짐, 엘라리엔의 화살이 튕김, 아우렐리아의 창이 부서짐. 아스트리드가 마지막 결계로 학생들을 감싸고 쓰러짐. 세라도 무너진 앞마당에서 쓰러짐.
9. **아홉 꼬리**(`st_void`): 어둠. 너울 본모습과의 대화 — 처음으로 "세라야." / "그릇이라고 부르지 마." / "…그래. 너는 나의 짝이다." 구슬이 완전히 울려 **꼬리 9개** → 구미호 완전 빙의(최종 구간 상시 여우 모드).
10. **반격**: 깨어난 세라. 강자들이 하나씩 다시 일어섬(레오니: 브론의 새 검 / 엘라리엔: 세계수의 가지로 만든 활 / 아우렐리아: 루멘의 마지막 빛 / 이졸데·엠버린·피피·교수들: 결계). 거신 위를 달려 오르는 구간(`st_colossus_*`). 아스트리드가 마지막 힘으로 세라를 하늘로 쏘아 올림(교장이 돕는 장면 5).
11. **하늘의 문**(`st_skygate`): 문이 된 리라와 최종전 — 모든 동료의 지원 공격. 푸른 불(잠재우는 불)로 문을 닫고 리라를 붙잡아 끌어냄. "너를 막는 건, 너를 구하는 거야."
12. **에필로그**: 다 같이 다시 세우는 학교(짧은 자유 이동 + 인물들과 마지막 대화). 리라는 별빛을 잃고 처음으로 늙기 시작 — 아스트리드와 차. 너울: "구슬은… 이제 안전하게 뺄 수 있지만. 조금만 더 맡겨 두마." **엔딩 크레디트**(인물 행진) → 타이틀 "계속 탐험하기".

## 5. 퍼즐·탐험
- 별자리 발판: 별(불을 붙이는 점)을 밝히면 별자리 선이 발판이 됨. 순서는 벽의 별 그림.
- 중력 반전 방 1개(별의 탑 4층): 별 문양을 지나면 위아래가 바뀜(짧게, 쉬운 구성).
- 절망 구간: 길이 계속 무너짐(쫓기는 연출), 학생들을 데리고 문 닫기(NPC 따라오기).
- 숨은 것: 마도석 6, 수호의 깃털 1, 리라의 기억 조각 7(엔딩 뒤 교장실에서 다시 볼 수 있음).

### 7.3 새 개체·소품·테마 (2단계)
- `st_bridge` 별자리 다리: `pts`(타일 점들)를 잇는 한쪽 통과 발판. `on_if` 조건이 서면 별빛이 점에서 점으로 0.9초에 달리며 이어진다. 꺼져 있을 땐 점선. 도달 검사기용으로 같은 `on_if`의 별빛 상승 기류를 함께 둔다(날개가 있으면 그걸로도 오를 수 있음).
- `st_follow` 따라오는 학생들: 세라 뒤를 줄지어 걷고, 높은 턱·먼 거리는 순간이동. 대본 `actor("followers").scatter()/gather()/say(i, 글)`.
- 소품: `st_star_door`(문 개체 `style="st"`와 겹쳐 쓰는 별의 문, `open_if`·`done_if`·`col`), `st_flip_sigil`(중력 반전 문양), 축제 가게 지역판(`kingdom`·`elf`·`temple`), 공통 `vflip`, 받침대 `lit_if`(열쇠가 꽂힘), 기억 수정 `seen`(본 기억은 밝게).
- 테마: `st_kingdom`·`st_elf`·`st_temple`·`st_garden`(리라의 별하늘 + 시련의 별줄기 + 각 지역의 밤 실루엣 3층), `dawn`(복숭앗빛 아침, 푸른 실로 꿰맨 하늘의 흉터, 비계 두른 부러진 시계탑, 다시 거는 축제 등불), `star_flip`(별하늘·층을 위아래로 뒤집어 그림).
- 배경 공통: 세로로 긴 방에서도 지평선·바닥이 카메라가 방 맨 아래일 때 화면 아래에 오도록 층 기준선(`_bot`)을 Parallax 세로 배율로 계산.

## 15. 요청 사항 (공용 파일 — 5장 담당은 고치지 않음)
1. **`game/player/player_visual.gd` `_draw_fox_tail`**: 꼬리 9개(5장 최종 구간 상시 여우 모드)에서 꼬리 다각형이 꼬여 `ERROR: Invalid polygon data, triangulation failed.`가 매 프레임 쏟아짐(그림은 그 꼬리만 빠짐). 폭 방향을 꼬리 방향에 맞춰 돌리면 해결:
   ```gdscript
   	var w := 4.0
   	var nrm := (tip - base).normalized().orthogonal() * w
   	var pts := PackedVector2Array([base - nrm * 0.5, mid - nrm, tip, mid + nrm, base + nrm * 0.5])
   ```
2. **`game/fox/neoul_pet.gd` 152행 꼬리 다각형**: 꼬리 4개 이상에서 같은 오류(4장 끝부터). 같은 방식으로:
   ```gdscript
   		var mid := tail_base.lerp(tail_tip, 0.5)
   		var nrm := (tail_tip - tail_base).normalized().orthogonal() * 2.0
   		draw_colored_polygon(PackedVector2Array([tail_base - nrm, mid - nrm * 1.5, tail_tip, mid + nrm * 1.5, tail_base + nrm]), fur)
   ```
3. (선택) `game/ui/map_screen.gd` 지역 이름 사전: 5장 환상 방은 영역 `vision`(장면 중에만 머묾, 지도를 열 수 없음)이라 이름이 필요 없지만, 넣는다면 `"vision": "같은 시각"`.
4. 2~4장 인물(`leonie`·`elarien`·`aurelia`)의 그림·초상화는 각 장 데이터에 있다는 전제로 쓴다. 이 브랜치 단독 실행에서는 학생 모습으로 대신 보인다(통합 뒤 정상).

## 16. 남은 문제 · 다음에 다듬을 것
- 시험 시나리오에서 하늘의 문 체력을 한꺼번에 깎을 때(`ehpf`) 한 번 `ERROR: Parameter "body->get_space()" is null.`(엔진 오류, 대본 오류 아님)이 찍힘. 실제 플레이 경로에서는 재현하지 못함.
- 어둠의 각성 꼬리(1단계 그림)가 꽃잎처럼 보이는 편. 중간 층 거신이 밝은 회색이라 무너진 학교 실내 방에서 눈에 많이 띔(의도한 압박감이지만 더 어둡게 할 여지).
- 별의 시련 결투장의 큰 구조체·리라·하늘의 문은 초보자 난이도로만 시험(보통 난이도 수치 밸런스는 체력값만 정본대로, 실제 손 플레이 시간은 미측정 — 13절은 추정).
- 거신 타기(`st_colossus_2`)의 실제 조작 통과는 1단계 시험장(`dev_st_ride`)에서만 확인. 2단계 방에서는 장면·트리거 흐름만 시험.
- 2~4장 방에 별의 시련을 덧붙이는 대신 시련 방을 새로 만들었다(제국·세계수·대신전의 밤 테마). 통합 뒤 원하면 각 장의 전이진 도착 방에 `st_star_door`(문간으로 가는 별의 문)를 덧붙일 수 있다.
