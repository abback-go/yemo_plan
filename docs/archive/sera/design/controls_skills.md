# 조작·스킬 재설계 — 결정 기록 (작업 중)

> 사용자와 Claude가 상의해 정한 것. 스토리·인물·대사 기획(GPT)과 별도로 진행하며, 확정되면 GPT 인계서 양식 B로 옮겨 공유한다.

## 6차 변경 — 전투 개편: 불 마법사 (2026-10-05) · 가장 우선

**발톱 근접 공격 삭제.** 마녀 컨셉에 맞게 기본 공격도 불덩이를 던진다. 원칙: **평소 = 순수한 불 마법사(붉은 불)**, **변신 중 = 여기에 여우 효과가 더해짐(푸른 여우불 + 여우 무늬)**.

| 항목 | 내용 |
|---|---|
| 기본 공격 X | 사이퍼즈 타라 '홍염화' 느낌. 세라 둘레에 **불덩이 3개가 늘 떠서 돈다** → X마다 하나를 손으로 끌어와 던짐. 1타 오른손 · 2타 왼손 · **3타 = 마지막 하나가 부풀어 두 손으로 던지는 큰 덩이**. 셋을 다 쓰면 0.3초(변신 중 0.2초) 뒤 다시 3개가 피어남 |
| 기본 공격 수치 | 간격·피해·게이지는 옛 발톱과 같음(0.26초 / 변신 0.18초, 21 × 꼬리 배율 × 변신 1.3, 적중 대상마다 폭주 +0.5). 사거리 화면 절반쯤(300px, 꼬리마다 +6). 맞으면 작은 폭발(반경 15, 3타 ×1.5 — 반경 안 대상 모두 피해). ↑ 위로 · 공중 ↓ 비스듬히 아래로. 지형에 닿아도 터짐 |
| 기본 공격 레벨 | **꼬리 수 = 기본 공격 레벨**: 불덩이·폭발 크기 꼬리 1개 ×1.0 → 9개 ×1.72, 위력 ×1.0 → ×1.48 |
| 타격감 | 손을 떠날 때 손 섬광·불꽃 줄기, 맞으면 멈춤(0.045초, 3타 0.075초)·흔들림·**던진 방향으로 화면이 밀렸다 돌아옴**·불꽃 꽃잎이 활짝 터짐·불티·연기, 3타는 X자 빛살 + 확대. 공중에서 던지면 잠깐 떠 있음 |
| 변신 중 기본 공격 | 푸른 여우불 덩이(불꽃 귀 둘 + 여우 꼬리 자국), 맞은 자리에 여우 발자국 |
| 등급 이름 (2026-10-05) | **초급·중급·대마법 → 일반마법·고급마법·대마법**. 학교의 일반반·고급반(`docs/archive/sera/concept.md`)과 맞물림 — 일반반에서 일반마법, 고급반에서 고급마법을 배움. 설정 문서(magic.md·bible/progression.md·인계서·status.md)도 같이 바꿈(옛 3단계 초급·중급·고급 → 일반마법·고급마법·대마법) |
| 마법 | **6종**(일반마법 2 · 고급마법 2 · 대마법 2). **여우불 발톱 난무 삭제**. 쿨·피해는 그대로 |
| 파이어볼 (일반마법 A) | 세라 앞에 **세로 마법진**이 열리고, 세라보다 훨씬 큰 **태양 같은 불덩이**(메이플 플레임 위자드 화염구 느낌)가 솟아 **천천히 굴러가며**(약 2초) 닿는 적을 태우고(0.22초마다 4 × 레벨 배율) **끝에서 크게 폭발**(48 × 레벨 배율, 예전과 같음). 각성 = 더 크고 작은 불덩이 다섯이 부채꼴로 튐 |
| 불비 (일반마법 ↓A / S) | 하늘로 불덩이를 던져 올리면 터지며 앞쪽에 불비. 평소 = 붉은·주황, 변신 중 = **푸른 여우비**(하늘에 여우 얼굴 문양) |
| 너울 바인드 (대마법 D / R) | 평소 = **불로 빚은 붉은 여우 정령**(굵은 꼬리 셋, 온몸에서 불꽃, 불 밧줄로 묶고 공격) · 변신 중 = 푸른 아홉 꼬리 여우신(그대로) |
| 키 | 등급 키: A 파이어볼 / ↓A 불비 · S 열선 / ↑S 대유성 · D 바인드 / ↑D 불사조. 전용 키: A S · Q W · E R (F 비움) |
| 평소 모드의 여우 흔적 정리 | 대시·벽 점프의 여우 발자국, 2단 점프의 푸른 고리 → 평소엔 불, 변신 중에만 여우. 모든 마법의 시전 마법진에 변신 중 아홉 꼬리·여우 귀 문양 |
| 쿨타임 (2026-10-05 늘림) | 기본공격 위주 싸움 + 마법은 가끔 쓰는 큰 한 방. **파이어볼 30 · 불비 20 · 열선 60 · 대유성 90 · 불사조 120 · 바인드 120** (초). 피해는 나중에 따로 조정 |
| 확인할 것 | 쿨이 길어져 폭주 게이지가 마법보다 기본공격으로 주로 참(1분에 마법 ≈ 30%, 기본공격 쉬지 않고 맞히면 ≈ 110%) — 변신 빈도·봉인의 무게를 플레이로 확인. 파이어볼 태우기 피해(폭발 48은 그대로)도 함께 |

## 5차 변경 — 폭주 게이지 (2026-10-04)

**마나 삭제.** 마법의 제약은 쿨타임만. 세라의 넘치는 마력이 싸울수록(마법·발톱) 차오르는 **폭주 게이지**가 가득 차면, 원하는 순간 Space로 너울에게 넘겨 **변신(극딜 타임)**. 1장의 "구슬이 폭주를 붙잡는다 · 빙의 = 너울이 폭주를 받아 다스린다"를 조작으로 옮긴 것.

| 요소 | 내용 |
|---|---|
| 차오름 (게이지 100) | 마법 사용 일반마법 +3 / 고급마법 +8 / 대마법 +15 · 발톱 적중 +0.5. **시간·피격으로는 차지 않음**(싸워야만 참, 2026-10-04 수정) |
| 가득 찼을 때 | **변신 전까지 마법 봉인**(발톱·대시·이동은 됨). 아껴 둘 수는 있지만 마법을 포기하는 대가. 90%부터 게이지 깜빡임 경고, 봉인 중 마법 키 = 마력이 튀는 연출 + "마법 봉인 · Space 변신!" |
| 변신 | 꼬리 수에 따라 10~15초, 연장 없음, 끝나면 반동 없이 0부터 |
| 난이도 | 쉬움 ×1.3, 보통·어려움 같음 |
| 표시 | HUD "폭주" 게이지(붉게 짙어짐, 70% 눈금), 70%부터 세라 몸에 불티, 가득 차면 손의 불꽃이 커지고 "Space 변신!" |
| 쿨타임 | 파이어볼 3 · 여우비 10 · 열선 20 · 난무 25 · 대유성 30 · 불사조 90 · 바인드 90 (초) — 6차 변경에서 늘림 |
| 연금술 성장 | "마나 칸 +1" → **모든 마법 쿨 −10%**(최대 2번) |
| 불사조 부활 | 하트 **1칸**(각성 2칸)으로 부활 — 3칸·각성 가득은 너무 강했음 |
| 플레이테스트 확인 | 싸우는 동안 60~90초에 한 번 꼴로 차는지 · 대마법 +15로 변신 직후 다시 차는 속도가 과하지 않은지 |

## 4차 변경 (2026-10-04)

| 항목 | 변경 |
|---|---|
| 마력 충전 | **서서 집중(꾹) 삭제** — 멈춰야 하는 구조가 속도감을 해치고, 맞으면 끊기는 벌이 이중이었음 |
| 마나 채우기 | **발톱으로 적을 맞힐 때마다 ¼칸**(꼬리마다 +6%) + **가만히 있어도 4초에 1칸**(변신 중 2.5초). 처음·석등에서 쉴 때 가득 |

| 키 | 충전 키(F·V) 없음 → 등급 키 방식 전투 키 9개 (Z X C · A S D · Space G) |

## 2차 변경 — 시제품 체험 후 (2026-10-04) · 아래 표와 다르면 이것이 우선

| 항목 | 변경 |
|---|---|
| 키 | **Shift = 대시**, **C = 여우방패**, B(의태 돌진 전용 키) 없음. 마법 키 D 비움 → A S F / Q W / E R |
| 마나 | **시작 5칸 · 최대 7칸**(연금술 성장). 집중 1초에 1칸은 그대로 |
| 발톱 | 사거리 **모든 꼬리 단계에서 1.5배**(기본 45px, 꼬리마다 +2.25). 휘두를 때 손끝에 **커다란 여우손(불꽃 발 + 금 팔찌)** 이펙트 — 평소 붉은 불, 변신 중 푸른 불 |
| 의태 돌진 | 별도 키 삭제. **변신 중 대시 = 의태 돌진**: 세라보다 훨씬 큰 푸른 여우 정령이 감싸고 뛰어듦, 적·탄 관통 + 피해 + 무적, 대시와 같은 간격(추가 쿨 없음). **맵 게이트로 쓰지 않음**(여우 장막 삭제) |
| 여우방패 | 세라보다 훨씬 큰 **여우 정령이 방패로 앞을 1.5초 완전히 막음**(무적) → 방패를 내리며 **옆으로 세 줄 가로베기 반격**(위에서 아래 반원이 아님). 피해 = 기본 + 막은 피해(칸)마다 추가, 막을수록 할퀴기가 커짐. 안 맞아도 항상 할퀴기. 평소 붉은 불 / 변신 중 푸른 불 |
| 솟는 불꽃(D) | **삭제** → 공격 마법 **7종**(일반마법 2 · 고급마법 3 · 대마법 2) |
| 대유성(W) | **고급마법으로 내림**(마나 2칸, 쿨 약 8초, Lv3까지). 세라 뒤쪽 하늘의 마법진에서 **거대한 운석 한 방**이 보는 방향 앞 땅에 떨어져 **화면 앞쪽 절반**을 덮는 폭발 |
| 너울 바인드(R) | 화면에 **거대한 아홉 꼬리 여우신**이 나타남 → 모든 적을 5초 붙잡음 → 그동안 여우신이 **무자비한 참격**(푸른 칼날 + 먹빛 가장자리, 가끔 발톱 세 줄)을 퍼붓고 마지막에 화면을 가르는 **X자 참격**. 참격 한 줄 한 줄이 **화면 전체를 가로지름** |
| 여우불 발톱 난무(F) | R과 겹치는 문제는 **나중에 따로 의논**(이번엔 그대로) |
