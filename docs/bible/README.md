## 사용자가 정한 것 (바꾸지 않음)
- 2D 사이드뷰 픽셀아트 메트로배니아, Godot 4.7.2, 640×360, 코드 그래픽(아트는 나중에). INARI풍.
- 주인공 세라피나(세라), 여우신 너울(낮은 계급의 작은 신), 마녀학교(서구풍) × 신계(한국풍).
- **장마다 대표 강자 1명** (모두 여성):
  - 2장 왕국(제국) — **기사단장**: 제국제일검, 마력 0, 순수 검술로 압도, 국민의 강한 신뢰.
  - 3장 엘프 마을(세계수) — **궁수**: 무엇이든 저격해 맞힌다.
  - 4장 신전 — **신전 수호자**: 금발, 강철 같은 성격, 창 + 금빛 신성력. 지금까지 중 가장 강함. 폭주한 수호자에게서 **구조물 발판을 밟으며 위로 도망**치고 **꼭대기 층에서 결전**, **기사단장이 함께 와서 돕는다**.
  - 5장 — **별의 마녀**(최강의 마녀): 지금까지의 모든 인물을 합한 만큼 강함. 학교 중심 + 모든 강자 등장 + 모든 맵 배경.
- 5장의 진실: 세라의 제어 못 하는 힘, 여우구슬이 반응해 흡수된 것 모두 별의 마녀의 목적. 자기 힘으로는 앞으로 감당이 안 되는 마녀가 **자신을 막아 줄, 자신보다 강한 존재**를 만들려 한 것. 다른 신들의 침략에서 세계를 지키기 위해.
- 진실이 밝혀진 뒤 막을 수 없는 신들의 침공 → 모든 것이 파괴되는 **압도적 절망**(진격의 거인 '땅울림' 같은 느낌) → 극적으로 극복하고 지켜 냄.
- 교장(아스트리드): 예전엔 세계관급 강자, 노화로 조금 약해짐. 최강급은 아니지만 아주 강함. **주인공을 돕는 장면이 여러 번**.
- 마법: 조건 달성 → 수업 해금 → **마법 배우기 UI**에서 고름 → 퀘스트 완료 → 습득. **등급·레벨**이 있고 올릴 수 있음. 고급 마법은 쿨타임이 길지만 아주 강력, 배우는 조건도 어렵다. 총 **약 7개**.
- 적: 잡몹 노가다가 아니라 한 마리 한 마리 개성 있는 중형 몹. 전투만이 아니라 이동·지역 해금·퍼즐·미로가 섞인다.
- 마법학교다운 **일상 퀘스트**(친구·교수·NPC). **퀘스트창·미니맵** 등 필요한 UI.
- 난이도는 **초보자용(낮게)**. 모바일 버전 함께.
- 분량 목표: 1장 약 45분, 전체 메인 스토리 약 8~9시간.

- 강자 이름: 기사단장 **레오니 발렌하르트**, 엘프 궁수 **엘라리엔**, 신전 수호자 **아우렐리아**, 별의 마녀 **리라**.
