# 능력·마법·게이트 장부 + 플래그 규칙

## 1. 기본기 (처음부터)
이동·점프·대시(대시 점프)·화염탄(X, 1.2초마다 묵직한 한 발)·발판 내려가기·폭주 게이지·폭주 폭발.

## 2. 마법 7종 (마법서) — 상세는 [`docs/magic.md`](../magic.md)
| ID | 이름 | 등급 | 종류 | 장착 | 배우는 때 (조건 → 수업 → 퀘스트) |
|---|---|---|---|---|---|
| `pillar` | 불기둥 | 일반마법 | 공격 | A/S | 처음부터 (1장) |
| `storm` | 화염 폭풍 | 일반마법 | 공격 | A/S | 1장 실습장 (기존) |
| `levitate` | 부양 | 일반마법 | 이동(상시) | — | 1장 부양 실습 (기존 `ab_double_jump`) |
| `wings` | 불꽃 날개 | 고급마법 | 이동(상시) | — | 2장: 1장 클리어 → 오필리아 수업 → 시계탑 상승 기류 시험 |
| `ward` | 불꽃 방벽 | 고급마법 | 방어·반격 | A/S | 2장: 레오니 대련 뒤 → 엠버린 수업 → 반사 시험 |
| `meteor` | 유성 낙화 | **대마법** | 궁극 | F | 3장: 세계수 정화 + 마도석 6개 이상 → 베로니카 대마법 시험(3단계) |
| `phoenix` | 불사조 | **대마법(금서)** | 궁극 | F | 4장 대신전 기록 열람 → 그레타의 금서 시련(4단계, 5장 초반까지) |

- 레벨 1~3. 올리는 재료는 **마도석**(탐험·서브 퀘스트·보스 보상). 비용: 일반마법·고급마법 Lv2 = 3개, Lv3 = 5개 / 대마법 Lv2 = 5개, Lv3 = 8개. 게임 전체 마도석 약 40개 → 전부는 못 올림(선택).
- 장착: A·S 칸에 공격·방어 마법 중 둘(불기둥·화염 폭풍·불꽃 방벽), F 칸에 대마법 하나(유성 낙화·불사조). 이동 마법은 상시.
- 여우 모드에서는 A·S·F가 여우 판으로 바뀐다(불기둥 → 여우비, 화염 폭풍 → 구미호 폭풍, 불꽃 방벽·유성·불사조는 푸른 불 판 + 피해 20%↑).

## 4. 게이트 장부 (메트로배니아)
| 게이트 | 필요한 것 | 처음 나오는 장 |
|---|---|---|
| 높은 턱 | 부양(2단 점프) | 1 |
| 환영 벽·숨은 발판 | 여우창문 | 1 |
| 열쇠 문 | 대본 열쇠 | 1 |
| 넓은 틈·지붕 사이 | 불꽃 날개(활공) | 2 |
| 상승 기류(굴뚝·대장간·바람길) | 불꽃 날개(기류 타기) | 2·3 |
| 별 수정 장벽 | 불꽃 방벽(탄을 되쏘아 수정 깨기) | 2 |
| 흰 역병 덩굴 | 불기둥·화염 폭풍(정화) | 3 |
| 빛줄기 거울 | 불꽃 방벽으로 빛을 되쏘기 / 거울 돌리기 | 4 |
| 금빛 봉인석 | 유성 낙화 (선택 구역·숨은 것) | 4 |
| 별의 봉인 | 해당 지역 강자와 함께 | 5 |

- 메인 길은 그 장에서 배우는 것까지만 요구한다. 이전 장 지역의 숨은 것은 나중 마법으로 열린다(되돌아가기 보상).

## 5. 플래그·ID 규칙 (코드)
| 종류 | 규칙 | 예 |
|---|---|---|
| 장 진행 | `chapter` = 1~5(정수, `ChapterFlow`가 씀), 장 끝 `chN_done` | `ch2_done` |
| 장별 이야기 플래그 | 2장 `k_`, 3장 `e_`, 4장 `tp_`, 5장 `st_` 접두사 | `k_met_leonie` |
| 방 ID | 2장 `k_`, 3장 `e_`, 4장 `tp_`, 5장 `st_`(새 방)·`r5_`(무너진 판), 학교 새 방 `s_` | `k_market` |
| 능력 | `ab_<id>`: storm, double_jump, fox_window, fox_mode, neoul, **wings, ward, meteor, phoenix** | `ab_wings` |
| 마법 레벨·장착 | `lv_<spell>`(정수, 없으면 1), `eq_a`·`eq_s`·`eq_f`(마법 ID) | `lv_pillar = 2` |
| 마도석 | `mana_stones`(가진 수), `mana_spent`(쓴 수). 줍는 개체 `pickup kind=stone` | |
| 꼬리 | `tails`(정수, 없으면 1) | |
| 퀘스트 | `q_<id>` = 0 없음 / 1 진행 / 2 완료, 단계 `q_<id>_step` | `q_pippa_herbs` |
| 수업 | 퀘스트로 처리: `q_cls_<spell>` | `q_cls_wings` |
| 전이진 | `warp_<area>` | `warp_kingdom` |
| 동료 | 대본이 `c.ally_join("leonie")` / `c.ally_leave("leonie")` (저장 안 함 — 장면 한정) | |
| 대본 ID | 방 들어올 때 `enter_<방ID>`, 인물 대화 `npc_<who>` (장별 덮어쓰기 `npc_<who>_ch<N>`), 장별 접두사 `k_`·`e_`·`tp_`·`st_` | `npc_pippa_ch2` |
