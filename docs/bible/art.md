# 그래픽 규칙 (코드 그래픽)

## 1. 공통 (1장과 같음)
- 640×360, 타일 16px, 가장 가까운 이웃 필터. 캐릭터 32px(모자 제외), 성인 36~42px.
- INARI풍: 어두운 저채도 배경 + 지역마다 **강한 강조색 하나**, 굵은 덩어리 픽셀, 깊은 안쪽은 거의 검게, 거대한 배경 구조물로 존재감.
- 빛나는 것(불·마법·신성력)은 `Fx.add_material`(가산 합성). 어두운 배경과 분리되게 인물 뒤에 은은한 윤곽 빛.

## 3. 강자 그림 기준 (일반 인물보다 공들여)
- 키 36~42px, 일반 인물(`CharacterVisual`)보다 **세부 2배**: 3단 명암(바탕·그림자·빛), 머리카락 가닥 2~3개가 따로 흔들림, 망토·천은 시간에 따라 물결, 무기에 빛 반사 점이 지나감.
- 숨쉬기(1px), 눈 깜빡임, 무기를 고쳐 잡는 대기 동작 1개 이상.
- 싸울 때 자세: 예고 자세는 실루엣이 확 바뀌게(창을 뒤로 당김, 검을 칼집에 넣음, 활을 끝까지 당김).
- 대화 초상화도 강자는 전용 그림(`Portrait`의 특수 그림). 일반 인물보다 큰 머리카락 볼륨·장식.
- 색 고정: 레오니 = 남색 머리·은 갑옷·진홍 망토 / 엘라리엔 = 연금초록 머리·잎 망토·흰 활 / 아우렐리아 = 금발·흰금 갑옷·금 광륜·창 / 리라 = 은백 머리·남색 별 로브·초승달 모자 / 아스트리드 = 은회색 머리·별 망토.

## 4. 바깥 신들 (5장)
- 하얀 얼굴 없는 거인: 매끈한 흰 몸 + 기하학 금(선), 얼굴 자리에 세로로 갈라진 틈. 크기는 화면보다 크게(배경 층과 전경 층 모두).
- 하늘의 균열: 검은 하늘에 흰 선이 갈라지고 그 안에 눈.
- 소리: 겹친 낮은 울림 + 높은 유리 소리.
