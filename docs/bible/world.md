# 세계관 정본

## 1. 신의 계층
| 층 | 누구 | 설명 |
|---|---|---|
| 관리자 | **루멘** (빛의 주재) | 이 세계를 "운행"하는 상위 존재. 사람과 직접 말하지 않고, 신전의 수호자에게만 금빛 신성력과 짧은 계시를 내린다. **수백 년째 약해지고 있다** — 그래서 바깥 신들이 틈을 보기 시작했다(4장에서 드러남). |
| 하위 신들 | **너울**(동방 신계의 여우신), 해태(신계의 문지기 짐승) 등 | 땅·짐승·고개의 작은 신들. 너울은 꼬리 9개의 구미호였지만 구슬을 잃어 꼬리 1개의 작은 여우가 됨. 하위 신은 관리자에게 이름조차 기억되지 않는다는 게 너울의 투덜거림. |
| 바깥 | **천외(天外)의 신들** ("바깥 신들") | 하늘 너머에서 관리자가 약한 세계를 먹어 치우는 존재들. 얼굴 없는 하얀 거인·기하학 무늬·금 간 하늘의 눈. 말은 겹친 메아리. 먼저 **사도(使徒)**를 보내 길을 닦고, 세계에서 가장 강한 그릇을 **문(門)**으로 삼아 들어온다. |

- **신성력**(루멘의 금빛)과 **마력**(사람·마녀), **신력**(하위 신, 너울의 푸른 여우불)은 서로 다른 힘이다. 세라는 마력 + 별의 씨앗(5장 공개) + 신력(구슬)이 한 몸에 섞인 유일한 존재.
- 너울의 **푸른 불** = "무엇도 태워 없애지 않고, 다만 잠재우는 불"(1장 금서). 봉인·정화에 쓰인다. 5장 마지막에 하늘의 문을 닫는 것도 이 불이다(1장과 수미상관).

## 2. 지역
| 지역 | 장 | 분위기 | 지도 영역 ID |
|---|---|---|---|
| 신계 (동방) | 1 | 한국풍, 홍살문·단청·여우 석상, 밤의 여우불 | `shingye` |
| 마녀학교 (거점) | 1~5 | 서구풍 고성, 시계탑, 도서관, 지하 봉인 | `school` |
| **아르덴 제국 · 황도 아르덴** | 2 | 성벽 도시, 시장·지붕·하수도·투기장·대성당·옛 성곽 지구(10년 전 별이 떨어진 곳), 은사자 기사단 | `kingdom` |
| **엘프의 숲 · 세계수 에일라흐** | 3 | 거대한 세계수의 뿌리·줄기·가지에 지은 마을, 바람길(엘프 바람 마법), 반딧불, 흰 역병 | `elf` |
| **성산 · 루멘 대신전** | 4 | 하얀 대리석과 금, 거대한 종탑, 빛의 거울, 순례길, 꼭대기 첨탑 | `temple` |
| **별의 탑 · 하늘의 문** | 5 | 학교 위에 나타난 별의 탑, 침공 뒤 무너진 모든 지역, 하늘의 균열 | `star` (5장 새 방), 기존 지역 재방문 |

- 거점 이동: 학교 앞마당 **전이진**(2장부터) ↔ 각 지역 전이진. 처음 갈 때는 이야기로 가고, 그 뒤엔 전이진으로 오간다.

## 3. 연표
| 시점 | 일 |
|---|---|
| 약 120년 전 | **창립자**(첫 번째 마녀)가 마녀학교를 세움. 동방의 여우신 너울에게 푸른 불을 빌려 지하의 굶주린 것(아귀)을 봉인. 이때 창립자 곁에 마지막 두 제자 — **아스트리드**와 **리라**. 아스트리드는 너울을 이때 만났다(1장 "처음 뵙겠습니다… 라고 해 두죠"). |
| 약 100년 전 | 창립자 죽음. 아스트리드는 학교에 남아 **학교의 큰 결계**를 혼자 떠받치기 시작(이 때문에 늙고 약해짐 = 노화). 리라는 "별을 보러 간다"며 떠남. |
| 약 20년 전 | 리라가 별을 읽다 **바깥 신들의 침공**과 루멘의 쇠약을 봄. 자기 힘으로는 못 막는다는 것, 그리고 바깥 신들이 **세상에서 가장 강한 그릇(= 리라 자신)을 문으로 삼으려 한다**는 것도. |
| 약 17년 전 | 리라가 갓난아기 세라에게 **별의 씨앗**(떨어진 별의 조각)을 심음 → 비정상적으로 큰 마력, 폭주("폐급"). |
| 10년 전 | **별이 떨어진 밤**: 황도 아르덴 옛 성곽 지구에 운석. 별의 마녀가 나타나 참사를 막고 사라짐 → 제국의 전설. 어린 기사 레오니가 그 자리에 있었다. (사실은 리라가 씨앗을 다룰 별 조각을 회수하러 온 것 — 5장에서 레오니가 깨닫는 대목) |
| 1장 직전 | "신계 깊은 곳에 폭주를 고쳐 줄 보물이 있다"는 **소문**이 학교에 돈다 — **리라가 퍼뜨림**. 세라가 신계에 들어가 구슬을 흡수. |
| 1장 | 구슬 → 봉인 반응 → 아귀 부활 → 세라·너울이 다시 봉인. |
| 2장 | 제국에 "별의 짐승"이 나타남(별의 씨앗과 구슬이 섞인 세라의 마력에 이끌림 + 별 신도들의 의식). |
| 3장 | 세계수에 **흰 역병** — 바깥 신들의 첫 사도가 세계수 꼭대기에 둥지. |
| 4장 | 루멘의 침묵. 바깥 신들이 수호자 아우렐리아의 신성 연결을 가로채 폭주시킴. 끝에 리라 등장. |
| 5장 | 리라의 시험 → 진실 → 리라가 문으로 붙잡힘 → 침공(거신의 행진) → 절망 → 아홉 꼬리 → 하늘의 문을 푸른 불로 잠재움. |

## 4. 떡밥 장부 (공개 시점을 지킬 것)
| 떡밥 | 처음 깔리는 곳 | 힌트 | 공개 |
|---|---|---|---|
| 세라 마력이 너무 큰 이유 | 1장 프롤로그 "폐급" | 2장 별의 짐승이 세라에게 끌림 / 3장 사도가 "별의 그릇"이라 부름 / 4장 아우렐리아 "네 마력에는 별빛이 섞였다" | **5장 중반** (리라) |
| "보물 소문"을 누가 퍼뜨렸나 | 1장 "소문을 들었다" | 2장 별 신도가 "그분은 소문 하나로 별을 움직이시지" | **5장 중반** |
| 교장이 너울을 아는 이유 | 1장 "처음 뵙겠습니다… 라고 해 두죠" | 2장 교장실의 오래된 사진(창립자와 두 소녀) / 3장 엘프 장로 "창립자의 제자 둘" | **5장 초반** (아스트리드·리라 대면) |
| 교장이 약해진 이유 | 2장 "예전엔 하늘을 셋으로 갈랐다던데" 소문 | 3장 결계를 떠받치느라 손이 떨림 | **5장** (결계가 깨질 때) |
| 별의 마녀 | 2장 제국 전설 + 별 신도 | 3장 달 위의 그림자 / 4장 끝 등장 | **4장 끝 등장 → 5장** |
| 바깥 신들 | 2장 별 신도가 말하는 "별 너머의 눈" | 3장 흰 역병·백색 사도 / 4장 신성 연결 가로채기 | **4장** (아우렐리아가 이름을 말함) → 5장 침공 |
| 루멘이 약해짐 | 4장 초반 "신전이 어두워졌다" | 4장 기록실 | **4장 중반** |
| 너울의 꼬리 | 1장 "꼬리 하나만큼의 힘" | 장마다 하나씩 돌아옴 | 5장 절정에서 아홉 개 |
| 구슬을 되찾는가 | 1장 "구슬을 되찾을 때까지만이다" | — | **5장 에필로그**: 이제 안전하게 뺄 수 있지만 너울이 "조금만 더 맡겨 두마" |

## 5. 금지 사항 (일관성)
- 너울은 하위 신이다. 루멘이나 바깥 신들과 맞먹는 척하지 않는다(허세는 OK: "내가 꼬리만 다 있었어도…").
- 레오니는 **마력이 0**이다. 마법·신성력을 쓰지 않는다(마법 무기도 없다). 강한 건 오직 검술·체술·의지.
- 엘라리엔의 화살은 마법이 아니라 **기술**(바람을 읽는 눈). 엘프 일반의 바람길(바람 마법)과 구분.
- 아우렐리아의 금빛은 **루멘의 신성력**. 폭주 중에는 **흰빛이 섞인 금색**(바깥 신들의 색 = 흰색).
- 바깥 신들의 색은 **흰색·무채색·기하학**. 다른 적과 섞지 않는다.
- 별의 마녀의 색은 **깊은 남색 + 별빛(연한 금·흰)**. 바깥 신들의 흰색과 구분되게 따뜻한 별빛.
- 세라의 불 = 붉은 불, 너울의 불 = 푸른 여우불 (1장부터).
