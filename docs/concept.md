# 콘셉트 결정 기록

> 대화로 확정한 내용을 기록한다. 새로 결정되면 이 문서를 갱신한다.

## 한 줄 콘셉트

마녀학교의 '저주 골동품 동아리' 부원이 되어, 학생들이 맡긴 저주 물건을 **매입**해 정화·판매하고, 교내에 퍼진 저주를 턴제 전투와 탐험으로 해결하는 세로형 RPG.

## 확정 사항

| 항목 | 결정 |
|---|---|
| 분위기 | 귀엽지만 으스스함 (「마녀의 집」 톤, 고어 없음) |
| 화면 | 모바일 세로 |
| 무대 | 마녀학교 하나. 교실 = 스토리 스테이지, 학교 지하 봉인 창고 = 탐험 던전 |
| 가게 | 폐부 직전 '저주 골동품 동아리' 부실을 선배에게 물려받음. 저주 물건 **매입 → 정화 → 판매** |
| 전투 | 턴제. 미션·스토리·재화를 전투로 얻음 |
| 성장 | 수업 = 마법 습득, 도서관 = 마법 강화, 시험 = 학년 상승 |
| 탐험 | 미로·특정 교실 찾아가기(아르피아 참고), 이상한 방 탈출(크라라 공주와 이상한 방 참고) |
| 탐험 던전 | 봉인 창고 층 구조, 깊을수록 상위 등급 골동품(일반·고급·희귀·전설) |
| 동물농장식 시스템 | 물건 구매, 훈장, 부실 꾸미기 |
| 펫 | 부실 고양이 1마리(작은 요소). 전투 보조·힌트 |
| 주인공 동기 | 부실 지키기(상속) + 주인공에게 걸린 저주 해제 |
| 출시 단계 | 1차 솔로 → 2차 서버(친구·방문) → 3차 교내 장터 |

## 레퍼런스와 참고 범위

| 레퍼런스 | 참고하는 것 | 가져오지 않는 것 |
|---|---|---|
| 「마녀의 집」(Fummy, 2012) | 귀엽고 으스스한 분위기 | 공포 연출 수위, 스토리 |
| 쥬니어네이버 「동물농장」(2003~2016) | 상점·훈장·꾸미기·포인트 게임 구조, 커뮤니티·장터(2차 이후) | 동물 입양·육성 중심 구조, 고유 설정 |
| 「크라라 공주와 이상한 방」(동물농장 포인트 게임) | 방 탈출 퍼즐 | 캐릭터·설정 |
| 「마법학교 아르피아」(2007~2012) | 턴제 전투, 미로·특정 방 찾기 | 종족 3개 구성, 고유 설정 |
| 웹툰 「이름 없는 가게」(하몽, 레진코믹스) | 저주 골동품이라는 소재 | 소원 성취·금기·파멸 구조, 정체불명 주인, '결정' 수집 |

## 표절 회피 원칙

- 거래 방향 반대: 저주 물건을 **파는** 가게가 아니라 **매입·정화**하는 동아리
- 주인공은 전능한 존재가 아닌 미숙한 학생
- 금기·파멸 구조 없음. 저주에 먹힌 사람은 회수하면 되돌아옴
- 고유 명칭(캐릭터명, 재화명, 에피소드)은 새로 만든다

## 주의 사항

- 경제: 상위 골동품은 판매가보다 장착 효과·수집 가치를 크게 둔다
- 유료 확률형 상품을 만들 경우 국내 확률 공개 의무 적용 (게임산업법, 2024년 3월 시행) — 출시 전 재확인
- 범위: 1차 솔로 기준으로도 초보 1인에게 큰 편 → 단계 분리 필수

## 미결정

- 게임 제목
- 주인공에게 걸린 저주와 메인 스토리 큰 줄기
- 턴제 전투 방식 (개별 행동 게이지 vs 일반 턴제)
- 엔진
- 수익 모델(BM)
- 대상 플레이어 연령
