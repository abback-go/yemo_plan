## 이 문서를 읽고 구현하는 법 (구현자·AI용 지침)

1. **숫자와 처리 순서는 이 문서가 정답이다.** 문서에 없는 규칙을 새로 만들지 않는다. [제안] 표시가 붙은 것도 사용자가 고치기 전까지는 그대로 구현한다.
2. **마법 하나하나의 수치**는 `witches_12.md` §4가 정답이다. 이 문서 §24.2는 그 표에서 **바뀌는 것만** 적는다.
3. **난수**: 쓰는 곳은 §3.3에 모았다. 검증(§25)은 난수 값을 입력으로 고정해 계산한다. §25의 정수가 하나라도 다르면 같은 구현이 아니다.
4. **표기**

| 표기 | 뜻 |
|---|---|
| [확정 N-M] | 사용자가 정함. `decisions.md` 항목 N-M (= README §0-12) |
| [확정 §0-x] | 사용자가 정함. README §0의 해당 절 |
| [제안] | Claude가 정한 세부·수치. 사용자 검토 전이지만 구현은 이대로 |
| [플레이테스트 필요] | 수치가 플레이로 바뀔 수 있음 |
| [측정 필요] | 실측값이 없어 가정을 씀 (가정을 함께 적음) |
| **(구현됨)** | 지금 코드(`game/proto/turn/`)에 있음 |
| **(미구현)** | 결정됐지만 코드에 아직 없음 — 구현은 사용자가 "만들자"고 할 때 |

5. **용어**: 화면에 쓰는 한국어 이름을 쓰고, 코드 식별자·데이터 키는 원문 그대로 쓴다(예: 공격력 버프 = `atk`).

## 1. 개요

### 1.1 목적

마녀 최대 3명이 파티를 이뤄 행동 게이지 순서로 싸우는 턴제 전투를, 이 문서 한 장으로 같은 결과가 나오게 구현할 수 있도록 정의한다.

### 1.2 범위

| 포함 | 제외 |
|---|---|
| 편성 입력(파티 3·마법 장착 4·장비·마법/장비 강화 레벨) | 마법을 배우는 방법 [대기] |
| 차례·크레딧·피해 공식·크리·버프·상태·적 AI·웨이브·승패 | 빌드 방식(물약 스밈·각인 등) [대기] |
| 대마법·패시브 | 레벨 곡선 (§27, [확정 4-5 C] 나중에) |
| 전투 화면·편성 화면 정의, 연출 시간, 효과음 | 이야기·설정 [보류], 전투 음악 [확정 22-2 A] |

### 1.3 하이 컨셉과 경험 기둥 [확정 1-1]

**하이 컨셉**: 원소의 마녀들을 3명 골라, 버프를 종류별로 몰아주고 징표를 쌓아 **수십만~수억의 한 방**으로 적을 끝내는 턴제 빌드 전투.

| 기둥 | 내용 | 이 문서에서 받치는 규칙 |
|---|---|---|
| ① 임계치를 넘기는 한 방 | 버프를 종류별로 몰아줘 곱으로 커지는 피해 | 같은 종류 합·다른 종류 곱(§11), 징표 겹 특공(§17.1), 대마법(§13) |
| ② 차례마다의 판단 | 크레딧을 모을지 쓸지 | 크레딧 +1/차례·상한 7(§12), 비용이 클수록 강한 마법(§15.3), 의도 표시(§18.3) |
| ③ 속성을 돌려 쓰는 편성 | 적 약점에 맞춰 파티를 짠다 | 약점 1.5배·속성 순환(§11.3), 속성 부여, 편성(§4) |

### 1.4 전투 길이 목표 [확정 1-2]

| 전투 | 목표 시간 | 목표 마녀 행동 수 [제안] | 구성 |
|---|---|---|---|
| 일반 전투 | **5~10분** | 70~110 | 1웨이브, 적 1~3 [확정 6-1 C · 6-2 A] |
| 보스 전투 | **20분 정도** | 200~260 | 2~3웨이브, 마지막 웨이브에 보스 |

**시간 모형** [측정 필요]: 전투 시간 ≈ 전체 행동 수 × 1.3초 + 마녀 행동 수 × 3초.
- 1.3초 = 행동 하나의 연출·대기 합(`t_stage.gd`: 적 차례 앞 0.4초 + 연출 `total` 기본 0.8초 + 뒤 대기 0.2초 안팎). 마법마다 다르다.
- 3초 = 마녀 차례에 플레이어가 고르는 시간의 **가정값**. 폰 실플레이로 재야 한다(§27 U01).

**적 체력·공격력 배수와 길이** — 헤드리스 시뮬레이션(규칙 엔진 `TBattle` + 자동 선택 `TAuto`, 기본 장착, 파티 에스카·이그니스·엠버, 60판, 2026-10-18). 배수는 프로토타입 적 3종(체력 합 120만) 기준:

| 적 체력 | 적 공격력 | 승 | 승리 평균 마녀 행동 | 전체 행동 | 시간 모형 |
|---|---|---|---|---|---|
| ×1 | ×1 | 59/60 | 49.3 | 71.9 | 약 4.0분 |
| ×2 | ×0.6 | 59/60 | 89.3 | 129.1 | **약 7.3분** |
| ×3 | ×0.4 | 60/60 | 129.6 | 187.1 | 약 10.5분 |
| ×4 | ×0.4 | 58/60 | 175.7 | 253.2 | 약 14.3분 |

- 그래서 **일반 전투 = 체력 합 ×2(240만)·공격력 ×0.6**, **보스 전투 = 웨이브 합 체력 ×5.6 안팎(약 680만)**으로 잡는다(§24.6) [제안][플레이테스트 필요].
- 공격력을 그대로 두고 체력만 늘리면 지구전에서 파티가 진다(체력 ×2·공격력 ×1이면 4/60승). 체력과 공격력은 함께 조정한다.
- 이 표는 **이번 결정으로 새로 들어가는 규칙(징표 겹·대마법·패시브·기절 등)이 없는 엔진**의 값이다. 구현 뒤 다시 잰다(§25.5).

### 1.5 전투 한 판의 흐름

```
편성(파티 3 · 마법 장착 4 · 장비) → 전투 시작
  → [반복] 다음 차례 결정(행동 게이지가 먼저 1000에 닿는 쪽)
        마녀 차례: 크레딧 +1 → 시간 멈춤 → 바퀴에서 행동 하나 고름(기본 공격 · 장착 마법 4 · 대마법) → 실행
        적 차례: 미리 보인 의도대로 행동 (입력 없음)
        차례 끝: 지속 감소 · 승패 확인
  → 웨이브의 적 전멸 → 다음 웨이브(있으면) / 승리
  → 마녀 3명 전원 쓰러짐 → 패배 → 바로 다시 시작
```

## 2. 용어 정의

| 용어 | 뜻 | 코드 |
|---|---|---|
| 마녀 | 플레이어가 조종하는 아군 유닛. 12명 | `TUnit` side `witch` |
| 적 | 적 유닛. 등급은 일반·강적·보스(§18.1) | `TUnit` side `enemy` |
| 파티 | 전투에 나가는 마녀 3명. 자리는 앞·중·뒤 | `party` |
| 행동 게이지 | 0→1000으로 차는 값. 1000이 되면 그 유닛의 차례 | `gauge` |
| 속도 | 시간 1당 게이지가 차는 양 | `speed` |
| 차례 | 한 유닛이 행동 하나를 하는 단위. 마녀는 한 차례에 행동 하나 [확정 §0-9] | `next_actor` |
| 차례 줄 | 화면 위에 보이는 앞으로의 차례 예상(지금 + 7) | `preview` |
| 크레딧 | 마녀의 행동 자원. 0~7 정수 | `credits` |
| 기본 공격 | 크레딧을 쓰지 않는 공격. 쓰면 크레딧 +1을 더 받는다 | `basic` |
| 마법 | 크레딧을 써서 쓰는 기술. 마녀당 10개를 배우고 4개를 장착 | `SKILLS` |
| 대마법 | 마녀마다 1개, 크레딧 7을 전부 써서 쓰는 큰 마법 (§13) | (미구현) |
| 패시브 | 마녀마다 1개, 전투 내내 켜져 있는 효과 (§15.6) | (미구현) |
| 장비 | 마녀당 1개. 한 장비는 한 명만 낀다 | `EQUIPS` |
| 배율 | 공격 마법이 공격력에 곱하는 값 (예: 6.0배) | `mult` |
| 버프 | 대상에게 붙는 일시 효과(이로운 것). 종류(`cat`)·값·지속을 가진다 | `buffs` |
| 디버프 | 적에게 거는 해로운 일시 효과(방어 다운 등) | `buffs` (적 쪽) |
| 종류 | 버프의 분류. 같은 종류는 더하고 다른 종류끼리 곱한다 | `cat` |
| 지속 "행동 N번" | 그 효과를 가진 유닛이 행동을 N번 마칠 때까지 | clock `own` |
| 지속 "적 행동 N번" | 적에게 건 것: 그 적의 행동 N번. 무적·받는 피해 감소·도발·근성: 아무 적이든 행동 N번 | clock `own`(적) / `enemy`(마녀) |
| 징표 | 화상·빙결·감전. 그 자체 효과는 없고 특공의 조건이다. 겹쳐 쌓인다 (§17.1) | `marks` |
| 겹 | 같은 징표가 쌓인 수. 1~5 | (미구현) |
| 특공 | 징표가 있는 적에게만 붙는 피해 증가 종류 | `special` |
| 터뜨리기 | 징표를 소모해 배율을 크게 올리는 마법 효과 (§17.1) | (미구현) |
| 속성 | 물·불·번개 / 특수 속성(공간·시간·검술) | `element` |
| 약점 | 적이 약한 공격 속성. 맞으면 1.5배 | `WEAK_TO` |
| 무상성 | 특수 속성 마녀의 공격: 약점 판정 없이 1.2배 | `special` (유닛) |
| 속성 부여 | 공격 속성을 바꾸는 버프·장비 | `element` 버프 |
| 기절 | 다음 차례 1번을 쉬게 하는 상태 (§17.2) | (미구현) |
| 도발 | 적의 단일 대상 공격을 끌어오는 상태 (§17.3) | (미구현) |
| 근성 | 쓰러질 피해를 한 번 체력을 남기고 버티는 상태 (§17.4) | (미구현) |
| 의도 | 적의 다음 행동 종류. 머리 위에 미리 보인다(수치 없음) | `intent()` |
| 차지 | 보스·강적이 행동할 때마다 쌓는 칸. 가득 차면 필살기 (§18.5) | (미구현) |
| 줄 | 보스 체력의 단계. 한 줄을 다 깎으면 브레이크 (§18.6) | (미구현) |
| 내성 | 디버프가 실패할 확률을 올리는 적의 값 (§16.5) | (미구현) |
| 웨이브 | 한 번에 나오는 적 무리. 보스 전투는 2~3웨이브 | (미구현) |
| 대가 | 강한 마법 뒤에 오는 불이익(예: 그 행동 뒤 크레딧 0) | `demerit_zero` |

## 3. 수치 단위와 공통 규칙

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | 모든 계산 | 비율은 소수, 피해·회복은 마지막에 한 번 반올림 | 화면은 %와 정수 | 난수 폭 ±5% | 예상 피해가 실제와 5% 안에서 맞아 숫자가 읽히게 [확정 3-1 A] |

### 3.1 단위

| 값 | 단위·범위 | 저장 예 | 화면 예 |
|---|---|---|---|
| 비율(버프 값·배율·방어율·확률) | 소수 (1.0 = 100%) | `0.5` | +50% |
| 행동 게이지 | 0 ~ 1000 (실수) | `620.0` | 막대 62% |
| 게이지 증감 | 1000에 대한 비율 | `0.3` | 게이지 +30% (= +300) |
| 크레딧 | 정수 0 ~ 7 | `4` | 점 4개 |
| 지속 | 정수(행동 수) | `3` | 버프 아이콘 옆 3 |
| 징표 | 겹 1~5 + 남은 행동 수 | `{burn: {n: 3, dur: 4}}` | 화상 3겹 · 4 |
| 피해·체력·회복 | 정수 | `453600` | 453,600 (§21.13) |

### 3.2 정수화 규칙

- 피해: 공식(§11)의 모든 항을 실수로 곱한 뒤 **마지막에 한 번 반올림**한다(0.5는 올림). 공격 피해는 1 이상(무적이면 0).
- 회복: 최대 체력 × 비율을 반올림. 최대 체력을 넘지 않는다.
- 되살림: 체력 = max(1, 반올림(최대 체력 × 비율)).
- 장비로 바뀌는 공격력·체력: 전투 시작 때 한 번 반올림해 정수로 둔다(`make_witch`).
- 버프 합·상한 계산은 반올림하지 않는다.
- 게이지는 실수 그대로 다룬다(반올림 없음).

### 3.3 난수

| 쓰는 곳 | 분포 | 절 |
|---|---|---|
| 피해 난수 | 0.95 ~ 1.05 균등 실수, 히트마다 | §11.2 [확정 3-1 A] |
| 마녀 크리 판정 | [0,1) 균등 < 크리 확률, 히트마다 | §14.1 |
| 적 크리 판정 | [0,1) 균등 < 적 크리 확률, 히트마다 | §14.5 |
| 적 단일 공격 대상 | 대상 후보 중 균등 | §18.4 [확정 18-2 A] |
| 디버프 성공 판정 | [0,1) 균등 < 성공률 − 내성, 효과마다·대상마다 | §16.5 [확정 16-3 B] |

- 전투 하나에 난수 생성기 하나(`TBattle.rng`). 시드를 주면 같은 입력에서 같은 전투가 나온다(시험용). 시드가 0이면 무작위.
- 뽑는 순서: 위 표의 사건이 일어나는 순서 그대로. 히트 하나 안에서는 크리 판정 → 피해 난수 순.
- 무작위 손패·연계·턴 시작 무작위는 없다 [확정 8-1 A · 9-1 A · 7-1 A].

## 4. 전투 입력: 편성·장비·강화

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | 마녀 3명·자리·마법 장착 4·장비 1·강화 레벨 | 전투 시작 때 유닛 생성, 장비·패시브를 능력치에 반영 | 편성 카드·설명 상자 | 파티 3, 장착 4, 장비 1(중복 불가), 강화 Lv1~3 | 빌드를 3명 안에서 완성 [확정 4-1 A], 들고 갈 4개의 고민 [확정 4-7 A] |

### 4.1 파티

- 파티는 **최대 3명**, 자리는 앞(0)·중(1)·뒤(2) [확정 §0-6]. 자리는 그림 위치와 동시 도달 순서(§7.3)에만 쓰이고 전투 효과는 없다 [확정 6-3 A].
- 같은 마녀는 한 파티에 한 번만 (12명 모두 고유).
- **예비 멤버(후열)는 없다** [확정 4-1 A]. **다른 사람의 마녀를 빌리는 서포트도 없다** [확정 4-2 A].
- 3명보다 적게도 나갈 수 있다 [제안]: 빈 자리는 없는 것으로 친다(차례 줄·대상에서 빠짐).

### 4.2 마법 장착

- 마녀마다 배운 마법(지금 10개 전부) 중 **4개**를 장착한다 [확정 4-7 A — 성장으로 늘지 않음].
- 장착 순서 = 스킬 바퀴의 칸 순서(공격 다음부터).
- **대마법**은 장착하지 않는다 — 마녀마다 하나가 늘 바퀴 끝 칸에 있다(§13) **(미구현)**.
- **패시브**도 장착하지 않는다 — 늘 켜져 있다(§15.6) **(미구현)**.
- 기본 장착(처음 상태) = `witches_12.md` §4 능력치 표의 "기본 장착 4개".

### 4.3 장비

- 마녀당 **1개** [확정 §0-9]. 장비 없음도 고를 수 있다.
- **한 장비는 한 명만 낀다** [확정 4-3 B] **(미구현)**. 편성 카드의 장비 ◀ ▶는 **다른 파티원이 낀 장비를 건너뛴다**. 파티원을 바꿔 넣을 때 새 마녀의 장비가 이미 파티에 있으면 새 마녀의 장비를 "없음"으로 한다 [제안].
- 장비 목록과 강화 수치는 §24.5.

### 4.4 강화 레벨

**마법 강화 (Lv1~3)** [확정 §0-8 · 확정 4-6 A — 수치만] **(미구현)**

| 레벨 | 수치 배수 | 오르는 것 | 그대로인 것 |
|---|---|---|---|
| Lv1 | ×1.00 | — | — |
| Lv2 | ×1.15 | 배율(`mult`), 버프·디버프 값(`v`), 회복·되살림 비율(`pct`), 게이지 증감(`v`), 이 공격만 특공(`this_special`) | 비용, 지속, 크레딧 +N, 징표 겹 수, 다단 히트 횟수, 크리 확정, 방어율 무시, 기절·도발·근성 |
| Lv3 | ×1.30 | 위와 같음 | 위와 같음 |

- 대마법도 같은 표를 따른다.
- 계산: 강화된 값 = 원래 값 × 배수(소수 그대로). 예: 태양의 창 6.0배 Lv3 = 7.8배(§25.1 D20).
- 디버프 값의 상한(방어 다운 50% 등)은 강화 뒤에도 그대로다.

**장비 강화 (Lv1~3)** [확정 4-4 B] **(미구현)**: 수치 효과 ×1.0 / ×1.25 / ×1.5 (정수 %로 반올림). 대가(받는 피해 +30% 등)는 그대로이고, 수치가 아닌 효과는 레벨마다 정한 것을 더한다. 장비별 표는 §24.5.

**레벨(능력치 곡선)**: 아직 정하지 않는다 [확정 4-5 C]. 이 문서의 능력치는 **기준 레벨**의 값이다. 엔드컨텐츠의 수천만~수억은 레벨로 공격력 ×5~10 + 강화 Lv3 + 장비로 만든다는 목표만 둔다(§27 U03).

### 4.5 능력치가 전투에 들어가는 순서

```
전투 공격력 = 반올림(기본 공격력 × (1 + 장비 공격력%))
전투 최대 체력 = 반올림(기본 체력 × (1 + 장비 체력%))
속도 = 기본 속도 + 장비 속도
시작 게이지 = 1000 × 장비 시작 게이지% (+ 호라 패시브 등, §15.6)
시작 크레딧 = min(장비 시작 크레딧, 7)
```

### 4.6 전투에 넘기는 입력 형식

```
{
  "party": ["eska", "ignis", "ember"],          # 앞 · 중 · 뒤
  "witch": {
    "eska":  {"equipped": ["crack", "seal", "doom", "blackstar"], "equip": "black_cup",
              "skill_lv": {"doom": 3}, "equip_lv": 2},
    ...
  },
  "battle": "normal_01",                         # 전투 데이터 id (§5.6)
  "seed": 0                                      # 0이면 무작위
}
```

- `skill_lv`에 없는 마법은 Lv1. `equip_lv`가 없으면 Lv1.
- 지금 코드의 입력(`TBattle.setup(party, enemy_ids, state, seed)`)에 `skill_lv`·`equip_lv`·`battle`(웨이브 목록)이 더해진다 **(미구현)**.

| `pattern` | 의도 목록 (순환) |
| **`rules`** | 조건 규칙 목록 (§18.2) |
| **`charge_max`** · **`charge_act`** | 차지 칸 수 · 가득 찼을 때의 필살기 의도 (§18.5) |
| **`bars`** | 줄마다 체력 목록 (§18.6) |
| **`on_break`** | 줄이 깨질 때 할 일 (§18.6) |
| `boss` | 참이면 보스 표시(머리 위 막대가 넓음) |

**의도 (`pattern[]`)**: `{k, mult?, v?, dur?}`. `k` = `attack`(공격) · `heavy`(강공격) · `aoe`(전체 공격) · `buff`(자기 공격력 +v, 행동 dur번) · **`stun_attack`**(기절 공격) · **`dispel`**(해제) · **`finisher`**(필살기, 차지로만).

## 6. 전투 구조: 웨이브·자리

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | 전투 데이터의 웨이브 목록 | 웨이브의 적이 전멸하면 다음 웨이브 | "웨이브 2/3" 배너 | 일반 1웨이브, 보스 2~3웨이브, 적 1~3 | 보스 앞에서 "아껴 둘까"를 고르게 [확정 6-1 C] |

### 6.1 웨이브 [확정 6-1 C] **(미구현)**

- **일반 전투**: 1웨이브.
- **보스 전투**: 2~3웨이브. 마지막 웨이브에 보스가 있다.
- 한 웨이브의 적은 **1~3체** [확정 6-2 A]. 웨이브 안에서 적을 보충하지 않는다(쓰러진 적의 칸은 빈 채로 둔다).

### 6.2 자리와 화면 위치

| 자리 | 마녀 발 위치 | 적 발 위치 |
|---|---|---|
| 앞 (0) | (206, 300) | (436, 300) |
| 중 (1) | (152, 270) | (500, 270) |
| 뒤 (2) | (100, 240) | (566, 240) |

- 좌표는 640×360 화면 기준(`t_stage.gd` `WITCH_AT`·`ENEMY_AT`). 아래(앞)에 있는 유닛이 위에 그려진다: `z = 1 + int((y − 230) / 25)`.
- 마녀 자리는 **전투 효과가 없다** [확정 6-3 A]. 적의 단일 공격은 자리와 상관없이 무작위(§18.4).
- 웨이브의 적이 1~2체면 앞자리부터 채운다 [제안].

### 6.3 웨이브 전환

웨이브의 마지막 적이 쓰러진 행동이 끝나면(§7.7의 승패 확인 단계에서):

1. 다음 웨이브가 없으면 → 승리(§20).
2. 있으면 → 배너 "웨이브 N/M" 1.0초(§22) → 다음 웨이브의 적을 자리 순서로 세운다. 새 적의 게이지는 0, 차지 0, 의도는 패턴의 첫 의도(규칙 평가 포함, §18.2).
3. 마녀 쪽은 아래 표대로 유지된다.

| 항목 | 웨이브가 바뀔 때 |
|---|---|
| 마녀 체력·쓰러짐 | 유지 |
| 크레딧 | 유지 |
| 버프(무적·도발·근성 포함) | 유지 (지속도 그대로) |
| 행동 게이지 | 유지 |
| 대가(다음 행동 뒤 크레딧 0) | 유지 |
| 장비 근성 사용 여부 | 유지 (전투당 1번) |
| 적에게 건 징표·디버프 | 적과 함께 사라짐 |
| 차례 줄 | 새 적을 넣어 다시 계산 |

### 6.4 대상 지정

- 단일 대상 마법·기본 공격: 플레이어가 그때마다 고른다(대상 고정 기능 없음).
- 대상 후보: 적 1 = 살아 있는 적, 아군 1 = 살아 있는 마녀, 쓰러진 아군 포함 1 = 파티 전원.
- 전체 대상: 실행 순간 살아 있는 대상 전원(§10.3).

## 7. 턴 흐름 (상태 기계)

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | (자동) 속도 | 게이지가 먼저 1000에 닿는 유닛의 차례. 마녀 차례엔 시간이 멈추고 행동 하나 | 머리 위 게이지·화면 위 차례 줄 | 게이지 1000, 시작 0, 라운드 없음 | 순서가 편성(속도·장비)과 게이지 조작으로 **계획되는** 전투 [확정 §0-2 · §0-8 · 7-1 A · 7-3 A] |

### 7.1 상태 표

| 상태 | 들어오는 조건 | 하는 일 | 나가는 곳 |
|---|---|---|---|
| `BATTLE_INIT` | 전투 시작 | 유닛 생성(§4.5), 패시브 적용(§15.6), 적 첫 의도 결정(§18.2), "전투 시작" 0.6초 | `NEXT` |
| `NEXT` | 행동이 끝남 | 다음 차례 결정(§7.3), 시간 흘리기 | 기절이면 `STUN_SKIP`, 마녀면 `WITCH_TURN`, 적이면 `ENEMY_TURN` |
| `WITCH_TURN` | 마녀 차례 | 크레딧 +1(§12.1), 바퀴 열기, **시간 멈춤** | `WITCH_ACT` |
| `WITCH_ACT` | 행동 하나 고름 | 실행(§10), 연출 | `TURN_END` |
| `ENEMY_TURN` | 적 차례 | 0.4초 뒤 확정된 의도 실행(§18), 연출 | `TURN_END` |
| `STUN_SKIP` | 기절한 유닛의 차례 **(미구현)** | "기절 — 쉼" 0.6초, 행동 없음(§17.2) | `TURN_END` |
| `TURN_END` | 행동(또는 쉼)이 끝남 | 차례 끝 처리(§7.7) | 웨이브 전멸이면 `WAVE_CHANGE`, 승패가 나면 `RESULT`, 아니면 `NEXT` |
| `WAVE_CHANGE` | 웨이브의 적 전멸, 다음 웨이브 있음 **(미구현)** | §6.3 | `NEXT` |
| `RESULT` | 승리 또는 패배 | 배너(§20) | 편성(승리) / 다시 시작(패배) |

- 적 차례에 플레이어 입력은 없다 [확정 §0-8]. 화면을 누르면 오른쪽 위 나가기만 받는다(§19).
- 라운드(턴 번호) 개념은 없다 [확정 7-3 A]. 지속은 모두 "행동 N번"으로 센다(§16.4). 내부의 차례 번호 `turn_no`는 대가 판정(§17.9)에만 쓴다.

### 7.2 전투 시작

1. 유닛 생성: 마녀는 §4.5, 적은 데이터 그대로(여러 줄이면 첫 줄 체력).
2. 시작 게이지: 모두 **0** [확정 7-1 A]. 장비(바람 신발·만화경 Lv2~3)·패시브(호라)만 바꾼다.
3. 시작 크레딧: **0** [확정 7-2 A]. 장비(만화경·마녀의 수첩)만 바꾼다.
4. 패시브 적용(§15.6), 적의 첫 의도 결정(§18.2).
5. 0.5초 기다림 → "전투 시작" 글 → 0.6초 → `NEXT`.

### 7.3 다음 차례 결정

```
살아 있는 유닛 전원에 대해:
    t(u) = 0                       (gauge ≥ 1000)
         = (1000 − gauge) / speed  (그 밖)
차례 = t가 가장 작은 유닛. 차이가 0.000001 이하면 동시로 보고 아래 순서로 고른다:
    ① 지금(시간을 흘리기 전) 게이지가 더 많은 쪽 (차이 0.5 초과일 때)
    ② 속도가 높은 쪽
    ③ 마녀
    ④ 자리 번호가 작은 쪽 (앞 0 → 뒤 2)
고른 뒤: 살아 있는 유닛 전원 gauge += speed × t(차례), 차례 유닛의 gauge = max(gauge, 1000)
차례 번호 turn_no += 1
```

- 쓰러진 유닛은 게이지가 차지 않는다. 되살아나면 게이지 0에서 다시 찬다(§17.7).
- 동시 도달 ①은 시간을 흘리기 **전** 게이지로 비교한다. 그래서 같은 순간에 닿으면 **느린 쪽**(그때까지 게이지가 더 찬 쪽)이 먼저다 (구현됨, §25.2).

### 7.4 차례 줄 (예상)

- 화면 위에 **지금 차례 + 다음 7명**(모두 8칸)을 보인다(§21.7).
- 계산: 지금 게이지에서 §7.3을 그대로 되풀이하되, 행동한 유닛의 게이지를 0으로 놓고 다음을 찾는다. 버프·게이지 조작·기절·되살림은 **반영하지 않은 예상**이다 — 행동이 끝날 때마다 다시 계산한다.
- 기절한 유닛도 줄에 그대로 넣고 아이콘에 기절 표시를 단다(그 차례는 쉬는 차례) [제안] **(미구현)**.

### 7.5 마녀 차례

1. 크레딧 +1 (+ 장비 `credits_per_turn`), 상한 7(§12) — **기절로 쉬는 차례에는 없다**.
2. 바퀴를 연다. **고르는 동안 시간이 멈춘다**(웨이트) [확정 §0-8]. 다른 마녀는 흐려진다.
3. 행동 **하나**: 기본 공격 / 장착 마법 4개 중 하나 / 대마법(크레딧 7일 때) [확정 §0-9].
4. 실행(§10) → 차례 끝(§7.7).

### 7.6 적 차례

1. 0.4초 기다림.
2. **이미 정해져 머리 위에 보이던 의도**를 실행한다(§18). 적 차례에 의도가 바뀌지 않는다.
3. 차례 끝(§7.7).

### 7.7 차례 끝 처리 순서

```
1. gauge = pending_gauge;  pending_gauge = 0      # 행동한 유닛 (자기 게이지 +N%는 여기서 들어간다)
2. 행동한 유닛의 own 시계 버프 지속 −1, 0이 되면 사라짐
3. 행동한 유닛에 걸린 징표 지속 −1, 0이 되면 사라짐 (겹째로 사라짐)
4. 행동한 유닛이 마녀면: 대가 확인 (§17.9) → 크레딧 0
   행동한 유닛이 적이면: 살아 있는 마녀 전원의 enemy 시계 버프(무적·받는 피해 증감·도발·근성) 지속 −1
                        차지 +1 (§18.5) → 다음 의도 결정 (§18.2)        (미구현)
5. 기절 처리: 이번 차례가 기절로 쉰 차례였으면 stunned 해제, stun_guard 켬 (§17.2)   (미구현)
   이번 차례가 stun_guard가 켜진 뒤 첫 차례였으면 stun_guard 끔
6. 승패·웨이브 확인 (§20 · §6.3)
```

- **기절로 쉰 차례**도 1~5를 그대로 거친다. 단, 적이 쉬면 4의 "마녀의 enemy 시계 −1"과 "차지 +1"을 하지 않고 패턴도 넘기지 않는다(쉬었으므로 공격이 오지 않았다) [제안] **(미구현)**.

### 7.8 크레딧 대가·지속의 예

- 버프 "행동 2번"을 받은 딜러: 딜러의 다음 행동이 끝날 때 1, 그다음 행동이 끝날 때 0 → 사라짐. 즉 **다음 두 행동에 적용**된다.
- 자기 차례에 자기에게 건 버프(예: 열기 응축 "행동 2번"): 이 행동이 끝날 때 바로 1 줄어든다 → 실제로 적용되는 건 **다음 1행동** [구현됨 그대로].
- 무적 "다음 적 행동 1번": 아무 적이나 행동을 한 번 마치면 사라진다(그 적이 공격하지 않았어도).

### 7.9 순서 예 (§25.2와 같음)

파티 엠버(속도 120)·에스카(110)·이그니스(95) 대 짚 골렘(80)·늪 두꺼비(105)·재의 기사(95), 장비 없음, 모두 게이지 0:

엠버 → 에스카 → 늪 두꺼비 → 이그니스 → 재의 기사 → 짚 골렘 → 엠버 → 에스카 → 늪 두꺼비 → 이그니스 → 재의 기사 → 짚 골렘

- 이그니스와 재의 기사는 속도가 같아 동시 도달 → ③ 마녀 먼저.
- 12번째: 엠버와 짚 골렘이 같은 순간(시간 25.0)에 닿지만, 흘리기 전 게이지가 더 많은 짚 골렘이 먼저(①).

## 8. 행동 선택 (FGO의 커맨드 카드 자리)

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | 바퀴의 칸 하나 + (필요하면) 대상 | 쓸 수 있는지 확인 → 실행 | 쓸 수 없는 칸은 흐림 | 칸 = 공격 + 장착 4 + 대마법 | 운 없이 **계획대로 터지는** 전투 [확정 8-1 A] |

### 8.1 고를 수 있는 것

| 칸 | 비용 | 조건 |
|---|---|---|
| 공격(기본 공격) | 0, 쓰면 크레딧 +1 | 늘 쓸 수 있다 (살아 있는 적이 있으면) |
| 장착 마법 1~4 | 1~5 | 크레딧 ≥ 비용, 그리고 대상 후보가 하나 이상 |
| 대마법 | 7 | 크레딧 = 7 (§13) **(미구현)** |

- **무작위 손패는 없다** [확정 8-1 A]. 장착한 4개는 매 차례 다 보인다.
- 사용 제한(전투당 횟수·쿨타임)은 없다 [확정 15-1 A]. 크레딧만이 제약이다.
- 대상 후보가 없는 마법(예: 아군 1에게 거는데 살아 있는 아군이 없음)은 흐리게 보이고 고를 수 없다.

### 8.2 FGO와 다른 점

FGO의 덱·분배·카드 보정(역기획서 §8)은 **우리에게 없다**. 카드 색이 하던 일(공격 종류별 보정)은 **속성**(§11.3)과 **징표 특공**(§17.1)이 맡는다.

## 9. 연계 (FGO의 체인 자리 — 없음)

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | — | 연계 보너스 없음 | — | — | 순서 재미는 이미 버프·징표·게이지가 맡는다. 규칙을 더하면 계산이 안 읽힌다 [확정 9-1 A] |

- 같은 속성 연속, 같은 마녀 연속 같은 보너스는 **없다**.
- 순서를 짜는 재미의 출처: ① 버프를 걸고 딜러 차례를 당겨 바로 치기(게이지 +N%) ② 징표를 쌓고 터뜨리기(§17.1) ③ 적 의도를 보고 무적·도발을 먼저 깔기(§18.3).

## 10. 공격 처리: 대상·히트·쓰러짐

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | 마법 하나 | 비용 → 선버프 → 히트 → 부가 효과 순 | 히트마다 피해 숫자 | 다단 히트 간격 0.09초 | 효과가 적힌 순서대로 일어나 설명과 결과가 같게 |

### 10.1 마법 하나의 처리 순서

```
1. 크레딧 −= 비용 (대마법은 7)
2. 대상 확정 (§6.4) — 전체 대상은 지금 살아 있는 전원
3. 선버프: effects 중 pre가 붙은 buff를 자신에게 (적힌 순서)
4. 공격이면, 대상마다 (자리 순서):
     a. 터뜨리기(burst)가 있으면 이 대상의 그 징표 겹 N을 센다                   (미구현)
     b. 히트 k = 1..n (multi가 없으면 n = 1):
          대상이 쓰러졌으면(또는 이번 행동에서 줄이 깨졌으면) 남은 히트를 버린다
          피해 계산(§11) → 체력에서 뺀다 → 근성·쓰러짐 판정(§17.4·§10.4)
     c. 이 대상에게 크리가 한 번이라도 났으면 on_crit 효과 실행
     d. 터뜨리기면 이 대상의 그 징표를 없앤다                                       (미구현)
5. 나머지 효과를 적힌 순서대로:
     who가 target이면 대상마다 한 번씩, 아니면(self·allies·enemies·others) 한 번만
     (this_special · ignore_def · sure_crit · multi · on_crit · burst · pre 버프는 이미 썼으므로 건너뜀)
6. 연출 사건 목록을 돌려준다 (hit · buff · debuff · mark · credits · gauge · heal · revive · …)
```

- 효과의 대상이 쓰러져 있으면 그 효과는 건너뛴다(되살림 제외).
- 디버프·게이지 감소·게이지 0의 성공 판정은 5에서 효과마다·대상마다 한다(§16.5).

### 10.2 다단 히트

- `multi n`: 배율을 n으로 나눠 n번 맞힌다. 히트마다 크리·난수를 따로 뽑는다(§14.4). 합의 기대값은 나누지 않았을 때와 같다.
- 히트 사이 연출 간격 0.09초(`t_stage.gd` `sub`).
- 터뜨리기의 배율 증가(+per×N)는 나누기 **전** 배율에 더한다.

### 10.3 광역 공격

- 대상: 실행 순간 살아 있는 적 전원. 앞자리부터 차례로 계산한다.
- 한 대상이 쓰러져도 다른 대상의 계산은 그대로 한다.

### 10.4 쓰러짐

```
hp = max(hp − 피해, 0)
hp가 0이면:
    근성이 있으면 → §17.4 (버팀, 쓰러지지 않음)
    없으면 → 쓰러짐: alive = 거짓, 버프·징표·기절 전부 지움, 게이지 0
              크레딧은 남는다 [확정 17-5 A]
```

- 쓰러진 마녀는 자리에 옅은 표시와 "쓰러짐" 글이 남는다(되살릴 수 있다).
- 쓰러진 적은 사라지고(연출 0.25초 뒤 흐려짐) 칸은 비운다.

### 10.5 막타 보상

- **없다** [확정 10-1 A]. 쓰러뜨린 마녀가 따로 받는 것은 없고, 넘친 피해는 다음 적으로 넘어가지 않는다.

### 10.6 여러 줄 체력에서의 넘친 피해 **(미구현)**

- 줄을 깨는 히트의 넘친 피해는 버린다. 그 행동에서 그 보스에게 남은 히트도 0이 된다(§18.6) [제안].
- 이유: 대마법 한 번에 줄 여러 개가 사라지지 않게 하고, "한 줄을 한 번에 깨기"를 목표로 만든다.

## 11. 피해 계산

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | 공격력·배율·버프·징표·속성·방어 | 같은 종류는 더하고 다른 종류끼리 곱한 뒤 마지막에 반올림 | 피해 숫자(크리 금빛·약점 주황) | 종류 5개와 상한, 약점 1.5·무상성 1.2, 난수 ±5% | 버프를 **종류별로 고루** 받는 빌드가 한 종류만 쌓는 빌드보다 세게 — 파티 조합의 이유 [확정 §0-9] |

### 11.1 공식 (마녀 → 적)

```
피해 = 반올림(
        공격력
      × 배율                                   (기본 공격·마법, 강화 반영, 터뜨리기 +per×겹)
      × 속성                                   (1.5 약점 / 1.2 무상성 / 1.0)
      × (1 + 공격력 합)                         상한 +300%
      × 크리                                   (크리면 1.5 + 크리 데미지 합(상한 +300%), 아니면 1.0)
      × (1 + 특공 합)                           상한 +200%, 대상에게 그 징표가 있을 때만, 겹을 곱함
      × (1 + 최종 데미지 합)                     상한 +100%
      × 방어                                   clamp(1 − 방어율 + 방어 다운 합(상한 50%), 0.3, 1.5)
      × 난수                                   0.95 ~ 1.05
      )
최소 1 (무적 대상이면 0 — 적은 무적이 없다)
```

- 최소 1은 지금 코드에 없다(지금 수치에선 0이 나오지 않는다). 구현 때 넣는다 **(미구현)**.

- 피해 상한(9999 같은 것)은 **없다** — 숫자 규모가 커지는 것이 이 게임의 재미다 [확정 §0-9 숫자 규모].
- 숫자 규모 목표: 기본 몇만 · 강하면 몇십만 · 초강력 몇백만 · 엔드컨텐츠 수천만~수억 [확정 §0-9].

### 11.2 항별 정의

| 항 | 값 | 들어가는 것 |
|---|---|---|
| 공격력 | 전투 공격력(§4.5) | — |
| 배율 | 기본 공격 `basic.mult` / 마법 `mult` × 강화 배수(§4.4) / multi면 ÷n / 터뜨리기면 +per×겹 | — |
| 속성 | §11.3 | — |
| 공격력 합 (`atk`) | 자신의 공격력 버프 값의 합 | 버프·선버프·패시브(조건이 맞을 때) |
| 크리 | §14 | — |
| 특공 합 (`special`) | Σ(특공 버프 값 × 대상의 그 징표 겹) + Σ(이 공격만 특공 × 겹) + 장비 `special`(징표가 하나라도 있으면, 겹을 곱하지 않음) | 버프에 `mark`가 붙은 것만, 그 징표가 대상에 있을 때 |
| 최종 데미지 합 (`final`) | 자신의 최종 데미지 버프 + 장비 `final` + 공격 마법이면 장비 `skill_final` | 기본 공격엔 `skill_final`이 안 붙는다 |
| 방어율 | 적의 `def` (0~30%). `ignore_def`면 0, 에스카 패시브면 −10%p(0 아래로 안 감) | — |
| 방어 다운 합 (`def_down`) | 적에게 걸린 방어 다운 값의 합 | 디버프 |
| 난수 | §3.3 | — |

- 속성 조건이 붙은 버프(`el`, 예: "화염 공격 크리 데미지 +50%")는 **공격 속성**(속성 부여 반영)이 맞을 때만 더한다.
- 종류별 합은 **상한을 먼저 적용**하고 곱한다.

### 11.3 속성과 약점 [확정 11-2 C · 11-1 A]

**기본: 속성 순환** **(미구현)** — 공격 속성 → 그 속성이 약점인 적 속성:

| 공격 속성 | 약점을 찌르는 적 속성 |
|---|---|
| 물 | 불 |
| 번개 | 물 |
| 불 | 번개 |

- 지금 코드(`t_data.gd` `WEAK_TO`)는 불 적·번개 적 모두 물이 약점이라 **순환이 아니다** → 번개 적의 약점을 불로 고친다.
- **특별한 적**은 데이터의 `weak`로 직접 정한다(순환보다 우선). 예: 짚 골렘(속성 "짚") = 불 약점, 재의 기사(속성 "재") = 약점 없음, 재의 왕(보스) = 물 약점(§24.6).

**배율 결정**

```
el = 공격 속성 (속성 부여 버프가 있으면 마지막에 건 것 → 없으면 장비 속성 반지 → 없으면 마녀 속성)
el이 대상의 약점이면                     → 1.5
아니고 마녀가 특수 속성이며 속성 부여가 없으면 → 1.2 (무상성)
그 밖                                   → 1.0
```

- **반감(불리 상성)은 없다** [확정 11-1 A].
- 특수 속성(공간·시간·검술) 마녀가 속성 부여를 받으면 1.2배를 잃고 약점 판정(1.5 또는 1.0)을 받는다 — 약점이 아닌 적에겐 손해다(§25.1 D14).
- **적의 공격엔 속성이 없다** [확정 11-3 A].

### 11.4 특공과 징표 겹 [확정 17-2] **(미구현 — 겹)**

- 특공 버프(예: 풀무질 "화상 특공 +50%")는 대상에게 그 징표가 있을 때만 붙고, **대상의 그 징표 겹 수를 곱한다**. 화상 3겹이면 +150%.
- "이 공격만 특공 +X%"(`this_special`)도 같은 방식으로 겹을 곱한다.
- 장비 재의 부적의 "징표가 있는 적에게 특공 +20%"는 겹을 곱하지 않는다.
- 합은 상한 +200%에서 자른다. 그래서 특공은 **겹 2~4에서 상한에 닿는다** — 상한이 균형의 손잡이다 [플레이테스트 필요].

### 11.5 종류와 상한

| 종류 | 코드 | 상한 | 비고 |
|---|---|---|---|
| 공격력 | `atk` | +300% | |
| 크리 데미지 | `crit_dmg` | +300% | 크리 배율 최대 4.5 |
| 특공 | `special` | +200% | 겹을 곱한 뒤 |
| 최종 데미지 | `final` | +100% | 장비 "공격 마법 피해"도 여기 |
| 방어 다운 | `def_down` | 50% | 적에게 거는 디버프 |
| 크리 확률 | `crit_rate` | +90% | 기본 10%와 합쳐 100% |
| 받는 크리 확률 증가 | `crit_taken` | +50% | 적에게 거는 "이 적을 때리는 아군 크리 확률 +" |
| 공격력 다운 | `atk_down` | 50% | 적에게 |
| 크리 확률 다운 | `crit_down` | 50% | 적에게 (적 크리 5%를 깎음) |
| 받는 피해 증감 | `dmg_taken` | −70% ~ +100% | 마녀에게 (감소는 음수) |

### 11.6 적 → 마녀 공식

```
피해 = 반올림(
        적 공격력 × 의도 배율
      × clamp(1 + 적 공격력 버프 합 − 공격력 다운 합, 0.3, 4.0)
      × (1 − 마녀 방어율)
      × max(1 + 받는 피해 합(−0.7 ~ +1.0) + 장비 받는 피해, 0.2)
      × (적 크리면 1.5)
      × 난수 0.95 ~ 1.05
      )
마녀가 무적이면 0 ("무적" 표시, 크리·난수를 뽑지 않음)
```

- 받는 피해 합에는 버프(불막이 벽 −40% 등)·네레이 패시브(−10%)가 들어간다. 장비(검은 잔 +30%·강철 심장 −15%)는 따로 더한 뒤 하한 0.2로 자른다.

### 11.7 예상 피해 (화면 안내)

```
예상 = §11.1에서 난수 = 1.0, 크리 = 아님(크리 확정 마법이면 크리)
크리 예상 = 같은 식에서 크리 = 예 (1.5 + 크리 데미지 합)          [확정 21-2 B] (미구현)
대상 = 대상 고르기 중이면 고른 대상, 아니면 첫 번째 살아 있는 적
```

- 디버프 성공 판정·다단 히트의 크리는 빼고 계산한다. 다단 히트는 합으로 보인다.
- 터뜨리기는 지금 겹 수로 계산한다.

### 11.8 계산 예

| 상황 (이그니스 공격력 12,000 → 짚 골렘, 불 약점, 방어율 0, 난수 1.0) | 피해 |
|---|---|
| 기본 공격 1.0배 | 18,000 |
| 태양의 창 6.0배 | 108,000 |
| + 풀무질, 화상 1겹 (+50%) | 162,000 |
| + 화상 3겹 (+150%) | 270,000 |
| + 불의 축복 30% + 열기 응축 50% | 486,000 |
| 위가 크리 (1.5 + 선버프 50% = ×2.0) | **972,000** |

전체 시험은 §25.1.

## 12. 크레딧 (FGO의 NP 자리)

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | 차례·기본 공격·마법·장비 | 정수로 더하고 빼며 상한 7 | 머리 위 점 7개, "크레딧 +N" 글 | +1/차례, 기본 공격 +1, 상한 7 | **모을지 쓸지**가 차례마다의 판단 — 기둥 ② [확정 §0-3 · §0-8 · 12-1 A] |

### 12.1 얻기

| 출처 | 양 | 시점 |
|---|---|---|
| 차례 시작 | +1 | 마녀 차례가 올 때 (기절로 쉬는 차례 제외) |
| 장비 마력 샘 | +1 더 | 차례 시작 |
| 기본 공격 | +1 더 | 기본 공격을 쓴 뒤 (그 차례에 합계 +2) |
| 마법 효과 `credits` | +N | 효과 실행 때 |
| 장비 시작 크레딧 | 전투 시작 | §4.5 |

- 그 밖의 길(맞으면·약점·막타)은 **없다** [확정 12-1 A · 10-1 A].
- 적에게는 크레딧이 없다 [확정 §0-8].

### 12.2 쓰기

- 마법의 비용만큼 뺀다. 대마법은 **7 전부**(§13).
- 비용보다 적으면 그 마법은 흐리게 보이고 쓸 수 없다.

### 12.3 상한

- **7** [확정 §0-8]. 넘치는 만큼은 버린다. 화면 글: 마법 효과는 실제로 늘어난 만큼만 "크레딧 +N"(0이면 글 없음). 기본 공격은 상한에서도 "크레딧 +1"이 뜬다 — 지금 코드 그대로이며 §26 X02에서 고칠 것을 제안한다.

### 12.4 쓰러짐·되살림

- 쓰러져도 크레딧은 **남는다**. 되살아나면 그대로 쓴다 [확정 17-5 A].

### 12.5 대가로 0

- "그 행동이 끝나면 크레딧 0"(불의 신 강림·별빛 역류): §17.9.

### 12.6 표시

- 머리 위 체력·게이지 막대 아래 점 7개(찬 점 금빛) — §21.6.
- 바퀴 칸 아래에 비용만큼 점, 설명 상자 제목 옆에 비용 점(§21.8·§21.9).

## 13. 대마법 (FGO의 보구 자리) [확정 13-1 B] **(미구현)**

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | 크레딧 7에서 바퀴 끝의 대마법 칸 | 크레딧 7을 전부 쓰고 마녀 고유의 큰 마법 | 화면 전체 연출 2초 | 마녀마다 1개, 비용 7 | "강력한 데미지" 순간을 마녀마다 하나씩 확실히, 크레딧 상한까지 모을 이유 |

### 13.1 사용 조건

- 크레딧이 **7**(상한)일 때만. 쓰면 0이 된다.
- 대상 후보가 있어야 한다(일반 마법과 같음).
- 전투당 횟수 제한은 없다 [확정 15-1 A]. 다시 7까지 모으면 또 쓴다.

### 13.2 칸

- 스킬 바퀴의 **마지막 칸**(공격 · 장착 4 · 대마법 = 6칸). 장착하지 않는다.
- 크레딧 7 미만이면 잠긴 모양(흐림 + 남은 크레딧 수, 예 "3"), 7이면 금빛 테가 숨 쉬듯 밝아진다(§21.8).

### 13.3 처리

- 일반 마법과 **같은 실행기**(§10.1)로 처리한다. 데이터에 `ultimate: true`, `cost: 7`.
- 강화 레벨 1~3을 따른다(§4.4).
- 효과 예산(§15.3의 연장) [제안]: 단일 공격 10.0배 + 고유 효과 / 광역 공격 7.0배 안팎 + 효과 / 보조 = 전체 버프 2종 + 자원 / 술사 = 전체 징표 3겹 + 디버프.

### 13.4 연출

- 화면 전체 2.0초(§22.2): 시전자 위로 떠오름 → 화면 어둡게 → 마녀 문장 고리 → 효과 → 피해 숫자.
- 연출을 건너뛰는 기능은 없다 [확정 21-3 A].

### 13.5 12명의 대마법

§24.4 [제안].

## 14. 크리티컬

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | (자동) 히트마다 | 확률 판정 → 배율 | 금빛 큰 숫자 + "!" | 기본 10%·1.5배, 확률 상한 100%, 크리 데미지 +300% | 운은 크리만 맡고, "크리 확정"이 확실한 한 방을 맡는다 [확정 14-1 A] |

### 14.1 마녀의 크리 확률

```
크리 확률 = min( 0.10
               + 자신의 크리 확률 버프 합(대상 조건 포함, 상한 +90%)
               + 대상에 걸린 받는 크리 확률 증가 합(상한 +50%)
               + 장비 crit_rate
               + 패시브(조건이 맞을 때)
               , 1.0 )
크리 = (크리 확정) 또는 (난수 [0,1) < 크리 확률)
```

- 대상 조건 크리 확률(예: "감전 적에게 크리 확률 +50%")은 대상에게 그 징표가 있을 때만 더한다(겹을 곱하지 않는다).

### 14.2 배율

```
크리 배율 = 1.5 + min(크리 데미지 합(속성 조건 포함) + 장비 crit_dmg + 패시브, 3.0)
```

### 14.3 크리 확정

- `sure_crit` 마법(일섬·종언참·종막의 검)은 판정 없이 크리다. **이때 크리 판정 난수를 뽑지 않는다**(구현됨).
- 다단 히트면 모든 히트가 크리다.

### 14.4 다단 히트

- 히트마다 따로 판정한다. `on_crit`은 그 대상에게 한 번이라도 크리가 나면 **한 번만** 실행한다.

### 14.5 적의 크리

```
적 크리 확률 = max(0.05 − 크리 확률 다운 합(상한 50%), 0)
적 크리 배율 = 1.5 (고정)
```

- 적의 크리는 **차지 필살기에도** 판정한다 [제안].

## 16. 버프·약화 체계

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | 버프·디버프 효과 | 따로 쌓아 종류별로 더하고 상한, 시계에 따라 줄어듦 | 머리 위 아이콘(종류 글자 + 남은 수) | 종류 10개, 시계 2개, 디버프 성공 판정, 보스 해제 | 몰아주기 빌드의 핵심은 지키고, 보스만 대응한다 |

### 16.1 데이터

```
{cat, v, dur, clock("own" | "enemy"), name, mark?, el?}
```

- `mark`: 대상(적)에게 그 징표가 있을 때만 적용(특공·조건 크리 확률).
- `el`: 공격 속성이 그 속성일 때만 적용(예: 화염 공격 크리 데미지).

### 16.2 종류 목록

§11.5의 10개 + 아래.

| 종류 | 코드 | 시계 | 뜻 | 상태 |
|---|---|---|---|---|
| 속성 부여 | `element` (`el`) | own | 공격 속성을 바꿈. 여럿이면 마지막 것 | (구현됨) |
| 무적 | `invincible` | enemy | 적의 피해 0 + 기절 막음(§17.5) | (구현됨) / 기절 막음 (미구현) |
| 도발 | `taunt` | enemy | §17.3 | (미구현) |
| 근성 | `guts` | enemy | §17.4 | (미구현) |
| 적 공격력 버프 | `atk` (적) | own(적) | 적 의도 "버프" | (구현됨) |

### 16.3 중첩 [확정 16-1 A]

- 같은 마법을 다시 걸면 **따로 쌓인다**(각자 값·지속). 합은 종류별 상한(§11.5)에서 자른다.
- 머리 위 아이콘은 같은 종류를 하나로 합쳐 값의 합과 가장 긴 남은 수를 보인다.

### 16.4 지속 시계

| 시계 | 줄어드는 때 | 쓰는 것 |
|---|---|---|
| `own` | 그 효과를 가진 유닛이 행동(또는 쉼)을 마칠 때 −1 | 아군 버프 대부분, 적에게 건 디버프 |
| `enemy` | 아무 적이 행동을 마칠 때 −1 (적이 기절로 쉬면 줄지 않음) | 무적, 받는 피해 증감, 도발, 근성 |

- 장비 모래시계 펜던트: 받는 버프 지속 +1(`dmg_taken` 제외 — 구현 그대로).
- 시간의 마녀의 "버프 지속 +N"(`extend_buffs`)은 `own` 시계 버프에만 더한다.

### 16.5 디버프 성공 판정 [확정 16-3 B] **(미구현)**

```
판정 대상: debuff(방어 다운·공격력 다운·크리 확률 다운·받는 크리 확률 증가), enemy_gauge, gauge_zero
성공률 = 효과의 rate (기본 1.0) − 대상의 resist
성공 = 난수 [0,1) < 성공률         (성공률 ≥ 1이면 판정 없이 성공, ≤ 0이면 실패)
실패 → 효과 없음, 대상 위에 "저항" 글 (회색)
```

| 적 등급 | 내성 `resist` [제안] | 기본 마법(rate 1.0)의 성공률 |
|---|---|---|
| 일반 | 0% | 100% |
| 강적 | 10% | 90% |
| 보스 | 30% | 70% |

- **판정하지 않는 것**: 징표(늘 성공 — 빌드의 재료), 기절(§17.2의 규칙), 피해.
- 성공률이 1보다 낮으면 설명 상자에 "성공률 70%"처럼 지금 대상 기준 값을 보인다 [제안].
- 지금 데이터의 디버프는 모두 rate 1.0이다. 강한 디버프에 rate를 낮출지는 수치 검토 때 정한다(§27 R04).
- 적이 마녀에게 거는 디버프(지금은 없음)는 판정 없이 성공한다 [제안].

### 16.6 버프 해제 [확정 16-2 B] **(미구현)**

- **보스만** 가진 행동. 의도에 **"해제"**로 미리 보인다(진보라 알약, §18.3).
- 효과: 살아 있는 마녀 전원의 **버프를 전부** 지운다(무적·도발·근성·속성 부여 포함). 마녀의 패시브·장비 효과·장비 근성·대가(크레딧 0)는 남는다. 적에게 건 징표·디버프도 남는다.
- 해제는 피해를 주지 않는다.
- 아군이 적 버프를 지우는 마법은 없다 [확정 16-2 B — 보스만].

### 16.7 표시

- 버프 아이콘: 8×8 칸, 종류 글자(공·크·확·특·종·막·화·방·약·무 + 도·근) + 오른쪽 아래 남은 수. 최대 6개(§21.6).
- 적에게 건 디버프(방어 다운·공격력 다운)는 같은 칸에 사선을 긋는다.

## 17. 특수 판정과 상태

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | 징표·기절·도발·근성·무적·회복·부활 효과 | 각 규칙대로 | 머리 위 표시·글 | 징표 최대 5겹, 기절 1차례, 근성 1회 | 상태이상은 **빌드의 재료**(징표)와 **명확한 대비 수단**(무적·도발·근성)으로만 |

### 17.1 징표 (화상·빙결·감전) [확정 §0-9 · 17-2]

- 징표 자체는 **아무 효과가 없다** — 특공·조건 크리·터뜨리기의 조건이다. 화상 지속 피해도 없다 [확정 §0-9].
- 속성별 징표: 불 = 화상(`burn`), 물 = 빙결(`frost`), 번개 = 감전(`shock`).

**겹** **(미구현)**

```
징표 걸기(kind, dur, n=1):
    겹 = min(지금 겹 + n, 5)                    # 최대 5겹 [제안]
    남은 수 = max(지금 남은 수, dur + 장비 mark_extra)
지속이 0이 되면 겹째로 사라진다.
징표 연장(extend_mark v): 남은 수 += v (겹은 그대로)
```

- 광역 징표 마법은 대상마다 1겹씩.
- 신더·토난의 패시브: 내가 거는 화상·감전은 1겹 더(§24.3).

**특공**: 겹을 곱한다(§11.4).

**터뜨리기** (`burst`) **(미구현)**

```
대상의 그 징표 겹 N을 센다 (0이면 보너스 없음)
이 공격의 배율 += per × N          (단일 per 0.5, 광역 per 0.3 [제안])
특공은 N겹 그대로 계산한다
맞힌 뒤 그 대상의 그 징표를 없앤다
```

- 터뜨리는 마법(§24.2): 대화재(불, 광역) · 쇄빙 일격(물, 단일) · 벼락 내리꽂기(번개, 단일).
- "징표를 터뜨리되 남겨 두는" 마법(장송의 불·뇌운)은 터뜨리기가 아니다 — 지금처럼 특공 + 연장.
- 결정: **쌓아 두면 파티 전원의 특공이 세지고, 터뜨리면 한 방이 커지는 대신 징표가 사라진다.**

### 17.2 기절 [확정 17-1] **(미구현)**

| 규칙 | 내용 |
|---|---|
| 효과 | 다음 차례 **1번을 쉰다** (행동 없음) |
| 마녀가 적에게 | **특수한 적이 아니면 100% 성공** — 확률·내성 판정 없음. 특수한 적(보스 전원 + 데이터 `stun_immune`)은 "면역" |
| 적이 마녀에게 | 의도 "기절 공격"으로 건다 (미리 보임). 판정 없이 성공. **무적이면 피해와 함께 막힌다** [제안] |
| 겹침 | 기절 중에 다시 걸면 아무 일 없음 |
| 연속 기절 막기 | 기절로 쉰 유닛은 **그다음 자기 차례 1번이 끝날 때까지 기절에 걸리지 않는다** ("기절 내성" 표시) [제안] |

**쉬는 차례의 처리** (§7.7과 함께):

| 항목 | 마녀가 쉴 때 | 적이 쉴 때 |
|---|---|---|
| 차례 시작 크레딧 +1 | 없음 | — |
| 행동 | 없음 ("기절 — 쉼" 0.6초) | 없음 |
| 게이지 | 0이 된다 | 0이 된다 |
| 자기 own 시계 버프·징표 | −1 (차례로 친다) | −1 |
| 마녀의 enemy 시계(무적 등) | — | **줄지 않음** |
| 패턴 위치·차지 | — | **그대로** (그 의도는 다음 차례로 미뤄짐) |
| 대가(크레딧 0) | 이 차례로 확인 | — |

- 그래서 적을 기절시키면 **미리 보인 강공격·필살기를 한 차례 미룬다**. 보스는 면역이라 보스전에선 쓸 수 없다.
- 마녀 쪽 기절 출처: 마법 2개(완전 동결·뇌격, §24.2)와 대마법 2개(심연 붕괴·절대 영도, §24.4).

### 17.3 도발 [확정 17-3 B] **(미구현)**

- 도발이 걸린 마녀가 **적의 단일 대상 행동**(공격·강공격·기절 공격·필살기 중 단일인 것)을 받는다.
- 도발한 마녀가 여럿이면 그중 균등 무작위.
- 전체 공격·해제에는 영향이 없다.
- 지속: 적 행동 N번(enemy 시계). 장비 강철 심장은 상시 도발.
- 출처: 네레이 샘물 붓기(§24.2), 장비 강철 심장(§24.5).

### 17.4 근성 [확정 17-4 B] **(미구현)**

```
hp가 0이 되는 순간 근성이 있으면:
    hp = max(1, 반올림(최대 체력 × 근성 비율))     # 비율 0이면 체력 1
    그 근성 하나를 소모한다 → "근성" 글
여러 개면: 마법 근성(지속이 짧은 것부터) → 장비 근성(전투당 1번) 순
```

- 근성으로 버틴 뒤에도 같은 행동의 남은 히트는 계속 들어온다(지금은 적의 공격이 모두 1히트라 생기지 않는다. 적의 다단 공격이 생기면 다음 히트에 다시 쓰러질 수 있다).
- 출처: 호라 되감기(§24.2), 장비 깃털 부적(§24.5).

### 17.5 무적

- 적의 피해를 0으로 막는다("무적" 글). 지속: 적 행동 N번(enemy 시계).
- 적의 기절 공격도 막는다 **(미구현)**. 해제(§16.6)에는 지워진다.

### 17.6 회복

- 최대 체력 × 비율. 쓰러진 마녀는 회복할 수 없다(되살림만).

### 17.7 되살림

- `revive pct`: 쓰러진 마녀를 체력 max(1, 반올림(최대 × pct))로 되살린다. 게이지 0, 크레딧은 쓰러질 때 그대로 [확정 17-5 A]. 걸려 있던 대가(크레딧 0)도 그대로 남는다(§26 X10). 살아 있는 대상이면 같은 비율만큼 회복한다.
- 되살린 마녀는 다음 차례부터 게이지가 찬다.

### 17.8 쓰러짐과 패배

- 쓰러짐: §10.4. 3명 전원이 쓰러지면 패배(§20).

### 17.9 대가 (`demerit_zero`)

```
걸 때: 대상.zero_after_turn = 지금 차례 번호
대상이 행동(또는 쉼)을 마칠 때: zero_after_turn ≥ 0 이고 지금 차례 번호 > zero_after_turn 이면
    크레딧 0 (0보다 많았을 때 "크레딧 0" 글), zero_after_turn = −1
```

- 즉 **"걸린 뒤 대상의 첫 행동이 끝나면"** 크레딧 0. 불의 신 강림(게이지 100% → 바로 다음 차례)과 함께 써서 "한 번 크게, 대가는 나중에"를 만든다.

## 18. 적 행동·AI·차지·여러 줄 체력

> **요약**
>
> | 입력 | 처리 | 피드백 | 파라미터 | 설계 의도 |
> |---|---|---|---|---|
> | (자동) 적 차례 | 미리 정해 보인 의도를 실행. 의도는 패턴 + 조건 + 차지로 정함 | 머리 위 의도 알약(종류만), 차지 칸, 줄 수 | 등급 3, 의도 7종, 차지 3~5, 줄 2~3 | 의도가 보이므로 **예측할 수 있어야** 하고, 조건이 보스의 성격을 만든다 [확정 §0-8 · 18-1 B] |

### 18.1 적 등급

| 등급 | 내성 | 기절 | 차지 | 여러 줄 | 해제 | 머리 위 막대 폭 |
|---|---|---|---|---|---|---|
| 일반 | 0% | 걸림 | 없음 | 없음 | 없음 | 50 |
| 강적 | 10% | 걸림 | 있을 수 있음 | 없음 | 없음 | 50 |
| 보스 | 30% | **면역** | 있음 | **2~3줄** | 있음 | 60 |

[제안] — 등급별 값. 적마다 데이터로 바꿀 수 있다(§5.4).

### 18.2 의도 결정 (패턴 + 조건) [확정 18-1 B] **(미구현 — 조건)**

```
다음 의도를 정하는 때: 전투(웨이브) 시작 · 그 적의 행동이 끝날 때 · 줄이 깨질 때 · 차지가 가득 찰 때
정하는 순서:
  1. 차지가 가득이면 → charge_act (필살기)
  2. 줄이 방금 깨졌고 on_break에 의도가 있으면 → 그 의도 (예: 해제)
  3. rules를 위에서부터 보고 처음 맞는 규칙:
       pattern이 있으면 그 패턴으로 바꾸고(위치 0부터) 그 첫 의도
       insert가 있으면 그 의도 하나를 끼워 넣음 (패턴 위치는 그대로)
  4. 맞는 규칙이 없으면 → 지금 패턴의 다음 의도 (순환)
정한 의도는 intent_now에 두고 머리 위에 보인다. 그 적의 차례까지 바뀌지 않는다 (위 "정하는 때"가 다시 오기 전까지).
```

**조건 (`rules[].when`)** [제안]

| 조건 | 값 | 뜻 |
|---|---|---|
| `hp_below` | 비율 | 지금 줄(또는 전체) 체력이 이 비율 미만 |
| `bar` | 줄 번호 | 지금 줄이 이 번호 |
| `witch_buffs` | 개수 | 살아 있는 마녀 전원의 버프 개수 합이 이 수 이상 (해제용) |
| `allies_dead` | 개수 | 같은 웨이브의 다른 적이 이 수 이상 쓰러짐 |
| `acted` | 횟수 | 이 적의 행동 수가 이 수의 배수 |

- 규칙은 한 번 맞으면 다시 평가될 때까지 유지된다(패턴을 바꾼 경우 새 패턴이 순환).

### 18.3 의도 표시 (종류만) [확정 §0-9]

| 의도 | 코드 | 알약 색 | 실행 |
|---|---|---|---|
| 공격 | `attack` | 연주황 `#ff9a7a` | 단일 무작위(도발 우선) × mult |
| 강공격 | `heavy` | 빨강 `#ff4f6a` | 단일 × mult (2.0 안팎) |
| 전체 공격 | `aoe` | 노랑 `#ffcf7a` | 살아 있는 마녀 전원 × mult |
| 버프 | `buff` | 보라 `#c9a0ff` | 자기 공격력 +v (행동 dur번) |
| 기절 공격 | `stun_attack` | 하늘 `#8fd8ff` [제안] | 단일 × mult + 기절 (§17.2) (미구현) |
| 해제 | `dispel` | 진보라 `#a070ff` [제안] | 마녀 전원의 버프 전부 제거 (§16.6) (미구현) |
| 필살기 | `finisher` | 진빨강 + 깜빡임 [제안] | 차지로만. 데이터대로 (예: 전체 × 2.5) (미구현) |

- 숫자(배율·피해)는 보이지 않는다. 대상도 보이지 않는다(무작위이므로).

### 18.4 대상 [확정 18-2 A]

- 단일 대상 의도: 도발한 마녀가 있으면 그중 균등 무작위, 없으면 살아 있는 마녀 중 **균등 무작위**. 자리 가중은 없다 [확정 6-3 A].
- 대상은 **실행 순간**에 뽑는다.

### 18.5 차지 [확정 18-3 B] **(미구현)**

```
charge_max = 3 ~ 5 (보스·강적 데이터)
적이 행동을 마칠 때: 그 행동이 필살기가 아니면 charge += 1 (기절로 쉬면 +0)
charge == charge_max가 되면: 다음 의도를 즉시 필살기로 바꾼다 (§18.2 ①)
필살기를 쓰면: charge = 0
```

- 아군이 차지를 직접 깎는 효과는 없다. **게이지 감소·게이지 0**으로 그 적의 차례를 늦추면 필살기도 늦어지고, **기절**은 일반·강적의 필살기를 한 차례 미룬다(보스는 면역).
- 표시: 머리 위 의도 알약 오른쪽에 칸 `charge_max`개(빈 칸 회색, 찬 칸 빨강). 가득이면 의도 알약이 "필살기"로 바뀌며 깜빡인다(§21.6).

### 18.6 여러 줄 체력 [확정 18-4 B] **(미구현)**

```
bars = [줄1 체력, 줄2 체력, (줄3 체력)]    # 보스만, 2~3줄
보스의 hp/max_hp = 지금 줄의 값. 줄 번호 bar_i = 0부터
줄의 hp가 0이 되면 (마지막 줄이 아니면) — 브레이크:
    1. 넘친 피해는 버린다. 이 행동에서 이 보스에게 남은 히트도 버린다 (§10.6)
    2. bar_i += 1, hp = max_hp = 다음 줄 체력
    3. 보스에게 건 징표·디버프는 남는다 [제안]
    4. on_break 실행: {pattern?, intent?, buff?} — 패턴 교체 / 다음 의도 지정(예: 해제) / 자기 버프
    5. 다음 의도를 다시 정한다 (§18.2 ②)
    6. 연출 "브레이크" 1.0초 (§22.2)
마지막 줄의 hp가 0이면 쓰러짐(§10.4)
```

- 표시: 체력 막대 오른쪽에 남은 줄 수 "×2". 적 상세(§21.11)에 줄마다 체력.
- 의도: "한 줄을 한 번에 깨는" 한 방이 목표가 되고, 보스전이 단계로 나뉜다.

### 18.7 기절 공격

- `stun_attack {mult}`: 단일 대상(도발 우선) 피해 × mult + 기절. 무적이면 둘 다 막힌다. 기절 내성(§17.2) 중인 마녀는 피해만 받는다.

### 18.8 적의 버프

- `buff {v, dur}`: 자기 공격력 +v, 지속 "행동 dur번"(own 시계). 따로 쌓인다. 해제 대상이 아니다(해제는 마녀 버프만).

### 18.9 적의 피해·크리

§11.6 · §14.5.

## 20. 승패 판정

### 20.4 특수 승패

- 없다(제한 차례·보호 대상·특정 적만 쓰러뜨리기 등). 콘텐츠를 만들 때 필요하면 이 절에 더한다.

### C.5 빌드 예시 (0.1)

- **에스카를 화염 딜러로**: 엠버 장작(화염 부여·크리뎀 +50%) → 이그니스 불씨(화상) → 엠버 풀무(화상 특공·크리 +30%) → 에스카 종언: 13,000 × 6.0 × 1.5 × 1.4 × 1.5 ≈ 245,000 / 크리면 ×2.0 = 491,000. 검은 잔(+60%)이면 785,000.
- **이그니스 몰빵**: 불씨 → 불의 축복 → 풀무(이그니스) → 화염 집중 → 불의 신 강림 → 태양의 창 ≈ 453,600 / 크리 907,000. 대신 그 뒤 이그니스 크레딧 0.
- **버티기**: 봉공(전체 무적 + 크레딧) → 온기(회복 + 게이지) → 불막이(받는 피해 −40%)로 강공격·전체 공격 차례를 넘기고, 모은 크레딧으로 흑성·대화재.
- 이 값들은 징표 겹(§17.1)이 없던 때의 계산이다.
