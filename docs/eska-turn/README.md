## 0. 턴제 전투 기획 — 사용자 1차 (2026-10-18) [확정]

> 사용자가 직접 쓴 기획을 구조만 정리해 옮겼다. **§1~§9와 부딪히면 이 절이 우선한다.** "(개수 확정 x)"라고 쓴 수치는 [가안].

### 0-1. 장르·화면
- **2D 대각선 사이드뷰, 픽셀아트, 턴제 RPG, 마녀 컨셉.**
- 주인공들은 **왼쪽**, 적은 **오른쪽**에 선다.
- 스킬 고르기 UI는 아르피아·33원정대처럼 **캐릭터 주위에** 뜬다.
- 머리 위에 **행동 게이지**가 차오르는 게 보이고(아르피아), 화면 맨 위에 **차례 줄**이 보인다(33원정대).

### 0-2. 기본 규칙 — 행동 순서
- 각자의 **행동 게이지가 차는 순서**대로 행동한다.

### 0-3. 행동 크레딧 (자원)
- 캐릭터마다 **행동 크레딧**을 가진다. 행동은 보유 크레딧만큼 할 수 있다. 어떤 행동은 적게, 어떤 행동은 많이 소모한다.
- **매 차례 1개**씩 주어진다. **기본 공격으로 차례를 넘기거나**, 크레딧을 주는 스킬로 **모을 수 있다**.
- 쓰지 않은 크레딧은 **다음 차례로 누적**된다.
- 마법은 **소모 크레딧이 높을수록 강하다**.

### 0-4. 마법
- 크게 **보조 마법 / 공격 마법**.
- **공격 마법**: 적 1~다수에게 피해. 단일 강타 또는 더 약한 광역. 강한 공격 마법엔 부가 효과가 붙을 수 있다(예: 화상 부여, 적 방어력 다운, 공격 전/후 자기 공격력 버프).
- **보조 마법**: 아군 1~다수에게 이로운 효과, 적 1~다수에게 해로운 효과. 부활처럼 강력한 것도 있다.
- 보조 효과는 아래 목록을 **적절한 배율로 한두 가지 섞어** 만든다. 1명 대상·전체 대상이 모두 있다:
  공격력 증가 · 크리티컬 확률 증가 · 크리티컬 데미지 증가 · 상태이상 부여(기절·화상·빙결·내성 다운·방어력 다운 등) · 크레딧 증가 · 부활 · 행동 게이지 증가(차례가 더 빨리 옴) · 공격력 크게 증가(대신 페널티) · 체력 회복 · 방어력 증가 · 무적 · 특정 상태이상 특공(추가 데미지) · 최종 데미지 증가 · 적 크리티컬 확률 다운 · 그 밖(불의 신으로 변신, 맵 환경 변화 등 재미 요소).
- 배울 수 있는 마법은 여럿, **전투에 장착해 나가는 건 최대 5개** (개수 확정 x). 마녀 한 명이 배우는 스킬은 **약 10가지** (개수 확정 x).

### 0-5. 속성
- 대부분의 마녀는 **물·불·번개** 중 하나.
- **특수 마녀**는 특수 속성(예: **공간, 검술, 시간**)으로 **무상성**을 지향하며, 단순 딜 증가보다 **부활·크리티컬 데미지 증가처럼 속성을 타지 않는 스킬**을 가진다.
- 특정 적은 **약점**이 있어 속성을 고루 키워 돌아가며 써야 한다: 약점 적중 **1.5배**. 특수 마녀는 무상성이되 그보다 약한 **1.2배**.
- 속성 조합 예: 화염 마녀들을 데려가면 화상을 걸고 화상 특공 버프로 화염 공격을 아주 강하게. **버퍼가 무상성 딜러에게 "공격에 화염 속성 부여"를 걸어 화염 딜러처럼 쓸 수도 있다.**

### 0-6. 파티·캐릭터 수
- 전투 파티 **최대 3명**.
- 초기 개발 단계의 마녀 수: **속성별 3명(물·불·번개 = 9명) + 무상성 3명 = 12명**.

### 0-7. 핵심 재미
- 마녀들을 성장시켜 스킬을 배우고 강화하고, 파티를 꾸려 **빌드**를 짜서 **강력한 데미지**로 적을 물리치는 것. 레퍼런스는 **33원정대와 FGO**.
- 빌드 예 (마녀 1 = 무상성 메인 딜러, 마녀 2·3 = 화염):
  - 마녀 2 → 마녀 1에게 "화상 상태 적 특공" + "화염 공격 시 크리티컬 확률 증가"
  - 마녀 3 → 마녀 1에게 "공격에 화염 속성 부여" + "화염 공격 크리티컬 데미지 증가"
  - 마녀 1 → 적 단일 "방어력 감소 후 피해" 스킬
- 빌드 예 (마녀 1 = 화염 딜러): 마녀 2 화상 특공·화염 크리 확률 / 마녀 3 화염 피해 20%·화염 크리 데미지 → 마녀 1 강력한 화염 공격.

### 0-8. 사용자 2차 답변 (2026-10-18) [확정]
- **파랑 금지·시계 모티프 금지는 푼다** ("폐기된 거니 다 허가해") — 물 속성은 파랑으로, 시간의 마녀는 시계 모티프를 써도 된다.
- **틈 증폭**(에스카가 찢은 틈을 동료 마법이 지나면 배율): 느낌은 좋지만 아직 생각 없음 → [보류].
- **게이지는 고르는 동안 멈춘다** (웨이트).
- **한 차례에 행동 하나** 쪽으로 기울었으나 "스킬 조합으로 빌드 짜기가 어려워지지 않을까" 걱정 → Claude 답변 뒤 결정 (0-9 참고).
- **기본 공격**: 피해를 주면서 차례를 넘긴다. 쓰면 **크레딧 +1을 더** 준다 (일단).
- **크레딧 상한 7.**
- **적 차례엔 입력 없음.** 적의 **다음 행동을 미리 볼 수 있다** (슬레이 더 스파이어의 의도 표시처럼).
- **내 공격에 타이밍 입력 없음.**
- **적은 게이지만 있고 크레딧은 없다.**
- **에스카**: 무상성, 강력하고 범용성이 높지만 **파티에서 뺄 수도 있다.**
- **속성별 3명**: 셋 다 공격·버프·디버프 스킬을 가지되 **비율이 다르다**(공격이 특히 강한 마녀, 버프·디버프 성능이 좋은 마녀). **장착 스킬에 따라 역할이 바뀐다.**
- **성장**: 레벨 + 스킬 배우기 + 스킬 강화(**레벨 3까지**) + **장비**.
- **그림**: 일단 코드로 그리고, 60%쯤 만든 뒤 스프라이트 시트로 바꾸는 안 → Claude 의견 뒤 결정 (0-9 참고).

### 0-12-2. 사용자 11차 지시 (2026-10-18) [확정] → 자율 개발 루프 진행 중
- `combat_proto.md`의 [제안]은 **모두 Claude 추천대로** 간다. 추천 순서(① 엔진·데이터·시험 → ② 화면·편성 → ③ 연출·그림·소리 → ④ 밸런스 재측정)로 개발하고, 끝나면 여러 시나리오로 밸런스를 검증한다. 그 뒤 FGO 역기획서를 참고해 **우리 게임에 필요한 부분**을 능동적으로 찾아 기획·개발한다(그대로 베끼지 않음).
- 진행 방식: **개발자 1 + 검토자 1** 루프. 개발자가 만들고, 검토자가 FGO 역기획서·우리 기획서·개발된 게임을 보고 비슷한 수준이 되도록 고칠 것을 말하면 개발자가 다시 만든다. 사용자가 따로 말할 때까지 멈추지 않는다. 질문하지 않고 Claude 추천대로 정한다. 진행 상태는 `loop_status.md`.
- 특히: **FGO처럼 보기 쉽고 직관적이며 조잡하지 않은 UI**, 전투 화면(UI·캐릭터 배치) 개선, 출시 가능한 수준의 전투 시스템, 아트는 최대한 예쁘게.
- 마법: 정해 둔 효과를 마구 조합하지 말고 **FGO의 강력한 인기 서포터·딜러의 스킬 구조**를 참고하고, 대마법은 **FGO의 강력한 보구들**, 패시브는 **클래스 스킬·서번트 기본 패시브**를 참고한다. 조합했을 때 재미있고 강력한 빌드가 나오도록 **계산해서** 만든다. (구조만 — 이름·고유 요소 복제 금지는 그대로)
- 속성별 플레이스타일을 다르게 [방향]: 예) 불 = 버스터처럼, 물 = 아츠처럼, 번개 = 퀵처럼 — 이름·규칙을 그대로 쓰지 말고 속성마다 다른 재미가 나게.
- 빌드 원형 [방향]: 초인 오리온처럼 **강력한 평타 크리** 빌드, FGO "시스템"처럼 **대마법 3연속** 빌드, 수행사제팟처럼 **아주 강한 적을 버티며 피해를 쌓는 예능 빌드** 등. 여기에 매몰되지 말고 다양한 재미를 찾는다.

| 무기 | **들지 않는다.** 손짓·주문으로 공간이 갈라진다 (빗자루 검은 2026-10-18 폐기 — 검은 파티원 "검의 마녀"의 것) | [확정] |
| 베기·근접 칼질 | **없다** ("베기가 있는 것부터 틀렸어. 정말 마녀식으로") | [확정] |
| 역할 | **딜러로도, 초고배율 서포트(증폭) 마녀로도** 쓸 수 있게 — 빌드로 고름. 증폭형이면 원소를 쓰는 다른 마녀를 딜러로 세움 | [방향] |
| 외형(현재 그림 기준) | 백발 장발(오른쪽 눈을 덮는 앞머리), 챙 넓은 검은 마녀 모자(챙 끝이 갈라져 흰 공허가 비침), 검은 롱드레스(자락 끝이 갈라져 흰 공허), 회보라 시스루 소매, 보라 안감. **흑백 바탕 + 보라는 포인트** | 기존 그림 |
| 위상 | 세계관 최강자급(먼치킨). "강해지는" 성장 설정은 [보류] — §8 | [확정](강자) / [보류](성장 이유) |

## 5. 전투

### 5-1. 파티
- **에스카 + 서포터 1~2명** [확정].
- 서포터 = **원소를 쓰는 다른 마녀** [방향]. 딜러형·보조형이 섞여 있어야 에스카의 딜러/증폭 빌드가 둘 다 성립한다.
- 서포터의 정체 [제안·미정]: "인간 형태의 사역마(폴리모프)"를 사용자가 떠올렸다. 이어서 사용자: **"동물 모습은 꼭 해야 하나? 스킬은 똑같이 둘까 싶은데"** → 전투에서 동물·사람 두 형태로 스킬을 나누는 안은 사실상 빠짐. Claude 제안: 동물 모습은 **쓰러졌을 때 작은 동물로 돌아가는 그림 하나**만(제작비 거의 없음) — 사용자 미결정.
- 서포터가 **대신 싸우는 하수인**은 [폐기] (사용자: "하수인은 좀 별로"). 서포터는 함께 싸우는 동료.
- 캐릭터 교체형(한 명만 나가고 바꿔 쓰기)은 비교만 했고 채택 안 됨.

### 5-2. 행동 게이지 [대기 — 사용자가 고름]
사용자가 "다양하게 제시해 달라"고 해서 아래 7가지를 보여 줬다.

| 방식 | 대표작 | 구조 | 장점 | 단점 |
|---|---|---|---|---|
| ① 액티브 ATB | 파이널 판타지 4 기본 | 게이지가 실시간으로 차고 **고르는 동안에도 시간이 흐름** | 긴장감 | 폰에서 바쁨 |
| ② 웨이트 ATB | 파이널 판타지 4 웨이트 모드 | 게이지는 실시간, **고르는 동안 멈춤** | 폰 친화 | 긴장 감소 |
| ③ 아르피아식 | 마법학교 아르피아 | 게이지가 차면 고름, 고르는 동안 다른 캐릭터·펫·몬스터가 움직임(①과 같은 계열) | 익숙함 | ①과 같음 |
| ④ 순서표(CTB) | 파이널 판타지 10 | 실시간 없음. 다음 차례 목록이 보이고 **무거운 행동일수록 다음 차례가 늦음**, 가속·감속으로 순서 조작 | 완전한 계획 게임 | 실시간 맛 없음 |
| ⑤ 행동값 | 붕괴: 스타레일 | 행동값 = 10000 ÷ 속도, 낮은 쪽 먼저. **당기기·밀기**로 조작 | 속도 맞추기가 빌드 재미 | 숫자가 많음 |
| ⑥ 시전 + 끊기 | 그란디아, 차일드 오브 라이트 | 게이지가 "대기 → 시전" 두 구간. **시전 중에 맞으면 끊기고 뒤로 밀림** | 주문을 읊는 마녀 판타지에 가장 잘 맞음. 서포터가 지키거나 적 시전을 끊는 역할이 생김 | 화면 모양까지 닮으면 안 됨 |
| ⑦ 예약 발동 | 파이널 판타지 택틱스 | 주문을 고르면 **나중에** 발동 | 큰 마법의 무게감 | 단독으론 단조로움 |

- Claude 추천: **⑥ 시전 + 끊기 + ② 고르는 동안 멈춤** [제안].

### 5-3. 기본 공격 [대기]
- 사용자: **"내가 말해줄 거야, 나중에."** — 먼저 제안하지 않는다.
- 참고(이전 제안, 결정 아님): 바늘(가리키면 적 자리에서 작은 균열) / 기본 공격 없음 / 짧은 광선. "작은 마력탄 기본기 없음"은 실시간판 때의 [확정]이었으므로, 다시 꺼내려면 사용자 확인.

### 5-4. 적 턴의 긴장 — 받아치기 없이
- **실시간 받아치기·패리 [폐기]** — "너무 카피야".
- 대안 [제안]: ⑥의 **시전 끊기**(서포터가 적의 시전을 끊음), FGO식 **사전 대비**(적의 다음 행동 예고를 보고 내 턴에 막기).

### 5-5. 속성 [방향]
- 실시간판의 [확정] "원소 없음"을 사용자가 풀었다: **"속성은 넣어도 될 것 같기도 하고"**.
- 제안한 3안: A 원소 속성(불·얼음 등, 상성) / B 마녀식 계통(찢기·묶기·부식·메아리) / **C 섞기 — 일반 마법은 원소, 에스카만 원소 밖의 "공간" 마법**.
- 이후 에스카=공간 증폭, 서포터=원소 딜러 방향에 사용자가 "좋아" → **C안 쪽으로 기움**. 공식 확정은 아님 — 확인할 것.

### 5-6. 에스카의 증폭: "틈 증폭" [제안 — 사용자 "좋아"]
- 에스카가 공간을 찢어 틈을 열고, **동료의 원소 마법이 그 틈을 통과하면 배율이 붙는다.**
- 에스카 고유 마법(공간 찢기) 정체성을 지키면서, 버퍼가 화면에서 수동적으로 보이는 문제를 막는다.
- 행동 게이지 ⑥과 맞물리면 "틈을 여는 순간과 동료 시전 끝을 맞추는 박자"가 재미가 된다.

### 5-7. 버프 배율 밸런스 [제안 — 반드시 지킬 것]
- FGO는 **같은 종류 버프는 더하고, 다른 종류끼리는 곱한다**(예: 버스터 +10%와 +50% = +60%, 버스터 +50%와 공격 +10% ≈ ×1.65). 버프를 여러 종류로 쌓으면 같은 양이라도 ×2.68이 아니라 ×3.73이 된다.
- 초고배율 증폭을 넣는다면:
  1. **버프 종류는 3~4개로 제한**
  2. **배율 상한**(FGO도 흔한 공격 버프 계열은 최대 1000% 상한)
  3. **보스는 버프 대응형**(버프 해제·시전 끊기·여러 줄 체력바)
  4. **에스카 딜러 빌드와 증폭 빌드의 체감 속도를 비슷하게**

## 7. 재해석 후보 자산 (설계 아이디어만 — 그대로 확정 아님)

실시간판에서 만든 것 중 **턴제에도 의미가 있는 아이디어**. 새 세션은 필요할 때 제안 재료로만 쓴다.

- **대마법 4종 + 종언 게이지**: 흑성(검은 별이 끌어모아 붕괴) · 유성우(하늘을 길게 찢고 유성이 쏟아짐) · 종말의 운석(거대한 운석 한 방) · 봉공(공간 정지). 게이지는 그믐달 → 보름달 그림. "가득 = 1회, 빈 채 시작, 순환 선택"이 실시간판 규칙이었다.
- **물약**: 나에게 쓰는 건 마시고 적에게 쓰는 건 던짐. **재료 2~3개 조합**, 결과에 **좋은 물약 · 쓸모없는 물약(흐린 물) · 페널티 물약(쓴 물)** 이 섞임(발견의 재미). 재료 6종(맨드레이크 뿌리·거미줄·독버섯·달이슬·까마귀 깃털·묘지 흙), 조합 21가지, 물약 11종(치유·메아리·포식·충만·가속·확장 / 속박·비명·부식 / 흐린 물·쓴 물), **마녀 수첩**(처음 달인 조합 기록, 모르는 칸엔 힌트), **가마솥**에서 달이기. 세부 수치는 `docs/eska/potions.md`.
- **틈 달이기**: 찢은 틈에 물약을 던지면 틈을 따라 스민다. → 턴제에선 §5-6 "틈 증폭"으로 이어짐.
- **마녀다움 연출 원칙**: 손끝 마녀 문장(원 안의 일곱 갈래 별 — 오각별 클리셰 피함) → 공간이 찢김 / 틈 안은 밤하늘 / 깨진 파편 일부가 까마귀 깃털 / 찢긴 공간은 꿰매지듯 닫힘 / 대마법 때 몸이 떠오르고 등 뒤 문장 고리.
- **검성(보스 컨셉)**: 고요히 서 있다 한순간에 베는 정통 위엄 검성, "벤 뒤에야 참격선이 터진다", 먹·뼈흰·붉은 끈. 그림자 분신 셋(모두 끊으면 크게 이득, 무시하면 손해) — 턴제 보스 기믹으로 바꿔 쓸 수 있음.
- **화면 전체 연출은 큰 순간에만**: 사용자가 루미너스(메이플스토리) 스킬 영상을 보여 줬고, Claude 판단은 "기본 전투로는 과하고 대마법·필살 순간엔 딱 맞다". 턴제에선 대마법 연출을 이 규모로 써도 공정성 문제가 없다.

- 낙제생 + 금서 사냥꾼 + 각성 겹치기 — "구린데"

## 12. 레퍼런스 조사 요약 (출처는 §13)

### 12-1. FGO
- **편성**: 내 서번트 최대 5 + 친구 서포트 1(선발 3·후발 3), 서번트마다 개념예장 1장, 마스터 레벨에 따른 편성 비용 상한.
- **커맨드 카드**: 매 턴 5장 중 3장 선택. Buster(피해 150%) · Arts(100%, NP 충전) · Quick(80%, 별).
  - 첫 카드 보너스: Buster 첫 = 피해↑, Arts 첫 = NP 획득↑, Quick 첫 = 별↑ + 치명 확률 +20%.
  - 위치 보너스(뒤일수록↑): Buster 10/15/20%, Quick 별 80/130/180%, Arts NP 300/450/600%.
  - 체인: Arts = NP +20%, Quick = 별 +10(일본판 20), Buster = ATK 20% 고정 추가 피해, **브레이브 체인**(같은 서번트 3장) = 4번째 엑스트라 어택(치명타 불가).
- **보구(NP)**: 100%면 사용. 오버차지(2017 가이드 기준 보구 2~4레벨 200%, 5레벨 300%)로 부가 효과 강화. 오버킬은 NP를 더 줌.
- **치명타 별**: 공격으로 생성 → 다음 턴 카드에 분배(클래스별 흡수 가중치, 예: 라이더 200·버서커 10). 50개 이상이면 전 카드 치명타.
- **스킬 층위**: 서번트 스킬 3 + 어펜드 3(2번 = 시작 NP) + 마스터 스킬(미스틱 코드, 오더 체인지) + 영주 3(하루 1 회복, NP +100% 또는 HP 회복).
- **상성**: 클래스 2배/1.5배/0.5배, 숨은 속성 ±10%.
- **적**: 차지 게이지(차면 보구, 적 턴에 갑자기 차기도 함 → 사전 대비가 핵심), 한 턴 최대 3행동, **브레이크 바**(한 턴 한 줄, 다음 줄에서 새 기믹), 처치 순서 기믹.
- **빌드 핵심 = 루프**: 지원 서번트(카스토리아·코얀스카야·오베론 등)의 버프·NP 충전을 한 명에게 몰아 보구 → 게이지가 다시 참 → 또 보구. **버프는 같은 종류 합산, 다른 종류 곱셈, 흔한 공격 버프 상한 1000%.**
- **한계**: 적 턴에 할 일이 없음, 메타가 소수 지원 서번트로 굳음.

### 12-2. 33원정대 (Clair Obscur: Expedition 33)
- **순서**: 속도 기반, 아군·적이 섞여 행동.
- **AP**: 턴 시작·기본 공격 +1·완벽 받아치기 +1로 얻고, 스킬·자유 조준(1발 1AP)에 씀 → "기본 공격으로 모으고 큰 스킬로 씀" 리듬.
- **공격 타이밍 입력**: 내 공격·스킬에도 타이밍 입력(완벽 시 최대 +100%라는 가이드), 설정에서 끌 수 있음.
- **방어**(우리는 쓰지 않음): 회피(넓음)·받아치기(좁음, 연속 전부 성공 시 반격)·점프·그라디언트 카운터.
- **브레이크**: 노란 게이지 → 브레이크 스킬로 1턴 기절 + 추가 피해. **그라디언트 공격**: 유대 레벨로 해금, 턴 순서 무시.
- **상태**: 표식(다음 공격 +50%), 무방비(+25% 또는 +50%, 출처 갈림), 강력·보호막·가속, 화상.
- **캐릭터 고유 자원**(이 게임 빌드의 핵심):
  - 귀스타브: 오버차지 충전 → 번개로 갑옷 파괴·기절
  - **루네: 얼룩 5종**(불·냉기·번개·땅·빛). 스킬이 만들고 다른 스킬이 소모, 빛은 아무 얼룩 대신
  - 마엘: 자세 3종 — 공격(주는 +50%/받는 +50%) · 방어(받는 −50%, 회피·받아치기 시 AP +1) · 비르투오즈(주는 +200%)
  - 시엘: 태양 스킬이 예언을 쌓고 달 스킬이 소모, 둘 다면 황혼 강화
  - 베르소: 완벽 단계(때리거나 피하면↑, 맞으면↓, S랭크)
  - 모노코: 야수의 바퀴(가면 5종 순환)
- **장비**: 픽토스 3칸(능력치+효과) → **4번 이기면 루미나로 습득** → 루미나 포인트로 아무 캐릭터에 효과만 장착. 속성 5종(활력·힘·민첩·방어·행운, 레벨당 3점). 지역·보스별 원소 약점.
- **비판**: 타이밍 창이 빡빡함(창 넓히기 모드 등장), "리듬 게임 같다".
- **복제 경계**: 자원 쌓기·소모 구조는 장르 공통 → 사용 가능. **픽토스→4승→루미나** 같은 고유 흐름, 받아치기는 그대로 쓰지 않음.

### 12-3. 마법학교 아르피아
- 2007년 엔씨소프트 계열 제이인터랙티브의 플래시 캐주얼 RPG. 2012년 플레이엔씨 종료 뒤 야후로 옮김. 현재 서비스 없음으로 보임.
- **행동 게이지형 턴제**: 게이지가 차면 커맨드를 고르고, 고르는 동안에도 다른 캐릭터·펫·몬스터가 행동.
- **펫이 아군으로 함께 싸움**(마법 대신 스킬 버튼), 훈련으로 원하는 스킬을 가르침. 잠재우기가 강해 베개 펫이 인기였다는 회고.
- **선행 점수**: 퀘스트 보상으로 받아 캐릭터·펫 스킬을 배움.
- 마법 수업이 불·얼음·대지 교실로 나뉘고 상성 있음. 종족 3 × 남녀.
- 우리와의 차이: 저연령 캐주얼이라 빌드가 얕음 → 깊이는 FGO에서.

### 12-4. 1인 개발과 턴제
- Slay the Spire는 사실상 두 사람, Balatro는 1인 개발.
- 실시간 액션을 만들다 적 구현이 막혀 턴제 RPG로 바꾸고 범위를 줄인 1인 개발 사례가 있음.
- 턴제의 손맛은 **피드백의 속도와 명료함**(옥토패스 트래블러 2 분석).
