2. 다 읽고 나면 **세 줄로만** 요약해서 알려 줘: 지금 단계, 정해진 핵심, 내가 정해야 할 것.
3. 그다음엔 **내가 말할 때까지 기다려.** 아무것도 만들거나 고치지 마.
