## 3. 공통 계산 기반 — 비용 효율

크레딧 수입: 마법을 쓰는 차례 +1, 기본 공격 차례 +2. 비용 c 마법을 끊임없이 쓰면 그 마법을 쓰는 차례 비율 f = 2/(c+1), 턴당 배율 = f×m + (1−f)×1.0.

| 마법 | 비용 | 배율 | 사용 비율 | **턴당 배율** | 크레딧당 배율 | 판정 |
|---|---|---|---|---|---|---|
| 1비용 단일 | 1 | 2.0 | 1.00 | 2.00 | 2.00 | 기준 |
| 2비용 단일 | 2 | 2.5 | 0.67 | 2.00 | 1.25 | 부가 효과로 값을 함 |
| 3비용 단일 | 3 | 3.5 | 0.50 | 2.25 | 1.17 | |
| 4비용 단일 | 4 | 4.0 | 0.40 | 2.20 | 1.00 | **3비용보다 낮다** → 4비용은 4.5배 또는 선버프 필수 |
| 에스카 종언 | 4 | 6.0 | 0.40 | **3.00** | 1.50 | **예산 위반** (대마법 3.25에 근접) |
| 5비용 단일 | 5 | 6.0 | 0.33 | 2.67 | 1.20 | |
| 하르페 종언참 (확정 크리) | 5 | 6.0×1.5/1.05 = 8.57 상당 | 0.33 | **3.52** | 1.71 | **예산 위반** (대마법보다 셈) |
| 대마법 (지금 안) | 7 | 10.0 | 0.25 | 3.25 | 1.43 | 5비용보다 +22% |
| 대마법 (12.0 안) | 7 | 12.0 | 0.25 | 3.75 | 1.71 | 5비용보다 +41% |

요건 [제안]:
- R1. **턴당 배율은 비용이 오를수록 단조 증가**해야 한다: 1비용 2.00 ≤ 3비용 2.25 ≤ 4비용 ≥ 2.40(배율 4.5 이상) ≤ 5비용 2.67 < 대마법.
- R2. **크리 확정은 배율 ×1.4로 친다**(기본 크리 10% 기준 기대 1.05 대비 1.5). 그래서 5비용 확정 크리는 4.5배 이하, 3비용 확정 크리는 2.5배 이하.
- R3. 대마법 단일은 **10.0배 그대로 두고 고유 효과로 1.2배 이상**을 얹는다(조건이 확정적으로 맞는 것만 — 크리면·무작위면 안 됨). 순수 배율만 올리고 싶으면 12.0배.
- R4. 보조·디버프 마법의 값도 같은 자로 잰다: "같은 크레딧으로 딜러가 직접 쳤을 때의 피해 증가분"보다 커야 쓴다. 예: 3비용 전체 공격력 +30% (행동 3번) → 딜러 3행동 × 2.67배 × 0.3 = +2.4배 상당 + 다른 아군 몫 → 3비용 공격(3.5배)보다 약간 낮음(버퍼 자신의 공격력이 딜러의 2/3라 맞음).

## 4. 빌드 원형 8개

공통 가정: 이그니스 공격력 12,000 · 풀구르 11,500 · 에스카 13,000 · 하르페 14,000, 약점 1.5, 방어율 0(따로 적은 곳 제외), 난수 1.0.

### B1. 평타 크리 (초인 오리온 구조)

| 항목 | 내용 |
|---|---|
| 구성 | 풀구르(딜러) + 아스트라(크리 버퍼) + 토난(감전·받는 크리 확률) · 장비 풀구르 거울 조각(크리 확률 +25%), 아스트라 별 조각 |
| 회로 | 기본 공격은 비용 0·크레딧 +2/차례 → 남는 크레딧을 **크리 버프 유지**와 대마법에 씀. 크리가 나면 게이지 + → 차례가 더 자주 |
| 지금 규칙의 문제 | ① 기본 공격 1.0배(크리 확률 10%) = 턴당 1.05배 · ② 자기 버프 "행동 2번"은 시전 행동에서 1이 닳아 **다음 1행동**뿐 · ③ 마법을 쓰는 행동도 버프를 닳게 함 |
| 필요 엔진 | **횟수제 버프** `count: {basic: N}` — "기본 공격을 N번 할 때까지" 남고 마법 행동에는 닳지 않는다 (FGO S3 "버스터 공격 시 크리 위력, 3회") |
| 필요 데이터 | 풀구르 기본 공격 **1.2배를 3히트**(각 0.4, 히트마다 크리 판정) · 새 2비용 "기본 공격 3번: 크리 확률 +50% · 크리 데미지 +150%" · 패시브 "크리가 난 행동 뒤 자기 게이지 +10%" |

계산 (풀구르 → 늪 두꺼비, 번개 약점 1.5, 방어 20%):

| 상태 | 크리 확률 | 크리 데미지 | 턴당 배율 | 기본 공격 한 번 피해 |
|---|---|---|---|---|
| 지금 기본 공격 | 10% | +0 | 1.05 | 14,490 |
| 안: 기본 1.2배 · 크리 100% · +200% | 100% | +200% (×3.5) | 4.20 | 57,960 |
| 안: +260% | 100% | +260% (×4.1) | 4.92 | 67,896 |
| 안: +300% (상한) | 100% | +300% (×4.5) | 5.40 | 74,520 |
| 비교: 같은 지원(크리 60%·+100%)의 마법 순환 (5비용 6.0 + 기본) | — | — | 5.07 | — |

수치 조건:
- **크리 확률 100%**: 기본 10 + 패시브(감전 적) 15 + 새 자기 버프 50 + 거울 조각 25 = **100%**. 감전이 없으면 85% → 토난 감전이 빌드의 부품.
- **크리 데미지 +260% 이상**이 유지돼야 마법 순환과 같다: 자기 +150 + 별빛 가루 +30 + 번개 옷 +50(번개 공격) + 별 조각 +30 = **+260%**. 상한 +300%는 아스트라 대마법(+50%)이 켜진 동안.
- 기본 공격 차례마다 크레딧 +2 → 4차례마다 1번 크리 버프(2) 갱신하고도 **4차례에 6 남음** → 대마법을 6차례마다. 평타 크리가 마법 순환보다 **+7%(상한일 때) + 대마법 빈도 이득**. 이 이상 세지 않게 기본 공격 배율은 1.2배를 넘기지 않는다.

### B2. 대마법 3연속 ("시스템", 스카디·캐스토리아 구조)

| 항목 | 내용 |
|---|---|
| 구성 | 딜러(이그니스 또는 운디네) + 배터리 2명(엠버 불씨 나눔 4→+3, 아스트라 번개 나눔 4→+3) |
| 회로 | ① 셋 다 크레딧 7까지 모은다(기본 공격 3차례, 장비 없으면) ② 딜러 대마법 → 아군 둘이 각자 +3 → 딜러 차례 시작 +1 = 7 → 대마법 ③ 한 번 더 |
| 순서 조건 | 딜러가 **가장 느려야** 한다(딜러 차례 사이에 아군이 한 번씩 행동). 이그니스 95 < 엠버 120 · 아스트라 130 ✓. 운디네 90 ✓ |

연속 횟수 계산(딜러 6 모음 + 차례 +1 = 7, 아군 둘 7 모음, 아군은 차례 시작 +1 뒤 배터리):

| 배터리 (비용 → 크레딧) | 대마법 자기 환급 | 연속 횟수 | 라운드당 평균 유입 (딜러 1 + 환급 + 아군 2명 × 교환비) |
|---|---|---|---|
| **4 → +3 (지금)** | 0 | **3** | 2.5 |
| 4 → +3 | 2 | 3 | 4.5 |
| 4 → +3 | 3 | 5 | 5.5 |
| 3 → +2 | 3 | 4 | 5.3 |
| 3 → +3 | 0 | 4 | 4.0 |
| 3 → +3 | 3 | 8 | 6.0 |
| 2 → +2 | 3 | 7 이상 | 6.0 |

- 아군 둘이 7씩 모아 둔 크레딧(14)이 연속의 연료다. 지금 숫자로 **딱 3연속**에서 끊긴다 → 사용자가 말한 "대마법 3연속"이 그대로 성립한다. **배터리 효율을 올리지 않는다.**
- 무한 순환 금지 요건: **라운드당 유입 < 7**, 그리고 **배터리 교환비(크레딧 +g / 비용 c) ≤ 1**. 물 딜러의 대마법 환급은 **최대 3**(환급 3 + 4→+3이면 5연속 — 물만의 보상).
- 피해(이그니스, 불 약점, 불씨 나눔 최종 +20%가 쌓임): 180,000 → 216,000 → 252,000 = **648,000**. 같은 6차례를 딜러 혼자 순환하면 6 × 3.25 × 1.5 × 12,000 = 351,000 → 시스템이 **1.85배**.
- 보스 한 줄(120만)을 3연속으로 깨려면 대마법 1번에 400,000 = 공격력의 33.3배 → 기본 15배(10×1.5)에 **버프 곱 2.22배**가 더 필요하다. 이그니스 대마법 "이 공격만 화상 특공 +60%/겹"이면 화상 2겹 396,000 · 3겹 504,000 → **화상 3겹이면 한 줄을 깬다**. 불 시스템의 목표치 = "화상 3겹 + 3연속".

### B3. 버티며 쌓기 (수행사제팟·가레스 구조)

| 항목 | 내용 |
|---|---|
| 구성 | 네레이(도발·보호) + 에스카(무적·되살림) + 하르페(딜러) · 장비 네레이 강철 심장, 하르페 깃털 부적 |
| 회로 | 네레이가 도발로 맞고 "맞을 때마다 공격력 +15% (최대 5겹)"를 쌓는다 → 필살기 차례(차지 칸이 보임)에 무적·피해 감소 → 쌓인 상태로 대마법 |
| 지금 숫자의 문제 | 재의 왕(공격력 6,000) 필살기 2.5배 = 네레이 12,300 · 하르페 14,250 = **체력의 11~19%**. 버틸 일이 없다 |

"시련 보스" 기준안 [제안] (보스전과 별개의 고난이도 1판):

| 값 | 안 | 계산 |
|---|---|---|
| 체력 | 3줄 × 300만 = 900만 | |
| 공격력 · 속도 | 40,000 · 100 | 일반 공격 1.0배 = 하르페 38,000(체력 51%) · 에스카 36,000(40%) · 네레이 32,800(30%) |
| 필살기 | 전체 2.5배, 차지 4(5번째 행동마다), **무적 관통** | 하르페 95,000 > 75,000 → **받는 피해 −21% 이상** 필요 · 에스카 90,000 = 90,000 → −1% 이상 · 네레이 82,000 < 110,000 버팀 |
| 파티 피해 | 버티기 편성은 보스 행동 1번당 약 133,000 (하르페 1.0행동 × 88,000 + 에스카 1.1 × 30,000 + 네레이 1.15 × 10,000) | 900만 / 133,000 = 보스 행동 **약 68번** |
| 견딜 횟수 | 필살기 68 / 5 = **약 13~14번**, 일반·강공격 약 54번, 해제 줄마다 1번 | 시간 모형(§1.4): 약 17분 — 보스전 목표(20분)와 맞음 |

요건:
- 필살기 13번 × "전체 −21% 이상 또는 하르페 근성"이 필요하다. 받는 피해 감소 마법(불막이 벽 −40%·얼음 벽 −40%·검은 연기 −30% 등, 3비용, 적 행동 2번)은 필살기 차례에 맞춰 쓰면 5행동마다 3크레딧 = 지속 가능.
- **쌓기 회로가 없으면 이 빌드는 "지는 걸 늦출 뿐"이다** → 네레이에 "맞을 때마다 쌓이는 공격력"(가레스 S2 구조), 에스카·하르페 쪽에 **체력 비례 피해**(체력이 낮을수록 강함) 하나씩.
- 무적은 필살기 관통으로 막히지 않게 해 두면 무적 쪽이 버티기를 독점한다(봉공이 2차례마다 공짜 수준 — §5.2). 그래서 시련 보스 필살기는 관통, 일반 공격은 무적으로 막힘.
- 받아치기 금지([확정]): "맞으면 바로 반격"은 넣지 않는다. 쌓인 것은 **자기 차례에** 쓴다.

### 5.2 효과 단위의 문제

| 문제 | 해당 마법 | 계산 | 요건 |

## 부록 A. 계산에 쓴 식

```
피해 = 공격력 × 배율 × 속성 × (1+min(공,3.0)) × 크리(1.5+min(크뎀,3.0) | 1) × (1+min(특공,2.0)) × (1+min(최종,1.0))
       × clamp(1 − 방어율 + min(방어 다운,0.5), 0.3, 1.5)               (combat_proto.md §11.1, 난수 1.0)
적 피해 = 적 공격력 × 의도 배율 × clamp(1+적 버프,0.3,4.0) × (1−마녀 방어율) × max(1+받는 피해,0.2)   (§11.6)
턴당 배율 = f×m + (1−f)×1.0,  f = 2/(c+1)                               (차례 +1, 기본 공격 +1 — §12.1)
```
