# 단계 C·D UI·아트 요건서 — 전투 화면 · 편성 · 그림 · 연출 (검토자, 2026-10-18)

> 검토자 라운드 산출물. 단계 C(전투 화면·편성 UI 개선)와 D(연출·아트)를 맡는 개발자가 **이 문서의 배치·규격을 기준으로** 고친다.
> 기준: `combat_proto.md` §21(우리 화면 정의서)·§22(연출) · `fgo_battle_reverse.md` §21(FGO 화면 정의서 — **구조만**) · 지금 코드 `game/proto/turn/` (커밋 97d6a0c, 단계 A 끝).
> 표기: [확정]은 건드리지 않는다. 이 문서의 새 배치·수치는 전부 **[제안]**이다(11차 지시에 따라 Claude 추천대로 진행). FGO의 이름·문구·고유 모양(Attack 원판, 카드 부채꼴, 영주 문양, 클래스 아이콘 등)은 쓰지 않고 **정보 배치의 구조**만 가져온다.
> 좌표는 모두 640×360 화면 기준 `(x, y, 폭, 높이)`. 글자 크기는 px(화면 기준).

## 6. 컴포넌트 규격

### 6.1 글꼴 (가장 먼저 고칠 것)

갈무리 글꼴은 크기마다 다른 파일이다(공식 저장소 표: Galmuri14 = 15px, Galmuri11 = 12px, Galmuri9 = 10px, Galmuri7 = 8px — https://github.com/quiple/galmuri). 프로젝트는 `antialiasing=0`(`Galmuri11.ttf.import`)이라 설계 크기가 아닌 크기로 그리면 획이 들쭉날쭉해진다(c11_enemy의 "짚 골렘", "늪 두꺼비"). 지금 `t_hud.gd`·`t_setup.gd`는 6·7·8·9·10·11·12·14·15·30px를 쓴다.

| 쓰임 | 글꼴 파일 | 크기 | 폰 위 실제 크기* | 예 |
|---|---|---|---|---|
| 배너 제목 | Galmuri14 | 30 (2배) | 5.6mm | "승리" "웨이브 2/3" |
| 큰 피해 숫자(크리·30만 이상) | Galmuri11 | 24 (2배) | 4.5mm | "1,234,567!" |
| 화면 제목·약점 피해 | Galmuri14 | 15 | 2.8mm | "편성" · 약점 숫자 |
| 이름·일반 피해·설명 띠 제목·행동 띠 | Galmuri11 | 12 | 2.3mm | "이그니스" |
| 보조 글·설명 본문·체력 숫자·의도·안내 | Galmuri9 | 10 | 1.9mm | "적 1 · 공격" |
| 아이콘 위 숫자만(비용·남은 수·겹) | Galmuri7 | 8 | 1.5mm | "3" |

\* 6.5인치 20:9 폰 가로(세로 1080px, 약 67.7mm)에서 `stretch/scale_mode="integer"` → 3배. 1 화면 px ≈ 0.19mm. Android 권장 최소 글자 12sp ≈ 1.9mm와 10px가 같다 → **읽어야 하는 글은 10px 이상**, 8px는 숫자 한두 자만.

- 새 글꼴 3개(Galmuri14·9·7)는 지금 Galmuri11처럼 **한글 완성형 + 기본 라틴 부분 집합**으로 넣는다(OFL, `game/assets/fonts/README.md`에 출처 추가). 웹 빌드 용량이 걱정되면 Galmuri7은 숫자·라틴·"겹턴×+−%" 정도만.
- 글자 테두리: 지금 `draw_string_outline` 3px(피해 숫자 4px). 10px 이하 글은 **테두리 2px**(3px면 획이 뭉침), 24px 이상은 4px.
- 글꼴 공통 함수: `THud._text()`·`TSetup._text()`가 똑같이 두 벌 있다 → 단계 C에서 크기 → 글꼴 고르기를 한 곳(예: `TIcon`처럼 static 도우미, 또는 기존 `_text`에 `fs`로 글꼴 선택)에 두고 두 화면이 같이 쓴다(DRY).
