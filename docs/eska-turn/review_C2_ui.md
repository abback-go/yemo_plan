## 4. 잘 된 것 (그대로 둘 것)

- **적 카드·보스 카드**: 의도(종류만)·차지·약점·체력이 한 장에 정리돼 "다음에 뭐가 오나, 언제 필살기인가"가 한눈에 보인다. 보스 카드 "차지 ›››››(가득 빨강) · 줄 2/3 ▬▬▬"는 FGO 패널 수준.
- **설명 띠**: 처음 보는 사람에게 "칸을 한 번 누르면 설명, 다시 누르면 사용"을 늘 같은 자리에서 알려 준다. 예상·크리 값이 빌드 손맛을 준다.
- **글꼴**: 6개 크기만 쓰고 최소 10px — 2배 그림에서 모든 한글이 또렷하다.
- **철수 확인 판·패배 두 버튼·웨이브 배너·전투 고르기**: 흐름이 막히지 않는다(편성 → 전투 고르기 → 전투 → 승리/패배 → 편성 모두 확인: `u00 → u01 → w0 → x1 → x2`, `k09 → k10`).

## 5. 단계 D 참고 (아트 — 짧게)

- **재의 왕·시련의 거상 = 재의 기사 그림 그대로**(`k05`, `t02`). 전투 고르기 카드 3장 중 2장이 같은 그림이라 화면이 단조롭다(`u01`) → D1을 먼저.
- 쓰러진 마녀 그림이 사라지고 발밑 고리만 남는다(`turn_boss b08` (100~180, 230~260)) · 패배 배너 때 운디네가 서 있다(`k09b`) → 쓰러짐 자세(무릎).
- 맞는 연출 번쩍·번개의 중심이 몸 가운데라 숫자와 겹친다 → H3 숫자 자리를 올리면 연출은 그대로 둬도 된다. 크리 섬광(G6)을 넣을 때도 숫자 칸을 피할 것.
- 어두운 옷 마녀(이그니스·운디네·토난)는 전장·편성 명단 모두에서 바탕에 묻힌다(`u00` 명단, `k01` 운디네) → D2 테 조명.
- 적이 쓰러질 때 그림이 한동안 그대로 남는다(`k04c` 재의 기사) → 재 입자로 흩어짐(G4).
- 이그니스 차례 줄 칸과 엠버 칸이 같은 불 색이라 첫 글자로만 구분된다 — 차례 줄 칸에 작은 얼굴(초상 잘라 쓰기)을 넣으면 FGO 수준으로 빨리 읽힌다(그림 작업과 함께).
