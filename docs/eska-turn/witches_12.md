## 2. 속성 결 (같은 역할이라도 다르게 느껴지는 이유)

| 속성 | 징표 | 결 | 그 속성만의 효과 |
|---|---|---|---|
| 불 | 화상 | **특공·연쇄** — 징표를 깔고 터뜨린다 | 화상 특공, 광역 화상, 속성 부여(화염) |
| 물 | 빙결 | **지연·보호** — 적을 늦추고 아군을 지킨다 | [신규] 적 게이지 −N% (빙결 적이면 두 배), 받는 피해 감소, 회복, 방어 다운 |
| 번개 | 감전 | **속도·크리** — 차례를 당기고 크리로 터뜨린다 | 아군 게이지 +N%, 크리 확률·크리 데미지, [신규] 감전 적에게 크리 확률 +N% |

| 시간 | — | **차례 조작** — 되감고 당기고 늘린다 | 게이지 ±, [신규] 버프 지속 +1, 부활, [신규] 적 게이지 0 |
| 검술 | — | **한 방·연격** — 흑백 참격 | 크리 확정, 방어 무시, 다단 히트(배율 분할) |

## 3. [신규] 효과 정의 (엔진에 넣을 때 기준)

| 효과 | 정의 |
|---|---|
| 적 게이지 −N% | 적의 행동 게이지에서 1000×N% 를 뺀다 (0 아래로는 안 감). 빙결 징표가 있으면 두 배 |
| 적 게이지 0 | 적의 게이지를 0으로 (차례가 처음부터) |
| 버프 지속 +1 | 대상에게 걸린 own 시계 버프 전부 dur +1 |
| 징표 연장 +N | 대상의 징표 남은 적 행동 수 +N |
| 크리 확정 (행동 1번) | 다음 공격의 크리 확률 100% |
| 다단 히트 N회 | 배율을 N으로 나눠 N번 맞힘 (크리·난수는 회마다) — 숫자가 여러 번 뜨는 손맛용, 합은 같다 |
| 감전 적 크리 확률 +N% | 공격 대상에 감전이 있을 때만 크리 확률 +N% (특공 종류가 아니라 크리 확률 종류) |
| 되살림 N% | 쓰러진 아군을 체력 N%로 (살아 있으면 N% 회복) — 프로토타입의 공허의 요람과 같음 |
