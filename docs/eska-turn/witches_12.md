## 3. [신규] 효과 정의 (엔진에 넣을 때 기준)

| 효과 | 정의 |
|---|---|
| 적 게이지 −N% | 적의 행동 게이지에서 1000×N% 를 뺀다 (0 아래로는 안 감). 빙결 징표가 있으면 두 배 |
| 적 게이지 0 | 적의 게이지를 0으로 (차례가 처음부터) |
| 버프 지속 +1 | 대상에게 걸린 own 시계 버프 전부 dur +1 |
| 징표 연장 +N | 대상의 징표 남은 적 행동 수 +N |
| 크리 확정 (행동 1번) | 다음 공격의 크리 확률 100% |
| 다단 히트 N회 | 배율을 N으로 나눠 N번 맞힘 (크리·난수는 회마다) — 숫자가 여러 번 뜨는 손맛용, 합은 같다 |
| 감전 적 크리 확률 +N% | 공격 대상에 감전이 있을 때만 크리 확률 +N% (특공 종류가 아니라 크리 확률 종류) |
| 되살림 N% | 쓰러진 아군을 체력 N%로 (살아 있으면 N% 회복) — 프로토타입의 공허의 요람과 같음 |

## 9. 사용자가 정할 것

1. 가명 9개(신더·운디네·네레이·글라시아·풀구르·아스트라·토난·호라·하르페)를 쓸지, 이름을 주실지.
2. [신규] 효과 8가지(§3)를 넣을지 — 특히 "적 게이지 감소"(물·시간)와 "다단 히트"(번개·검술)는 엔진에 새로 들어가는 규칙.
3. 술사 역할의 이름(술사 / 디버퍼 / 징표꾼 …)과 비율(공격 4 · 디버프 4 · 보조 2)이 §0-8 "비율이 다르다"에 맞는지.
4. 하르페(검의 마녀)를 순수 딜러로 두는 것 — §0-5의 "특수 마녀는 속성을 타지 않는 보조"와 어긋나는 예외.
5. (3차) 장착은 4개(사용자 제안). 호라는 초침 20%·시간 가속 25%·한 번 더 크레딧 +1·종말의 시계는 게이지 −50%로 낮췄다(그래도 무작위 파티 11판 전승 — 더 낮출지). 버퍼의 1비용 공격은 1.5 → 1.6배.
