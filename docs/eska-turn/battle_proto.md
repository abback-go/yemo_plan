# 에스카 — 턴제 전투 프로토타입 기획 (데모 v0.2 · 라운드제)

> 2026-10-17. v0.1(칸 시간축)을 사용자 피드백으로 **v0.2 라운드제**로 바꿨다. Claude가 정한 것은 **[판단]** 으로 표시한다 — 사용자가 바꾸면 그대로 따른다.
> 코드: `game/turn/` (코어 `core/`는 노드 없는 순수 로직, 화면 `ui/`, 흐름 `flow/`). 수치의 정본은 `game/turn/core/t_data.gd`. 이 문서는 그 수치를 설명한다.
> 검증: `tools/test/check_scripts.gd`(컴파일) · `tools/test/turn_sim.gd`(헤드리스 밸런스 시뮬레이션) · `godot --path game -- --smoke`(자동 전투 3판 연기 시험) · `-- --smoke --manual`(탭 흉내) · `--shots`(화면 저장).

## 0. 한 줄

**내 턴에 행동 4개**를 어느 마녀의 마법으로든 순서대로 쓰고, 적 턴이 온다. 마법마다 **턴 쿨타임**, 버프는 **턴 지속**이라 같은 버프를 **2겹**까지 쌓아 딜러의 **대마법 한 방**을 키운다. 에스카는 **무상성 ×1.2**의 만능 마녀, 화염 마녀 둘은 **약점 ×1.5**와 화염 버프로 하이엔드를 낸다.

## 1. 사용자가 확정한 것 (2026-10-17)

- 파티 최대 3명, 에스카 제외 가능(데모는 3명 고정). 마녀마다 마법이 다르고 공격/지원 비율이 다름. 마녀당 마법 5~6개.
- 에스카는 처음부터 강함(레벨로 크지 않음), 나머지는 키움(레벨·해금). "마법학교 느낌"의 성장.
- **에스카 배율 1.2배 무상성**: 모든 적에게 어느 정도 강함. 하이엔드는 상성 캐릭터(화염 ×1.5 + 화염 버프)를 키워야 나옴.
- **버프는 지속되어 겹침**: 지속이 쿨타임보다 길어 같은 버프 2겹 가능.
- 마법 장비(빗자루·물약)는 피해·유틸·행동 중 하나에 이점.
- 데모 로스터: **화염 계열 2명 + 에스카**, 에스카 딜러도 화염 딜러도 되게.
- **v0.2에서 바뀐 것**: "매 턴 원하는 마법을 모두 쓸 수 있게, 대신 마법마다 쿨타임" → "내 턴에 자유롭게 4마법을 순서대로" (사용자 제안). 자리(서 있는 위치)에는 효과 없음. 대마법 게이지는 유지하고 해 보고 재검토. 마법창은 포켓몬식 고정 패널이 아니라 **선택한 마녀 옆에 펼침**. 화면은 **2.5D**(파티 뒤에서 비스듬히 적을 봄), 카메라·모션은 수수하게, 캐릭터는 도트지만 크게.
- 파랑 금지는 규칙이 **아님**. 세라·에스카의 기존 코드·아트는 활용.

## 2. 시간 — 라운드제 [확정 구조 · 수치는 판단]

| 규칙 | 내용 |
|---|---|
| 라운드 | **내 턴 → 적 턴**이 한 라운드. 실시간 없음, 고르는 동안 아무것도 안 움직인다 |
| 내 턴 | **행동 4개**. 어느 마녀의 마법이든, 어떤 순서로든. 같은 마녀가 네 번 써도 된다. [턴 종료]로 남은 행동을 버릴 수 있다 |
| 행동 늘리기 | 잉걸불(이번 턴 +1, 다음 턴 +1)·가속 물약(+1). 라운드 시작 행동 = 4 + 가속 합(최대 +2) |
| 쿨타임(cd) | 마법을 쓰면 **내 턴 N번** 뒤에 다시 쓸 수 있다. cd 0 = 매 턴(금·불꽃탄·잿불). 밤까마귀 빗자루는 cd 2 이상을 1턴 줄인다 |
| 버프 지속(dur) | **내 턴 수**로 센다. 내 턴이 시작될 때 1씩 줄고 0이면 사라진다. 지속 3 · 쿨 2인 버프는 다시 걸 수 있을 때 아직 1턴 남아 있어 **저절로 2겹** |
| 적 턴 | 살아 있는 적마다 행동 1개, 행동표(pattern) 순서대로 |
| 적 시전(cast) | 적의 큰 기술은 **이번 적 턴에 예고**(머리 위에 붉게)하고 **다음 적 턴에 발동**. 그 사이 내 턴에 **끊기** 마법·물약으로 취소한다 |
| 굳센 시전(heavy) | 기사왕의 「멸화」는 **봉공·속박·비명만** 끊는다(천열은 못 끊음) → 봉공(쿨 3)을 아껴 두는 결정이 생긴다 |
| 봉쇄(skip) | 봉공·속박은 그 적의 **다음 행동을 건너뛰게** 한다 |
| 대마법(ult) | 게이지 100이 차면 행동 1개로 **즉시 발동**(시전 없음, 끊기지 않음). 쓰면 게이지 0 |
| 물약 | **행동을 쓰지 않는다**. 전투당 가방 3개, 쓴 것은 사라짐 |

쿨타임을 엇갈리게(0 / 2 / 3 / 4) 두어 "매 턴 4개를 뭘로 채울지"가 고민이 되게 했다 [판단]. 난사 억제 장치는 쿨·지속·게이지 셋뿐이고, 행동 자체에는 비용이 없다.

## 3. 자원 — 게이지(대마법) [판단 · 사용자 "해 보고 재검토"]

에스카(종언)·세라(불씨)만 게이지가 있다(0~100). 아셰는 가벼운 보조형이라 없음.
- 대마법 아닌 자기 마법 +8(천열·불기둥·화염 폭풍은 +12) · 맞힐 때 타당 +2 · 맞을 때 +5 · 불꽃 축제 +20. 잿가루 빗자루는 획득 ×1.3.
- 에스카는 20으로 시작(처음부터 강함), 세라는 0.
- 대마법은 100을 쓰고 즉시 발동. 보스 1줄(화염 저항)에서는 세라의 유성 낙화를 아껴 2줄(화염 약점)에 쓰는 게 정석 — 자동 조작도 그렇게 한다.

## 4. 버프 — 범주 합산 · 범주 간 곱셈 · 상한 (FGO 구조만 차용)

| 범주 | 누가 | 상한 |
|---|---|---|
| 공격(atk) | 아셰 불꽃 축제 +35%, 들개 울부짖음 +40%, 기사왕 2줄 진입 +30% | +300% |
| 속성(elem) | 아셰 풀무 +50% **화염만**(2겹), 잿가루 빗자루 +25% 자기 속성 | +300% |
| 치명률 / 치명피해 | 에스카 별빛 눈 +30% / +60% (2겹), 유리 빗자루 +15% / +30% | 95% / +300% (치명 기본 ×1.5, 기본 확률 5%) |
| 최종(final) | 에스카 틈 열기 +45% (2겹) — "틈 증폭"의 구현 | +200% |
| 취약(vuln, 적) | 아셰 기름 붓기 +30% (2겹), 봉공 +25%, 비명 +15% | +200% |
| 방어(def, 적) | 불씨 흩기 −20%, 부식 −30%, 기사왕 방패 +50% | −80% ~ +100% |

**겹침 규칙**: 같은 마법의 같은 버프는 `stack`까지 따로 쌓인다(각자 남은 턴). 넘치면 가장 오래된 것을 새로 고친다. 같은 범주는 **더하고** 범주끼리는 **곱한다**.

## 5. 피해 공식

```
피해 = 위력 × 공격력/100 × (1+공격) × (1+속성) × 치명 × (1+최종) × (1+취약) × 상성 × 100/(100+방어) × 난수(0.95~1.05)
상성: 공간(에스카) = 항상 ×1.2 · 약점 ×1.5 · 저항 ×0.5 · 그 밖 ×1.0
```
- 여러 타(hits)는 위력을 나눠 타마다 치명을 따로 굴린다. 여러 타·전체 공격은 **합계**가 따로 뜬다.
- 큰 한 방(1,500↑)은 화면에 배율 풀이가 같이 뜬다 — "공격 ×1.35 · 치명 ×2.4 · 최종 ×1.9 · 취약 ×1.6". 2,500↑은 화면이 번쩍·흔들림. 결과 화면은 그 전투의 최고 한 방과 배율을 보여 준다(빌드 학습 장치).

### 두 빌드가 성립하는 이유
- **에스카 딜러**: 한 턴에 틈·별빛·기름을 깔고 천열(4타)이나 흑성으로 마무리. 기름(취약 ×1.6)·축제(공격 ×1.35)·잉걸불(행동 +1)이 통한다. 보스 1줄(화염 저항 ×0.5)에서 특히 강함.
- **세라 딜러**: 에스카의 틈(최종 ×1.9)·별빛(치명 ×2.7) + 아셰 풀무(화염 ×2.0~2.25) + 기름 + 약점 ×1.5 → 보스 2줄에서 폭발. 2줄 전까지 게이지를 모아 두는 운용.

## 7. 장비 · 물약

빗자루(마녀당 1, 한 자루는 한 사람): 밤까마귀(쿨 2 이상 −1턴) · 유리(치명률 +15%, 치명피해 +30%) · 잿가루(자기 속성 +25%, 게이지 ×1.3). 기본 배정 에스카 유리 · 세라 잿가루 · 아셰 밤까마귀.
물약(가방 3, 행동 안 씀, 던지는 것은 병이 날아가 깨짐): 치유 35% · 가속(이번 턴 행동 +1) · 속박(굳센 끊기 + 봉쇄) · 비명(모두 굳센 끊기 + 취약 15% 2턴) · 부식(방어 −30% 3턴). 시작 보유 치유 2·나머지 1. 수치는 `docs/eska/potions.md`의 역할을 턴제로 옮긴 것.

적은 다음 행동을 머리 위에 예고한다(시전은 붉게, 굳센 시전은 [굳셈]). 적 대상 선정: 무작위(에스카 가중 1.2), 멸화는 체력 비율이 가장 낮은 아군.

## 9. 성장 · 흐름

타이틀 → 교실(점수로 마법 배우기 · 빗자루 바꾸기 · 물약 가방 · 딜러 지정) → 전투 → 결과(최고 한 방·배율·피해 비중·점수·레벨) → 다음.
- 이기면 수업 점수 +2/+3/+3, 세라·아셰 레벨 +1(체력·공격 성장). 에스카는 그대로.
- 지면 물약을 돌려받고 교실로(빌드를 바꿔 재도전).
- "자동" 단추: TPolicy(딜러 지정)가 아군을 조작 — 위험 시전 끊기 → 살리기 → 잉걸불 → 대마법 준비(버프 깔고 쏘기) → 버프 겹치기 → 딜러 공격 순.

읽기: 에스카 빌드는 보스를 7라운드에 끝내고, 세라 빌드는 1줄(화염 저항)을 버티느라 길지만 2줄에서 따라잡는다. 아무것도 안 갖춘 에스카도 이기긴 하지만 라운드가 1.5배 길고 체력이 반 남는다 — "에스카는 어디서나 통하지만 하이엔드는 빌드". 자동 조작은 적의 예고 시전을 거의 다 끊어(끊기 1.3~2.8회/판) 적 시전이 발동한 적이 1% 미만 — 사람이 하면 놓칠 것이므로 봉공·물약 압박이 생긴다.
**v0.1 대비**: 적 체력 ~2~3배, 적 피해 ~1.6~2.3배로 올렸는데도 라운드가 짧다(행동 4개 × 버프 겹침). 사용자가 해 보고 "너무 빨리 끝난다"면 적 체력을 더 올리기보다 **쿨타임·게이지**를 손보는 쪽이 먼저 [판단].

## 11. 화면 (640×360, 터치, 2.5D)

- **구도**: 파티 뒤에서 비스듬히 적을 본다. 왼쪽 아래에 마녀 셋의 **뒷모습**(에스카 ×3 ≈ 140px, 세라 ×2.7, 아셰 ×2.5 — 도트지만 크게), 오른쪽 가운데에 **정면 적**(들개 ~55px, 수도사 ~84px, 기사왕 ~163px). 바닥은 지평선으로 모이는 원근 돌판 + 마녀 문장, 위는 밤하늘·먼 첨탑(기존 EScenery 층 재사용). 카메라는 고른 마녀 쪽으로 살짝(0.18)·×1.05만 당긴다 — 화려한 무빙 없음.
- **위 HUD**: 왼쪽 파티 카드 3장(머리글자·이름 Lv·체력·게이지·버프 아이콘) — 카드를 누르면 그 마녀의 마법창. 가운데 "라운드 N · 내 턴 · 행동 ●●●○". 오른쪽 [턴 종료] [자동] [×1/×2].
- **마법창**: 고른 마녀 **옆에** 세로로 펼친다(오른쪽에 선 마녀는 왼쪽으로). 6칸(이름·종류·대상·위력/쿨·번호·끊기 표시) + 물약 단추(가방 3개 하위 메뉴). 마법을 누르면 대상에 고리, 대상을 누르면 발동(다시 누르면 기본 대상). 마법창 밖을 누르면 닫힘.
- **적 머리 위**: 다음 행동 예고(시전은 붉게·[굳셈]·봉쇄됨), 이름, 체력바(보스는 줄 핍), 버프 아이콘. 아군 버프는 몸에 그림(틈 = 보랏빛 찢김, 별빛 = 눈가 별, 방벽 = 불 고리, 가속·풀무·공격 표시).
- **큰 한 방**: 숫자가 커지고 화면이 번쩍·흔들림, 아래에 배율 풀이. 여러 타·전체 공격은 합계 라벨. 최고 기록 갱신 시 "최고 기록!".
- **키보드**(PC 확인용): 1~6 마녀 선택 또는 마법, Tab 마녀 순환, P/Q 물약, E 턴 종료, A 자동, Space 빠르기, Enter/Z 확인, 방향키 대상, Esc 취소.
