## 1. 목적과 완성 기준

**목적**: 튜토리얼 한 판으로 "죽음 카드를 쓰는 순간이 아프고, 그 전까지의 고민이 재미있는가"를 검증한다.

**60~70% 완성의 정의 [결정]**
- **기능 100%**: 캠프부터 탈출까지 끊김 없이 플레이할 수 있다. `combat-system.md` v0.1 규칙이 전부 동작한다.
- **연출·아트 일부**: 핵심 순간(죽음 카드 사용, 사망 컷신)에 집중한다. 나머지는 GPT 이미지 + 코드로 그린 간단한 그래픽으로 채운다.

### 검증 질문
| # | 질문 | 확인 방법 |
|---|---|---|
| Q1 | 피해 옮기기가 매 턴 의미 있는 고민이 되는가 | 운명 전가·대신 받기·감싸기 사용 횟수, 아무것도 안 하고 턴을 넘기는 비율 |
| Q2 | 죽음 카드를 손에 든 3턴 동안 갈등하는가 | 몇 턴째에 카드를 썼는지, 끝까지 버티다 전멸한 비율 |
| Q3 | 사망 컷신에서 상실·죄책감을 느끼는가 | 플레이 후 인터뷰 |
| Q4 | 용사의 안내만으로 규칙을 이해하는가 | 막힌 지점, 잘못 낸 카드 |
| Q5 | 전멸 후 재시작을 "강제"로 느끼는가 | 재시작 후 바로 카드를 쓰는지, 인터뷰 |

## 2. 범위

### 포함 [결정]
| 장면 | 내용 |
|---|---|
| 시작 화면 | 제목(가제)과 시작 버튼만 |
| 캠프 대화 | 비주얼노벨식. 스탠딩 + 대사, 클릭으로 진행. 용사를 중심으로 파티 애착 형성 (3~5분, 대사 초안은 Claude가 작성) |
| 일반 전투 | 광신도 3명. 용사가 턴마다 규칙 안내, 성검으로 광신도를 일격에 쓰러뜨림 |
| 거대 존재 등장 | 광신도 1명이 남으면 발이 내려와 짓밟음 → 거대 존재 전투로 이어짐 |
| 거대 존재 전투 | 공격 무효, 죽음 카드 획득, 3턴 카운트다운 |
| 사망 컷신 | 용사 리버스 샷 → 그림자가 얼굴을 덮음 → 암전 + 텍스트 → 부러진 성검만 남은 빈자리 (용사 컷신 전까지 07 임시 사용) |
| 짓밟힘 → 탈출 | 짓밟힘 사용 → 존재가 물러남 → 탈출 → 종료 화면(다시 하기) |
| 전멸 → 재시작 | 끝까지 버티면 전멸 → 거대 존재 등장 직후부터 재시작 |
| 타격 연출 | 카드 사용 모션, 피해 숫자, 화면 흔들림, 발이 내려오는 연출, 그림자 |
| 디버그 패널 | 장면 바로 가기, HP·수치 수정, 특정 카드 드로우, 전투 즉시 승리 |

### 제외 [결정]
- 사운드
- 표정 차분, 동료 스킬 카드 그림, 카드 뒷면, 짓밟힘 장면 그림 → 코드 연출 또는 이후 작업
- 저장·불러오기, 회차, 캠프 휴식 선택지(튜토리얼에는 휴식 시점이 없음), 모바일 지원
- 탈출 후 추가 전투

## 3. 기술 [결정]

| 항목 | 내용 |
|---|---|
| 구현 | 순수 HTML/CSS/JS. 라이브러리·빌드 없음 |
| 실행 | `index.html`을 브라우저로 열면 실행 (로컬 파일로 열어도 동작하도록 ES 모듈 대신 일반 `<script>` 사용 [제안]) |
| 공유 | 저장소에 두고, 비공개 claude.ai 아티팩트 링크로도 게시 |
| 화면 | 1920×1080 기준 좌표, 창 크기에 맞춰 비율 유지 확대·축소 (남는 부분은 검은 여백) |
| 대상 환경 | PC 데스크톱 브라우저(Chrome·Edge), 마우스 |
| 수치 | 카드·HP·적 수치는 `js/data.js` 한 파일에 모음. 코드 수정 없이 조정 가능 |

### 폴더 구조 [제안]
```
prototype/
  index.html
  css/style.css
  js/data.js       ← 카드·캐릭터·적 수치, 대사
  js/*.js          ← 전투 규칙, 화면, 연출, 장면 진행, 디버그
  assets/          ← GPT 이미지 (아래 파일명 규칙)
```

## 4. 조작 — 하스스톤식 드래그 [결정]

- **대상이 있는 카드** (공격, 운명 전가, 치유 등): 카드를 끌면 손패 위치에서 화살표가 나오고, 대상 위에서 놓으면 사용. 유효한 대상만 강조 표시.
- **대상이 없는 카드** (성광, 죽음의 예지, 짓밟힘 등): 카드를 손패 영역 위로 끌어올려 놓으면 사용.
- 놓을 곳이 잘못됐거나 에너지가 부족하면 카드가 손패로 돌아감.
- 피해 옮기기 카드의 대상: ① 적의 **예고**(어떤 공격을 옮길지) → ② 새로 맞을 아군 순서로 지정 [제안]. `대신 받기`·`감싸기`는 ①만 지정.
- 카드에 마우스를 올리면 확대해서 보여줌. 적 예고에 올리면 대상까지 선이 그어짐.

## 5. 화면 배치 — 마녀 1인칭 손패 [결정] (`reference/images/09_..._APPROVED.webp` 기준)

**배경**: UNREASON X(참고 01)와 "아군 뒷모습 + 정면의 적 + 고딕 성당" 구도가 겹쳐, 첫 화면의 주인공을 **마녀의 손·카드·붉은 실**로 바꿨다.

- 카메라: 마녀의 눈. 동료들 바로 뒤, **동료 머리보다 약간 위**에서 살짝 내려다봄 [결정]
- 마녀의 손: 화면 아래 가운데. 창백한 두 손이 부채꼴 손패를 쥠. 카드는 손에서 뽑아 대상에게 드래그 [결정]
- 동료(출전 3명, 뒷모습): **궁수 왼쪽 · 용사 가운데 · 전사 오른쪽**, 간격을 넓게 [결정]. 가운데 동료의 하체는 손패에 가려짐
- 적: 동료들 너머 가운데와 동료 사이. 머리부터 무릎까지 보이게. 머리 위에 예고(아이콘 + 수치 + 대상)
- 거대 존재: 화면 위쪽 가장자리에서 잘린 발, 그림자가 위쪽 절반과 동료들을 덮음
- **붉은 실 [결정]**: 평소에는 모든 동료의 등에서 손패 쪽으로 희미한 실. 죽음 카드가 손에 들어오면 그 동료의 실만 그 카드에 진하고 팽팽하게 걸림. 카드를 내면 실이 끊어짐
- HP 표시 [제안]: 동료 HP는 각자 머리 위 가까이(목업처럼 멀리 띄우지 않음), 적 HP는 발밑에 다른 모양으로
- 마녀 HP·에너지 [제안]: 손 양옆 아래 구석(왼쪽 마녀 HP, 오른쪽 에너지), 턴 종료 버튼은 오른쪽 아래
- 안내: 용사의 대사는 화면 위쪽 대사창 + 작은 얼굴 그림

## 7. 캐릭터 외형 (프롬프트 기준)

- **궁수 엘리안**: 엘프, 땋은 긴 금발 + 짙은 녹색 리본, 녹색 눈, 금색 자수의 짙은 녹색 후드 망토, 갈색 가죽 갑옷, 흰 깃털 화살통 (기존)
- **용사 세라피나 [결정]**: 기존 '검사' 디자인 — 은발 롱헤어 + 붉은 리본, 판금 갑옷, 붉은 망토. 성검
- **전사 브룬힐드 [결정]**: 키 크고 다부진 성인 여성, 짧은 잿빛 백발, 얼굴의 흉터, 낡은 철제 중갑, 몸을 가리는 대형 타워 실드
- 사제: 흰 베일, 가시 후광, 붉은 보석이 박힌 지팡이 (기존, 튜토리얼 이후)
- **마녀 노엘 [결정]**: 긴 흑발, 창백한 피부, 잠을 못 잔 듯한 눈 밑 그늘, 짙은 붉은 눈, 낡은 검은 로브, 목에 끈으로 묶은 카드 묶음 — 동료보다 수수하고 어둡다

## 9. 작업 순서 [제안]
1. 이미지 프롬프트 작성 (캐릭터 시트 4장 먼저) → 사용자가 GPT로 생성
2. 병행: 전투 규칙 + 회색 박스 화면 + 드래그 조작
3. 장면 흐름 (캠프 → 일반 전투 → 거대 존재 → 컷신 → 탈출/재시작)
4. 타격·컷신 연출
5. 디버그 패널, 그림 교체, 아티팩트 게시
