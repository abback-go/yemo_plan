# 03. 전투 시스템

이 문서는 플레이어와 적이 어떻게 공격하고, 피격되고, 사망하며, 보상을 발생시키는지 정의한다. 기준 문서는 00_게임 콘셉트, 01_핵심 플레이 루프, 02_플레이어 조작이며 세 문서와 충돌하는 내용을 두지 않는다.
능력 해금 조건은 04_능력 게이트, 제단·리스폰 규칙은 05_맵·진행, 회복 수단과 자원은 06_아이템·보상, 화면 표시는 07_UI 흐름, 개별 적·보스 배치는 08_스테이지 설계, 모든 수치는 09_데이터 테이블에서 확정한다.

## 2. 전투 콘셉트

플레이어는 이동하면서 근접 기본공격을 잇달아 넣고, 남은 신력을 보고 신성을 판단해서 끼워 넣으며, 적의 공격은 이동과 대시로 피해 처치하고 자원과 신력을 얻는다.

- 플레이어의 행동: 이동·점프·대시로 위치를 잡고 기본공격으로 적을 처치한다. 적의 대응: 유형별로 접근, 원거리 견제, 돌진, 공중 추적으로 진로를 막는다.
- 전투의 목표: 탐험 동선을 막는 적의 제거다. 전투는 탐험과 부탁 수행의 수단이다. (00_게임 콘셉트 4-2절)
- 보상 연결: 적 처치로 자원을 얻어 신성 습득과 강화에 쓰고, 함께 충전되는 신력은 신성 사용에 쓴다.
- MVP 범위: 기본 이동(좌우·점프·일반 대시), 근접 기본공격, 더블점프, 여우의 신성 세트(수업 절차 없이 초기 보유로 지급), 능력 게이트, 일반 적 처치까지다. **MVP에서는 신력 게이지를 두지 않고 쿨타임만 검사한다(검증 범위 축소).** 보스·수업·회복 수단은 이후다. (00_게임 콘셉트 7절)

전투는 기본공격 위주로 유지한다. 신성 난사는 신력 소모로 막고, 쿨타임은 병행 제약으로 둔다. 기본공격 위주 전투 참고: 스컬. 1타 공격 리듬 참고: 할로우 나이트.

## 3. 전투 기본 흐름

이 게임은 스테이지 클리어형이 아니다. 전투는 탐험 중 발생하는 **조우 단위**로 성립하고 종료된다.

기본 흐름: 탐험 중 적 조우 → 적 감지·추적 시작 → 플레이어 공격 입력 → 공격 판정 생성 → 고정 데미지 적용 → 적 HP 감소·넉백 → 적 HP 0 이하 → 적 Dead 전환 → 자원 1회 지급과 신력 충전 → 조우 종료 → 탐험 재개

상세 설명: 플레이어가 적의 감지 범위 안에 들어오면 적이 추적을 시작한다. 플레이어는 D로 기본공격을 넣거나 Q/W/E/R/S로 신성을 사용한다. 공격 판정 안에 살아 있는 적이 있으면 해당 공격의 고정 데미지를 적용한다. 적 HP가 0 이하가 되면 Dead로 전환하고 자원을 한 번만 지급한다. 살아남은 적이 없으면 조우가 종료되고 플레이어는 탐험을 계속한다.
전투를 회피하고 지나가는 것도 허용한다. 플레이어가 감지 범위를 벗어나면 적은 복귀 상태로 돌아간다. 적을 모두 처치해야 다음 구역으로 갈 수 있는 강제 전투 구간을 둘지는 미정 (08_스테이지 설계에서 결정). 두더라도 "전투는 탐험 동선을 막는 장애물 수준"(00_게임 콘셉트 4-3절) 원칙을 상한으로 하며, 갇힘 방지를 위한 이탈 가능 여부도 08에서 함께 정의한다.

## 4. 플레이어 공격 기획

### 4-1. 기본공격 (D)

| 항목 | 내용 |
|---|---|
| 공격 입력 | D (누르는 순간). 방향은 캐릭터가 바라보는 방향(좌우) |
| 공격 종류·판정 방식 | 근접 1타 공격. 애니메이션 이벤트 시점에 전방 범위 판정 생성 |
| 판정 발생 타이밍 | BasicAttackHitTiming. 값 미정 (09) |
| 공격 범위 | BasicAttackRange. 값 미정 (09) |
| 공격 데미지 | BasicAttackDamage(고정값). 값 미정 (09) |
| 공격 쿨타임 | BasicAttackCooldown. 연속 입력 시 이 간격으로 같은 공격을 반복한다. 값 미정 (09) |
| 가능·불가능 상태 | 가능: Idle, Move, Jump(공중), Attack(재입력은 입력 버퍼로 저장). 불가능: Dash, Dead |
| 이동 허용 | 공격 중 좌우 이동 가능 |
| 애니메이션 | Attack 단일 애니메이션 |

처리 흐름:

1. D 입력을 받고 상태와 BasicAttackCooldown 경과 여부를 검사한다.
2. 조건을 만족하면 Attack 상태로 전환하고 Attack 애니메이션을 재생한다.
3. BasicAttackHitTiming 시점에 전방 판정을 생성하고, 판정 안의 살아 있는 대상에게 BasicAttackDamage를 적용한다.
4. 애니메이션이 끝나면 이동 입력이 있으면 Move, 없으면 Idle, 공중이면 Jump(공중)로 돌아간다.
5. 공격 모션 중이나 쿨타임 중에 들어온 D 재입력은 InputBufferTime 동안 저장하고, 모션과 쿨타임이 모두 끝난 시점에 1회 실행한다.

- 공격 중 피격돼도 공격은 취소되지 않는다.
- 하나의 판정으로 같은 대상에게 데미지를 두 번 적용하지 않는다. 판정마다 적중 대상 목록을 기록한다. 기본공격의 성장 경로(데미지 상승 등)는 미정 (06_아이템·보상에서 결정)
- 공격 방향: 좌우뿐이다. 상단·하단 베기는 두지 않는다.
- 캔슬 규칙: 공격 모션 중 점프·신성 입력은 남은 모션을 끊고 즉시 실행한다(캔슬 허용). 판정 발생 시점(BasicAttackHitTiming) 이전에 캔슬되면 그 공격의 판정은 생성하지 않는다.

### 4-2. 공격 신성 (Q/W/E/R/S)

| 항목 | 내용 |
|---|---|
| 구성 | 발현 중인 가호의 초급 2 + 고급 2 + 강림 1 = 5개. 배운 것 전부 사용 가능 |
| 신력 소모 | 사용 시 신성별 DivinityCost만큼 신력을 차감한다. 쿨타임과 함께 검사하며, 남은 신력이 DivinityCost보다 적으면 사용을 거부한다. 소모는 세 형태다. ① 1회 차감형(대부분. 사용 성립 시 DivinityCost 차감) ② 지속 소모형(화영난무·비행: 초당 소모) ③ 증가형(번개 광선: 회차마다 기하급수 증가). 세부는 04_능력 게이트 5절 |
| 신력 게이지 | 가호와 무관하게 게이지 하나를 공유한다. 가호를 전환해도 남은 신력은 유지된다. 자연 회복은 없다 |
| 신력 충전 | ① 타락한 수인 처치 시 충전(PurifyChargeAmount) ② 맵의 꺼진 신앙 오브젝트(작은 사당·등불 등) 점등 시 충전(ShrineChargeAmount. 종류·배치는 05_맵·진행, 08_스테이지 설계에서 결정) ③ 제단에서 완전 충전 |
| 신력 메모 | 신력 충전 방식은 프로토타입 검증 후 수정될 수 있다(가안). 구현 시 충전 규칙을 교체 가능한 구조로 만든다 |
| 데미지·사거리 | 신성별 DivinityDamage(고정값), DivinityRange. 근접·원거리 혼합. 값 미정 (09), 목록은 04_능력 게이트 5절 참조 |
| 상태 전환 | 사용 시 Attack 상태로 전환한다 |
| 가능 상태 | Idle, Move, Jump(공중), Attack(기본공격 모션 캔슬 발동) |
| 불가능 조건 | Dash, Dead, 쿨타임 진행 중, 신력 부족, 미습득, 발현 중이 아닌 가호의 신성 |
| Attack 중 사용 | 기본공격 모션 도중 신성 입력 시 남은 모션을 끊고 즉시 발동한다. 판정 발생 시점(BasicAttackHitTiming) 이전에 캔슬되면 그 공격의 판정은 생성하지 않는다 (4-1절 캔슬 규칙) |
| 시전 중 이동 | 신성별로 다르다. 미정 (신성 목록 확정 후 09에서 확정) |

| 등급 | 개수 | 쿨타임 | 신력 소모(DivinityCost) |
|---|---|---|---|
| 초급 | 2 | 짧음 (연타 방지 수준, 가안) | 낮음 (값 미정) |
| 고급 | 2 | 약 20초 (가안) | 높음 (값 미정) |
| 강림 | 1 | 60초 이상 (가안) | 높음 (값 미정) |

이 표는 방향성만 확정한 가안이며 값은 09_데이터 테이블에서 확정한다. 초급 신성은 연타 방지 수준의 짧은 쿨타임만 두고 실질 제약을 신력 소모로 옮긴다. 고급·강림 신성은 긴 쿨타임과 높은 신력 소모를 병행한다.
유틸을 겸하는 신성(화영난무·번개창)은 등급별 쿨타임·소모 기준의 예외로 개별 책정한다 (값은 09).
쿨타임과 신력 차감은 신성 사용 입력이 성립한 시점에 시작·적용한다. **가호를 전환해도 쿨타임은 초기화되지 않고 남은 신력도 그대로 유지된다.** 전환으로 쿨타임이나 신력 소모를 회피할 수 없다.
가호 전환은 장소 제약이 없고 전투 중에도 Tab으로 할 수 있다 (02_플레이어 조작 8-1절). 전환 입력에는 전환 쿨타임(BlessingSwitchCooldown)이 걸리며, 값은 미정 (09_데이터 테이블에서 확정)이다. 전투 중 전환은 세 가호의 신성을 잇는 조합을 만들기 위한 것이며, 피격 직전 전환으로 가호 패시브만 취하는 악용은 전환 쿨타임으로 막는다.

## 5. 적 공격 기획

적의 정체는 타락한 수인이다 (00_게임 콘셉트 3-2절). 유형별 구체 종은 미정 (08_스테이지 설계에서 결정).

| 항목 | 내용 |
|---|---|
| 공격 조건 | 플레이어가 AttackRange 안에 있고 AttackCooldown이 끝났을 때 |
| 공격 대상 | 플레이어 1인 |
| 공격 범위·데미지·쿨타임 | 유형별 AttackRange, AttackDamage(고정값), AttackCooldown. 값 미정 (09) |
| 준비 시간·후딜레이 | AttackWindupTime, AttackRecoveryTime. 값 미정 (09) |
| 애니메이션·판정 타이밍 | 유형별 Windup → Attack → Recovery. 판정은 애니메이션 이벤트 시점(AttackHitTiming)에 발생. 값 미정 (09) |

| 유형 | 이동 | 공격 방식 |
|---|---|---|
| 근접 보행형 | 지상 보행 | 접근 후 전방 근접 판정 1회 |
| 원거리형 | 지상 보행, 거리 유지 | 일정 거리 밖에서 투사체 발사. 플레이어와 충돌하면 데미지 적용 후 소멸 |
| 돌진형 | 지상 보행 | 예고 동작 후 플레이어 방향으로 직선 돌진. 돌진 중 접촉 판정. 돌진 후 빈틈 |
| 비행형 | 공중 이동 | 지형에 막히지 않고 접근한 뒤 근접 판정 |
| 방어형 | 후순위 확장 | 이 문서에서 정의하지 않는다 |

모든 적 공격은 예고 동작 뒤에 판정이 발생한다. 예고 없이 즉시 판정되는 공격은 두지 않는다.

## 6. 데미지 계산 규칙

이 게임은 **고정 데미지형**이다. 계산식을 두지 않는다.

- 데미지 결정 방식: 공격마다 정해진 고정값을 그대로 적용한다. 최종 데미지는 해당 공격의 Damage 값이다.
- 두지 않는 요소: 방어력, 최소 데미지 보정, 치명타, 속성 상성, 캐릭터 레벨·경험치.
- 능력치형 버프·디버프 시스템은 두지 않는다. 다만 스킬 효과로 정의된 배율·감산(가호 패시브, 번개창 증폭 장막, 강림 강화, 빙갑 반사 비율)은 허용하며, 해당 필드는 04_능력 게이트 10절에 한정한다.
- 데미지 값을 가지는 대상: 기본공격 1개, 공격 신성별 각 1개, 적 유형별 공격 각 1개, 보스 패턴별 각 1개. 값은 전부 미정 (09에서 확정)
- 성장은 신성 강화(신성 데미지 상승)와 기본공격 성장 두 가지뿐이다. 기본공격 성장 경로는 미정 (06_아이템·보상에서 결정)

## 7. 체력과 사망 처리

| 항목 | 플레이어 | 적 |
|---|---|---|
| HP 필드 | MaxHp, CurrentHp. 값 미정 (09) | 유형별 MaxHp, CurrentHp. 값 미정 (09) |
| HP 감소 조건 | 적 공격 판정 적중, 무적 시간이 아닐 때 | 플레이어 공격 판정 적중 |
| HP 회복 조건 | 제단 상호작용 시 완전 회복. 횟수 제한형 회복 수단 사용 시 회복 | 없음 |
| HP 0 이하 | Dead 전환, Dead 애니메이션 재생 | Dead 전환, Dead 애니메이션 재생 |
| 사망 후 판정 | 판정 대상에서 제외 | 판정 대상에서 제외. 추가 데미지 없음 |
| 사망 후 처리 | 모든 플레이 입력 무시, 체크포인트 부활 (01_핵심 플레이 루프 9절) | 모든 AI 행동 정지, 자원 1회 지급 후 오브젝트 제거 |

회복 수단은 둘이다. 전투 중 자연 회복은 없다.

- **제단(체크포인트 거점)**: 상호작용하면 HP를 최대치로 회복하고 신력을 완전 충전한다. 제단 휴식 시 적 리스폰 여부는 미정 (05_맵·진행에서 결정)
- **횟수 제한형 회복 수단**: 사용 횟수가 제한되고 제단에서 충전된다. 형태(공용 신성인지 아이템인지), 사용 횟수, 회복량, 사용 동작은 미정 (06_아이템·보상에서 결정)

## 8. 피격 처리

이 게임은 **피격 경직(히트스턴)을 두지 않는다.** 피격은 상태 전환 없이 처리한다. 조작이 끊기지 않게 하기 위함이다.

| 항목 | 플레이어 | 적 |
|---|---|---|
| 피격 조건 | 공격 판정 접촉, 무적 시간이 아님, Dead 아님 | 공격 판정 접촉, Dead 아님 |
| 상태 전환·경직 | 없음. 현재 상태를 유지한다 | 없음. AI 상태를 유지한다 |
| 넉백·방향 | 있음. 공격이 온 방향의 반대로 가벼운 넉백 | 공격이 온 방향의 반대. KnockbackImmune이 false인 적만 적용 |
| 넉백 거리·시간 | KnockbackDistance, KnockbackDuration. 값 미정 (09) | 유형별. 값 미정 (09) |
| 무적 시간 | HitInvincibleTime. 값 미정 (09) | 없음 |
| 중복 피격 방지 | 무적 시간으로 차단 | 하나의 판정당 대상별 1회만 적용 |
| 연출 | 피격 연출(플래시 등)과 무적 중 연출(깜빡임 등). 형식 미정 (07 또는 아트) | 피격 연출만. 형식 미정 (07 또는 아트) |

플레이어 피격 처리 흐름:

1. 적 공격 판정이 플레이어에 접촉한다. 무적 시간 진행 중이면 처리를 중단한다.
2. CurrentHp에서 해당 공격의 고정 데미지를 빼고, 공격이 온 방향의 반대로 넉백을 적용한다.
3. 피격 연출을 재생하고 HitInvincibleTime 동안 무적을 적용한다.
4. CurrentHp가 0 이하면 Dead로 전환한다.

플레이어 무적의 원천은 둘이다. 피격 후 부여되는 **피격 무적**(HitInvincibleTime)과, 특정 신성의 시전 중에만 유지되는 **스킬 무적**(여우 화영난무 시전 중, 강림 연출 중 등)이다. 위 표와 처리 흐름의 "무적 시간이 아님"은 두 원천을 모두 포함한다. 어느 한쪽이라도 진행 중이면 데미지와 넉백을 적용하지 않는다. 스킬 무적을 가지는 신성 목록과 지속 구간은 04_능력 게이트에서 확정한다.
예외적으로 데미지 흡수형 신성(늑대 빙갑)이 유지 중이면, 흡수된 데미지에 대해 HP 감소·넉백·무적 부여를 적용하지 않는다. 흡수 상한 초과분은 정상 피격 처리한다 (04_능력 게이트 5-2-3절).
KnockbackImmune이 true인 적(일부 대형 적)과 보스는 넉백을 적용하지 않고 데미지만 적용한다. 유형·개체별 지정은 09_데이터 테이블에서 한다.

## 9. 전투 상태 정의

플레이어 상태는 **6종**이며 02_플레이어 조작 9절과 일치한다. **경직이 없고 피격을 상태 전환 없이 처리하므로 Hit 상태를 두지 않는다.**

| 상태 | 좌우 이동 | 점프 | 기본공격 | 공격 신성 | 이동 신성 | 일반 대시 | 상호작용 |
|---|---|---|---|---|---|---|---|
| Idle | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 |
| Move | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 |
| Jump(공중) | 가능 | 더블점프 보유 시 1회 | 가능 | 가능 | 가능 | 가능 | 불가능 |
| Dash | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 |
| Attack | 가능 | 가능 (모션 캔슬) | 입력 버퍼로 처리 | 가능 (모션 캔슬) | 가능 (모션 캔슬) | 불가능 | 불가능 |
| Dead | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 | 불가능 |

상태별 전환 조건:

| 상태 | 진입 조건 |
|---|---|
| Idle | 지면에 있고 이동 입력이 없다 |
| Move | 좌우 이동 입력 |
| Jump(공중) | 지면에서 점프 또는 지면 이탈(낙하) |
| Dash | Shift 입력, 쿨타임 종료 |
| Attack | D 또는 Q/W/E/R/S 입력 |
| Dead | CurrentHp 0 이하 |

Dash 상태에서는 적을 통과한다. 전환 우선순위: Dead > Dash > Attack > Jump(공중) > Move > Idle. 피격은 이 우선순위에 관여하지 않는다.

일반 대시 규칙:

- 방향: 좌우 입력 중이면 그 방향이며 캐릭터도 그 방향을 바라본다. 입력이 없으면 바라보는 방향이다.
- 무적: 없다. 대시 중에도 적 공격 판정에 피격된다.
- 충돌: 적과의 충돌을 무시하고 통과한다. 지형 충돌은 유지한다.
- 공중 사용: 가능하다. 공중에서는 착지 전까지 **1회만** 사용할 수 있고, 착지하면 초기화된다. 쿨타임과 별개로 적용한다. (AirDashMaxCount, 기본 1. 값은 09에서 확정)

조작 보정은 둘 다 채택한다. 값은 미정 (09에서 확정) 입력 버퍼(선입력)는 행동 불가 시점의 입력을 InputBufferTime 동안 저장하고 가능해지면 실행한다. 접지 유예(코요테 타임)는 지면을 벗어난 뒤 CoyoteTime 동안 지상 점프를 허용한다.

## 10. 적 AI 전투 행동

적 상태는 대기 → 감지·추적 → 공격 → 복귀 / Dead다.

| 상태 | 행동 | 전환 조건 |
|---|---|---|
| 대기 | 정지 또는 지정 구간 순찰 | 초기 상태 |
| 감지·추적 | 플레이어 방향으로 이동 | 플레이어가 DetectRange 안에 진입 |
| 공격 | 예고 동작 후 공격 판정 생성 | 플레이어가 AttackRange 안, AttackCooldown 종료 |
| 복귀 | 초기 위치로 이동 후 대기로 전환 | 플레이어가 DetectRange를 벗어남 |
| Dead | 모든 행동 정지, 판정 제외 | CurrentHp 0 이하 |

인식 범위 DetectRange, 공격 범위 AttackRange, 이동 속도 MoveSpeed는 유형별로 따로 둔다. 값은 전부 미정 (09에서 확정). 공격 대상이 플레이어 1인이므로 공격 우선순위 판정과 타깃 재탐색은 두지 않는다. 유형별 이동과 공격 방식은 5절 표를 따르고, 개별 적 목록·배치·수치는 08_스테이지 설계와 09_데이터 테이블에서 정의한다.

## 11. 보스 전투 기획

| 대상 | 페이즈 | 넉백 |
|---|---|---|
| 일반 적 | 없음 | 적용 (KnockbackImmune이 false일 때) |
| 중간보스·강적 | 없음. 페이즈 없는 강화 적으로 취급한다 | KnockbackImmune으로 개별 지정 |
| 큰 보스(지역 보스) | 있음. 체력 구간 기반 전환 | 면역 (KnockbackImmune = true) |

큰 보스 규칙:

- 등장 조건과 HP: 지역 부탁 진행 중 지정 위치 진입. 보스 HP는 BossMaxHp. 개별 조건 미정 (08), 값 미정 (09)
- 페이즈 구분·전환 조건: 체력 구간(PhaseHpThreshold) 기준. 현재 HP가 다음 페이즈의 임계값 이하로 내려간 순간 전환한다. 페이즈 수와 구간 값 미정 (08·09에서 결정)
- 패턴 목록·실행 조건: 페이즈별로 사용 가능한 패턴 목록을 따로 두고, 패턴별 쿨타임(PatternCooldown)이 끝나면 실행한다. 패턴 내용 미정 (08에서 결정)
- 예고 동작: 모든 패턴에 예고 동작을 둔다. 예고 시간 PatternWindupTime. 값 미정 (09)
- 전환 연출: 페이즈 전환 시 1회성 연출을 재생한다. 연출 중 보스는 무적이며 패턴을 실행하지 않는다
- 보스 사망 조건: CurrentHp 0 이하. 보상은 자원 지급과 신력 충전이며, 부탁 완료 처리는 부탁(퀘스트) 시스템이 담당한다 (01_핵심 플레이 루프 4~5단계). 보스 수와 개별 패턴은 전부 미정 (08_스테이지 설계에서 개별 정의)

보스 전투 예외:

| 예외 상황 | 처리 |
|---|---|
| 보스 사망과 플레이어 사망 동시 발생 | 처리 방침 미정 (05_맵·진행에서 결정). 01_핵심 플레이 루프 10절의 "부탁 완료와 사망 동시 발생"과 같은 항목으로 다룬다 |
| 페이즈 전환 연출 중 플레이어 공격 | 보스는 무적이므로 데미지를 적용하지 않는다 |
| 한 프레임에 두 페이즈 구간을 통과하는 데미지 | 처리 방침 미정 (09_데이터 테이블 확정 후 재검토) |

## 12. 보상 연결

- 적 처치 보상과 보스 처치 보상: 자원을 지급한다. 자원 이름·종류·수량 미정 (06·09에서 결정)
- 부탁 관련 보상: 가호는 부탁 완료가 아니라 **수령 시점**에 부여된다 (00_게임 콘셉트 3-2절). 완료 시에는 지역 신앙 회복과 중심 서사 진전이 이뤄진다. 모두 전투 시스템이 아니라 부탁 시스템이 처리한다 (01_핵심 플레이 루프 8절)
- 경험치: 없다. 캐릭터 레벨업을 두지 않는다.
- 지급 조건과 중복 방지: 대상이 Dead로 **처음 전환될 때** 1회만 지급한다. 보상 지급 완료 플래그를 두고, 이미 지급한 대상에게 다시 지급하지 않는다.
- 드랍 형태: 즉시 획득인지 필드 드랍 후 습득인지 미정 (06_아이템·보상에서 결정)

## 13. 전투 UI 피드백

확정된 항목만 적는다. 표시 형식과 위치는 07_UI 흐름에서 정의한다.

- 표시가 확정된 항목: 플레이어 HP, 신력 게이지(남은 신력. 소모·충전 시 갱신), 신성 쿨타임(공격 신성 5개·이동 신성·일반 대시), 가호 전환 쿨타임, 현재 발현 중인 가호, 피격 연출, 무적 중 연출. 일곱 항목 모두 형식은 미정 (07 또는 아트에서 결정)
- 상태 이상: **스킬에 내장된 형태로만 존재한다.** 현재 2종이다. ① **빙결** — 늑대 아이스 차지(04_능력 게이트 5절에서 정의) 적중 시 걸리며, 이어지는 연계 참격 연출 동안만 지속되고 마지막 참격과 함께 해제된다. ② **경직** — 용 번개 광선(04_능력 게이트 5절에서 정의)의 빔이 적중하는 동안만 유지되고, 빔이 끊기면 해제된다. 둘 다 보스를 포함한 모든 적에게 적용되며 면역 대상을 두지 않는다. 독립적으로 지속되는 상태 이상 시스템은 두지 않는다. 빙결·경직의 지속은 스킬 자체의 효과 필드(빙결=FreezeDuration, 연계 참격 시간과 일치 / 경직=빔 적중 중)로만 관리한다.
- 미정 항목: 적 HP 표시, 보스 HP 표시, 데미지 숫자 표시, 보상 획득 표시 (06·07에서 결정). 내장형 상태 이상 2종(빙결·경직)의 표시 여부와 형식도 미정 (07_UI 흐름에서 결정)

## 14. 전투 데이터 목록

필드 이름만 정의한다. 값은 전부 미정이며 09_데이터 테이블에서 확정한다. 시간 단위는 초, 거리 단위는 유닛으로 통일한다.

| 하나의 판정이 같은 적에게 중복 적용 | 다단 히트 방지 | 판정이 여러 프레임 유지됨 | 판정마다 적중 대상 목록을 기록하고 대상당 1회만 적용한다 |
| 무적 시간 중 데미지·넉백 | 연속 피격 방지, 무적 중 밀림 기준 | HitInvincibleTime 진행 중 피격 판정 접촉 | 데미지를 적용하지 않는다. 따라서 넉백도 적용하지 않는다 |
| 적 사망 보상 중복 지급 | 자원 복사 방지 | 사망 처리가 두 번 실행됨 | 보상 지급 완료 플래그로 차단하고 1회만 지급한다 |
| 공격 중 피격 | 공격 취소 방지 | Attack 상태에서 적 공격 적중 | 공격을 취소하지 않는다. HP 감소·넉백·무적만 적용한다 |
| 신력 부족 상태에서 신성 사용 | 신력 부족 처리 | 남은 신력이 그 신성의 DivinityCost보다 적음 | 사용을 거부한다. 신력을 차감하지 않고 쿨타임도 시작하지 않으며, 신력 부족을 표시한다 |
| 신성 성립 후 판정 미적중 | 성립·소모 기준 확정 | 발동 조건을 충족해 성립했으나 판정이 빗나감 | 소모한 신력·쿨타임을 되돌리지 않는다 (성립 기준은 4-2절) |
| 신력이 가득 찬 상태에서 충전 | 초과 충전 방지 | 적 처치·오브젝트 점등·제단 상호작용 시 CurrentDivinePower가 MaxDivinePower 이상 | MaxDivinePower를 넘기지 않고 최대치에서 멈춘다. 초과분은 버린다 |
| 가호 전환 직후 신성 키 입력 | 쿨타임·신력 회피 방지 | 전투 중 가호를 바꾼 직후 Q/W/E/R/S 입력 | 전환해도 쿨타임과 남은 신력은 유지된다. 쿨타임이 남아 있거나 신력이 부족하면 입력을 무시한다 |
| 전환 쿨타임 중 가호 전환 시도 | 피격 직전 전환 악용 방지 | BlessingSwitchCooldown 진행 중 Tab 입력 | 입력을 무시한다. 선택을 열지 않고 슬로우도 걸지 않는다 (02_플레이어 조작 8-1절) |
| 빙결·경직 중 대상이 사망 | 내장형 상태 이상 잔류 방지 | 빙결 또는 경직이 걸린 대상의 CurrentHp가 0 이하 | 상태 이상을 즉시 해제한다. 연계 참격과 빔은 정상 진행하되, Dead 대상에는 이후 데미지를 적용하지 않는다 |
| 공중 대시 남용 | 도달 범위 통제 | 착지 없이 공중에서 대시를 반복 입력 | 공중에서는 착지 전까지 1회만 허용한다. 초과 입력은 무시하고, 착지 시 횟수를 초기화한다 |
| 대시 중 적과 겹침 | 통과 규칙 확정 | Dash 상태에서 적과 위치가 겹침 | 적과의 충돌을 무시한다. 무적이 아니므로 적 공격 판정에는 피격된다 |
| 넉백 중 지형에 막힘 | 벽 끼임 방지 | 넉백 방향에 벽이 있음 | 지형 충돌을 우선해 넉백 이동을 중단한다. 넉백 시간은 그대로 종료시킨다 |
| 보스 사망과 플레이어 사망 동시 발생 | 판정 순서 확정 | 같은 프레임에 양쪽 HP가 0 이하 | 처리 방침 미정 (05_맵·진행에서 결정. 01_핵심 플레이 루프 10절과 동일 항목) |
| 조우 종료 후 전투 입력 | 불필요한 판정 방지 | 범위 안에 살아 있는 적이 없음 | 입력은 정상 처리한다. 판정은 생성되지만 대상이 없으면 아무 처리도 하지 않는다 |
| 전투 중 UI 팝업이 열림 | 입력 충돌 방지 | 팝업·일시정지·로딩 진행 중 | 모든 플레이 입력을 무시한다. 적 AI와 쿨타임 진행 정지 여부는 미정 (07_UI 흐름에서 결정) |
| 회복 수단 사용 횟수 소진 | 사용 횟수 소진 처리 | 남은 사용 횟수가 0 | 사용을 거부하고 횟수를 차감하지 않는다. 세부 미정 (06_아이템·보상에서 결정) |

## 16. AI 구현 요청용 프롬프트

**목적**
2D 메트로배니아의 전투 시스템을 구현한다. 근접 1타 기본공격, 긴 쿨타임의 신성, 고정 데미지, 경직 없는 피격 처리, 적 AI, 보스 페이즈를 각각 분리해 구현한다.

**환경**
Unity 6, C#, PC 단독 실행, 싱글 플레이, 2D 횡스크롤 픽셀아트.

**요구 기능**

1. 기본공격: D 입력으로 Attack 상태 전환. 근접 1타 공격이며 단계 개념을 두지 않는다. BasicAttackHitTiming 시점에 애니메이션 이벤트로 전방 판정을 생성하고 BasicAttackDamage를 적용한다. 공격 중 좌우 이동 허용. 연속 입력 시 BasicAttackCooldown 간격으로 같은 공격을 반복하고, 모션·쿨타임 중 재입력은 InputBufferTime 동안 저장했다가 1회 실행한다.
2. 공격 신성: Q/W/E/R/S. 발현 중인 가호의 배운 신성만 사용. 쿨타임과 남은 신력(DivinityCost)을 함께 검사하고, 사용이 성립하면 신력을 차감한다. 신력은 가호와 무관하게 하나를 공유하며, 가호를 전환해도 쿨타임과 남은 신력을 초기화하지 않는다. 신력 자연 회복은 구현하지 않는다. 충전은 적 처치, 신앙 오브젝트 점등, 제단 완전 충전의 세 경로로 들어오며, 충전 규칙은 교체 가능한 구조로 분리한다(가안이므로 프로토타입 검증 후 바뀔 수 있다). 가호 전환은 장소 제약 없이 전투 중에도 가능하고, 전환이 성립하면 BlessingSwitchCooldown을 시작한다. 상태 이상은 스킬에 내장된 2종(빙결·경직)만 두고, 독립적으로 지속되는 상태 이상 시스템은 만들지 않는다.
3. 데미지 적용: 고정 데미지형. 방어력·치명타·속성 보정 없이 공격별 Damage 값을 그대로 적용한다.
4. 피격 처리: 경직 없음. Hit 상태를 만들지 않는다. HP 감소 + 반대 방향 넉백 + HitInvincibleTime 무적 + 피격 연출로 처리한다. 무적 판정은 피격 무적과 스킬 무적(신성 시전 중 무적) 두 원천을 함께 검사한다. 공격 중 피격돼도 공격을 취소하지 않는다. KnockbackImmune이 true인 대상에는 넉백을 적용하지 않는다.
5. 일반 대시: 좌우 입력이 있으면 그 방향, 없으면 바라보는 방향. 무적 없음. 공중 사용 가능. 적과의 충돌 무시, 지형 충돌 유지.
6. 조작 보정과 상태 머신: 입력 버퍼(InputBufferTime)와 접지 유예(CoyoteTime)를 구현한다. 상태는 Idle, Move, Jump(공중), Dash, Attack, Dead 6종이며 Hit 상태를 추가하지 않는다.
7. 적 AI: 대기 → 감지·추적 → 공격 → 복귀 / Dead. 유형은 근접 보행형, 원거리형, 돌진형, 비행형 4종. 모든 공격에 예고 동작을 둔다.
8. 보스: 체력 구간 기반 페이즈 전환. 페이즈별 패턴 목록, 패턴 쿨타임, 예고 동작, 전환 시 1회성 연출.
9. 보상: 대상이 Dead로 처음 전환될 때 자원을 1회만 지급하고, 같은 시점에 PurifyChargeAmount만큼 신력을 1회만 충전한다.

**데이터 구조**
PlayerCombatData, DashData, DivinityData, EnemyData, BossData, BossPatternData, ProjectileData. 필드는 14절 표를 따른다. PlayerCombatData는 기본공격 필드 BasicAttackDamage, BasicAttackRange, BasicAttackCooldown, BasicAttackHitTiming과 신력 필드 MaxDivinePower, CurrentDivinePower를 포함하며, 기본공격 단계용 별도 데이터는 두지 않는다. DivinityData는 근접·원거리를 구분하는 RangeType, 판정 시점 DivinityHitTiming, 신력 소모량 DivinityCost를 포함한다. EnemyData는 처치 시 신력 충전량 PurifyChargeAmount를 포함한다. AttackPower와 Defense 필드를 만들지 않는다. 모든 수치는 ScriptableObject 등 외부 데이터로 분리하고 하드코딩하지 않는다.

**처리 흐름**
공격 입력 → 상태·쿨타임 검사 → Attack 전환·애니메이션 재생 → 애니메이션 이벤트로 판정 생성 → 살아 있는 대상에게 고정 데미지 적용 → HP 감소·넉백 → HP 0 이하 시 Dead 전환 → 자원 1회 지급 → 상태 복귀.

**예외 조건**

- Dead 대상은 판정에서 제외하고 추가 데미지를 적용하지 않는다. 판정이 유지되는 도중 대상이 사망하면 그 이후 접촉에도 적용하지 않는다.
- 하나의 판정은 대상당 1회만 데미지를 적용한다.
- 무적 시간(피격 무적·스킬 무적) 중에는 데미지도 넉백도 적용하지 않는다. 빙결·경직이 걸린 대상이 사망하면 상태 이상을 즉시 해제하고, 연계 참격과 빔은 정상 진행한다.
- 보상은 Dead 첫 전환 시 1회만 지급한다.
- 쿨타임 중 입력은 InputBufferTime 동안 저장했다가 실행한다. 가호 전환으로 신성 쿨타임과 남은 신력을 초기화하지 않는다.
- 신력이 DivinityCost보다 적으면 신성 사용을 거부한다. 신력을 차감하지 않고 쿨타임도 시작하지 않으며, 부족 표시를 요청한다. 충전은 MaxDivinePower를 넘기지 않는다.
- 공중 대시는 착지 전까지 1회만 허용한다(AirDashMaxCount). 초과 입력은 무시하고 착지 시 초기화한다.
- 공격 모션 중 점프·신성 입력은 캔슬로 처리한다. 판정 발생 전 캔슬 시 판정을 생성하지 않는다.
- 보스와 플레이어 동시 사망, 한 프레임 다중 페이즈 통과, 팝업 중 적 AI·쿨타임 정지 여부, 회복 수단의 형태·횟수·회복량은 미정이다. 임의로 구현하지 말고 TODO 주석으로 남긴다.

**출력 형식**
Unity 6용 C# 스크립트. 하나의 클래스에 모두 작성하지 않는다. 입력 처리는 PlayerCombat, 데미지 적용은 DamageCalculator, 체력 관리는 Health, 피격 처리는 HitReceiver, 넉백은 KnockbackReceiver, 적 AI는 EnemyStateMachine, 보스 페이즈는 BossPhaseController로 책임을 나눈다. 데이터와 로직을 분리한다. 미정 항목은 값을 채우지 말고 TODO 주석으로 남긴다.

## 17. 테스트 기준

- 기본공격이 판정 범위 안의 적에게 고정 데미지를 적용하고, 범위 밖의 적은 받지 않는가?
- D 연속 입력 시 같은 공격이 BasicAttackCooldown 간격으로 반복되고, 공격 모션·쿨타임 중 D 재입력이 InputBufferTime 동안 저장되었다가 1회만 실행되는가?
- 공격 중 좌우 이동이 가능하고 공격 중 피격돼도 공격이 취소되지 않으며, 하나의 판정이 같은 적에게 데미지를 두 번 적용하지 않는가?
- 피격 시 Hit 상태로 전환되지 않고 조작이 유지되며, 반대 방향 넉백과 무적 시간이 적용되고, 무적 시간 중 추가 데미지와 넉백이 모두 차단되는가?
- KnockbackImmune인 적과 보스에게 넉백이 적용되지 않고, 대시가 적을 통과하고 지형에는 막히며 대시 중 적 공격에 피격되는가?
- 쿨타임 중 신성 입력이 무시되고, 가호를 전환해도 쿨타임과 남은 신력이 초기화되지 않는가?
- 신력이 부족하면 신성이 발동하지 않고 신력·쿨타임이 소모되지 않는가? 적 처치와 제단 상호작용으로 신력이 충전되고 최대치를 넘지 않는가?
- 적 HP가 0 이하가 되면 Dead로 전환되고 판정에서 제외되며, 판정이 유지되는 도중 사망한 대상에게 추가 데미지가 들어가지 않고, 사망 보상이 한 번만 지급되는가?
- 적이 감지 범위 진입 시 추적하고 이탈 시 복귀하며, 적 공격에 예고 동작이 재생된 뒤 판정이 발생하는가?
- 보스가 체력 구간에서 페이즈를 전환하고 전환 연출 중 무적인가? 플레이어가 Dead 상태일 때 모든 입력이 차단되는가? 제단 상호작용으로 HP가 최대치까지 회복되고 신력이 완전 충전되는가?
