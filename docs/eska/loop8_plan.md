# 루프 8 개선 기획 (7차 평가 → 수정 계획)

> 근거: 7차 평가 4건(HEAD 8c53f59). **마녀다움 9/10**(타이틀 주인공 구도 + 흰 X 바느질 땀), 손맛 8/10, 아트 8.5/10, 첫 경험 7/10. 배움 느려짐 곡선은 부드러움(0.15초/0.3초 확인), 쓰러짐 원인 줄은 실용적, 분신 테두리 굽기는 무손실(도형 8648 → 4666).
> 이번 루프의 중심: **검성 첫 9초를 사람이 소화하게**(배움 몰림 풀기) + **다섯 처방 모두 단독 성립** + **글자 겹침 정리**.

## 1. 검성 첫 만남 박자 [결정]

- 문제: 가만히 서 있으면 싸움이 열린 뒤 9초 안에 배움 4개(발도·반격·비검·삼연참)가 2~3초 간격으로 터져 첫 9초의 약 60%가 느린 상태 → "배움"보다 "자꾸 끊김".
- **배움 사이 최소 5초**: 배움이 나간 뒤 5초 안에 나오는 다른 첫 기술은 배움을 건너뛰고 다음 기회에 보여 줌.
- **첫 도전 개막 20초는 순서 고정**: 발도 → (3초 쉼) → 비검 → (3초 쉼) → 삼연참 → (3초 쉼) → 반격 자세. 배움을 다 본 세션에서는 평소 AI.
- 배움 동안 **해당 터치 버튼에 맥박 고리**(`ETouch.spot` 재사용, 튜토리얼과 같은 문법): 발도 → 점프·순간, 비검 → 점프·스킬, 반격 → 물약, 삼연참 → 방향 ←.
- **개막 구도**: 싸움이 열릴 때 에스카를 x ≥ 360으로(왼쪽 벽에 붙어 카메라가 치우칠 수 없던 문제), 검성은 화면 가로 55% 안에서 시작.
- **2막 확인점**: 2막(체력 55%)에 들어간 뒤 쓰러지면 2막 시작부터 다시(검성 체력 55%, 종언 게이지 0). 1막 쓰러짐은 그대로 처음부터. 발도 피해는 그대로(검성의 위엄).

## 2. 다섯 처방 모두 단독 성립 [결정]

7차 측정(분신 1200): 메아리+천열 3/3(2.15초) · 갓 찢긴 속박 3/3(5.35초) · 흑성 3/3(4.55초) · **봉공+베기 0/3** · **유성우 단독 0/3**.
- 봉공·유성우는 흑성과 같은 값(종언 게이지 가득)이므로 단독으로 셋을 끝낼 수 있어야 공정.
- **유성우**: 분신이 살아 있으면 모이는 유성을 8 → **9발(분신당 3발)**로 고르게 나누고, **분신에 맞을 때만 한 발 420**(분신당 1260 ≥ 1200). 검성 본체·일반 표적 피해는 그대로.
- **봉공**: 봉공으로 굳은 분신이 받는 피해 **×1.3**(5초 베기 약 14번 980 → 1274). 봉공 범위 밖 분신은 걸어가서 마무리.
- **그림자 일섬 배움 둘째 줄에 처방**: "메아리+천열 · 흑성 · 유성우"(두 마디 규칙 유지, 터치는 버튼 이름).

## 3. 글자 겹침·쓰러짐 화면 [결정]

- **장면 안내 한 줄은 배움·쓰러짐 알림 동안 숨김**. 배움이 끝나면 그 기술에 맞는 안내로 이어 줌(반격 → 비명·속박 안내). 돌리기는 처음 30초와 부활 직후 10초만, 그 뒤엔 숨김.
  - 코어가 `EHud.hold_hints(sec: float, next: String = "")`를 열고, 보스장이 배움·쓰러짐 때 부름(`has_method`로 확인).
- **쓰러짐 원인 줄**: "쓰러졌다" 바로 아래로 올리고 붉은 ■ + 혼잣말 크기 글씨, 부활 대기 내내 보임. "입구에서…"는 그 아래 작게. 문구는 행동 + 버튼 이름: "삼연참 — {es_left}로 물러나거나 {es_jump} 두 번", "발도 — 번뜩이면 {es_blink}"(EKeys.fmt).
- 쓰러지는 순간 전체 흰빛 번짐 → 2프레임 + 붉은 가장자리 비네트.
- 외곽선 모드에서 **버튼 글자도 30%** 진하기(지금은 병 그림만).

## 4. 그림 [결정]

- **타이틀 에스카를 진짜 실루엣으로**: 달 중심에 세우고, 달 앞에서는 몸을 먹빛(명도 −60%)으로, 테두리는 라벤더 **아트 픽셀 1칸(= 화면 3px)**. 달 앞 전나무는 뒤로. 문장 고리는 그대로.
- **분신 테두리를 먹 쪽으로**: 평소 `CORD_DEEP`(#7a0d18) 알파 0.8, 예고(9px 십자) 뒤부터만 밝은 붉은색 → 위험 신호가 더 삼. 분신은 에스카 몸 뒤(z −1)에 그림.
- **틈 부식 웅덩이**: 높이 5~6px 타원(어두운 초록 몸 + 연두 윗선 1px), 거품 2~3개가 0.3초마다 터짐, 가장자리 디더로 2초 동안 줄어들며 사라짐.
- **튜토리얼 마무리 운석 섬광**: 화면 전체 라벤더 씻김 → 착지점 중심 방사형 빛 + 가장자리 어둠(0.2초). 에스카 실루엣과 땅 문장이 또렷하게 남게.
