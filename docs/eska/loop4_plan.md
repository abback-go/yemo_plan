# 루프 4 개선 기획 (3차 평가 → 수정 계획)

> 근거: 3차 평가 4건(손맛·아트·설계성능·첫 10분 체험), HEAD effeacf. 마녀다움 8/10, 시나리오 35개 오류 0, 보스 과부하 도형 18090.
> 가장 큰 결론: **이 게임만의 재미(물약·가마솥·틈 달이기·단공 튕겨내기·대마법)를 첫 10분에 아무도 만나지 못한다.** 체감이 "보라색 검사"에 머무는 이유.

## 1. 튜토리얼이 대표 재미를 가르치게 [결정] — 이번 루프의 중심

기존 단계·소품·안내 칸·버튼 고리(ETouch.spot)를 재사용해 단계를 바꾼다.
1. **망령 구간** → "구슬이 몸에 닿기 직전 ↑+스킬 = 가르는 틈(딱 맞춤)" 1회가 통과 조건. 이어서 높이 떠 있는 망령은 ↓+스킬 낙성으로.
2. **가마솥 쉼터(새)** → 마녀 수첩의 메모 힌트를 보고 속박(거미줄+거미줄)을 달여 ↓칸에 담기. 들르면 물약이 가득 찬다는 것도 보여 줌.
3. **사냥개 구간** → 봉공 대신 "↓+물약 = 속박을 던져 묶기".
4. **거상(마무리)** → 처음 한 번은 **천열로 찢기 → 틈이 열린 동안 시간 0.5배 + "지금 ↓+물약"** → 병이 틈에 스며 진하게 퍼지고 꿰매지는 장면. 게이지는 **실제 피해로** 채워지는 걸 보여 주고(가득 차면 안내), 대마법 고르기(순환) → 발동으로 끝.
5. 안내 글은 입력 방식에 맞춰 바뀜(키보드 "A" / 터치 "스킬").

## 2. 터치 사용자 정보 끊김 [결정]

- 웹 글꼴에 없는 "•"(→ "2022" 상자) → 그린 점으로.
- 터치일 때도 장면 안내(context_hints)를 보스바 아래 가운데에, **처음 15초와 부활 직후만**.
- 안내 문구 입력 방식별(공용 함수 `EKeys.label(action)`).
- 보스장 가마솥·부활 지점을 방향키 밖(x≈260/300)으로, 가마솥 버튼이 뜨는 거리 34 → 56.
- 훈련장 틈 달이기 안내판은 가마솥 위로 옮기고, 오른쪽 봉공 안내판 잘림 고침.

## 3. 훈련장에 목표 [결정]

- 오른쪽 위 "마녀의 연습 과제" 5줄 체크: 낙성으로 공중 표적 / 단공 딱 맞춤 / 새 물약 달이기 / 틈 달이기 / 대마법 쓰기. 체크 연출은 튜토리얼 안내 칸 것 재사용.
- 공중 허수아비 1 + 구슬을 천천히 쏘는 망령 표적 1.
- 적 물결은 기본 꺼짐(버튼으로 켬).

## 4. 틈 달이기를 진짜 선택으로 [결정]

- **"갓 찢긴 틈"만 보상**: 열린 지 0.5초 안의 틈에 스민 병만 진함·저항 무시·꿰맬 때 한 번 더. 그 뒤엔 틈 모양으로 퍼지기만(보통 세기). → "천열 직후 0.5초"가 실제 박자가 됨.
- 던지는 물약 병 수 +1(속박 4, 부식 4, 비명 3) — 판당 2~3번 양념에서 벗어나게. (맞혀서 채우기·싸움 중 조제는 금지 규칙이라 쓰지 않음.)
- 틈 부식 그림: 형광 관 → 디더 초록 연기가 틈을 따라 뚝뚝 떨어져 바닥에 고임. 틈 달이기 그림 비용 줄이기(RiftBrew 도형 1728).

## 5. 검성 공정성 [결정]

- 발도 번뜩임 0.2 → 0.3초. 돌진 길이는 **웅크림 시작 순간의 거리로 고정**(물러서기가 대응이 되게).
- 2막 되돌아 베기 웅크림 0.42 → 0.55초.
- **단공으로 지운 순간부터 점프·순간이동으로 끊기 가능**(2막 이중 비검 둘째 파도 대응).
- 대숲 등 정지 배경을 한 장으로 구워 도형 약 4800 줄이기.

## 6. 그림 [결정]

- 천열·단공: 처음 0.1초는 두껍게 열린 밤하늘 몸통(2차 때처럼), 판정 뒤에만 얇게. 천열은 마지막 고리만 흐리게.
- 피해 숫자 쌓기 최대 3단, 넘치면 "896×8".
- 깃털 7px + 흰 깃대.

### 공통 약속 (루프 4)
- `ERifts.age(rift) -> float`: 열린 뒤 지난 초(게임 시계). 물약은 `age < 0.5`면 보상.
- `EKeys.label(action: String) -> String`: 지금 입력 방식(터치/키보드)에 맞는 이름. 튜토리얼·HUD·안내판이 쓴다.
- 튜토리얼 시간 느리게: `Fx` 기존 slowmo 사용.
