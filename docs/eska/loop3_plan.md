# 루프 3 개선 기획 (2차 평가 → 수정 계획)

> 근거: 2차 평가 3건(HEAD 3006cde). 1차 문제는 수치로 거의 다 고쳐짐. 마녀다움 7.5/10. 시나리오 33개 SCRIPT ERROR 0.
> 이번 루프의 목표: **틈 달이기를 "고를 이유가 있는" 대표 재미로**, 단공 튕겨내기에 실력 창, 보스전 2~2.5분.

## 1. 틈 달이기 — 보상과 오작동 [결정]

| 문제 | 근거 | 고침 |
|---|---|---|
| 자기 손 근처 틈이 병을 삼킴 (단공 뒤 비명 0명) | 시나리오 rift·봇 | 던진 뒤 **0.12초 또는 손에서 40px까지는 틈 무시** + **적이 걸치지 않은 틈(틈 ±24 안에 살아 있는 표적 0)은 무시**(흐린 물은 예외) |
| 직접 던지는 것과 결과가 같아 고를 이유 없음 | 봇 74초 중 3번 | **틈에 스민 물약 = 자동으로 진함 + 강자 저항(status_resist) 무시** + **틈이 꿰매질 때 한 번 더**(속박 → 버팀 300, 비명 → 기절 0.4초 다시, 부식 → 시간 갱신) |

| 속박 거미줄이 사다리처럼 보임 | 아트 | 불규칙 방사형 실 + 처진 줄 + 이슬 점, 점점 흐려짐 |

→ 보스전 결정: "그냥 던질까(즉시·보통 세기), 천열을 열고 0.5초 안에 넣을까(위험·진하고 강자에게도 다 걸림)".

## 2. 단공 튕겨내기 — 실력 창 [결정]

- 지금: 비검 약 0.75초, 천검 약 0.65초 창, 늘 쿨다운 초기화 → 무위험 정답이 되어 점프 회피를 대체.
- 고침: 판정 시간 0.36 → 0.22초, 폭 ±90 → ±64. **"딱 맞춤"(발사체가 에스카 몸 70px 안에 왔을 때 지움)만 쿨다운 초기화 + 게이지 +4% + 강한 불꽃**, 그보다 이르면 지우기만(쿨다운 그대로).
- 단공 틈은 피해 판정이 끝나면 밝기 40%, 남은 시간은 얇은 선만(다음 예고를 가리지 않게).

## 3. 밸런스 [결정]

봇(전부 사용, 합친 상태): 잘함 74~107초 · 서툼 95~131초 · 버팀 붕괴 판당 7~9번(일상이 됨).
- 검성 체력 42000 → **48000**, 버팀 2400 → **3600**, 비명 버팀 피해 400 → 250(진한 1000 → 700).
- 종언 게이지 6600 → **7600**.
- 반격 자세 예고 고리를 크게(누르고 있기 베기가 반격을 부르는 걸 읽히게).
- 합친 뒤 봇으로 다시 재고 체력만 조정. 목표: 잘함 2~2.5분, 서툼 4분 안·쓰러짐 0~1.
