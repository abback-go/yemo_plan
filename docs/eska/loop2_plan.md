# 루프 2 개선 기획 (1차 평가 → 수정 계획)

> 근거: 평가 3건(조작감·밸런스 / 아트·화면 / 설계·성능·시험), 2026-10-11. 기준서 `design.md`의 [확정]은 그대로 두고, [결정]만 바꾼다.
> 사용자 허락: "마법이 별로라면 과감히 바꿔도 됨" → 이름·자리(입력)는 두고 **역할**을 고친다.

## 1. 평가 요약

| 영역 | 좋음 | 가장 큰 문제 |
|---|---|---|
| 설계 | 대마법·물약이 전투를 23~36% 줄임(의미 있음). 비명·속박으로 반격 자세 깨기는 진짜 판단 | **마법과 물약이 서로 닿지 않음 — 이 게임만의 대표 재미가 없음.** 단공·낙성이 손해, 유성우가 보스에 약함, 마시는 물약은 "시작할 때 누르는 버프", 진한 물약이 손해 |
| 조작감 | 이동이 즉각적, 묶이지 않음, 낮춘 점프가 이 보스에 맞음, 예고가 공정 | 공격 누르고 있기 = 1타(폰에서 피곤), 천열 히트스톱 떨림, 입력 기억 부족, 터치에서 오른쪽 벽 근처 캐릭터가 엄지 밑 |
| 아트 | 찢김 참격, 종말의 운석, 보스장·검성 모습, 물약 던지기, 가마솥 화면 | 큰 기술이 표적·숫자를 가림, 어둠 폭발 원판이 조잡, 마녀 신호(문장·깃털·병)가 너무 작음, 검성 등장 위엄 부족 |
| 성능 | 웹 콘솔 오류 0, 보통 장면 그리기 90~110 | 유성우 노드 약 20개, 화면 셰이더 2개 겹침 |
| 시험 | 24개 SCRIPT ERROR 0 | 낡은 시나리오 3개(튜토리얼·마시기·가마솥) |

## 2. 대표 메커니즘 [결정]: 「틈 달이기」 — 찢긴 밤하늘이 마녀의 가마솥

- 고급 마법·대마법이 찢은 틈은 닫히기 전 **약 1초 열려 있다**(지금도 꿰매지듯 닫힘 — 그 시간을 판정으로 씀).
- **던진 병이 열린 틈에 닿으면** 깨지지 않고 틈 속으로 스며들어, 효과가 **틈의 모양을 따라** 퍼진다(틈 전체 길이 ±24px 안의 적).
  - 속박 → 틈을 따라 호박색 거미줄이 한 줄로 쳐짐 · 비명 → 틈이 울려 참격 자리마다 기절 · 부식 → 틈 전체에서 독안개
  - 흑성은 닿은 물약을 빨아들여 그 색의 검은 별이 됨(끌려온 적 모두에게 효과)
  - 실패작도 쓰임: 흐린 물 → 틈이 1초 더 열려 있음 · 쓴 물 → 틈의 적이 빨라지지만 받는 피해 +15%
- 근거: Witcher 오일처럼 "준비가 공격을 바꾼다", Nine Sols의 "쌓기 → 터뜨리기". 고유 요소 복사 없음. **물약 3종 × 틈 하나**라 조합표가 늘지 않는다.
- 연출: 병이 틈에 빨려 들며 물약 색이 틈의 가장자리를 타고 번짐 → 마녀가 공간에 약을 부어 넣는 그림.

| 마법 | 지금 문제 | 고침 |

## 4. 물약 다듬기 [결정]

- 마시는 물약을 **짧고 날카롭게**: 메아리 = "다음 고급 마법 2번이 메아리" · 가속 = "즉시 고급 마법 쿨다운 모두 초기화 + 4초 이동 +15%" · 포식 = 12초, 1200마다 +1, **한 번에 최대 +2** · 확장·충만·치유 그대로.
- **진한 물약 = 한 번에 강하게, 병은 적게**: 총량이 같거나 약간 이득(×1.2)이 되게 수치 조정 + 던지는 진한 물약은 성질이 바뀜(진한 비명 = 반격 자세를 확실히 깨고 버팀 1000, 진한 속박 = 강자도 덜 버팀(status_resist 무시 절반), 진한 부식 = +45%).
- 수첩: "???" 대신 마녀의 메모 힌트("뿌리 둘을 함께… 비명이 난다").
- 전투 시작 전 몰아 마시기 방지: 마시는 버프는 같은 칸 연속 사용 사이 1.5초.

## 5. 조작감 [결정]

- 공격 **누르고 있기 = 0.32초마다 자동 베기**(한방 베기 [확정]은 그대로).
- 순간이동·고급 마법·물약·대마법 **입력 기억 0.12초**(상태가 끝나는 순간 꺼냄).
- 순간이동 무적 0.15 → 0.2초.
- 터치: 오른쪽 끝에서도 캐릭터가 엄지 위에 오지 않게 카메라 여유(+180px, 배경 연장), 순간 버튼 반지름 26, 스킬 버튼은 쿨다운 중에도 이름 + 호.

## 6. 아트·화면 [결정]

- 피해 숫자: 같은 표적에 0.25초 안에 들어온 피해는 한 숫자로 합쳐 커짐, 표적마다 위치 엇갈림.
- 어둠 폭발 원판 → 작은 "찢김 렌즈"(밤하늘이 보이는 틈)가 꿰매지며 닫힘 + 깃털, 크기 절반.
- 마녀 신호 키우기: 손끝 문장 1.4배·2프레임 유지, 의식 문장은 몸 **뒤**, 깃털 5~7px + 옅은 테, 마시는 병 3×5 + 마실 때 몸 전체 물약 색 틴트, 에스카 1px 테두리 빛(배경·보스와 겹쳐도 보이게).
- 검성: 등장 근접 연출 0.8초, 이름 자막 뼈흰+붉은 선, 칼코등이 번뜩임 9px 십자 별 + 살짝 어두워짐, 입구 장막 = 먹빛 연기 + 부적(붉은 세로선 금지 — 천검 예고와 겹침), 삼연참 판정 높이 48→40(점프로 넘게).
- HUD: 연타 숫자 y≥85, 연출 중 키 안내 숨김, 보스장은 보스장용 안내, HUD 뒤 옅은 어둠, 버프 아이콘 모양 구분, 독안개 디더, 큰 섬광 2프레임·색 입힘.
- 성능: 봉공(화면 흑백) 중에는 흑성 렌즈 끔.

### 공통 약속 (루프 2)
- **틈 등록부 `ERifts`** (e_rifts.gd): `open(pts, width, life) -> int` · `at(pos, radius) -> Dictionary` (열린 틈 하나, 없으면 {}) · `infuse(rift, potion_id, color)` (연출) · `extend(rift, sec)` · 틈 = {"id","pts","w","until"}. 고급 마법·대마법 연출 노드가 찢을 때 등록한다.
- **튕겨낼 수 있는 발사체**: 그룹 `"es_projectile"`, 함수 `deflect(by: Node2D) -> bool` (지워졌으면 true). 단공이 부른다.
- **HUD 장면 안내**: `hud.context_hints: Array[String]` (비어 있으면 기본 키 안내), `hud.cinematic: bool` (true면 안내·시험 버튼 숨김).
