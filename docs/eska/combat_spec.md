### 밸런스 결정 (밤샘 작업)
- **천열 쿨다운 2초 → 5초.** 천열(896)을 2초마다 쓰면 초당 피해가 기본 공격(약 200/초)의 2배를 넘어 기본 공격을 쓸 이유가 없어진다.
  5초면 천열 한 번 + 연격 사이사이가 비슷한 몫이 된다. 사용자가 "쿨다운 유지"를 말한 적이 있어 되돌리기 쉽게 상수 한 줄(`CD`)로만 바꿨다.
- 적 체력은 천열 한 번에 돌진형·원거리는 쓰러지고, 거구는 2~3번 + 연격이 필요하게 맞췄다.

## 4-2. 물약 입력 · 물약이 바꾸는 값

- F = 허리띠 0칸, ↑+F = 1칸, ↓+F = 2칸 → `EPotions.use(eska, 칸)`. 빈 칸·실패면 작은 막힘 소리. 마지막으로 고른 칸 = `EEska.last_potion_slot`.
- 동작은 `EEska.start_item(kind, dur, fire_at, on_fire)` (`St.ITEM`):
  - 마시기 `"drink"`: 이동 40%(`DRINK_MOVE`), 공격·마법 막힘, 병(3×5px 몸통 + 코르크 + 유리 빛 한 점, 물약 색)을 입에 대고 고개를 젖힘, 몸 전체가 물약 색으로 물듦(`EArt.DRINK_TINT` 0.45 — 색은 `belt.slots[last_potion_slot].id`의 `EPotions.color`). **fire_at 전에 맞으면 끊김**(on_fire 안 부름).
  - 던지기 `"throw"`: 짧게(약 0.22초), 공중에서도 됨(낙하 초속 20으로 잠깐 머묾). 팔을 뒤로 젖혔다 위로 휘둘러 던짐 — 병은 손을 떠나면 그림에서 사라짐.
- 쓰러졌다 부활하면 `belt.refill()` (허리띠 가득).
- 물약 개편(루프 2, 수치는 `potions.md`): 메아리 = 다음 고급 마법 2번 · 가속 = 즉시 고급 마법 쿨다운 0 + 4초 이동 +15% · 포식 = 12초, 한 번에 최대 +2 · 진한 물약 = 한 번에 강하게, 병 하나 적게 · 마시는 버프는 같은 칸 1.5초 안 다시 못 씀.
- 물약이 켜는 값 `EEska.mods`: `cd_rate` 고급 마법 쿨다운이 줄어드는 빠르기 · `speed` 이동 배수 · `size` 베기 반지름·굵기·판정과 단공 판정 범위 배수 · `dmg` 주는 피해 배수(`deal`에서 곱함) · `leech` 이만큼 피해마다 체력 +1(최대 6, 0 = 꺼짐) · `echo` > 0이면 고급 마법이 0.35초 뒤 같은 자리에서 한 번 더(그 이펙트에 `power` = echo) · `gauge` 게이지 차는 배수.

## 4-2b. 틈 달이기 (루프 2·3 — 상세 수치·연출은 `potions.md` 5-1)

- 틈 등록부 `ERifts`(`e_rifts.gd`): `open(pts, width, life)` · `at(pos, radius)` · `infuse` · `extend`. 등록하는 곳: 베기·천열·단공의 찢김(1초), 낙성의 떨어지는 길(1초), 순간이동 경로 찢기(굵기 18, 0.8초), 대마법.
- 던진 병이 열린 틈에 닿으면 깨지지 않고 스며들어 틈 전체 길이 ±24 안의 적에게 효과. **스민 물약 = 자동으로 진함 + 강자 저항 무시 + 틈이 꿰매질 때 한 번 더**(속박 → 버팀 300 · 비명 → 기절 0.4초 다시 · 부식 → 시간 갱신).
- 무시하는 틈: 던진 뒤 0.12초 또는 손에서 40px 안 · 적이 걸치지 않은 틈(±24 안에 살아 있는 표적 0 — 흐린 물은 예외). 병이 틈 쪽으로 휘는 범위 24px(예전 40).
- 훈련장: 허수아비 위 안내판 "틈 달이기 — 천열(A)로 찢은 틈이 열려 있을 때 물약을 던져 넣으면(↓F 속박 등) 진하게 스며들어 강자에게도 다 걸린다" (`e_arena.gd` `RiftSign`).

## 4-3. 화면 표시 (HUD, `e_hud.gd`)

- 왼쪽 위: 모서리에서 타원으로 옅어지는 어둠 바탕(진하기 0.42, 220×90) 위에 이름 + 체력 마름모 6개(예전 빌드 줄을 지운 자리만큼 14px 위로 — `EHud.ROW_UP`) → 오른쪽에 **종언 게이지 달**(그믐 → 보름, 오른쪽부터 차오름. 가득이면 분홍빛 맥박, 막 찬 순간 고리가 퍼짐 + 소리) + 고른 대마법 이름.
- 그 아래 **허리띠 3칸**: 병(물약 색 — `EPotions`가 `info`/`look`/`name_of`/`color_of` 정적 함수나 `POTIONS`/`DATA`/`INFO` 상수 사전으로 알려 주면 그 색), 칸 방향 표시(• ↑ ↓), 남은 병 점, 빈 칸·다 쓴 칸은 흐림. 키보드일 땐 F가 지금 고를 칸에 옅은 바탕.
- 아래(키보드일 때): 키 안내 두 줄 — 고급 마법 쿨다운(A 천열 · ↑A 단공 · ↓A 낙성) + "S 대마법 이름 게이지% · D 고르기".
  장면이 `hud.context_hints: Array[String]`을 채우면 기본 안내 대신 그 줄들(보스장 안내 등). `hud.cinematic = true`(연출 중)면 안내를 모두 숨기고 훈련장 시험 버튼도 숨는다 — 튜토리얼 연출(`_cutscene`)이 켬.
- 오른쪽 위 연타 수: 숫자 바닥선 y 104(`COMBO_Y`, 윗끝 약 86 — 시험 버튼 아래). 빌드 번호는 오른쪽 아래 구석에 아주 작게(8px).
- 버프 아이콘은 HUD가 그리지 않는다 (머리 위 아이콘은 물약 쪽 `EPotionFx`).
- 값이 바뀔 때만 다시 그림 (가득일 때 맥박만 초당 15번).

### 적 물결 (`e_waves.gd`, 훈련장)

### 공간 고정 시험 구역 (훈련장 오른쪽 끝)
높은 턱(바닥에서 200px — 이단점프 81px로는 안 닿음) + 돌이 떨어지는 두 기둥(x 1040·1096, 0.5초 간격, 초속 170, 기둥끼리 반 간격 어긋남).
돌은 평소엔 에스카를 지나치고, 봉공으로 굳으면 위에서만 밟히는 발판이 된다 → 엇갈린 계단을 밟고 턱에 오르면 "공간 고정" 알림. 순서: 돌진 → 돌진 2 → 원거리 → 돌진+원거리 → 거구 → 돌진 2+원거리 → 거구+원거리 → 돌진 2+원거리 2 → 거구+돌진 2.
다 돌면 처음부터, 한 바퀴마다 적 체력 +25%. 허수아비는 그대로 있다(겨누기 대상에 포함).
