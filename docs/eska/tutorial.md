## 1. 조사 요약 → 설계 원칙

| 근거 (조사) | 이 튜토리얼에서 |
|---|---|
| 글로 설명하기보다 해보게 만든다 — 텍스트 대시 안내를 "장벽을 대시로 뚫어야 지나가는 구간"으로 바꿨더니 나아졌다는 사례 ([Wayline](https://www.wayline.io/blog/tutorials-ux-player-onboarding)) | 기술마다 **그 기술로만 지나갈 수 있는 지형·적**: 높은 턱(이단점프) · 장막(순간이동) · 공허 틈(조합) · 칼이 닿지 않는 높이의 망령(낙성) · 묶어야 통과(속박) |
| 안내는 필요한 순간에만, 실패하면 그때 힌트 ([Wayline](https://www.wayline.io/blog/in-game-tutorials-design-guide)) | 안내 칸은 구간에 들어설 때 한 번 뜨고 해내면 체크 표시로 사라진다. 3초 넘게 머물면 다시 흔들림. 단공을 너무 일찍 쓰면 "너무 일렀다", 맞으면 "조금만 더 빨리" |
| 기술을 안전한 곳에서 먼저 익히고, 적 하나하나가 작은 튜토리얼 ([Wayline](https://www.wayline.io/blog/build-effective-game-tutorials)) | 허수아비 → 원거리 적(느린 구슬로 딱 맞춤) → 높이 뜬 적(낙성) → 쉼터(달이기) → 돌진 적(속박) → 거구(틈 달이기·대마법) |
| Celeste는 레벨 디자인으로 가르치지만 '보이지 않는 능력'은 따로 알려 준다 ([Game Developer](https://gamedeveloper.com/design/video-the-level-design-of-i-celeste-i-), [itch.io 토론](https://itch.io/post/9047440)) | 보이지 않는 입력·판정(이단점프 · ↑/↓+스킬 · 딱 맞춤 거리 · 틈이 열린 순간)만 글·고리·느려짐으로 알려 주고, 나머지는 지형이 말하게 |
| 갇힌 느낌을 주지 않게 언제든 나갈 수 있게 | Esc/✕로 언제든 나감, 쓰러지면 바로 앞 확인점에서 (체력·물약 가득) |

## 2. 흐름 (가로 4960px, 바닥 y=300)

안내 칸의 키 이름은 입력 방식에 맞춰 바뀐다(`EKeys.label` — 키보드 `A`/`F`/`S`/`D`, 터치 "스킬"/"물약"/"대마법"/"고르기"). 터치일 때는 실제 화면 버튼 둘레에도 맥박 고리(`ETouch.spot`).

| 구간 | x | 배우는 것 | 지나가는 조건 | 안내 | 사람 기준 시간 |
|---|---|---|---|---|---|
| 0 깨어남 | 0~560 | 이동 | 오른쪽으로 걸어감 | 검은 화면 → "종언의 마녀가 눈을 뜬다." → `←→` 이동 | 0:10 |
| 1 턱 | 560~1160 | 점프 · 이단점프 | 낮은 턱(34) → 높은 턱(66) | `Z` 점프 → "공중에서 한 번 더 `Z`" | 0:20 |
| 2 장막 · 틈 | 1160~1900 | 순간이동 · 조합 | 보라 장막 → 폭 250 공허 틈 | `C` → "점프 → 이단점프 → 순간이동" | 0:30 |
| 3 허수아비 | 1900~2560 | 베기 · 천열 | 베기 3번 / 천열로 둘 이상 | `X` ×3 → `A` 천열. 봉인 문 열림 | 0:30 |
| 4 등불 망령 | 2560~3180 | **단공 "가르는 틈" 딱 맞춤** | 구슬을 몸 가까이(70px 안)에서 ↑+스킬로 1번 지움 → 망령 처치 | "구슬이 몸에 닿기 직전 `↑`+`A` 가르는 틈 — 딱 맞춤". 구슬이 0.5배로 느림(75px/초), 몸 둘레에 **딱 맞춤 고리**(구슬이 들어오면 밝아짐). 이르면 "너무 일렀다", 맞으면 "조금만 더 빨리". 딱 맞추면 "단공이 곧바로 다시 차오른다" | 0:45~1:30 |
| 5 높이 뜬 망령 | 같은 방 | **낙성** | 머리 위 158px에 떠 옆으로 150px 거리를 두는 망령 처치 (베기·단공이 닿지 않음) | "저 높이엔 칼이 닿지 않는다" → `↓`+`A` 낙성. 빗나가면 1.2초 뒤 다시 쓸 수 있게 | 0:20 |
| 6 가마솥 쉼터 | 3180~3640 | **물약 달이기** (속박 = 거미줄+거미줄) | ↓칸에 속박이 담긴 채 달이기 화면을 닫음 → 문 열림 | "들르기만 해도 물약이 다시 가득 찬다" → 솥 앞에서 수첩 메모 「실에 실을 꼬면 무엇이든 붙든다.」 + `↑` 열기. 달이기 화면 아래 띠가 한 줄씩(거미줄 두 번 → 달이기 → 넘기기 → 닫기), 담을 칸은 ↓칸·초점은 거미줄로 맞춰 둠. 처음 달이면 "새 물약!" | 0:45~1:00 |
| 7 사냥개 | 3640~4260 | 피하기 · **속박 던지기** | 사냥개가 던진 속박에 묶임 → 처치 | 첫 웅크림에 느려짐 + "뛰거나, 사라져라" → `↓`+`F` "속박을 던져 묶는다 — 앞으로 약 다섯 걸음". 병이 다 떨어지면 다시 채움, 묶기 전에 쓰러뜨리면 멀리서 하나 더 | 0:40 |

## 3. 연출·룩앤필

- **화면 열기**: 검은 화면에서 1.2초 걸쳐 밝아짐 + 위아래 영화 띠(0.6초)가 걷힘. 장 이름 "종언의 문턱"이 커지며 나타남.
- **혼잣말(자막)**: 화면 위 가운데 한 줄, 한 글자씩(초당 28자), 2.6초 머묾. 글 속 `{es_down}` 같은 자리표는 그릴 때 입력 방식 이름으로 바뀜(`ETutHud.fmt`). 세로 화면에서 보스 체력바가 떠 있으면 그 아래로.
- **안내 칸**: 키보드는 화면 아래 가운데, 터치는 위쪽(24%). 키 모양 그림(둥근 사각 + `EKeys.label` 글자) + 짧은 설명. 해내면 키가 번쩍이고 체크가 그려지며 0.5초 뒤 접힘 + 맑은 소리. 게이지 %·대마법 이름처럼 살아 있는 글은 `set_text`로 바뀜.
- **딱 맞춤 고리**(`ETutProps.PerfectRing`): 에스카 몸 가운데 둘레 반지름 70(= `ESkillFx.Upsweep.PERFECT_R`)의 도는 점선. 구슬이 안에 들어오면 마젠타→밝은 테로 굵어짐. 딱 맞추면 줄어들며 사라짐.
- **달이기 화면 아래 띠**(`ETutHud.BrewTip`, 층 46 — 달이기 화면 45 위, 멈춤 중에도 돔): 지금 할 일 한 줄. 화면이 열릴 때 담을 칸 ↓칸 · 초점 거미줄로 맞춤.
- **집중**(`ETutHud.focus_to`): 틈 달이기 순간, 화면 가장자리 56px가 먹빛으로 어두워지고 안쪽에 맥박 치는 마젠타 테. (Fx의 붉은 비네트는 "맞았다"로 읽혀서 쓰지 않음)
- **봉인 문 · 장막 · 공허 틈 · 확인점**: 그대로(보라 결계·일렁이는 막·소용돌이·등불).
- **음악**: 탐험 구간 `temple_dark` → 마지막 `boss` → 끝 화면 `jingle_chapter`.

## 4. 수치

| 항목 | 값 | 이유 |
|---|---|---|
| 높은 턱 | 66px | 점프 46 < 66 < 이단점프 합 81 |
| 공허 틈 폭 | 250px | 점프+이단점프 수평 약 220 < 250 < +순간이동 150 |
| 망령 구슬 빠르기 | × 0.5 (`ORB_SLOW`) | 딱 맞춤 거리 70 → 몸까지 약 0.8초. 보통(150)이면 0.4초라 처음엔 어렵다 |
| 첫 망령 체력 | × 0.7 | 딱 맞춤을 익힌 뒤 금방 쓰러지게 |
| 높이 뜬 망령 | 몸 가운데 위 158 · 옆 150 | 단공(머리 위 ±76)·베기가 닿지 않고 낙성(앞 30~240) 안 |
| 종언 게이지 | 거상이 나타날 때부터 쌓임 (`eska.mods.gauge` 0 → 1) | 앞 구간에서 몰래 차 있으면 "싸워서 채운다"를 못 보여 줌. 단공 딱 맞춤 보너스(+4%)는 그대로 |
| 거상 체력 | 2400 × 4 = 9600 | 게이지 7600이 실제 피해로 차는 데 봇 약 20초, 사람 약 25~35초 → 남은 체력은 대마법 몫 |
| 거상 버팀 | 대마법을 쓰기 전엔 10% 밑으로 안 내려감 | "끝은 대마법으로" — 쓰면 풀림 (봉공을 골랐으면 그 뒤 베어 끝냄) |
| 틈 달이기 느려짐 | 0.5배 · 실제 2.4초 · 놓치면 2.8초 뒤 다시 | 천열 틈이 열린 약 1초(게임 시간)를 덮음 |
| 수첩 속박 조합 | 튜토리얼 동안만 지움(나갈 때 되돌림) | 처음 달일 때 "새 물약!"을 보게 |
| 처음 허리띠 | 치유 · 메아리 · (↓칸 비움) | ↓칸을 쉼터에서 직접 채운다 |
| 힌트 다시 띄우기 | 같은 자리에서 3초 | 헤매기 시작하는 시점 |

## 5. 성공 기준 (자동 시험)

- `eska_tutorial.json` — 순간이동 eval로 구간을 건너뛰며 각 단계 `step_name()`·스크린샷(새 단계는 키보드·터치 둘 다, `test_touch(true)`). 단공은 `test_orb(Vector2(110, -50))`로 구슬을 띄우고 ↑+A(딱 맞춤 → `dangong sub=2`, 쿨다운 0), 낙성 실제 입력, 가마솥 ↑ → Z·Z·Z → Z → Esc(↓칸 `bind`), 사냥개 ↓+F(`last_splash` bind·hits 1), 거상 천열 → ↓+F(`stitches` 1), 게이지는 `eska.deal`(실제 피해 경로) → D·D → S(종말의 운석) → 끝에 `end sub=1`. `FRAME_CLOCK=1`.
- `eska_tutorial_bot.json` — 봇(`tools/test/eska_tut_bot.gd`)이 **실제 입력만으로** 처음부터 끝까지(약 4500프레임). 6000프레임에 `end sub=1`이면 통과.
- 오류 없음 · 성능(그리기 호출 수)이 훈련장과 비슷.
