| 갇힌 느낌을 주지 않게 언제든 나갈 수 있게 | Esc/✕로 언제든 나감, 쓰러지면 바로 앞 확인점에서 (체력 가득) |

## 3. 연출·룩앤필

- **화면 열기**: 검은 화면에서 1.2초 걸쳐 밝아짐 + 위아래 영화 띠(0.6초)가 걷힘. 장 이름 "종언의 문턱"이 커지며 나타남.
- **혼잣말(자막)**: 화면 위 가운데 한 줄, 한 글자씩(초당 28자), 2.6초 머묾. 말수는 구간마다 한 줄 이하.
- **안내 칸**: 화면 아래 가운데. 키 모양 그림(둥근 사각 + 글자) + 짧은 설명. 해내면 키가 번쩍이고 체크가 그려지며 0.5초 뒤 접힘 + 맑은 소리.
  터치일 때는 키 그림 대신 실제 화면 버튼 둘레에 맥박 치는 고리.
- **봉인 문**: 보라 문양이 흐르는 세로 장벽. 열릴 때 문양이 위에서 아래로 깨지며 어둠 폭발 + 화면 흔들림.
- **장막**: 반투명 보라 막이 일렁임. 걸어서 닿으면 물결치며 밀어냄(피해 없음).
- **공허 틈**: 바닥이 끊기고 아래로 검보라 소용돌이. 가장자리에 마젠타 빛.
- **확인점**: 꺼진 보라 등불 → 지나가면 확 켜짐(소리 `checkpoint`).
- **음악**: 탐험 구간 `temple_dark` → 마지막 `boss` → 끝 화면 `jingle_chapter`.
