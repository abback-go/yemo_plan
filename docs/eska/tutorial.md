## 1. 조사 요약 → 설계 원칙

## 2. 흐름 (가로 4060px, 바닥 y=300)

## 3. 연출·룩앤필

- **화면 열기**: 검은 화면에서 1.2초 걸쳐 밝아짐 + 위아래 영화 띠(0.6초)가 걷힘. 장 이름 "종언의 문턱"이 커지며 나타남.
- **혼잣말(자막)**: 화면 위 가운데 한 줄, 한 글자씩(초당 28자), 2.6초 머묾. 글 속 `{es_down}` 같은 자리표는 그릴 때 입력 방식 이름으로 바뀜(`ETutHud.fmt`). 세로 화면에서 보스 체력바가 떠 있으면 그 아래로.
- **안내 칸**: 키 칸 글과 설명이 같으면(터치 "[점프] 점프") 설명은 빼고 키 칸 하나만. 키보드는 화면 아래 가운데, 터치는 위쪽(24%). 키 모양 그림(둥근 사각 + `EKeys.label` 글자) + 짧은 설명. 해내면 키가 번쩍이고 체크가 그려지며 0.5초 뒤 접힘 + 맑은 소리. 게이지 %·대마법 이름처럼 살아 있는 글은 `set_text`로 바뀜.
- **딱 맞춤 고리**(`ETutProps.PerfectRing`): 에스카 몸 가운데 둘레 반지름 70(= `ESkillFx.Upsweep.PERFECT_R`)의 도는 점선. 구슬이 안에 들어오면 마젠타→밝은 테로 굵어짐. 딱 맞추면 줄어들며 사라짐.
- **달이기 화면 아래 띠**(`ETutHud.BrewTip`, 층 46 — 달이기 화면 45 위, 멈춤 중에도 돔): 지금 할 일 한 줄. 화면이 열릴 때 담을 칸 ↓칸 · 초점 거미줄로 맞춤.
- **연출 중 숨김**(`_cutscene`): 깨어남·거상 등장·마무리 동안 HUD(`hud.visible = false`, `hud.cinematic`)와 지난 안내·자막(`tut.clear()`)을 숨김 — 영화 띠가 HUD 글자를 자르고 지난 단계 안내가 남던 문제. 거상 이름은 `tut.chapter("검은 거상", …)`. 등장 카메라는 에스카~거상 사이 60% 자리를 가운데로(둘 다 한 화면, 터치 치우침 CamBias는 연출 중 약해짐).
- **집중**(`ETutHud.focus_to`): 틈 달이기 순간, 화면 가장자리 56px가 먹빛으로 어두워지고 안쪽에 맥박 치는 마젠타 테. (Fx의 붉은 비네트는 "맞았다"로 읽혀서 쓰지 않음)
- **봉인 문 · 공허 틈 · 확인점**: 그대로(보라 결계·소용돌이·등불). 턱(`Ledge`)·장막(`Veil`)은 루프5 압축으로 쓰지 않음(코드는 남김).
- **음악**: 탐험 구간 `temple_dark` → 마지막 `boss` → 끝 화면 `jingle_chapter`.

## 연습 과제 기록 (훈련장 연동)

해낸 순간 `EStage.practice_done[id] = true` (코어 정적 저장소, 없는 트리에서도 컴파일되게 `(EStage as Script).get("practice_done")`). id는 훈련장 `PracticeList.T_*` 번호: 높이 뜬 망령 처치 = 0(낙성 공중 표적) · 딱 맞춤 = 1 · 속박 달여 담기 = 2 · 틈 달이기 성공 = 3 · 대마법 = 4.

## 5. 성공 기준 (자동 시험, `FRAME_CLOCK=1`)

- `eska_tutorial.json` — 순간이동 eval로 구간을 건너뛰며 각 단계 `step_name()`·스크린샷(새 단계는 키보드·터치 둘 다, `test_touch(true)`). 틈은 실제 입력(점프·점프·순간이동), 단공은 `test_orb(Vector2(110, -50))` 두 번(0.5배 → 0.75배)에 ↑+A, 낙성 실제 입력, 가마솥 옆(솥 가운데 −12) ↑ → Z·Z·Z → Z → Esc(F칸 `bind`), 사냥개 F, 거상 천열 → F 두 번(`last_splash.fresh` true 둘), `eska.deal`(실제 피해 경로) 한 번 → D·D → S(종말의 운석) → 3320프레임에 `end sub=1`.
- `eska_tutorial_bot.json` — 봇(`tools/test/eska_tut_bot.gd`)이 **실제 입력만으로** 처음부터 끝까지(약 3200프레임). 4200프레임에 `end sub=1`이면 통과.
- 오류 없음 · 성능(그리기 호출 수)이 훈련장과 비슷.
