## 1. 왜 바꾸는가 — 지금까지의 진단

| 겪은 문제 | 원인 | 결론 |
|---|---|---|
| 근접 액션 손맛이 안 나온다 | 손맛을 INARI식 **속도**에서 찾았는데, 강자 마녀가 뛰어다니면 위엄이 깨진다 | 손맛의 출처를 **속도 → 맞부딪힘·끝냄**으로 옮긴다 |
| 베기가 검사 같다 | "손짓 참격"은 결국 칼질 | **베기 폐지.** 모든 공격은 가리키면 그 자리가 찢어지는 마법 |
| 먼치킨 마녀가 능력을 얻으러 탐험하는 게 어색하다 | 메트로배니아 성장 서사 ↔ 최강자 설정 충돌 | **메트로배니아 폐기 → 결투 로그라이트.** 강한 이유가 곧 끝내 주는 이유 |
| 보스가 선역이라 긴장이 없다 | 적대 동기 부재 | 보스 = **절망에 먹혀 끝나지 못하는 강자** (엘든링 미드라의 "무너진 강자" 원형만 차용) |
| 컨셉이 복잡해진다 | 요소를 더해 풀려 함 | 한 줄로 설명되는 구조만 남김: **"접고, 달이고, 끝낸다"** |

## 2. 컨셉

- **코어 판타지**: "나는 피하지 않는다. 네 칼을 접어 돌려주고, 네 절망을 끝내 준다." — 통제감과 연민이 섞인 압도.
- **경험 기둥** (모든 요소는 이 넷 중 하나를 받친다)

| 기둥 | 한 문장 | 받치는 시스템 |
|---|---|---|
| **접는다** | 공격이 닿는 순간 공간을 접어 되돌린다 — 매 결투의 박자 | 접기(§5-1), 닫힌 공격, 연접기 |
| **달인다** | 틈을 찢고 물약을 부어 내 식대로 싸움을 바꾼다 — 계획의 재미 | 틈 달이기, 가마솥, 매듭(§6) |
| **끝낸다** | 무너진 강자에게 종언을 내리고 세계가 한 조각 무너진다 — 보상 | 버팀·처형(§5-3), 대마법, 처형 연출 |
| **되감긴다** | 쓰러지면 세계가 되감기고, 꿰맨 자국과 기억만 남는다 — "한 판 더" | 메타 루프(§4), 보스 대사 변화 |

- **톤**: 고요하고 장엄. 보스는 돌아가라고 경고하고, 마녀는 말없이 끝을 내린다. 유머 없음. 잔혹 묘사는 상징(먹물·꿰맴)으로만.
- **지키는 확정 사항**: 원소 없음 · 무기 없음 · 보라 한 계열(파랑 금지) · 시계 모티프 금지 · 특정 작품 고유 요소 복제 금지 · 터치 조작 1급 시민.

## 3. 세계와 이야기

- **세계**: 끝이 오지 않은 지 오래. 이음새가 헐거워져 공간에 **틈**이 벌어진다 — 마녀가 공간을 찢을 수 있는 이유이자, 세계가 죽어 가는 증거.
- **붙드는 자**: 세계를 붙든 마지막 기둥 다섯. 각자의 절망이 곧 전투 패턴이다. 끝날 때마다 세계가 한 조각 무너진다(아레나 배경이 실제로 떨어져 나감).
- **되감김**: 붙드는 자들은 끝을 거부하므로 마녀가 쓰러지면 세계를 되감는다. 되감겨도 마녀가 틈을 꿰맨 자국(**꿰맨 자리** = 거점)과 기억은 남는다 → 회차가 쌓일수록 보스의 대사가 바뀐다(텍스트만, 제작비 낮음).
- **에스카의 동기** `[미결정]`: 후보 (a) 그녀 자신이 처음으로 세계를 붙들었던 자 (b) 세계가 스스로 부른 끝. 마지막 보스 전에만 드러낸다.
- **엔딩** `[미결정]`: 기본 「세계가 닫힌다」 하나. 두 번째 엔딩(붙드는 자 전원을 처형이 아닌 체력으로 끝냈을 때 등) 추가 여부.

## 4. 코어 루프

```
[마이크로 — 결투 안, 10~20초]
예고를 읽는다 → 접는다(되돌림·버팀 깎임) / 닫힌 공격은 틈 걸음 → 바늘·천열로 틈을 찢는다
→ 갓 찢긴 틈에 물약을 붓는다 → 버팀 0 → 무너짐 → 처형 → 세계 한 조각 무너짐 → [다음 단계]

[매크로 — 한 판, 약 25분]
꿰맨 자리(시작 물약·매듭) → 길(재료·잡몹·제단) → 가마솥 → 결투 1 → 매듭 3택1 → 길 → … → 결투 5(꿰매는 자) → 세계의 끝
                                                     ↘ 쓰러짐 → 세계 되감김 → 꿰맨 자리(실로 해금·기억) ↗

[메타 — 판 사이, 주 단위]
실(처형·승리로 얻음) → 매듭 해금·시작 슬롯·시작 물약 → 회차마다 바뀌는 보스 대사 → 엔딩
```

- **"한 판 더"가 생기는 곳**: ① 처형 직전에 쓰러졌을 때(무너짐은 봤는데 못 끝냄) ② 새로 해금한 매듭을 써 보고 싶을 때 ③ 되감긴 뒤 보스가 **나를 기억하는 대사**를 했을 때 ④ 다음 순서 조합이 궁금할 때.
- **판 길이 산출**: 결투 2.2·2.2·3.2·3.2·5.5분 = 16.3 + 길 4×1.5 = 6 + 가마솥·매듭 선택 3 ≈ **25분** (목표 22~30). 쓰러짐 평균 2번째 결투 기준 **한 번의 손실 ≤ 10분**.

### 5-1. 접기 (Fold) — 이 게임의 첫 번째 동사

- **입력**: X. 방향 무관(몸으로 막는 게 아니라 공간을 접으므로 전방향).
- **시스템**: 누르면 0.35초 동안 "접힘" 상태. 그 안에 닿는 공격(근접·투사체·참격선)은 **0~0.2초 = 완벽**, **0.2~0.35초 = 늦음**. 완벽: 피해 0 · 공격자 버팀 −600 · 되돌림 피해 = 400 × 공격 무게(1 또는 2) · 게이지 +3%. 늦음: 피해 0 · 보상 없음 · 0.2초 밀림. 실패: 피해 그대로. 접기 뒤 쿨다운 0.4초(연타 방지 — Sekiro식 창 축소 벌칙은 쓰지 않음). 투사체는 되돌아가 쏜 자에게 원 피해(기존 `deflect` API). **연접기**: 완벽 3연속 → 추가 버팀 −400 + 화면 균열. **닫힌 공격**(붉은 예고): 접을 수 없음 → 틈 걸음·점프로만. 보스 패턴의 20~35%.
- **피드백**: 멈춤 8프레임 · 카메라가 공격 반대쪽으로 6px 튐 · 공격 궤적이 **종이처럼 접혀 뒤집히는** 그림 · 유리 깨짐 + 낮은 종 · 화면 테두리 보라 0.1초 · 터치는 접기 버튼 고리가 번쩍.
- **파라미터**: 완벽 창 12f · 늦음 9f · 터치 기본 +3f · 「느슨한 이음새」 옵션 ×1.5 — 모두 `[플레이테스트 필요]`.
- **근거**: Sekiro의 받아치기 창은 애니메이션 데이터 기준 약 0.2초(12f)로 읽힌다. Nine Sols는 완벽하지 않은 받아치기에도 관용을 줘 "맞물릴 때의 쾌감"이 평가의 핵심이었고, 33원정대는 창이 빡빡하다는 불만으로 창을 넓히는 모드가 나왔다 → 우리는 **늦음 구간 + 옵션**으로 관용을 설계에 넣는다. Furi가 지적받은 "받아치기와 공격이 이어지지 않음"은 접기 중 바늘·틈 걸음으로 **언제든 끊기**로 막는다.

### 5-3. 버팀 · 무너짐 · 처형 — 두 번째·세 번째 동사

- **시스템**: 보스는 **절망 단계 2~3개**(체력 칸 2~3). 각 단계에 버팀 게이지(검성 5400 현행). 피해·접기로 버팀 0 → **무너짐 2.5초**(받는 피해 ×1.25) + X = **처형**: 1.0초 연출 후 **현재 단계 즉시 종료** + 게이지 +25%. 무너짐을 놓치면 버팀 50%로 회복. 단계 체력을 0으로 깎아도 단계는 끝나지만 처형 보상은 없다 → **접기 빌드(버팀)와 주문 빌드(체력)가 모두 끝에 닿는다**. 잡몹은 처형 없음(즉사 연출만).
- **피드백**: 멈춤 20f → 0.3배 느림 0.6초 → 공간이 접혀 닫히며 보스 자리가 흰 땀으로 **꿰매짐** → 화면이 갈라지고 **아레나 배경 한 조각이 떨어져 나감**(단계마다 누적) → 이름 자막 한 줄.
- **근거**: Sekiro의 "체력과 별개의 체간 → 처형"이 결투를 절정으로 끌고 가는 구조라는 평가. 우리는 처형을 **이야기의 "끝을 내린다"와 같은 조작**으로 만들어 손맛과 컨셉을 한 점에 모은다.

### 5-4. 틈 달이기 (현행 유지)
찢은 틈에 던진 물약이 틈을 따라 스민다. 갓 찢긴 틈(0.5초)이면 저절로 진하고 강자 저항을 무시하며 꿰매질 때 한 번 더. 수치는 `potions.md`. 로그라이트에서는 **길 끝 가마솥**에서만 달이고(판당 4~5번), 재료는 길에서 줍는다.

## 6. 빌드 — 틈 모양 × 물약 × 매듭

- **매듭**: 결투를 끝낼 때마다 3택1(서로 다른 계열 2개 이상 보장, 같은 계열 2개 보유 시 상위 매듭 등장). 판이 끝나면 사라진다. 4계열 × 7 = 28, **출시 20**.

## 9. UX · FTUE · 접근성

- **FTUE**: 0~1분 타이틀 → 바로 첫 길(튜토리얼 = 길 1: 표지판 셋으로 바늘·접기·틈 걸음) · 1~5분 첫 결투 = **검성 1단계 "접기 교본"**(현행 첫 만남 배움 느려짐·쓰러짐 원인 줄 재사용) · 5~15분 가마솥·틈 달이기·첫 매듭 · 15~30분 두 번째 결투, 첫 쓰러짐 → 되감김 → 꿰맨 자리에서 실 사용.

- **접근성**: 접기 창 ×1.5 「느슨한 이음새」 · 닫힌 공격 예고 길게 · 화면 흔들림 끄기 · 글자 크기 2단계 · 키 리매핑.

크리티컬 패스: **M0의 손맛 판정**. 여기서 떨어지면 나머지는 의미가 없으므로 M0에 시간을 아끼지 않는다.

### 자체 평가 (루브릭 10축, 컨셉 기획서 기준 — 근거 없이 올리지 않음)

**평균 4.0 — 양호(실무 통용 가능)**. 약점은 수치가 아직 가설이라는 것이고, 그래서 로드맵이 M0 손맛 판정을 모든 것 앞에 둔다.

### 재미없을 수 있는 조건 (솔직하게)
1. 접기가 모든 보스에서 유일한 정답이 되면 리듬 게임이 된다 → 보스마다 축을 다르게 하고, 체력 루트(주문 빌드)가 **처형 루트와 같은 속도**로 끝에 닿는지 M2에서 측정.
2. 매듭이 "+10%"뿐이면 빌드가 아니라 숫자다 → 출시 20개 중 최소 8개는 **규칙을 바꾸는 매듭**(겹틈·되스밈·접힌 틈)으로.
3. 5명을 20판 보면 질린다 → 보스 수 자체가 한계. 후속 2명 없이 출시하면 평균 플레이 10시간을 넘기기 어렵다.

### 사용자 결정이 필요한 항목
1. **장르 전환 확정**: 메트로배니아(`design.md` 1장 [확정]) → 결투 로그라이트.
2. **기본 베기 폐지 → 바늘**, 단공 → 접기, 이단점프·대시 폐지 ([확정] 변경).
3. **모바일**: 출시 플랫폼인가, 웹 데모 전용인가(접기 박자 때문에).
4. **붙드는 자 5명 가칭 명단**(검성·거상·가수·의원·꿰매는 자) 승인 또는 교체.
5. **에스카의 동기·엔딩 수**.
6. M0 착수 승인(검성 1단계 접기 시험판).
