# 루프 6 개선 기획 (5차 평가 → 수정 계획)

> 근거: 5차 평가 4건(HEAD 6850a3d). 마녀다움 8.5/10, 틈 박자는 진짜 실력 박자(천열 0.3초·낙성 0.33초 창), 튜토리얼 두 번째 틈 달이기가 "마녀의 박자"로 절정, 시나리오 38개 오류 0, 과부하 도형 10914.
> 이번 루프의 중심: **그림자 일섬을 "무시하면 손해, 풀면 크게 이득"**인 마녀다운 선택 순간으로 + 튜토리얼 → 검성 다리 + 결정적 순간 가독성.

## 1. 그림자 일섬 재설계 [결정]

평가가 엇갈림: 손맛 평가는 "분신 900 > 천열 896이라 줄째 베기가 무너짐 → 880"(advisor가 860으로 바로 반영), 설계 평가는 "천열 하나로 끝나면 고르기가 아님 + 분신 무시하고 서 있는 검성을 때리는 게 더 이득". **설계 평가를 따른다**(이 기술의 목적이 '모양 고르기'이므로).
- 분신 체력 **1200** — 천열 하나(896)로는 약 300 남음 → 두 번째 도구가 필요: 메아리 + 천열(1344) / 갓 찢긴 틈에 속박(자세 시간 멈춤) 뒤 베기 / 부식 먼저 → 천열(×1.3 = 1165, 갓 찢긴 ×1.45 = 1299) / 흑성으로 모아 갈기 / 유성우 — 서로 다른 정답.
- **대기 중 검성은 먹물 속(무적)** — 공짜 표적에서 뺌.
- **무시하면 손해**: 살아 돌아간 분신마다 검성 버팀 +800 회복(먹이 돌아온다).
- **풀면 크게 이득**: 셋 다 베면 **즉시 버팀 붕괴**(무릎 2초 = 대마법 기회) + 게이지 +15%.
- 일섬선은 그대로(단공으로 가를 수 있음, 한 번에 가운데 판정 안의 선만).
- 가독성: 분신에 붉은 1px 테두리 빛, 발밑 먹물 웅덩이, 예고 십자 9px, 터지기 0.3초 전 칼끝 번뜩임, 먹물 꽃잎 키움.

## 2. 튜토리얼 → 검성 다리 [결정]

- 튜토리얼 끝 화면에 **[검성에게]** 버튼 + 한 줄 다리("가르는 틈과 틈 달이기로 — 검성의 칼을 갈라라").
- 튜토리얼에서 해낸 연습 과제는 훈련장에서 체크된 채 시작(남은 과제만).
- **검성 첫 만남 배움 느려짐**: 처음 도전에서만, 반격 자세·비검·그림자 일섬이 처음 나올 때 0.5배 느려짐 + 한 줄 안내(튜토리얼 focus 연출 재사용). 다시 하기부터는 없음.

## 3. 결정적 순간 가독성·터치 [결정]

- 카메라 치우침 강제: 튜토리얼 틈 달이기 느려짐 동안, 보스 발도 예고 동안(적이 화면 가로 55% 안).
- 물약·순간 버튼이 적을 가릴 때는 바깥 고리만 남기는 외곽선 모드.
- 발도 "벤 뒤 터짐" 피해 표시: 베인 순간의 표시(CutMark)를 크게 + 색 반전 → 피했다고 느낀 뒤 깎이는 착시 줄임.
- 기본 허리띠: **속박을 방향 없는 F칸**(폰에서 스킬 → 물약 0.3초 박자가 되게), 메아리 ↑, 치유 ↓.

## 4. 그림 [결정]

- 갓 찢긴 신호: 틈 가장자리를 따라 흰 바느질 땀 8~10개가 0.2초 동안 차례로 박힘(길이 5px 이상, 흡수 고리 바깥) — "마녀가 틈을 꿰맨다"(design 3-4 #4).
- 틈 부식: 틈 안 = 초록 디더 안개, 방울 = 8~12px 덩어리(어두운 초록 + 연두 하이라이트 1px)가 늘어져 떨어짐, 웅덩이 거품 2~3개. 틈 따라 남는 금실 1초 안에 사라짐.
- 타이틀의 SD 마녀(빨간 목도리)를 게임 속 에스카와 같은 모습·팔레트로.

## 5. 기술 부채

- 웹에서 천열 직후 0.2초 단색 판 프레임(swiftshader에서 3회 재현, 데스크톱 0회) — 원인 찾기(연출을 하나씩 끄며 웹 빌드로 확인), 실제 원인이면 고침.
- 입구 장막(Curtain 도형 1074)도 굽기. 노드 수 증가 추세 확인.
- `eska_potion_rift` D(흑성 + 속박)가 FRAME_CLOCK=1에서 의식이 안 끝나 실패 → `st == 0` 기다리기.
