# 루프 7 개선 기획 (6차 평가 → 수정 계획)

> 근거: 6차 평가 4건(HEAD 58f1b24). **마녀다움 9/10**(바느질 땀이 "찢고·붓고·꿰맨다"를 완성), 그림자 일섬이 진짜 선택 순간(메아리+천열 / 갓 찢긴 속박 / 봉공 = 서로 다른 정답), 웹 단색 판 해결 확인(53프레임 0), 시나리오 42개 오류 0.
> 이번 루프의 중심: **검성 첫 만남을 실제 사람이 배우게** + **대마법 모양도 분신의 답** + **무시 비용**.

## 1. 검성 첫 만남 [결정]

- 문제: 배움 느려짐이 "세션 첫 도전"에만 켜지고 처음 쓰러지면 꺼짐 → 가장 공들인 배움(2막 그림자 일섬)을 실제 사람은 거의 못 봄. 첫 위협인 발도·삼연참엔 배움 없음(웹 첫 도전 6초 만에 쓰러짐).
- 배움은 **기술마다 세션 동안 한 번**(`_taught`를 세션 동안 유지, 쓰러져도 못 본 배움은 다음 도전에 나옴).
- 배움 추가: **발도**("칼집에 손 · 뛰어넘거나 순간이동"), **삼연참**("다가오는 세 번 · 물러나거나 위로").
- 배움 문구는 두 마디·15자 안팎(폰에서 1.4초에 읽히게).
- 느려짐 들어갈 때 0.15초·나올 때 0.3초 부드럽게(계단 전환 없앰).
- **쓰러지면 "무엇에 맞았나" 한 줄**: 마지막으로 맞은 기술 이름 + 대응(예: "발도 일섬 — 웅크리면 점프").
- 싸움이 열릴 때 force_bias 1.5초(검성이 버튼 밑에 서지 않게).

## 2. 그림자 일섬: 대마법 모양도 답, 무시는 늘 손해 [결정]

- **흑성**: 끌려 드는 분신은 자세 시간이 멈춤(속박과 같은 규칙) → 붕괴 폭발로 셋을 끝냄 = "모아서 끝내기".
- **유성우**: 분신이 살아 있으면 모이는 8발이 분신 줄을 노림 = "긴 틈으로 줄 전체".
- **무시 비용**: 살아 돌아간 분신마다 버팀 +800(가득이면 잘림) **+ 종언 게이지 −5%**(가득이어도 손해가 남음).
- 결과: 메아리 / 갓 찢긴 속박 / 봉공 / 흑성 / 유성우 = 각자 다른 자원을 쓰는 다섯 처방.
- 성능: 분신 붉은 테두리 빛이 분신마다 도형 약 1700 → 한 번 그린 텍스처로.

## 3. 화면·글자 [결정]

- 장면 안내: 키보드에서도 보스바 아래 가운데에 한 줄씩 돌아가며(왼쪽 아래 3줄이 바닥·캐릭터·일섬선을 가림).
- 외곽선 모드에서 물약 병 그림·숫자도 30% 진하기.
- 훈련장 틈 달이기 안내판 "↓+F" → 지금 칸 기준(EKeys.fmt로 "{es_potion}").
- 타이틀 에스카: 3배 확대에서 테두리 빛 끄고 1px 외곽선을 따로, 모자 챙 반짝 점 정리, 보름달 앞 실루엣 + 등 뒤 문장 고리 천천히(주인공 구도).
- 이웃 표적 피해 숫자: 쌓기 판단 거리를 "숫자 폭 + 4px"로(50px 간격에서 붙는 문제).
- 틈 부식: 틈 굵기와 관계없이 틈 둘레 ±8px 디더 안개, 웅덩이 4px 타원 + 거품.
