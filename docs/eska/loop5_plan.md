# 루프 5 개선 기획 (4차 평가 → 수정 계획)

> 근거: 4차 평가 4건(HEAD 26650a3). 마녀다움 8.5/10, 첫 10분 체감 "보라색 검사 → 공간을 찢어 약을 붓는 마녀", 시나리오 36개 오류 0, 보스 과부하 도형 11079(배경 굽기 −39%).
> 이번 루프의 중심: **보스전에 "모양을 고르는 순간"**(여러 표적) + 틈 박자 규칙 정리 + 튜토리얼 앞부분 압축·마무리 보상 + 터치 가림.

## 1. 보스전에 여러 표적의 순간 [결정] — 그림자 일섬

- 문제: 차별점은 틈의 **모양**(천열 호 · 낙성 기둥 · 흑성 원 · 유성우 긴 틈) × 물약인데, 검성전은 단일 표적이라 모양 선택이 의미 없음.
- 2막 새 기술 **「그림자 일섬」**: 검성이 칼을 거두면 그의 잔상 분신 3개가 한 줄(간격 ~70px)로 나타나 각자 자세를 잡는다(1.6초 예고). 시간이 다 되면 분신마다 늦게 터지는 일섬선을 긋는다(각 피해 1).
  - 분신: 체력 1600, 버팀 없음, 넉백 없음. 베어 없애면 그 분신의 일섬은 사라지고 **검성 버팀 −500**.
  - 그래서 "천열 호로 줄째 베기 / 갓 찢긴 틈에 부식 → 줄 전체 취약 / 흑성으로 모아 속박 / 유성우 긴 틈 / 단공으로 일섬선 가르기 / 그냥 피하기" 중 고르는 순간이 생긴다.
  - 연출: 먹빛 잔상, 붉은 끈만 또렷, 분신이 사라질 때 먹물 꽃잎. 검성 정체성("벤 뒤에야 참격선이 터진다")과 맞음.
- 2막 이중 비검: 간격 0.4 → 0.55초 + 둘째 파도에도 번뜩임·소리.
- 일섬 번뜩임 0.3 → 0.4초(번뜩임을 보고 점프해도 됨).

## 2. 틈 박자 규칙 정리 [결정]

- 문제: 천열은 참격 10장이 차례로 새 틈을 열어 "갓 찢긴" 창이 0.75초 넘게 늘어남 → 실력 박자가 아니라 입력 순서. 낙성은 앞으로 던지면 구조적으로 불가.
- 고침: **틈의 나이를 시전 단위로** — 한 시전이 연 틈들은 모두 그 시전의 첫 틈이 열린 시각을 "born"으로 공유(`ERifts.open(..., cast_id)`).
- 낙성: 땅까지 내려오는 길 틈은 **첫 별이 땅에 닿는 순간 열림**(그림 논리와 맞고, 앞으로 던지는 순서로도 갓 찢긴 틈에 닿음).
- 갓 찢긴 신호를 색이 아니라 **모양**으로: 흰 별빛이 튀고 틈 가장자리가 한 번 번쩍 꿰매지는 선(호박색 속박과도 구별).
- `eska_potion_rift`의 늦은 틈 경우가 규칙대로 `fresh: false`가 되게.

## 3. 튜토리얼 [결정]

- 앞부분 압축: 턱·장막·공허 틈 세 구간을 하나로(이단점프 + 순간이동으로 틈 하나), 허수아비 베기 3번 → 1번. **첫 마녀 기술(가르는 틈)을 1분 30초 안에**. 첫 확인점 x≈200(방향키 밖에서 시작).
- 단공 다리: 통과 뒤 두 번째 구슬을 0.75배로 한 번 더(딱 맞춤 창 0.8 → 약 0.55초 → 보스 0.23초로 가는 계단).
- 틈 달이기 통과 조건 = 갓 찢긴 틈(`fresh`), 처음엔 0.5배 느림, 두 번째는 **느림 없이** 한 번 더(실전 박자).
- 마무리 게이지 구간을 보상으로: 틈 달이기 성공 = 게이지 +30%, 이 구간 거상 공격 빈도 절반, 중간 망령 없음 → 사람 기준 15초 안팎·맞음 2회 이하.
- 마무리 연출 중 HUD·안내 숨김(letterbox가 HUD 글자를 자름, 지난 단계 안내 남음 고침), 가마솥 앞 서는 자리를 12px 옆으로, 달이기 화면 아래 안내 두 줄 중복 없앰.

## 4. 터치 가림·글자 과밀 [결정]

- 적이 버튼 밑에 오면 그 버튼을 40% 투명하게. 터치 중 카메라는 가장 가까운 적이 화면 오른쪽 60% 안쪽에 오도록 살짝 치우침.
- 안내 칸 중복 라벨("[점프] 점프") 없앰.
- 연습 과제는 접힌 한 줄("연습 과제 1/5 ▸", 체크될 때만 펼침), 연타 숫자는 그 아래로, 안내판은 가까이 갔을 때만 진하게, 봉공 안내판은 화면 안쪽.

## 5. 그림 [결정]

- 틈에 스민 부식: 디더 덩어리 4~6개가 틈을 따라 맺혀 늘어지며 떨어지고, 바닥은 거품 점이 있는 납작한 웅덩이, 초록 테두리선 없음.
- 틈 속박이 큰 표적을 칭칭 감는 지그재그 → 표적엔 방사형 거미줄 원반 하나, 틈을 따라 남는 실은 1초 안에 흐려짐.
