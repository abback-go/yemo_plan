# 조작·스킬 재설계 — 결정 기록 (작업 중)

> 사용자와 Claude가 상의해 정한 것. 스토리·인물·대사 기획(GPT)과 별도로 진행하며, 확정되면 GPT 인계서 양식 B로 옮겨 공유한다.
> 수치는 아직 없음 — 의도부터 정하고, 시제품 플레이로 맞춘다.

## 확정 (2026-10-04)
| 항목 | 결정 | 의도 |
|---|---|---|
| 기본 공격 | **여우 발톱 근접 연타** (세라가 너울의 발톱을 의태) | 할로우 나이트 계열. 터치에서도 단순하고 타격감이 좋게 |
| 마법 | **마나를 소모해 크게** + 마법마다 **쿨타임** | 난사 방지, 한 방의 무게 |
| 마나 충전 | **서서 집중해야만** 찬다 (가득 차는 데 약 3초) | 전투 중 "안전한 틈 만들기"가 긴장의 축 |
| 집중 규칙 | 끊어서 할 수 있다(모은 만큼 남음) · **맞으면 끊긴다**(초보자 모드는 예외 가능) · 성장으로 집중 속도가 빨라진다 | 짧은 틈도 쓸모 있게, 후반 성취감 |
| 습득 경로 | **학교 = 마녀 마법**(공격·방어, 수업 퀘스트) / **너울 = 여우술**(이동·의태·변신·회피, 이야기 속 필요한 순간에) | 두 스승의 개성, 게이트용 이동 능력은 주로 너울 |
| 방어 | **여우방패**: 누르면 전방에 약 1초 방패 = **무적기**. 짧은 쿨타임(2~3초 안, 시제품에서 조정) | 타이밍 부담 없이 위기 탈출, 연타 무적 방지 |
| 마나 모양 | **칸 3개** — 집중 1초에 1칸, 초급 1칸 · 중급 2칸 · 대마법 3칸. 성장으로 칸 추가(4~5칸) | 짧은 틈 = 1칸, 판단이 눈에 보이게 |
| 집중 입력 | **전용 '집중' 버튼을 누르고 있기** | 오입력 없음 (터치 큰 버튼 하나를 씀) |
| 변신 게이지 | **때리면 찬다** (마법 타격 포함 여부는 미정) | 마나(서서 집중)와 반대로 "공격적으로 움직이면" 차는 자원 → 두 자원이 다른 플레이를 요구 |
| 공격 마법 수·키 | **공격 마법 7종 모두 전용 키**(메이플 방식, PC 기준). 이동기는 별도. 예: 마법 A·S·D·F·Q·W·E, 점프 Z·발톱 X·대시 C·집중 V·방패 Shift (키 바꾸기 설정 제공) | 장착 대신 마나·쿨이 선택을 만든다. 태블릿은 나중에 퀵슬롯(4개)으로 |
| 변신 중 변화 | 발톱 강화·빨라짐 / 마법이 여우 판 / 마나가 저절로 느리게 참 / 이동이 달라짐 / 스킬이 더 크고 화려하고 강력 | 게임에서 가장 화려한 순간 |
| 발톱 콤보 | **3타 콤보지만 같은 위력**, 모션만 바뀌며 빠르게 반복 | 리듬이 일정한 연타 |
| 아래 찍기 튕김(포고) | **넣지 않음** | 조작 단순 |
| 대시 | 처음엔 **그냥 대시**(무적·공중 없음) → 너울에게 **회피술**을 배우면 **공중 사용 + 무적** 추가 | 성장 체감, 이야기 연결 |
| 공중 이동 | **2단 점프 + 활공**(떨어질 때 점프 길게, 상승 기류) | 지금 데모 방식 유지 |
| 방향 공격 | **↑+공격 = 머리 위, 공중 ↓+공격 = 발밑**(튕김 없음) | 비행·작은 적 처리 |
| 벽 | **벽에 붙으면 천천히 미끄러짐 + 벽 점프** | 세로 맵, 벽에서 오래 버티지 못하게 |
| 의태 돌진 | **별도 버튼 또는 커맨드**로 발동. 사용처(통과 대상·피해 여부)는 고민 중 | — |
| 여우술 해금 순서 | **변신 → 회피술 → 벽 → 의태 돌진** (2단 점프·활공은 학교) | 관계의 시작(빙의) → 생존 → 탐험 → 후반 게이트 |
| 회복 | **물약**(개수 제한, 저장 지점에서 채움, 최대 개수 성장) | 마나(집중)와 자원이 섞이지 않게 |
| 쓰러짐 | **마지막 저장 지점, 손실 없음**(주운 것 유지, 보스는 처음부터) | 초보자 친화 |
| 접촉 피해 | **일부 적만**(가시·불덩이 등). 일반 적은 공격 모션에만 맞음 | 근접 전투가 답답하지 않게, 적마다 개성 |
| 마법 레벨 | 초급 **Lv4**까지 · 중급 **Lv3**까지 · 대마법 **Lv2**까지, **최고 레벨에서 각성**(모양·효과가 바뀜) | 가벼운 마법일수록 오래 키우는 재미 |
| 장신구 | **넣는다** — 할로우 나이트 부적식 장착 패시브(칸 제한), **마녀 소재**를 섞어서 | 내 스타일 조합, 탐험 보상 |
| 체력 표시 | **칸(하트) 5칸에서 성장**, 한 대 = 1칸(큰 공격 2칸) | 판단이 쉽게 |
| 피해 숫자 | **띄운다**(설정에서 끄기) | 큰 마법의 상쾌함 |
| 재화·상점 | **있다** — 적·상자에서 돈, 학교 매점·마을 상인에게 물약·장신구 등 구입 | 탐험·전투가 보상으로 이어짐 |
| 최대 체력 성장 | 보스 처치로 얻는 **특별 재료 2~3개**를 모아 **연금술 교실**에서 '체력 증가 물약'을 만들어 마심 | 보스 보상과 학교 생활을 연결 |
| 장신구 얻기·칸 | **탐험·상점·퀘스트**, 장신구마다 비용 1~3, 총 **3칸 → 6칸** | — |
| 너울의 역할 | 게이지형 **변신(빙의)** + 기본기(발톱) + 여우 형상이 섞인 스킬 + 이동의 의태 | 너울이 조작 전반에 드러나게 |
