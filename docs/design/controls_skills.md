# 조작·스킬 재설계 — 결정 기록 (작업 중)

> 사용자와 Claude가 상의해 정한 것. 스토리·인물·대사 기획(GPT)과 별도로 진행하며, 확정되면 GPT 인계서 양식 B로 옮겨 공유한다.
> 수치는 아직 없음 — 의도부터 정하고, 시제품 플레이로 맞춘다.

## 3차 변경 (2026-10-04) · 가장 우선

| 항목 | 변경 |
|---|---|
| 여우방패 | **조작에서 뺌**(속도감을 해침). 정령 방패·세 줄 가로베기 반격 코드는 남겨 둠 — 되살리면 키만 연결 |
| 키 방식 | 시제품 시험 패널에서 **두 방식을 바꿔 가며 비교** (기본 = 등급 키) |
| 등급 키 (기본) | Z 점프 · X 발톱 · C 대시 · **F 꾹 마력 충전** · Space 변신 · G 물약 · **A 초급 · S 중급 · D 대마법** + 누르는 순간의 방향 |
| 등급 키 배치 | A = 파이어볼 / ↓A 여우비 · S(꾹) = 압축 열선 / ↑S 대유성 / ↓S 발톱 난무 · D = 너울 바인드 / ↑D 불사조. 방향에 마법이 없으면 중립 마법 |
| 전용 키 (비교용) | Shift 대시 · V 꾹 충전 · A S F / Q W / E R 마법마다 한 키 |
| 원칙 | 한 키에 "짧게/꾹" 두 뜻을 겹치지 않음(오입력·지연 방지). 꾹은 충전·열선처럼 짧게 누르는 뜻이 없는 키에만 |

## 2차 변경 — 시제품 체험 후 (2026-10-04) · 아래 표와 다르면 이것이 우선

| 항목 | 변경 |
|---|---|
| 키 | **Shift = 대시**, **C = 여우방패**, B(의태 돌진 전용 키) 없음. 마법 키 D 비움 → A S F / Q W / E R |
| 마나 | **시작 5칸 · 최대 7칸**(연금술 성장). 집중 1초에 1칸은 그대로 |
| 발톱 | 사거리 **모든 꼬리 단계에서 1.5배**(기본 45px, 꼬리마다 +2.25). 휘두를 때 손끝에 **커다란 여우손(불꽃 발 + 금 팔찌)** 이펙트 — 평소 붉은 불, 변신 중 푸른 불 |
| 의태 돌진 | 별도 키 삭제. **변신 중 대시 = 의태 돌진**: 세라보다 훨씬 큰 푸른 여우 정령이 감싸고 뛰어듦, 적·탄 관통 + 피해 + 무적, 대시와 같은 간격(추가 쿨 없음). **맵 게이트로 쓰지 않음**(여우 장막 삭제) |
| 여우방패 | 세라보다 훨씬 큰 **여우 정령이 방패로 앞을 1.5초 완전히 막음**(무적) → 방패를 내리며 **옆으로 세 줄 가로베기 반격**(위에서 아래 반원이 아님). 피해 = 기본 + 막은 피해(칸)마다 추가, 막을수록 할퀴기가 커짐. 안 맞아도 항상 할퀴기. 평소 붉은 불 / 변신 중 푸른 불 |
| 솟는 불꽃(D) | **삭제** → 공격 마법 **7종**(초급 2 · 중급 3 · 대마법 2) |
| 대유성(W) | **중급으로 내림**(마나 2칸, 쿨 약 8초, Lv3까지). 세라 뒤쪽 하늘의 마법진에서 **거대한 운석 한 방**이 보는 방향 앞 땅에 떨어져 **화면 앞쪽 절반**을 덮는 폭발 |
| 너울 바인드(R) | 화면에 **거대한 아홉 꼬리 여우신**이 나타남 → 모든 적을 5초 붙잡음 → 그동안 여우신이 **무자비한 참격**(푸른 칼날 + 먹빛 가장자리, 가끔 발톱 세 줄)을 퍼붓고 마지막에 화면을 가르는 **X자 참격**. 참격 한 줄 한 줄이 **화면 전체를 가로지름** |
| 여우불 발톱 난무(F) | R과 겹치는 문제는 **나중에 따로 의논**(이번엔 그대로) |
