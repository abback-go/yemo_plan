## 6. 작업 규칙
`CLAUDE.md`(질문으로 95% 확신, 추측 대신 검색, 모호한 말 금지, 완료 보고에 실행한 시험 명시, DRY, 범위 지키기, 파괴적 명령 전 확인)는 그대로 지킨다. 아래는 대화에서 받은 것 중 지금도 유효한 것.

**소통**
- 한국어로 짧게. 근거 없이 동의하지 말고 반론한다. 개념은 구체적인 예를 들어 설명한다(2026-11-15 `HANDOFF.md`).
- 사용자가 **질문하면 답만** 하고 생성·구현은 하지 않는다(계정 설정).
- **서브에이전트는 쓰기 전에 묻는다**(계정 설정). 사용자가 지시한 방식: 큰 개발은 백그라운드 에이전트에게 맡기고, 메인 세션은 사용자와 기획·그림 프롬프트를 한다(2026-11-16, 11-21).
- "얼마나 남았어?"는 지금 돌고 있는 백그라운드 작업 기준으로 답한다. 스크린샷은 나오는 대로 바로 보여 준다(2026-11-21).
- 계정 설정의 사용자 소개(직업 등)는 이 프로젝트 사용자와 맞지 않는다 — 그것으로 사용자를 부르거나 추측하지 않는다(2026-11-21).
- 사용자는 휴대폰 앱과 PC를 오가며 확인한다(주 10시간 정도). 휴대폰 앱에서는 환경 변경 승인 카드가 뜨지 않는다.
- 사용자가 자리를 비울 때는 질문으로 작업을 멈추지 않는다. 사용량 한도로 끊길 수 있으면 다시 시작하는 예약을 건다(2026-11-15·17·21). 컨텍스트를 압축하기 전에는 남길 것을 문서에 먼저 저장한다.

**기획·내용**
