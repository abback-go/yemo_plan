## 1. 틀 시안 (2026-11-15) — `game/proto/party/`, 주소 끝 `?party`

사용자 요청: "간단하고 작은 맵 1개와 시점, 그리고 캐릭터와 기본 이동 조작까지만". 고른 것: 숲속 유적 · 코드 임시 픽셀 그림 · WASD 8방향 + 패드.

- **맵**: 숲속 유적 56×36칸(칸 16px)
  - 빽빽한 숲 테두리
  - 연못과 금빛 석상 섬, 물에 선 기둥 둘
  - 무너진 기둥이 선 돌바닥 광장(가운데 새긴 원)
  - 흙길(왼쪽·오른쪽 위로 나감), 연못가의 빛나는 파란 꽃, 땅을 기는 뿌리
- **시점**: 고정 탑다운 3/4
  - 640×360 설계 화면을 키움(넓은 화면은 옆이 더 보임)
  - 카메라는 캐릭터를 부드럽게 따라가고, 맵 밖은 보이지 않음
  - 소품·캐릭터는 y 정렬이라 기둥·나무 뒤로 가면 가려짐
  - 연못 위쪽 물가는 땅의 앞면(절벽 6px)이 보임
  - 화면 가장자리 어둠 + 비스듬한 빛줄기
- **캐릭터**: 검사(임시)
  - 20×28 픽셀, 아래·위·옆 3방향(왼쪽은 옆 그림을 뒤집음)
  - 대기 2장(숨쉬기) + 걷기 4장
- **이동**:
  - WASD · 방향키 · 패드 왼쪽 스틱으로 8방향, 초당 90px(약 5.6칸)
  - 막힘: 숲·물 칸 + 기둥·바위·안쪽 나무 밑동
  - 폰 시험: 화면 왼쪽 절반을 끌면 조이스틱
  - Esc = 타이틀
- **그림**: 전부 코드 임시 — AI 그림으로 바꿔 끼울 자리
  - 소품·캐릭터: `pt_art.gd`, 함수 하나가 텍스처 하나
  - 땅: `pt_ground.gdshader` 한 장
- **아직 없는 것**: 공격·전투·적·캐릭터 교체·UI·상호작용.

## 1-2. 성 방어 시안 (2026-11-15) — `game/proto/defense/`, 주소 끝 `?defense`

사용자 요청은 그림 한 장(성벽 위 엘프 궁수와 기사들, 성 밖에서 몰려오는 괴물·마법사, 해 질 녘 보라빛)과 함께 왔다: "이런 느낌의 프로토타입 — 성벽 위가 아니라 평지에서 싸울 수 있는, 성을 침공으로부터 지키는 컨셉. 시점은 기존과 비슷하게."

고른 것:
- 조작: 엘프 궁수
- 병사: 서 있기만 하는 연출 — "동료 AI 없음"과 맞춤
- 승패: 성문 체력 + 웨이브 3
- 배치: 성이 위쪽
- 적: 2종(구울·어둠 마법사)
- 공격: 마우스 조준 + 구르기
- 빌드 요소: 없음
- 그림: 코드 임시

**성을 지키는 컨셉은 이 시안의 것 — 게임 전체 컨셉으로 정한 것은 아니다** [대기].
**"공격 타이밍 입력"**: 사용자가 마우스 조준 사격 + 구르기를 골랐다. 옛 규칙 "내 공격 타이밍 입력 없음"은 이 시안에 쓰지 않았다. 게임 전체로 풀지는 [대기].

- **맵**: 48×37칸
  - 위쪽 성벽: 높이 168px(사람 키의 약 5배). 문 옆 탑 둘(불 켜진 창), 쇠창살 성문, 남색 깃발 넷(금빛 해 문장)
  - 성문 앞: 돌바닥과 새긴 원, 화로 둘, 서 있는 기사 둘과 창병 둘
  - 가운데: 풀밭, 갈래 흙길, 바위, 양옆 숲
  - 아래: 적 진지 셋(보라로 빛나는 타락한 땅, 말뚝 바리케이드, 붉은 깃발, 보라 수정)
  - 해 질 녘 보라빛, 가장자리 어둠
- **엘프 궁수**
  - 걷기는 `?party`와 같습니다(WASD·방향키·패드, 초당 90px).
  - 조준: 마우스(조준점 표시). 패드는 오른쪽 스틱, 폰 시험은 화면 오른쪽 절반을 누른 자리입니다.
  - 사격: 왼클릭을 누르고 있으면 0.3초마다 화살을 쏩니다(패드 R1·RT). 피해 10, 사거리 약 300px이고, 쏘는 동안은 75% 속도로 걷습니다.
  - 구르기: Space(패드 A). 0.3초 동안 무적이고, 0.6초 뒤 다시 구를 수 있습니다.
  - 체력 100. 맞으면 0.6초 동안 무적입니다.
- **적**
  - 구울: 체력 30. 성문으로 달려가다가 궁수가 80px 안이면 쫓아옵니다. 붙으면 0.3초 칼을 들었다가(예고) 내려칩니다. 궁수에게 8, 성문에 4.
  - 어둠 마법사: 체력 24. 궁수가 170px 안이면 멈춰 0.55초 예고 뒤 보라 구슬을 쏩니다(궁수에게 10). 궁수가 멀면 성문을 쏩니다(6).
- **웨이브**
  - 1: 구울 8
  - 2: 구울 10 + 마법사 3
  - 3: 구울 14 + 마법사 5
  - 웨이브 사이 3.5초. 성문 체력 400.
- **승패**: 웨이브 3개를 다 막으면 승리합니다. 성문이 부서지거나 궁수가 쓰러지면 패배합니다. R 다시 · Esc 타이틀.
- **시험 봇 결과**
  - 성문에 가까운 적부터 쏘고 적이 붙으면 구르는 봇은 2판 모두 이겼습니다(성문 244·334/400, 궁수 24·48/100).
  - 아무것도 안 하면 18초에 궁수가 쓰러졌습니다.
- **그림 수준**: 보내 준 그림보다 단순한 코드 임시 그림입니다. 그림의 비룡·멀리 불타는 성·보름달 하늘은 위에서 내려다보는 시점이라 넣지 않았습니다.
