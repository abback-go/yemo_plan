## 1. 틀 시안 (2026-11-15) — `game/proto/party/`, 주소 끝 `?party`

사용자 요청: "간단하고 작은 맵 1개와 시점, 그리고 캐릭터와 기본 이동 조작까지만". 고른 것: 숲속 유적 · 코드 임시 픽셀 그림 · WASD 8방향 + 패드.

- **맵**: 숲속 유적 56×36칸(칸 16px)
  - 빽빽한 숲 테두리
  - 연못과 금빛 석상 섬, 물에 선 기둥 둘
  - 무너진 기둥이 선 돌바닥 광장(가운데 새긴 원)
  - 흙길(왼쪽·오른쪽 위로 나감), 연못가의 빛나는 파란 꽃, 땅을 기는 뿌리
- **시점**: 고정 탑다운 3/4
  - 640×360 설계 화면을 키움(넓은 화면은 옆이 더 보임)
  - 카메라는 캐릭터를 부드럽게 따라가고, 맵 밖은 보이지 않음
  - 소품·캐릭터는 y 정렬이라 기둥·나무 뒤로 가면 가려짐
  - 연못 위쪽 물가는 땅의 앞면(절벽 6px)이 보임
  - 화면 가장자리 어둠 + 비스듬한 빛줄기
- **캐릭터**: 검사(임시)
  - 20×28 픽셀, 아래·위·옆 3방향(왼쪽은 옆 그림을 뒤집음)
  - 대기 2장(숨쉬기) + 걷기 4장
- **이동**:
  - WASD · 방향키 · 패드 왼쪽 스틱으로 8방향, 초당 90px(약 5.6칸)
  - 막힘: 숲·물 칸 + 기둥·바위·안쪽 나무 밑동
  - 폰 시험: 화면 왼쪽 절반을 끌면 조이스틱
  - Esc = 타이틀
- **그림**: 전부 코드 임시 — AI 그림으로 바꿔 끼울 자리
  - 소품·캐릭터: `pt_art.gd`, 함수 하나가 텍스처 하나
  - 땅: `pt_ground.gdshader` 한 장
- **아직 없는 것**: 공격·전투·적·캐릭터 교체·UI·상호작용.
