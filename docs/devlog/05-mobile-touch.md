# 모바일 버전 — 터치 조작과 인터넷 없이 실행 (2026-10-03)

> 요청: "컴퓨터를 사용할 수 없을 때 모바일로 플레이해 보며 테스트하겠다. 인터넷 연결이 없어도 가능하게. 왼쪽에는 가상 패드, 오른쪽에는 점프·스킬 등 버튼."
> 결정(질문으로 확인): 안드로이드 태블릿(가끔 휴대폰) · **홈 화면 웹앱** · **떠 있는 조이스틱** · **공격 맨 오른쪽** 버튼 배치.
> 설치·조작 안내: [`game/README.md`](../../game/README.md) "태블릿·휴대폰에서"

## 2. 정한 것과 이유

- **내장 `VirtualJoystick`을 쓰지 않음**: 4.7.2에서 시험해 보니 축마다 기울기만큼 눌려서, 오른쪽으로 달리며 아주 조금만 아래로 기울어도 ↓가 눌렸다. 이 게임에서 ↓+점프는 발판 내려가기, ↑는 상호작용이라 오입력이 곧 사고 → 방향을 **구역**으로 판정하는 조이스틱을 직접 만들었다(▲▼는 수직에서 약 44도 안쪽만).
- **버튼 = 키와 같은 동작 신호**: `Input.parse_input_event(InputEventAction)`으로 보내서 세라 조작(누르고 있기·길게 점프 포함), 멈춤 안내, 대화, 일시정지가 키보드와 똑같이 반응한다. 기존 대본·UI를 고칠 필요가 거의 없었다.
- **오프라인 저장 보완**: Godot 기본 서비스 워커는 설치할 때 `index.html` 등만 저장하고 게임 본체(`index.wasm` 약 40MB·`index.pck` 약 6MB)는 저장하지 않는다. 처음 연 페이지는 서비스 워커를 거치지 않아서, **첫 접속 뒤 바로 인터넷을 끊으면 오프라인 안내 페이지가 뜨는 것**을 Playwright로 확인했다. 새 버전이 받아진 뒤에도 같은 문제가 생긴다(옛 저장분은 지워지고 새 본체는 아직 없음). → 배포 단계에서 서비스 워커가 설치 때 전부 저장하게 한 줄 바꿨다(`web-build.yml`).
