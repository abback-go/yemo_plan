# 06. 전체판 v1.0 — 2~5장, 마법 7종, 수업·퀘스트·동료 (2026-10-03~04)

> 사용자 요청(한 번의 프롬프트로 위임): 2~5장을 장마다 대표 강자 한 명과 함께 만들고, 5장에서 별의 마녀의 진실 → 신들의 침공과 압도적 절망 → 극복. 마법은 조건 → 수업 해금 → 배우기 창 → 퀘스트 → 습득, 등급·레벨, 7종. 학교 일상 퀘스트, 퀘스트창·미니맵, 초보자 난이도, 모바일, 메인 8~9시간. "아트만 빼면 출시해도 손색없게."

## 1. 어떻게 만들었나
- **정본 먼저**: `docs/archive/sera/bible/`(세계관·인물·줄거리·능력 장부·밸런스·그림 규칙)을 쓰고, 2~5장 기획서 뼈대(흐름·방 목록·적·퍼즐·서브 퀘스트)를 고정한 뒤 만들기 시작했다.
- **장별 모듈 구조**(`ChapterRegistry`): 장마다 자기 파일(`data_chN`·`scripts_chN`·`enemies/chN`·`entities/chN`·`themes_chN`·`tools/rooms/chN.py`)만 쓰고, 공용 파일은 고치지 않는다. 덕분에 장 담당 넷이 동시에 만들고 충돌 없이 합쳤다(겹친 것은 학교 방 생성 파일뿐 — 생성기로 다시 만들어 해결).
- **공통 시스템**(통합 담당): 마법 7종(`Spells`), 수업 게시판·수업 4종, 퀘스트(`Quests`)·퀘스트창·마법서, 전이진, 미니맵, 동료(`Ally`), 장 흐름(`ChapterFlow`), 연출층(`Cinema`: 레터박스·틴트·장 카드·크레디트), 난이도.
- **음악·효과음**: 2~5장 배경음악 22곡과 효과음 33종을 코드로 합성(`tools/gen_music.py`, `autoload/sfx.gd`). 지역마다 주제 동기를 서로 인용한다.

## 3. 공통 시스템 메모
- **수업 4종**: 불꽃 날개(바람의 탑 — 바람 기둥 활공), 불꽃 방벽(발사대 마력탄 되쳐 과녁 셋 + 엠버린 화염구 10발), 유성 낙화(별 관측대에서 거문고자리(리라) 잇기 → 폭주 제어 시험 → 베로니카 결투), 불사조(교장 서명 → 재의 서고 촛불 미로 → 불사조의 알 2분 지키기 → 그림자 세라 "불 속의 나"). 자동 시나리오 `sys_classes.json`으로 넷 다 처음부터 끝까지 통과(방벽은 실제 되쏘기).
- **HUD 목표**는 지금 장의 목표 줄만 본다(통합 중 발견: 앞 장의 선택 목표가 남아 다음 장에서도 2장 첫 목표가 보이던 문제).
- **장 카드·크레디트**는 화면 페이드 위층(61)에 — 검은 화면에서도 보인다.
- 다음 장 대본이 없을 때(제작 중 빌드)는 화면을 되돌리고 말풍선만 띄운다.

## 4. 통합하며 고친 공용 문제 (장 담당 요청)
- 너울·세라 여우 꼬리가 여러 개일 때 다각형이 꼬여 매 프레임 엔진 오류 → 꼬리 축에 수직인 방향으로 폭을 잡음.
- 쓰러진 적이 흰색으로 남음 → 죽은 뒤에도 번쩍임이 걷히게.
- 세로로 긴 방에서 배경이 아래를 못 덮음 → 세로 시차 배율을 반영.
- 시험 실행기: 멈춤 안내 키가 비었을 때 방어, 수업·동료·되쏘기 시험 명령.

## 6. 남은 것 (정직하게)
- 플레이 시간과 손으로 하는 난이도는 **사람이 직접 해 봐야** 확정된다(시나리오는 순간이동·처치로 진행).
- 일부 인물(이졸데 결투 등)은 1장 기본 인물 그림, 실내 몇 곳은 바깥 배경을 쓴다. 정화한 뒤에도 흰 역병 방 배경은 그대로.
- 2장 파견 중 학교에도 피피·이졸데·엠버린이 서 있다(공관과 동시에).
- 동료 레오니는 2장 옛 성곽 구간에서 저장되지 않는다(방에 들어올 때 다시 부름).
- 효과음 합성 방식(`load_from_buffer`)이 웹에서 소리를 내는지는 귀로 확인하지 못했다(대체 경로 있음).
