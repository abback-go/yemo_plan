## 2. 1장 흐름 (첫 플레이 약 35~45분)

1. **신계** — 걷기·점프·대시 → 도깨비불(화염탄) → 석상 여우(퍼펙트 회피) → 등롱 감시자(불기둥·발판 내려가기) → 봉화 시련(폭주 게이지·폭발) → 왕좌의 전당(여우구슬) → 붕괴 탈출(대시 점프) → 해태(첫 빙의)
2. **의무실** — 피피와 미라벨, 물약 2개. "사역마" 오해
3. **동관 복도** — 폭주 빗자루(학교 첫 전투, 30초 안)
4. **중앙 홀** — 이졸데의 "폐급" → 너울 "…감히." → 이졸데 "갑자기 왜 춥지"
5. **마법반·실습장** — 엠버린의 과제 → 훈련 골렘 폭주 → 화염 폭풍 → "봉인이 흔들리는 건 내 구슬 탓, 곧 네 탓이니라"
6. **도서관** — 마도서가 금서 열쇠를 물고 서가로 → 비속성마법반(천장에서 자던 오필리아) → 부양 실습실 → 서가 미로의 마도서
7. **금서 구역** — 창립자가 여우신의 푸른 불을 빌려 아귀를 봉인했다는 기록 → 너울의 기억 → 여우창문
8. **상층 회랑·고급마법반** — 시간 문, 갑옷 수호기사, 베로니카·이졸데와 함께 폭주 갑옷 진압
9. **시계탑·교장실** — 톱니 사이 2단 점프 등반 → 아스트리드 "처음 뵙겠습니다… 라고 해 두죠" → 지하실 열쇠
10. **앞마당 → 지하 저장고 → 봉인 회랑** — 연금 슬라임(금 간 벽), 그림자 늑대, 여우창문으로만 보이는 벽화의 순서대로 봉인 촛대 점화
11. **봉인의 방** — 아귀 → 교장·엠버린 도착 → 기숙사의 밤 "네 마력은 폐급이 아니니라. 그릇이 아직 덜 자랐을 뿐." → 1장 끝 화면(기록 + 계속 탐험하기)

## 3. 무엇을 어떻게 만들었나

### 3.1 월드
- 게임 화면 하나(`world/world.tscn`)가 방을 바꿔 끼운다. 방은 ASCII 지도 + 개체 목록이며 **`tools/roomgen.py`가 생성**한다.
- 타일은 방마다 이미지 한 장으로 구워 그린다(웹에서 그리기 호출 수를 줄이기 위해). 충돌은 같은 칸을 직사각형으로 합친다.
- `python3 tools/roomgen.py check`로 출구·문·수집품 사이의 도달 가능성을 한 번 점프 / 2단 점프 / 여우창문 세 경우로 검사한다.

### 3.2 이야기 도구
- 대본은 `story/scripts_*.gd`의 메서드이며, `Cut` 도우미로 대사·이동·카메라·연출·안내를 순서대로 `await`한다.
- 컷신 중에는 적이 멈춘다. 인물이 화면 아래에 있으면 대화창이 위로 올라간다.
- 쓰러져 부활하면 진행 중이던 대본은 세대 번호로 무효화된다. 보스전 대본은 적이 이미 처치되어 있으면 바로 뒷이야기로 넘어가서, 어떤 순서로 쓰러져도 진행이 막히지 않는다.

### 3.3 적 (서브에이전트 3명이 병렬로 제작)
| 지역 | 적 |
|---|---|
| 신계 | 도깨비불(110), 석상 여우(160), 등롱 감시자(90), **해태**(1000, 붉은 불 50%·불 먹기·기와 낙하 — 여우 모드 시범전) |
| 학교 | 폭주 빗자루(160, 벽에 박히면 발판), 훈련 골렘(1400, 등의 핵 2배), 갑옷 수호기사(420, 정면 방패), 마도서(600, 150 피해마다 덮고 패턴 변경) |
| 지하 | 연금 슬라임(380, 자폭으로 금 간 벽 파괴), 그림자 늑대(340), 독덩굴(420, 선택), **아귀**(3000, 2페이즈) |
