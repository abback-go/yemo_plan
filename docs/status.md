## 1. 사용자 작업 방식 (지켜야 할 것)
- 한국어, 간결하게. 근거 없이 동의하지 말고 반론할 것. 불확실하면 검색해서 확인.
- 이미지 프롬프트는 **한 번에 하나씩, 코드 블록으로**(복사 버튼으로 바로 복사) 채팅에 준다. 무엇을 첨부할지(기준 그림·직전 컷)와 새 대화창 여부를 함께 적는다. 결과 그림을 받으면 검수 → `art/raw/vs/`에 원본 저장 → 커밋·푸시(게임에 넣는 배경 제거·크기 조정은 개발 쪽에서).
- 서브에이전트는 쓰기 전에 사용자에게 묻는다(이번 세션은 큰 개발 작업을 Opus 5.5 · xhigh 백그라운드 에이전트로 맡겨 왔음).
- 사용자는 휴대폰(앱)과 PC를 오가며 확인한다. 휴대폰 앱에서는 환경 변경 승인 카드가 뜨지 않는다.
- 사용자를 '교수님'으로 부르지 않는다(사용자 정정: 본인은 '아들'). 버티컬 슬라이스 목표일 2027-04-27은 사용자의 전역일.
- **그림 검수는 디테일까지**(2026-11-22 지시): `art-direction.md` 5-1 체크리스트(옷 앞뒤·뒷모습 무릎/겹침·좌우·장식 위치·노출·비율·지시 반영·그림체·반투명 옷 배경색 물듦·배경 제거)로 부위별 확인 후 보고. 어긋나면 "통과"라고 하지 않고 수정 프롬프트를 함께. 같은 그림 2번 넘게 고쳐도 안 되면 프롬프트를 다시 써서 새 대화창에서. 프롬프트를 쓰기 **전에** 시안에서 장식 위치·옷 길이·앞뒤 공통 부분 색을 확인.
- 대사는 AI 티 금지: 명언형·쉼표/말줄임 뜸·인물 소개형("이름. 직함. 특징.")·조각문·대비 구조 금지. 노엘 속마음은 '계산하는 사람의 생각'. 규칙: `tutorial-script-vs.md` 머리.
- 받은 그림은 `art/raw/vs/<번호>_<이름>.webp`로 저장해 바로 커밋·푸시(사용자가 대화 중 붙인 그림은 다음 메시지 전에 파일로 남지 않을 수 있음 — 저장 안 된 건 다시 첨부를 부탁).
- 이미지 생성은 ChatGPT 기본 모델로(Astra·High 추론은 사용량만 많이 씀).

## 2. 지금까지 확정된 핵심 (요약)
> 2026-11-21~22 버티컬 슬라이스 결정(5-2장)이 아래 옛 요약보다 우선한다(예: 탑뷰 없앰, 죽음 카드 컨셉 변경, 누설 규칙 없앰, 대본 새로 씀).
- **컨셉**: 동료의 죽음을 미리 보고 그 죽음을 카드로 쓰는 마녀. 노엘은 학생이 아니라 **최강급 이름난 파티의 마녀**.
- **파티**: 마녀 노엘 + 핵심 동료 5명(용사 세라피나·전사 브룬힐드·궁수 엘리안·사제·도적). 전투는 동료 3명 출전. 튜토리얼은 세라피나·브룬힐드·엘리안. **세라피나가 튜토리얼에서 참혹하게 사망**.
- **전투 화면**: 마녀 1인칭 손패 + 동료 3명 뒷모습(궁수 왼쪽·용사 가운데·전사 오른쪽) + **붉은 실**(동료 등 → 손패, 죽음 카드에 팽팽). UNREASON X와 구도가 겹치지 않게 하려는 결정.
- **규칙**: 에너지 3, 5장 드로우, 방어 = **피해 옮기기**, 쓰러지면 상처 카드, 죽음 카드 비용 0·손패 보존, 죽은 동료 카드는 **유품 카드**(강하지만 마녀 HP 소모), 상속 카드 `짓밟힘`.
- **연출**: 대표 카드(성검 베기·저격·감싸기·저주의 불꽃·짓밟힘)는 낼 때마다 컷인. **모든 카드는 손으로 들어 올려 낸다.** 사망 컷신 8컷(C1~C8, 손·피·잔해까지 보여주는 수위).
- **튜토리얼 흐름(확정)**: 캠프 → 1층 전투 → 이동·갈림길 3택(시체 발견 / 휴식(잠) / 훈련) → 세라피나와의 대화(계단) → 2층 광신도 → 거대 존재 → 사망 → 짓밟힘 탈출 → 빈 캠프. 오프닝: 왕도 의뢰(광신도 의식 저지) + 귀환 못 한 원정대 + 노엘의 "나와 같은 마녀" 소문 [결정].

## 5-1. 버티컬 슬라이스 (2026-11-21 결정)
- 범위: 1~3층을 거의 완성본 품질로. 목표일 **2027-04-27**. 그 뒤 스팀 상점 페이지·트레일러 → 2027년 6월 스팀 넥스트 페스트(6/14~21) 데모 후보.
- 제작 조건: 그림은 ChatGPT로만(손보정 없음, 재미가 확인된 뒤 한참 후에), 작업 시간 주 10시간(휴대폰·PC).
- **그림체: D(잔혹동화 그림책 — 잉크 선 + 바랜 수채, 붉은색만 선명, 가시·장미 테두리, 까마귀, 붉은 실) 확정.** 기준 그림 `reference/style/style_D_seraphina_anchor.webp`를 매번 첨부해 그림체를 유지한다. 죽음 카드만 E(붉은 잉크 동판화)로 그리는 안은 제안 단계(미결).
- **데스신 수위 기준(2026-11-21): 잔혹동화 수준.** 피는 보여 준다(흐름·튀김·웅덩이). 관통·상처는 방패·그림자·뒷모습·화면 밖으로 암시하고, 몸이 뚫린 단면은 그리지 않는다. 감정 컷(얼굴·손·유품)은 피를 줄이고 슬픔에 집중. ChatGPT 요령: 거절되면 새 대화창, 피투성이 컷은 참고 그림으로 첨부하지 않기. 시안: `reference/deathscene/`.
- **캐릭터 디자인 확정(시안)**: 세라피나 = 은백 성기사 미녀(허리~허벅지 맨 위 붕대) · 브룬힐드 = 흑기사 여우상 미녀(들꽃 방패) · 엘리안 = 도도한 엘프 귀족 궁수(노래책 설정 삭제) · 노엘 = 와인빛 머리 마녀(흑발에서 변경, 손가락의 붉은 실). 세부·영어 묘사: [`art-direction.md`](art-direction.md), 시안: `reference/style/`.
