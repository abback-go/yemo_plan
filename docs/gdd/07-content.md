## 7.1.1 월드 구조 [확정]

- **하나의 세계**를 무대로 하는 **옴니버스** 구성. 장(章)마다 그 세계의 다른 지역·인물이 맞는 종말을 다룬다.
- **허브 연결형 구조**: 거점(허브)을 중심으로 여러 지역이 이어지고, 플레이어는 지역 사이를 오간다.
- 맵 구성은 블랙소울2의 맵 구성에서 좋게 느낀 '느낌'을 참고한다.
- 유지할 탐색 요소: **지름길 개방**(소울류식), **숨은 지역**. [확정]

```
[다이어그램: 월드 구조 (후보)]
마녀의 서고 (역할 미결정 — 8장)

하나의 세계
 └─ 거점 (허브: NPC, 성장)
      ├─ 지역 A ─ 보스 (타락한 존재)
      ├─ 지역 B ─ 보스        ← 지름길이 열리며 지역끼리 연결
      ├─ 숨은 지역
      └─ 지역 C ─ 최종 보스 → 세계의 종언 → 한 권의 책으로 저장
```

- **장 구성**: 블랙소울2처럼 **지역별**로 구성한다. [확정]
- **비선형 진행**: 여러 우회 루트가 있고, 지역을 공략하는 순서가 아주 중요하지는 않게 한다. [확정]
- [미결정: 장마다 지역 수 / 거점이 하나인지 장마다 있는지]
- [미결정: 공략 순서가 자유로울 때의 난이도 설계 — 지역별 고정 난이도 / 진행도에 따른 보정 등]

> 🎮 디자이너 노트: 버티컬 슬라이스는 1장 하나다 (17장). 1장 안에서 지역 2곳 이상과 우회 루트 1개 이상을 넣어야 "비선형 허브 연결" 구조를 검증할 수 있다. [제안: 버티컬 슬라이스 최소 범위로 검토]
