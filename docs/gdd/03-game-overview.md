# 3. 게임 개요

> 상태: [작성 중] · 목표 분량: 600~1,000자 · 연관 섹션: 2, 4, 8, 10, 16
> 📝 작성 기준: 게임의 정체성을 규정한다. 이후 모든 설계는 여기의 경험 기둥을 근거로 판단한다.

## 3.1 하이 컨셉 (한 문장)

- 수명이 다해 멸망해가는 세계에서, **종언의 마녀**가 되어 타락한 존재들을 쓰러뜨리고 끝나가는 세계를 **한 권의 책**으로 거두는 다크판타지 픽셀아트 액션. [검토 대기: 문장 다듬기]

## 3.2 코어 판타지

> 플레이어가 느끼는 힘의 판타지 또는 감정.

- 끝나가는 세계에 **마지막을 내리는 자**가 되는 감각. 잔혹함과 절망 속에서, 세계와 그 안의 존재들에게 종언을 선고하고 그 이야기를 기록으로 남긴다. [검토 대기]

## 3.3 경험 기둥 (Experience Pillars) — 3~4개

> 게임의 모든 요소는 최소 하나의 기둥을 뒷받침해야 한다. 기둥에 어긋나는 기능은 넣지 않는다.
