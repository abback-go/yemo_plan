# 4. 코어 게임플레이 루프

> 상태: [작성 중] · 목표 분량: 800~1,500자 · 연관 섹션: 3, 5, 6, 7
> 📝 작성 기준: 마이크로(2~5분) / 매크로(20~60분) / 메타(장기) 루프를 각각 텍스트 다이어그램과 함께 쓴다.

## 4.1 마이크로 루프 (2~5분)

- **전투 성격**: 적과 **한 마리씩 신중하게** 싸우는 느낌 (소울류). [확정]
- **탐색 중 반복 행동**: 블랙소울2를 참고해 아래 행동으로 구성한다. [확정] / 루프 순서·소요 시간 [후보]

```
[다이어그램: 마이크로 루프 (후보)]
구역 진입 → 위협 파악(적 배치·환경 힌트) → 적과 1:1 신중한 전투 → 보상(재화·아이템)
    ↑                                                              ↓
    └── 책갈피(체크포인트) ← 탐색(숨은 길·지름길·NPC·아이템) ←───────┘
```

| 단계 | 플레이어 행동 | 게임 반응 | 소요 시간 |
|---|---|---|---|
| 위협 파악 | 적 배치와 환경 힌트(남겨진 시체 등)를 살핀다 | 적의 대기 동작, 환경 연출 | [미결정] |
| 전투 | 적 한 마리와 거리·타이밍을 재며 검술·마법으로 싸운다 | 피격·처치 피드백 | [미결정: 일반 적 1마리당 목표 시간] |
| 보상 | 재화·아이템을 줍는다 | 획득 표시 | |
| 탐색 | 플랫폼 이동, 숨은 길·지름길 찾기, 아이템 줍기, NPC와 대화 | 지름길 개방, 대화·퀘스트 진행 | |
| 책갈피 | 책갈피(체크포인트)를 찾아 활성화 | 회복 [미결정: 회복 방식], 서고 복귀 가능 | |
