## 채우는 순서 (권장)

1. **1단계 — 컨셉 확정**: 3 → 4 → 16 → 8·10(톤만) → 1 → 2. 여기까지 채우면 그 자체로 **컨셉 기획서**가 된다.
2. **2단계 — 시스템 설계**: 5 → 6 → 14.
3. **3단계 — 콘텐츠·표현**: 7 → 8·10(상세) → 9 → 11.
4. **4단계 — 사업·제작**: 13 → 15 → 17 → 18. 마지막에 2(요약)를 다시 정리한다.

> 🎮 디자이너 노트: 요약(2장)은 맨 앞에 있지만 가장 마지막에 완성하는 섹션이다. 1단계에서 임시로 쓰고 4단계 후 다시 정리한다.

## 작성 표준 (모든 섹션 공통)

- **구체성**: "다양한 적" 대신 "일반 적 HP 100~500, 감지 범위 8m"처럼 수치로 쓴다.
- **메커닉 5요소**: 입력 / 시스템 / 피드백 / 파라미터(표) / 설계 근거.
- **외부 수치**: 출처와 데이터 기준 연도를 적는다. 출처가 없으면 `[자료 필요]`.
- **디자이너 노트**: 명세가 아닌 맥락은 `> 🎮 디자이너 노트:` 인용 박스로 분리한다.
