## 5.0 전투 개요와 무기 [확정]

- **전투 방식**: 실시간 액션.
- **무기**: 칼과 빗자루가 결합된 무기. 이 무기로 **검술과 마법을 모두** 사용한다.
- **무기 개념 (가안)**: 검과 검집이 한 세트이며 검은 뽑아 쓴다. 검집 아래쪽이 나뭇가지 빗자루 형태다. 참고 이미지: [`assets/concept-witch-weapon-draft.png`](assets/concept-witch-weapon-draft.png) — 생성형 이미지로 느낌만 나타낸 가안이며 디자인은 확정 아님.

## M-01. 이동 — 떠서 미끄러지는 활주

**1) 입력**: ← → (키보드)

**2) 시스템**: 땅 위를 살짝 떠서 미끄러지듯 달린다. 최고 속도까지 가속·감속이 아주 짧다. 최고 속도에선 옅은 잔상, 방향을 바꾸면 미끄러지는 먼지.

**3) 피드백**: 활주 자취(발밑 보랏빛 바람), 속도선, 잔상, 방향 전환 먼지·찌그러짐

**4) 파라미터**

| 파라미터 | 값 | 단위 | 비고 |
|---|---|---|---|
| 최고 속도 | 210 | px/s | 약 13타일/초 |
| 땅 가속 | 2800 | px/s² | 최고 속도까지 약 0.075 s |
| 땅 감속 | 3200 | px/s² | 멈출 때까지 약 0.066 s |
| 공중 가속 | 1900 | px/s² | 손을 떼면 그 0.6배로 감속 |

**5) 설계 근거**: 이나리·산나비처럼 빠르고 즉각적인 조작감. 에스카에서 다듬어 둔 값을 그대로 쓴다.

## M-02. 점프 · 이단점프

**1) 입력**: Z. 공중에서 한 번 더 누르면 이단점프. ↓를 누르고 있으면 빨리 떨어짐.

**2) 시스템**: 점프 높이는 **고정**(버튼 길이와 상관없음). 정점 근처에선 중력이 약해져 잠깐 뜬다. 이단점프는 착지 전까지 1번, 누른 방향으로 바로 꺾는다.

**3) 피드백**: 점프 때 늘어남·먼지, 이단점프 때 발밑 회오리 고리·몸 한 바퀴(치맛자락이 퍼짐), 착지 먼지·소리

**4) 파라미터**

| 파라미터 | 값 | 단위 | 비고 |
|---|---|---|---|
| 점프 속도 | 360 | px/s | 높이 약 46 px (약 2.9타일, 고정) |
| 이단점프 속도 | 320 | px/s | 착지 전까지 1번 |
| 중력 | 1350 | px/s² | |
| 정점 근처 중력 배수 | 0.55 | 배 | 세로 속도 60 px/s 미만일 때 |
| 최대 낙하 속도 | 330 | px/s | ↓를 누르면 440 (중력 1.35배) |
| 코요테 타임 | 0.09 | s | |
| 점프 버퍼 | 0.12 | s | |

**5) 설계 근거**: 에스카 이동 채택(19장 결정 로그). 가변 점프 대신 고정 높이 + 이단점프로 높이를 고른다.

## M-03. 순간이동 (회피·대시 역할)

**1) 입력**: C

**2) 시스템**: 바라보는(또는 누른) 쪽으로 짧게 사라졌다 나타난다. 벽에 막히면 그 앞까지. 땅에선 자유, 공중에선 착지 전까지 1번. 휘두름의 거둠과 마법을 모으는 중에도 쓸 수 있다(동작 끊기).

**3) 피드백**: 사라질 때 찢어진 틈, 지나간 경로의 참격 자취, 나타날 때 길게 늘어났다 돌아옴, 화면 밀림

**4) 파라미터**

| 파라미터 | 값 | 단위 | 비고 |
|---|---|---|---|
| 거리 | 128 | px | 8타일 |
| 사라져 있는 시간 | 0.07 | s | |
| 다시 쓰기까지 | 0.26 | s | |
| 무적 | 0.2 | s | 사라짐 0.07 + 나타난 뒤 0.13 |

**5) 설계 근거**: 에스카 데모의 "대시처럼 짧은 순간이동". 빗자루 비행(M-14)과 역할이 겹치는지 [미결정].

## M-04. 검술 — 검 모드

> 빗자루 검은 **모드 두 개**를 S로 오간다: 마법 모드(빗자루) ↔ 검 모드(검). 바꾸는 순간 전환 공격이 나간다(M-06 아래 표). [후보: 에스카 데모 방식]

| 휘두름 | 준비 (s) | 휘두름 (s) | 거둠 (s) | 피해 | 앞으로 미끄러짐 (px/s) | 히트스톱 (s) | 비고 |
|---|---|---|---|---|---|---|---|
| 땅 1타 "\" 내려베기 | 0.04 | 0.05 | 0.16 | 55 | 170 | 0.05 | |
| 땅 2타 "/" 올려베기 | 0.035 | 0.05 | 0.16 | 55 | 150 | 0.05 | |
| 땅 3타 큰 내려베기 | 0.09 | 0.06 | 0.30 | 130 | 260 | 0.09 | 잔영 참격, 틈 자국을 남김 |
| 공중 1·2타 | 0.035 | 0.05 | 0.14 / 0.18 | 55 | 60 | 0.05 | 공중 2번까지 |
| A 공간참 (스킬) | 0.14 | 0.045 | 0.32 | 110 | 120 | 0.08 | 가른 선이 한 박자 뒤 터짐(160), 틈 자국, 재사용 2.5 s |

| 공통 | 값 |
|---|---|
| 공격 입력 기억 | 0.14 s |
| 거둠 중 다음 휘두름·점프·순간이동·모드 바꾸기로 끊기 | 휘두름이 끝나고 0.04 s 뒤부터 |
| 연격 이어지는 시간 | 거둠 끝난 뒤 0.4 s |
| 히트스톱 방식 | 게임 속도를 0.03배로 낮췄다가 실제 시간 기준으로 복귀 |
