# 5. 게임 메커닉

> 상태: [작성 중] · 목표 분량: 1,500~3,000자 · 연관 섹션: 4, 6, 9
> 📝 작성 기준: 독립 시스템마다 **5요소**(입력 / 시스템 / 피드백 / 파라미터 / 설계 근거)를 빠짐없이 채운다.

## 5.0 전투 개요와 무기 [확정]

- **전투 방식**: 실시간 액션.
- **무기**: 칼과 빗자루가 결합된 무기. 이 무기로 **검술과 마법을 모두** 사용한다.
- **무기 개념 (가안)**: 검과 검집이 한 세트이며 검은 뽑아 쓴다. 검집 아래쪽이 나뭇가지 빗자루 형태다. 참고 이미지: [`assets/concept-witch-weapon-draft.png`](assets/concept-witch-weapon-draft.png) — 생성형 이미지로 느낌만 나타낸 가안이며 디자인은 확정 아님.
- **검술과 마법의 역할 분담** [후보]

| 구분 | 성격 | 비고 |
|---|---|---|
| 검술 | 근접, 빠른 공격 | |
| 마법 | 캐스팅 시간이 걸리지만 큰 공격 | [플레이테스트 필요: 캐스팅 중 피격 처리 — 아래 후보를 프로토타입에서 비교 후 결정] |

- **캐스팅 중 피격 처리 후보** [플레이테스트 필요]

| 후보 | 방식 | 참고 사례 | 성격 |
|---|---|---|---|
| A. 피격 시 끊김 + 자원 손실 | 캐스팅 중 제자리, 맞으면 취소되고 소모 자원은 날아감 | Hollow Knight의 회복(Focus): 제자리 고정, 맞으면 끊기고 SOUL 손실 | 위험이 가장 큼. 큰 한 방의 무게감이 큼 |
| B. 경직 수치 판정 | 받은 공격이 일정 경직 값을 넘을 때만 끊김 | Elden Ring: 경직을 일으킬 만큼의 피해면 캐스팅이 끊김 (커뮤니티 설명) | 약한 공격은 버티고 강한 공격은 끊김 |
| C. 이동 캐스팅 | 일부 마법은 이동하며 캐스팅 | Elden Ring 일부 마법(Stars of Ruin 등)은 이동 중 시전 가능 | 기동성 유지. 마법 간 차별화 수단 |
| D. 캐스팅 모션 자체에 보호·공격 | 시전 동작이 주변에 피해를 줌 | Blasphemous: 기도 시전 동작이 주변에 검 기본 피해의 3배 피해 (팬 위키) | 근접 상황에서도 시전 가능 |

- 프로토타입에서는 위 요소를 **파라미터로 분리**해 바꿔가며 비교한다: 끊김 여부, 경직 기준값, 캐스팅 중 이동 속도 배율, 취소 시 자원 환급 비율. [제안]

- 검집(빗자루)의 전투 역할 [미결정]
- **빗자루 비행** [후보: 넣고 싶음]
  - 만능이 아니도록 **제약을 분명히 둔다**. [확정]
  - 구체 제약 (활공만 / 시간·자원 제한 / 특정 구간 전용 / 전투 중 사용 여부 등) [미결정]

## M-10. 사망과 부활 규칙 (요약 — 5요소 양식은 확정 후 작성)

| 항목 | 내용 | 상태 |
|---|---|---|
| 사망 패널티 | **재화 손실** | [확정] |
| 회수 | 잃은 재화는 **회수할 수 있다** | [확정] |
| 사망·부활 설정 | 마녀는 세계(책)를 **읽으며** 그 안에 들어간다. 죽음 = **책이 덮이는 것**. 마녀는 **서고에서 다시 깨어난다** (8.1 참조) | [확정] |
| 잃은 재화의 형태 | 책이 덮일 때 **찢긴 페이지**로 세계에 남는다 | [확정] |
| 회수 ① 현장 | 찢긴 페이지를 다시 주워 회수. 회수 기회는 **여러 번** (다시 죽어도 이전 페이지가 바로 사라지지 않음) | [확정] |
| 여러 번 죽었을 때 페이지 처리 | 죽은 자리마다 따로 남는지 / 한곳에 합쳐지는지, 남아 있는 기간·최대 개수 | [미결정] |
| 손실 방지 아이템 | 특정 아이템을 **소모**하거나 **장착**하면 사망 시 재화를 잃지 않는다 | [확정] / 아이템 종류·획득처 [미결정] |
| 손실 방지 아이템 — 소모형 | **사망 시 사용 여부를 선택**한다. 사용하면 그 사망에서 재화를 잃지 않고 아이템은 사라진다 | [확정] |
| 손실 방지 아이템 — 장착형 | 보유만으로는 효과 없고 **장착해야** 효과가 있다. 장착 칸을 차지하는 것 자체가 대가(다른 장비를 포기)다. 사망해도 깨지지 않음 | [확정] |
| 회수 ② 서고 | 회수하지 못한 재화의 일부를 **서고의 존재**에게 대가를 내고 되찾는다 | [확정] / 비율·대가 [미결정] |
| 강한 지역·보스에서 사망 시 | 찢긴 페이지를 그 지역 입구 쪽에 남김 | [후보] |
| 체크포인트 | **책갈피**. 책을 다시 펼치면 마지막 책갈피부터 시작한다 | [확정] |
| 서고 → 지역 복귀 | 서고에서 책을 펼쳐 마지막 책갈피로 바로 복귀 (7.1.1 "입구 근처 체크포인트" 기준 충족) | [확정] |
