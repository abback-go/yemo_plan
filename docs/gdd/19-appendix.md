## 19.1 용어집

| 용어 | 정의 |
|---|---|
| 종언의 마녀 | 주인공. 수명이 다한 세계에 종언을 내리고 그 세계를 한 권의 책으로 저장하는 존재 |
| 마녀의 서고 | 종언의 마녀가 끝낸 세계들의 책이 모인 곳 |
| 타락한 존재 | 끝나가는 세계에서 타락한 존재. 마녀가 쓰러뜨려야 할 대상 |
| 장(章) | 옴니버스의 한 단위. 하나의 세계 안에서 한 지역·인물이 맞는 종말의 이야기 |
| 책이 덮임 | 마녀의 사망. 마녀는 서고에서 다시 깨어난다 |
| 책갈피 | 체크포인트. 다시 책을 펼치면 마지막 책갈피부터 시작 |
| 찢긴 페이지 | 사망 시 세계에 남는 잃은 재화. 다시 주워 회수 |
| 서고의 존재 (가칭) | 덮인 책에서 마녀를 수습하고, 대가를 받고 잃은 페이지 일부를 되찾아 주는 존재 |
