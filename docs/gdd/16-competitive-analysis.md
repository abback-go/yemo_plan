# 16. 경쟁 분석

> 상태: [작성 중] · 목표 분량: 600~1,000자 · 연관 섹션: 2, 3, 13
> 📝 작성 기준: 직접 경쟁작 3~5개. 지표는 공개 확인 가능한 것만, 출처와 데이터 기준 연도를 함께 적는다.

## 16.0 레퍼런스 원칙 [확정]

- 레퍼런스 게임에서 **좋게 느낀 '느낌'을 참고**한다. 시스템·설정·구조를 그대로 가져오지 않는다.
- 겉모습이 겹치는 요소는 16.4 "차별화 필요 항목"에 기록하고 다르게 설계한다.
