## 탑뷰 이동 시험판 (`?scene=topdown`)
- 맵: 코디네이터 지시로 넓힌 판 `art/raw/map_f1_fork_wide_raw.png`(2112×1662)를 기본으로 썼다. GPT 가짜 픽셀은 격자가 고르지 않아 `pixel_sheet.py` 의 격자 찾기가 9.6px(배수)을 골라 쓸 수 없었다 → `--block` 으로 블록 크기를 직접 지정하는 옵션을 더했다(`--no-key --whole` 도 추가).
- 맵 축소 배율: 블록 3px(지시의 "약 3px")로 줄이면 문 높이 약 97px → 사람(문 높이의 절반) ≈ 48px 로 노엘(키 약 58px)보다 20% 작아 어긋났다. **블록 2.5px**로 줄여 문 높이의 절반 ≈ 56px 로 맞췄다(맵 844×664, 64색).
- 화면 배율: 맵·노엘 모두 **정수 3배**(픽셀 한 칸 = 무대 3px, 1280×720 창에서 2px). 맵(2532×1992)이 무대보다 커서 카메라가 노엘을 부드럽게 따라가며, 카메라는 맵 픽셀 단위로 맞춰 움직인다. 그림은 무손실·밉맵 없음으로 가져와 Nearest 로 그린다.
- 가림: 앞벽(입구 아치 양옆, 아치 안쪽 통로는 비움)은 맵 그림을 다각형으로 잘라(`Polygon2D` + 같은 텍스처) 노엘 위에 덮는다. 카드 기둥·붉은 실 돌무더기·무너진 기둥 더미·가운데 돌 조각도 같은 방식으로 잘라 발끝 y 기준 정렬(`y_sort`). 별도 그림 파일을 만들지 않아 다각형만 고치면 된다.
- 충돌: 걸을 수 있는 바닥 다각형 − 막힌 곳 다각형, 발 자리(가로 7·세로 3px)가 다 들어가야 설 수 있다. 탭 이동은 `AStarGrid2D`(6px 격자) 경로를 직선으로 편다. 아래 입구 아치는 바닥 다각형 밖이라 나갈 수 없다(시작 연출만 다각형을 무시하고 걸어 들어옴).
- 조사 대화: 기존 `G.dialog` 를 화면 아래(`dock = "bottom"`)에 두고 얼굴 칸 대신 옆에 스탠딩(`stand_witch` / 첫 대사는 `stand_hero`). 노엘이 화면 왼쪽에 있으면 스탠딩을 오른쪽·대화창을 왼쪽으로 바꿔 노엘·물건을 가리지 않게 했다. 물건을 탭하면 멀어도 걸어가서 조사한다.
- 출구 안내: 기존 `FX.toast` 는 장면 레이어 아래에 그려져 보이지 않으므로, 출구 설명 상자(화면 아래 가운데)에 "시험판은 여기까지" 를 띄운 뒤 암전 → 입구 자리로 되돌린다. 출구 설명 문구는 `script_data.gd` explore.fork 그대로.
- 물건마다 옅은 반짝임, 조사 거리 안이면 ! 말풍선(맵 픽셀 단위로 그림).
- 동료 따라 걷기: 노엘 발끝을 1px마다 기록한 경로(`TopdownNav.Trail`)에서 경로 길이로 `followGap`(18맵px)×순번만큼 뒤의 점에 동료를 둔다. 경로 길이로 재므로 노엘이 멈추면 간격을 둔 채 멈추고 겹쳐 쌓이지 않는다. 동료는 충돌 검사 없음. 시작·출구에서 되돌아올 때는 노엘 뒤(아래)로 일직선 줄을 다시 깐다.
- 입구 자리(`entry`)를 y 556 → 510 으로 올렸다: 556 이면 뒤에 선 동료 둘이 아치 통로 안(앞벽 아치 윗부분에 몸 가운데가 가려짐)에 서게 되어서. 18px 간격이면 셋이 y 528·546·564 로 방 안에 선다.
- 방향 행: 가장 가까운 4방향, 단 지금 보는 쪽이 이동 방향의 한쪽이면 다른 축이 1.25배 넘게 클 때까지 유지(조이스틱 45도 근처 깜빡임 방지). 키보드 대각선은 예전과 같다.
- 터치 이동 패드: 왼쪽 절반을 누른 자리에 조이스틱(실제 화면 지름 130 CSS px = 130/`FX.css_scale` 무대 px), 가운데 16% 는 멈춤, 그 밖은 0.3~1배 속도, 테두리 밖으로 끌면 받침이 따라온다. 끌지 않고 떼면 탭(물건·출구·설명 상자). 터치 빈 바닥 탭으로는 걷지 않는다(마우스 클릭 이동은 그대로). 터치는 `_input` 의 `InputEventScreenTouch/Drag` 로 받고, 흉내 낸 마우스(`DEVICE_ID_EMULATION`)는 버린다.
- 조사 버튼: 터치 화면·자유 이동 중에만 오른쪽 아래(78 CSS px), 가까운 물건(조사)·출구(들어가기)가 있을 때만 금테로 켜지고 누르면 E 키와 같다. 오른쪽 아래 도움말은 터치에서 화면 위 터치용 문구로 옮겼다.
- 동료 간격 18px 은 지시 범위(16~20) 가운데 값. 시트 몸 폭(약 35~48px)보다 좁아 옆으로 걸을 때 절반쯤 겹쳐 보인다 — 넓히려면 `followGap` 만 바꾸면 된다(입구 자리 아래 공간 때문에 20 넘게 하면 `entry` 도 올려야 함).

## 버티컬 슬라이스 1단계 — 튜토리얼 "장례 탑 1층" (2026-11-21, 판단 기록)
우선순위: `docs/vertical-slice.md` 1~5장 머리 결정 → `docs/tutorial-script-vs.md` v3 → `docs/fate-design.md`(2026-11-21 변경) → 이 파일의 앞 기록.
- **흐름**: 곁방(VN) → 장례 회랑(VN → 같은 배경 전투 ① → 카드 보상) → 안치 홀(VN) → 지도(첫 안내: 방·랜턴) → 방을 골라 들어감 → 가장 깊은 곳(VN → 광신도 → 거대한 발) → 빈 캠프 → 「1층 — 끝」 → 2·3층. `core/ctl.gd` 를 새로 썼다(장면마다 함수, 방은 `_room`).
- **지도 [제안 그대로 + 판단]**: 문서는 골라 들어가는 방 8개가 "안치 홀·계단 앞 홀에 붙음"까지만 정해서, 안치 홀에 광신도 기도실(→ 그 안쪽 무덤지기)·순장된 자의 방·핏자국 통로 끝·묘지기의 좌판, 계단 앞 홀에 촛불 예배당·무너진 훈련장·발자국 방을 붙였다(`game_data.gd floorMaps`). 지나간 방과 이어진 방만 들어갈 수 있고, 지나간 방은 공짜로 지나간다(눌러도 장면 없이 자리만 옮김). 방은 한 번 누르면 오른쪽 칸에 설명, 한 번 더 누르거나 「들어간다」로 들어간다(휴대폰 터치도 같게). 지도 그림은 코드로 그린 임시 모양(양피지·아이콘·랜턴 그림이 오면 바꾼다).
- **촛불 [판단]**: 랜턴을 받기 전에 지나온 방(곁방·장례 회랑·안치 홀)은 타지 않는다 — 안치 홀 안내에서 "네 개"라고 하므로. 그 뒤로는 계단 앞 홀·가장 깊은 곳을 포함해 **처음 들어가는 모든 방**에서 탄다(안내 문구 "처음 들어가는 방마다"를 그대로). 방마다 `candle: false` 로 바꿀 수 있다. → 열린 질문 1
- **어둠 [판단]**: 촛불 0개에서 처음 들어가는 방마다 +1. 단계마다 예고 1개를 무작위(전투 난수)로 '?'로 가린다. 가린 예고도 규칙은 그대로이고 옮기기·지우기를 할 수 있다(무엇인지 모를 뿐). '?' 예고에는 대상 선을 보이지 않는다. 층 끝 전투는 가장 깊은 곳의 광신도 전투와 거대한 발 전투 **둘 다**(`encounters.deep/giant: floorEnd`), 강적은 무덤지기. 전조(발자국 방)는 층 끝 전투만 막고 강적 전투는 막지 않는다. 운명 공격(`fate` 가 걸린 예고)은 늘 보인다.
- **보상 [임시]**: 일반 전투 3장 중 1장(넘기기 있음, 후보는 기본 카드 10종). 강적의 희귀 보상은 희귀 카드가 아직 없어 **강화표 카드 4종을 Lv2(강화된 채)로** 3장 중 1장 → 열린 질문 3. 거래는 HP 가 대가 이하이면 그 선택지를 누를 수 없고(노엘이 죽지 않게), 카드는 고른 뒤에만 HP 를 낸다(넘기면 안 냄). 촛불은 최대 8개를 넘게 살 수 없다. 사건 [꺼낸다]의 HP −2 는 1 아래로 줄지 않는다.
- **새 카드 [임시]**: 「이름 없는 마녀의 카드」(비용 0, 예고 하나를 지움 — 「꿰뚫린 방패」가 막을 수 있는 예고와 같은 범위: 옮길 수 있는 공격·운명이 아닌 광역. 운명 공격 불가, 노엘 HP 3, exhaust 로 그 전투에서 한 번). 「작은 손의 부적」은 동료 위로 끌어 놓는 새 대상 종류 `ally`(서 있는 동료만, 노엘 제외).
- **죽음 카드 컨셉 변경**: 죽음 카드는 모두 `unplayable`(손패 한 칸만 차지, 비용 표시 없음). 받아들이면(`offer_fate`) 카드의 effects(사망·유품·상속)가 실행된다 — 내부 이름 offer/offered 는 시험판 v2 그대로 두고 화면 문구만 "받아들인다"로(자동 진행 인자 `--fates=accept` 도 됨). 세라피나는 운명 `hero_stomp`(`noDefy`·`endsBattle`)로 처음부터 걸려 있고 카드는 뒤집힌 채(`faceDown`) 손패에 있다. 뒤집힌 카드는 붉은 실로 누구와 이어졌는지 보여 주지 않는다(누구의 죽음인지 숨김).
- **거대한 발 3턴 [판단]**: 「짓밟기」는 카운트다운 3단계에 `fate: hero_stomp` 를 단 것으로, 예고는 "짓밟기 · 모두에게 큰 피해"(누가 죽는지 안 보임). 실행되면 발이 내려오다 멈추고(화면 정지) → 카드가 저절로 뒤집힘 → "알고 있었는데." → 받아들임(선택 화면 없음) → 데스신(기존 컷, 대본 v3 자막을 C1·C2·C4 에) → 노엘의 손에 남은 카드를 크게(재가 된 뒤 카드 획득 화면으로 — 대본은 "손에 남은 카드"지만 기존 재 연출을 그대로 두었다) → 안내 → 엘리안·브룬힐드 대사 → 발이 들리며 전투 끝. **세라피나만 죽고 다른 동료는 피해가 없다**(대본에 다른 피해가 없음) → 열린 질문 2. 「짓밟힘」은 이제 튜토리얼에서 낼 일이 없어 "얻은 턴 비용 0"을 없앴다(비용 2).
