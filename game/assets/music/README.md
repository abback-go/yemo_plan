# 배경음악 / 징글 (game/assets/music)

이 폴더의 모든 오디오는 **`tools/gen_music.py` 가 코드로 합성**한 것입니다.
외부 샘플, 다운로드한 에셋, AI 오디오 서비스는 전혀 사용하지 않았습니다.
(가산 합성·대역제한 톱니파, 1극 필터, Karplus-Strong 현 모델, 잡음 타악기, ADSR,
피드백 지연선 잔향을 파이썬 표준 라이브러리만으로 직접 구현.
2~5장 곡에서 더한 악기: 필터 엔벨로프 금관, 모음 포먼트 합창 '아·오·우', 파이프 오르간, 플루트,
스피카토 현, 실제 종 부분음 비율의 교회 종, 글로켄슈필, 팀파니, 비조화 FM 유리음, 심벌 스웰 등)

- 포맷: Ogg Vorbis, 32000 Hz, 스테레오
- 음량: 각 파일 최대 피크 약 -1 dBFS (클리핑 없음)
- 루프 곡은 길이가 **정확히 정수 마디**이며, 끝부분의 잔향을 곡 앞부분에 접어 넣어
  이음매 없이 반복되도록 만들었습니다.

## Godot 에서 쓰는 법

- Godot 의 Ogg Vorbis 임포트 설정에서 `loop` 의 기본값은 **꺼짐(false)** 입니다.
  루프 곡 27개(징글이 아닌 모든 곡)는 `.import` 파일에서 **`loop=true`**, `loop_offset=0` 으로 맞춰 두었습니다.
  (`Music.play()` 도 불러올 때 코드에서 `AudioStreamOggVorbis.loop = true` 로 켭니다)

## 다시 만들기

저장소 루트에서 (Python 3 표준 라이브러리 + ffmpeg/libvorbis 필요, numpy 불필요):

```
python3 tools/gen_music.py                 # 33곡 전부 (4프로세스: 1장 11곡 약 35초 + 2~5장 22곡 약 155초)
python3 tools/gen_music.py --only boss     # 특정 곡만
python3 tools/gen_music.py --only kingdom lyra --jobs 2
```

고정 시드를 쓰므로 몇 번을 실행해도 같은 파일이 나옵니다.
루프 곡은 초당 10.5 KB, 곡 하나 최대 700 KB 안에서 가장 높은 Vorbis 품질(q4 → q0)을 고릅니다.
곡의 악보(선율·화성·리듬)와 악기 음색은 모두 `tools/gen_music.py` 안에 있습니다.
