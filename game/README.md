## 태블릿·휴대폰에서 (터치, 인터넷 없이)

안드로이드 태블릿·휴대폰의 **Chrome**으로 홈 화면 웹앱을 설치하면 인터넷 없이도 실행된다.

1. 인터넷에 연결된 상태로 Chrome에서 위 주소를 열고, 타이틀 화면이 뜰 때까지 기다린다 (처음엔 약 45MB를 받는다).
2. Chrome 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치** → 설치.
3. 이후 홈 화면의 아이콘으로 열면 인터넷이 없어도 실행된다 (가로 화면·전체 화면). 기록도 기기에 남는다.
4. **새 버전 받기**: 인터넷이 될 때 앱을 한 번 열면 새 버전을 뒤에서 받아 두고, 타이틀 메뉴 맨 위에 **"새 버전으로 업데이트"**가 생긴다. 누르면 바로 바뀐다(기록은 그대로). 타이틀 오른쪽 아래 **"빌드 ○○○○○○○"**가 지금 실행 중인 커밋이다 (`version.txt`와 같으면 최신).
- 브라우저는 저장 공간이 모자라거나 오래 안 쓰면 저장해 둔 게임을 지울 수 있다. 그때 인터넷 없이 열면 "인터넷 연결이 필요해요" 안내가 뜨고, 인터넷에 연결해 한 번 열면 다시 저장된다.

**터치 조작** — 화면을 만지면 나타나고, 키보드를 누르면 숨는다.
- **왼쪽 절반 아무 곳**: 손가락을 댄 자리에 조이스틱이 생긴다. ◀▶ 이동, ▲ 상호작용(말 걸기·문·기록), ▼ 빠른 낙하 / ▼ + 점프 = 발판 내려가기. ▲▼는 거의 위·아래로 밀어야 들어간다(달리다 실수로 내려가지 않게).
- **오른쪽**: 큰 버튼 **공격**(누르고 있으면 계속)·**점프**·**대시**, 작은 버튼 **불기둥**·**폭풍**·**여우창**·**물약**(배운 뒤에만 보임). 버튼 귀퉁이 글자(X·Z·C·A·S·D·Q)는 안내 문구의 키와 같다. 여우 모드에서는 여우불·여우비·구미호로 이름이 바뀐다.
- **오른쪽 위**: 지도 · 일시정지(II).
- 대화·알림·지도는 화면을 탭해 넘기고, 메뉴는 항목을 누른다. 멈춤 안내가 기다리는 버튼은 금색 테두리로 깜빡인다.
- 버튼이 멀거나 작으면: 일시정지 → 설정 → **터치 버튼 크기**(작게·보통·크게).

## Godot 에디터로 열기 (Git 없이)

1. 전달받은 ZIP(또는 GitHub **Code → Download ZIP**)을 압축 풀기
2. Godot 4.7.2 → 프로젝트 관리자 **Import** → `project.godot` 선택 → **Import & Edit**
3. F5 = 타이틀부터 실행 (타이틀 메뉴의 "전투 연습장" = v0.3 연습 방)

## 조작

| 행동 | 키보드 | 게임패드 |
|---|---|---|
| 이동 | ← → | 왼쪽 스틱 / 방향 패드 |
| 점프 (길게 = 높이, 꼭대기에서 누르고 있으면 잠깐 체공) | Z | A |
| 빠른 낙하 (공중) / 발판 내려가기 (통과 발판 위에서 ↓ + Z) | ↓ | 아래 |
| 화염탄 (약 1.2초마다 묵직한 한 발, 누르고 있으면 계속) | X | X |
| 대시 (짧은 무적. 대시 중 Z = 대시 점프) | C | B 또는 RT |
| 불기둥 | A | LB |
| 화염 폭풍 | S | RB |
| **상호작용** (말 걸기·문·기록·읽기) | **↑** | 위 |
| **2단 점프** (부양을 배운 뒤) | **공중에서 Z** | **공중에서 A** |
| **여우창문** (배운 뒤) | **D** | **Y** |
| **회복 물약** | **Q** | **LT** |
| **지도** | **Tab 또는 M** | Back |
| 대화 넘기기 | Z · X · Enter · Space | A · X |
| 일시정지 (계속·지도·목표·설정·타이틀로) | Esc 또는 P | Start |
| 디버그 표시 | F1 | — |

- 쓰러지면 마지막 기록 지점(촛대·석등·침대·동상)에서 체력·물약을 채워 다시 시작한다. 잃는 것은 없다.
- 저장은 기록 지점과 큰 장면 직후에 자동으로 된다. 타이틀의 "이어하기"로 계속한다.

## 1장 데모 안내 (v0.4)

- **여우 모드(빙의)**: 너울과 함께한 뒤에는 폭주 게이지가 가득 차면 폭발 대신 12초 동안 푸른 여우불의 고급 기술로 바뀐다 (X 여우불 · A 여우비 · S 구미호 폭풍). 쓰고 나면 너울의 기운이 다시 찰 때까지(약 50초) 예전처럼 폭주 폭발이 나니 주의.
- **마법 습득**: 실습장(화염 폭풍), 부양 실습실(2단 점프), 금서 구역(여우창문).
- **여우창문(D)**: 창 안의 환영 벽이 사라지고 숨은 표식이 드러난다. 길이 막혔다 싶으면 비춰 볼 것.
- 숨겨진 것: 수호의 깃털 3개(최대 체력 +1씩), 낡은 쪽지 2장, 피피의 부탁(물약 +1).

## 전투 요령 (v0.3)

- **위치 타임**: 돌진해 오는 돌진형이나 저격탄이 닿기 직전에 대시로 스치면 적만 1.1초 느려진다.
- **스타일 랭크** (우상단 D → C → B → A → S → SS): 화염탄·불기둥·화염 폭풍을 섞어 끊김 없이 맞히면 오른다. 같은 공격만 반복하면 덜 오르고, 맞으면 크게 깎인다.
- **띄워 맞히기**: 불기둥으로 띄운 적을 공중에서 화염탄으로 계속 맞히면 떨어지지 않는다. 공중에서 쏘면 세라도 잠깐 떠 있다.
- **과열**: 폭주 게이지 70% 이상이면 화염탄이 강해진다(가득 차면 폭발하니 주의).
- 자세한 수치: [`docs/prototype.md`](../docs/prototype.md) 14절 · 개발 기록: [`docs/devlog/03-prototype-v03.md`](../docs/devlog/03-prototype-v03.md)
